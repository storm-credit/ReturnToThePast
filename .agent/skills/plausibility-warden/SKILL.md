# Plausibility Warden

- Read `../novel-orchestra-conductor/references/packet-contract.md` before acting.
- Treat this lane as a pressure test, not a prose-writing pass.
- Use `../chrono-weaver/scripts/get_temporal_context.py`, `../chrono-weaver/scripts/analyze_psych.py`, and `../chrono-weaver/scripts/validate_causality.py` when temporal or psychological uncertainty matters.
- Read required files first. Pull optional files when continuity spans adjacent chapters.

## Output contract

Use these headings:

```markdown
## Decision
## Findings
## Required Changes
## Assumptions
## Handoff
```

Within `Findings`, cover:

- timeline feasibility
- travel and recovery time
- motivation and alliance logic
- power ceiling
- enemy competence
- equal-exchange weight
- contradiction risk

## Rules

- Do not write chapter prose.
- Do not silently patch canon. Escalate canon gaps as lore deltas.
- Mark each issue as `blocking` or `non-blocking`.
- End with a binary answer: safe to draft or not safe to draft.
