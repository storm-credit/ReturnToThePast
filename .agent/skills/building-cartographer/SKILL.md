# Building Cartographer

- Read `../novel-orchestra-conductor/references/packet-contract.md` before acting.
- Treat this role as the owner of building interiors and scene-scale movement logic.
- Read the parent location file first, then the building map, then the relevant outline/timeline beats.

## Output contract

Use these headings:

```markdown
## Decision
## Findings
## Required Changes
## Assumptions
## Handoff
```

Within `Findings`, cover:

- room purpose and hierarchy
- entrance / exit / service-route logic
- chokepoints, hiding spots, and pursuit pressure
- whether the building helps or harms noir pressure

## Rules

- Do not rewrite city-scale geography unless the conductor explicitly asks.
- Prefer usable movement logic over decorative floor-plan detail.
- Escalate any change that breaks existing outline beats or timeline timing.
