# Context Pack Compiler

## 목적

원고 에이전트가 저장소 전체를 임의로 훑거나 [`CLAUDE.md`](../../../CLAUDE.md) 요약만 믿지 않도록 한다. 작업 범위에 필요한 정본을 선별해 CP로 묶고 출처·commit SHA·현재 상태를 기록한다.

CP는 새로운 정본이 아니다. 사실을 추가·수정하지 않으며 원본 문서가 바뀌면 재생성한다.

## Legacy 격리

`Drafts/`, 기존 `outline/`, 기존 `lore_bible/`은 기본 CP 출처에서 제외한다.

- 저장소 전체 검색 결과에 Legacy 파일이 나타나도 CP에 자동 편입하지 않는다.
- 현재 원고 사실·사건·관계·문체는 `manuscript/`와 상위 정본에서만 가져온다.
- 작가가 명시적으로 Legacy salvage를 요청한 경우에만 Legacy를 읽는다.
- Legacy에서 현재 작품으로 채택할 항목은 `docs/00_project/legacy-salvage-ledger-v1.md`의 개별 심사를 거친 뒤에만 CP에 포함할 수 있다.
- 옛 원고가 현재 설계의 공백을 메우는 자동 대체재가 되어서는 안 된다.

## CP 단계

### Series CP
필수:
- Canon Constitution
- 최신 Canon Amendment
- Decision Log 관련 항목
- 시간여행·기억·인과 규칙
- 결말 조건
- 영구손실·금지선

### Grand Act CP
필수:
- Grand Act 목표·선택·비용·상태변화
- 세 권의 시작/종료 상태
- 주제 질문
- 인간 대립축
- 장기 미스터리·손실

### Volume CP
필수:
- 권 목표·맥거핀·반전·선택·권말 상태
- 2 Arc·4 Subact
- 주요 인물·관계 시작값
- 주요 지역·기관·세력
- 자산·미스터리·손실 상태
- 권별 장면밀도·훅 분포

### Subact CP
필수:
- 6~7화 국소 목표
- 해결 조건
- 현재 자원·권한·제약
- 종료 상태와 다음 원인
- 반복 방지 차별점

### Episode CP
필수:
- Episode ID와 이전/다음 인과
- 시간·장소·이동경로
- POV와 보조 POV 정당화
- 등장인물별 현재 상태·욕망·정보상한
- 관계 상태·호칭
- 기관·세력의 현재 절차와 권한
- 마법·질병·시간 규칙
- 종교·문화·언어·생활 디테일
- 아이템·유산·신수의 소유·접근·상태
- 미스터리 공개·비공개 범위
- 영구손실 금지선
- 작법 Manifest
- 참조한 원본 파일 목록

## 컴파일 절차

0. Legacy 경로를 기본 검색·출처 집합에서 제외한다.
1. 최신 main commit SHA를 기록한다.
2. 작업 ID를 확정한다.
3. Authority Stack에서 관련 작가 결정·헌법·개정안을 읽는다.
4. 직전 상태 장부를 읽는다.
5. 분야별 의존성 질문표를 실행한다.
6. 필요한 Bible만 가져온다.
7. 설계도에서 Promise/Goal/Choice/Cost/Next Cause를 가져온다.
8. 작법 선택 결과를 연결한다.
9. 충돌·누락·미확정을 분리한다.
10. S0/S1이 있으면 CP 상태를 BLOCKED로 한다.
11. 출처 경로와 commit SHA를 기록한다.
12. A02와 A13이 정본·연속성을 확인한다.

## 분야별 의존성 질문

### Character
- 등장 인물 ID가 존재하는가?
- 현재 시대·나이·신체·부상·기억은?
- Want/Need/Lie/Fear/Boundary는?
- 이번 장면에서 바뀔 관계축은?
- 주인공 부재 중 무엇을 했는가?

### Place
- 실제 이동시간은?
- 출입권한·검문·계층 경계는?
- 생산·보급·피난 기능은?
- 시대변형 전후 차이는?

### Institution/Faction
- 누가 승인·거부하는가?
- 절차와 소요시간은?
- 실제 시민 효용은?
- 내부파벌과 지지층은?

### Magic/Temporal
- 범위·준비·지속·비용·대응책은?
- 실패하면 무엇이 남는가?
- 시간선 변경 단계와 기억 적용은?

### Religion/Culture
- 어떤 교리·분파·의례가 장면에 작동하는가?
- 신앙과 기술적 기능이 어떻게 겹치는가?
- 음식·복식·언어·장례·달력 중 무엇이 행동에 영향을 주는가?

### Item/Relic/Beast
- 현재 소유자와 보관 장소는?
- 누가 사용을 거부할 수 있는가?
- 운반·파손·양도 상태는?
- 실제 기능과 등장인물의 오해는?

### Mystery/Loss
- 독자가 이미 아는 단서는?
- POV 인물이 아는 범위는?
- 이번 화가 심을 것·재점화할 것·회수할 것은?
- 영구손실을 우회하는가?

## CP 출력 원칙

- 사실마다 가능한 한 원본 경로를 붙인다.
- 요약은 원본보다 권한이 낮다.
- `[ASSUMPTION]`은 정본 사실과 분리한다.
- 원고에서 새 사실이 필요하면 CP에 임의 추가하지 않고 World Detail 또는 Canon Change 라우트로 되돌린다.
- 완료 CP는 해당 commit에서만 유효하며 main 변경 후 stale 검사를 한다.
