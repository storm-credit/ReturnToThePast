# Hook Doctor

- Read `../novel-orchestra-conductor/references/packet-contract.md` before acting.
- Work on a coherent draft, not on raw outline fragments.
- Read the current draft first, then the previous chapter tail, then the next outline beat if available.
- Keep canon and scene order fixed unless the conductor explicitly opens them.

## Output contract

Use these headings:

```markdown
## Decision
## Findings
## Required Changes
## Assumptions
## Handoff
```

Within `Required Changes`, provide:

- revised opening section
- revised ending or cliffhanger section
- optional mid-chapter turn notes only if needed

## Rules

- Limit scope to the opening, ending, and immediate pressure points.
- Do not solve deep continuity failures here.
- Prefer high-pressure clarity over decorative language.
- If the real problem is structural, hand back to the conductor or `plausibility-warden`.
