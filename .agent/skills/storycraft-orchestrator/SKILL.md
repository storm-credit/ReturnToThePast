# Storycraft Orchestrator

## 역할

이 스킬은 모든 회차에 같은 공식을 적용하지 않는다. 먼저 서사 문제와 독자 효과를 진단한 뒤 중심 작법 1개와 보조 작법 최대 2개를 선택한다.

스킬은 정본을 만들거나 변경하지 않는다. A20 Storycraft Director가 사용하며 A00이 전체 흐름을 관리한다.

## 공통 규칙

- 중심 작법 1개, 보조 작법 최대 2개
- 같은 조합 3화 연속 금지
- 작법 이름만 보고서에 적고 원고에서 구현하지 않는 행위 금지
- 모든 해결은 상태변화와 다음 원인을 생성
- 주인공 외 인물은 독립 욕망과 선택을 가짐
- 설정은 장식이 아니라 권한·제약·비용·행동 가능성으로 사용
- 맥거핀·유산·신수·마법은 단독 해결키 금지
- 결말 해결요소는 최소 세 번 다른 기능으로 사전 노출

## 1. 진단 범주

회차의 중심 문제를 하나 선택한다.

- 생존 압박
- 조사·추리
- 시간선 이상
- 정치·법·행정
- 협상·거부권
- 전투·추격·공성
- 재난·대피·보급
- 관계 변화·상실
- 종교·신화·의례
- 문화충돌·번역
- 유산·신수·소유권
- 미래변형·귀환
- 애도·회복·생활 후과
- 결말 기능 준비

중심 독자 효과도 하나 선택한다.

- 긴장
- 불신
- 공포
- 발견
- 도덕적 곤란
- 전술적 쾌감
- 관계적 아픔
- 세계 확장
- 제도 이해
- 미스터리 추론
- 승리의 대가
- 여운

## 2. 시리즈·결말 작법

### 결말 역산

검사:
- 결말 선택이 초반 질문에 답하는가
- 최종 비용이 중간부터 누적됐는가
- 해결요소가 사전에 실제 기능과 실패를 보였는가
- 새 법칙·새 유물·새 인물이 마지막 해결키가 아닌가

### 약속–진행–회수

각 계층은 독자에게 다른 크기의 약속을 준다.

- Series: 과거를 고치면 누가 현재에서 지워지는가
- Grand Act: 한 시대의 권리와 비용
- Volume: 25화 안에 답할 문제
- Arc: 관점 또는 전략의 전환
- Subact: 6~7화 국소 목표
- Episode: 이번 화에서 달라질 단일 상태

### 시작–결말 대칭

반복이 아니라 가치 반전이어야 한다.

- 기록이 사람을 허가 → 기록되지 않은 사람도 이의 제기
- 타인의 주소를 비용으로 사용 → 자기 주소를 비용으로 사용

### 점층적 복잡화

위험 크기만 확대하지 않는다.

개인 → 공동체 → 미래 시민 → 여러 시대 → 문명 운영체제

각 단계는 이전 승리의 결과여야 한다.

## 3. Act·Arc·Subact 작법

### 국소 완결 + 다음 원인

- 국소 목표 해결 또는 명확한 실패
- 시작과 종료 상태 차이
- 해결 비용이 다음 단계의 진입 원인
- 단순히 더 큰 적이 나타나는 연결 금지

### 시도–실패–학습 변주

실패 원인을 바꾼다.

- 정보 부족
- 가치 우선순위 오류
- 권한 부족
- 비용 오판
- 동맹의 독립 선택
- 공간·보급 제약
- 승리했지만 다른 권리 손상

마지막 성공은 힘 증가보다 판단 기준 변화에서 나온다.

### 중간점 재정의

목표의 규모가 아니라 의미를 바꾼다.

예: 도시 복원 → 어느 주민의 어느 권리를 복원하는가.

### 압박 지점

적대자의 능력을 공격 이외의 방식으로 보여 준다.

- 승인 취소
- 배급 변경
- 기록 공개
- 주민 지지 확보
- 주인공보다 나은 대피·치료 성과

## 4. 장면·회차 작법

### 목표–방해–선택–비용

장면마다 구체적 목표, 능동적 방해, 선택, 가치변화를 둔다. 정보만 전달하고 상태가 안 바뀌는 장면은 합치거나 삭제한다.

### 장면–반응

반응 장면은 다음에 우선 사용한다.

- 영구손실
- 윤리선 침범
- 관계 정의 변화
- 부상·장례·법적 책임
- 미래변형 체감

반응 순서: 감각 충격 → 해석 → 선택지 → 다음 행동.

### 동기–반응 단위

외부 자극을 관찰 가능한 순서로 제시하고 인물 반응은 감정·신체·행동·말의 자연스러운 순서를 따른다.

### 가치 변화

장면 전후 최소 한 축이 바뀐다.

안전/위험, 신뢰/의심, 자유/통제, 기록/소거, 소유/공동관리, 치료/비용전가, 귀환 가능/불가.

### 긴장–이완 파형

강한 장면만 연속 배치하지 않는다. 이완 장면도 관계·정보·비용·다음 선택을 움직여야 한다.

### 정보 간극

- 미스터리: 독자와 인물 모두 모름
- 서스펜스: 독자는 위험을 알고 인물은 모름
- 드라마틱 아이러니: 독자는 선택의 다른 의미를 앎
- 제한 우위: 인물은 일부 알고 독자는 모름

한 형태를 장기간 고정하지 않는다.

## 5. 미스터리·복선·맥거핀

### 공정 단서

최종 답 전에도 범위를 좁힐 수 있게 문서·물질·행동·제도결과·생태/마법반응 중 최소 세 종류를 사용한다.

### 복선 유형

- 직접 사실
- 행동·회피
- 제도 예외와 피해
- 환경 변화
- 시대별 언어 차이
- 있어야 할 것이 없는 부재

### 오답

당시 증거와 이해관계로 믿을 만해야 한다. 정답 공개 후에도 왜 믿었는지 납득되어야 한다.

### 맥거핀

반드시 추적한다.

- 원하는 사람과 이유
- 소유·관리·거부 주체
- 실제 기능과 오해된 기능
- 운반·손상·양도·반환
- 회수 뒤 의미 변화

### 식물–회수–재맥락화

첫 등장 생활기능 → 중간 충돌 → 후반 권리·비용 연결 → 결말 선택 기준 완성.

## 6. 인물·관계

### 욕망–필요–거짓 믿음

Want / Need / Lie / Fear / Boundary를 분리한다.

### 독립 행동

주인공이 없는 동안에도 다음을 기록한다.

- 현재 목표
- 가용 자원
- 보고 대상
- 숨기는 정보
- 주인공에게 반대할 조건
- 다음 등장 전 바뀐 상태

### 관계 상태

신뢰·부채·권한·비밀·공포·애정·정치적 이해·호칭으로 관리한다. 한 장면에서 최대 두 축만 크게 바꾼다.

### 대립자

실제 성과, 지지층, 보호 대상, 타협선, 비용, 주인공이 배워야 할 정당한 지점을 가진다.

## 7. 보조 POV

허용 조건:
- 에이든 부재 장소의 선택이 다음 인과에 필수
- 현지인의 독립 권리를 증명
- 적대 체제의 실제 효용을 보여 줌
- 에이든 행동의 피해를 다른 위치에서 체감
- 동시다발 사건 연결
- 에이든의 오해를 정답 누설 없이 다른 각도로 제시

금지:
- 악역 계획 설명 회의
- 미스터리 정답 선공개
- 분량용 단역 시점
- 고유 욕망 없는 카메라 POV
- 같은 사건의 무의미한 반복

기본 한 화 1 POV, X형 최대 3 POV. 시점 전환 첫 문단에서 시간·장소·목표를 명시한다.

## 8. 장르별 권장 조합

- 조사: 공정 단서 + 오답 + 정보 간극
- 정치/법정: 이해관계 협상 + 권한 절차 + 대립자 성과
- 재난: 제한자원 선택 + 공간 명료성 + 생활 후과
- 전투: 공간 목표 + 전술 변화 + 부상/자원 비용
- 관계: 관계 상태 변화 + 장면–반응 + 부재 복선
- 종교: 네 층 진실 충돌 + 의례 생활기능 + 권력 정당화
- 유산/신수: 소유권·거부권 + 오해된 기능 + 반환/분해
- 시간변경: 구체적 현실 불일치 + 기억 신뢰도 + 현재인의 권리
- 권말: 권 질문의 불완전한 답 + 영구비용 + 다음 권 원인

## 9. Craft Manifest

회차 전 반드시 기록한다.

- Episode / Volume / Arc / Subact
- POV / Offstage Movers
- Primary Craft
- Secondary Crafts
- Reader Effect
- Episode Promise
- Scene Density / Hook Type
- Why This Combination
- Canon Dependencies
- Local Resolution
- Next Cause
- Anti-Repeat Difference

이 필드가 없으면 원고를 시작하지 않는다.
