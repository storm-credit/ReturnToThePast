# 발음·호칭 사전 v1

Status: CANON OPERATIONS

## 원칙

- 원문에 전체 이름이 있으면 전체를 읽고, 개인 이름만 있으면 성을 덧붙이지 않는다.
- 음절 표시는 확인용이며 실제 낭독에서는 자연스럽게 이어 읽는다.
- 직함·계급·개인 이름을 구분한다.
- 현재 에이든과 젊은 에이든은 같은 이름을 가진 별도 인물이다.
- 이름 소거 뒤 대사에서 본명을 임의 복구하지 않는다.

### 기관 호칭 규칙

- 원고 첫 등장에서는 정식명을 쓰고 기능을 같은 단락에서 한 번 제시한다.
- 이후 대사에서는 축약 호칭만 쓴다. 한 대사에 기관명이 3개 이상 이어질 때는 축약형을 쓴다.
- `아스트라`와 `솔라`는 각각 별과 태양을 뜻하는 외래 어근이며, 두 기관은 서로 다른 조직이다. 같은 계열로 묶어 읽지 않는다.
- **`솔라 종탑`의 대사 축약은 `종탑`이다** (DEC-017). 조연 `메이라 솔`과 음이 겹치므로 대사에서 `솔라`를 단독으로 쓰지 않는다. 정식명 표기에서만 `솔라 종탑`을 쓴다.
- `잔문감사실`은 기관이 아니라 칼레온 대기록소 내부 부서다. 정본 표기는 `팔림프세스트 감사실`이며 원고 표층에서는 `감사실`로 부른다 (DEC-017).

### 지명·종족 혼동 방지

- **`네르바`(지명)와 `네바르`(종족)**는 음소 순서만 다르다. 단독으로 쓰지 않는다.
  - 지명: 항상 `네르바 변경`, `서부`, `잿빛 변경` 형태로 쓴다. 단독 `네르바` 금지.
  - 종족: 항상 `네바르 사람`, `네바르 장례판관`처럼 수식과 함께 쓴다. 단독 `네바르` 금지.
  - 한 장면에 둘 다 등장하면 지명은 `서부`, 종족은 `네바르 사람`으로 고정한다.

## 종족·문화권

- 에르나: `에르-나`, 엘프 대체명처럼 읽지 않는다.
- 카르둔: `카르-둔`, 광부·대장장이로 축소하지 않는다.
- 라하크: `라-하크`, 야만족 억양을 사용하지 않는다.
- 네바르: `네-바르`, 망자소환 집단으로 축소하지 않는다.
- 무명종: `무-명-종`, 생물종이 아니라 주소상실 상태다.

## 설정어

- 시간여행: 회귀와 구분한다.
- 역사주소: 일반 거주지 주소와 구분한다.
- 출발 인장: 출발 / 인장.
- 귀환 고정망: 귀환 / 고정망.
- 팔림프세스트: 팔-림-프-세-스트.
- 잔문: 잔-문.
- 마나열병: 마나 / 열병.
- 회색 재앙: 회색 / 재앙.
- 아홉 상처: 아홉 명의 조직이 아니다.
- 연대유산: 주인공 전용 장비가 아니다.
- 주권신수: 계약과 거부권이 있는 주체다.
- 소거 거부권: 부활권이 아니다.
