# 발음·호칭 사전 v1

Status: CANON OPERATIONS

## 원칙

- 원문에 전체 이름이 있으면 전체를 읽고, 개인 이름만 있으면 성을 덧붙이지 않는다.
- 음절 표시는 확인용이며 실제 낭독에서는 자연스럽게 이어 읽는다.
- 직함·계급·개인 이름을 구분한다.
- 현재 에이든과 젊은 에이든은 같은 이름을 가진 별도 인물이다.
- 이름 소거 뒤 대사에서 본명을 임의 복구하지 않는다.

## 기관

- 세르바 왕실평의회: `세르바 / 왕실 / 평의회`
- 왕좌승인원: `왕좌 / 승인원`
- 아홉 상처 대성당: `아홉 상처 / 대성당`
- 아르켄 중앙관측탑연합: `아르켄 / 중앙관측탑 / 연합`
- 칼레온 대기록소: `칼레온 / 대기록소`
- 잔문감사실: `잔문 / 감사실`
- 연대출귀원: `연대 / 출귀원`
- 최후 연대국: `최후 / 연대국`
- 연대개입산업연합: `연대개입 / 산업연합`
- 지역 연대감사소: `지역 / 연대감사소`

## 종족·문화권

- 에르나: `에르-나`, 엘프 대체명처럼 읽지 않는다.
- 카르둔: `카르-둔`, 광부·대장장이로 축소하지 않는다.
- 라하크: `라-하크`, 야만족 억양을 사용하지 않는다.
- 네바르: `네-바르`, 망자소환 집단으로 축소하지 않는다.
- 무명종: `무-명-종`, 생물종이 아니라 주소상실 상태다.

## 설정어

- 시간여행: 회귀와 구분한다.
- 역사주소: 일반 거주지 주소와 구분한다.
- 출발 인장: 출발 / 인장.
- 귀환 고정망: 귀환 / 고정망.
- 팔림프세스트: 팔-림-프-세-스트.
- 잔문: 잔-문.
- 마나열병: 마나 / 열병.
- 회색 재앙: 회색 / 재앙.
- 아홉 상처: 아홉 명의 조직이 아니다.
- 연대유산: 주인공 전용 장비가 아니다.
- 주권신수: 계약과 거부권이 있는 주체다.
- 소거 거부권: 부활권이 아니다.
