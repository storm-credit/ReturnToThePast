# 원고 문체·낭독 품질검사표 v1

Status: REQUIRED AFTER GATE OPEN

각 화 초고 완료 뒤 아래를 순서대로 검사한다. 사건·설정·인물 의도를 바꾸지 않고 문장 전달만 고친다.

## A. 자연스러운 한국어

- [ ] 영어식 주어·대명사가 반복되지 않는가
- [ ] `~되어졌다`, `~에 의해`, `~하는 것이었다`가 불필요하게 남지 않았는가
- [ ] 명사형보다 동사가 더 자연스러운 자리에 명사형을 쓰지 않았는가
- [ ] 한 문장에 조건·예외·설명이 과도하게 겹치지 않았는가
- [ ] 동일 종결어미가 한 문단에서 기계적으로 반복되지 않는가
- [ ] 소리 내 읽을 때 첫 청취만으로 행동 주체를 알 수 있는가

## B. 생동감과 공간

- [ ] 인물이 어디에 서 있고 어디로 움직이는지 알 수 있는가
- [ ] 묘사가 다음 판단·행동·위험과 연결되는가
- [ ] 감각을 장식처럼 나열하지 않았는가
- [ ] `기묘한`, `불길한`, `이상한` 같은 추상 형용사에 의존하지 않았는가
- [ ] 전투·추격에서 대상·방향·거리·결과가 명확한가
- [ ] 부상·피로·보급·이동시간이 다음 장면에 남는가

## C. 감정과 대사

- [ ] 감정을 직접 설명한 뒤 행동으로 다시 중복하지 않았는가
- [ ] 대사가 상대에게 가하는 행동으로 기능하는가
- [ ] 서로 이미 아는 설정을 독자에게 강의하지 않는가
- [ ] 인물마다 어휘·호흡·회피방식이 다른가
- [ ] 대립자를 악역 말투로 단순화하지 않았는가
- [ ] 침묵·이름·물건·버릇 등 구체적 반응이 감정을 대신하는가

## D. 이름·호칭·발음

- [ ] 정식 이름이 발음사전과 일치하는가
- [ ] 공식 회의·현장·사적 관계에 맞는 호칭인가
- [ ] 성·서임명·출신지명을 혈연으로 오해하지 않았는가
- [ ] 현재 에이든과 젊은 에이든을 구분했는가
- [ ] 소거된 이름을 인물 대사에서 임의 복구하지 않았는가
- [ ] 한 문단에 비슷한 이름이 몰릴 때 식별 단서를 두었는가

## E. 시점·정보상한

- [ ] 시점 인물이 볼 수 없는 것을 단정하지 않았는가
- [ ] 미래 기록을 정답처럼 서술하지 않았는가
- [ ] 거짓말·배신·사망을 억양이나 서술로 미리 폭로하지 않았는가
- [ ] 기억과 기록, 사망과 소거, 귀환과 복원을 구분했는가
- [ ] 새 시간법칙이나 예외를 반전 직전에 추가하지 않았는가

## F. 장면 리듬

- [ ] 실제 장면 수가 Q/S/E/X 유형과 맞는가
- [ ] 앞선 세 화와 같은 훅 유형을 반복하지 않았는가
- [ ] 각 장면 시작과 끝에서 가치·관계·정보·위험 중 하나가 변하는가
- [ ] 회의 다음에 또 다른 설명 회의를 붙이지 않았는가
- [ ] 전투 뒤 부상·장례·배급·법적 후과가 있는가
- [ ] 최소 분량을 위해 같은 정보를 반복하지 않았는가

## G. 작품 고유 정조

- [ ] 다크 판타지를 검은색·피·비명만으로 표현하지 않았는가
- [ ] 시간 이상을 몽환적인 시어보다 현실의 작은 불일치로 보여 주는가
- [ ] 관료제 공포가 실제 생활 기능과 함께 드러나는가
- [ ] 정치 선택이 구호가 아니라 누가 비용을 지는지로 표현되는가
- [ ] 비극을 아름답게만 꾸미지 않고 후유증을 남기는가
- [ ] 참고작의 고유 장면·조직·대사·반전을 복제하지 않았는가

## H. 분량

- [ ] 공백 포함 최소 7,000자인가
- [ ] 상한을 이유로 필요한 장면을 자르지 않았는가
- [ ] 최소치를 맞추기 위한 군더더기가 없는가
- [ ] 한 화 안에서 독자 보상과 다음 화 원인이 모두 있는가

## 판정

- `PASS`: 정본·문체·호흡 차단 문제 없음
- `REVISION`: 문장·호칭·공간·정보상한 교정 뒤 재검사
- `BLOCKED`: 사건·설계·정본 충돌. 원고를 푸시하지 않고 A02/A13/A16에 이관
