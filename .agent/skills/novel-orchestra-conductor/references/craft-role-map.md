# Storycraft Role Map

| Lane | Skill | Best used for | Core inputs | Default output |
| --- | --- | --- | --- | --- |
| `structure` | `structure-architect` | ending-backsolve, act turns, midpoint repair, volume promise design | endings, roadmap, target outlines, mandatory events, target draft if present | structure report, beat map, or lock sheet |
| `arc` | `arc-psychologist` | wound/need design, relationship pressure, identity drift, emotional cost mapping | protagonist file, key character files, target outline, target draft, relevant lore | arc pressure report |
| `reveal` | `reveal-choreographer` | reveal ladder, red herring fairness, truth release order, secret staging | endings, secrets activation, foreshadow ledger, roadmap, target outlines and drafts | reveal ladder report |
| `foreshadow` | `foreshadow-bookkeeper` | seed tracking, mid-stage reinforcement, payoff debt, fair clue bookkeeping | foreshadow ledger, endings, mandatory events, outlines, drafts | foreshadow/payoff report |
| `cadence` | `serial-tension-engineer` | scene pressure, chapter exits, retention, anti-drag revisions | target draft, previous chapter tail, next outline beat, checklist | cadence report |

## Selection guide

- Choose `structure-architect` when the story still lacks a stable skeleton.
- Choose `arc-psychologist` when plot exists but the people inside it are not changing convincingly.
- Choose `reveal-choreographer` when the truth is clear but the delivery is weak.
- Choose `foreshadow-bookkeeper` when clues exist but setup and payoff are not tracked cleanly.
- Choose `serial-tension-engineer` when the chapter works in outline but feels flat on the page.
- Use only the lanes that remove the current bottleneck.
