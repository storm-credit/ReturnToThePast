# Storycraft Algorithms

These are the default craft algorithms the orchestra should use when planning or auditing story design.

## 1. Ending Backsolve

Use when a volume or the whole series feels directionless.

1. Lock the final truth.
2. Lock the final choice.
3. Lock the final cost.
4. Lock the final image.
5. Work backward to determine the latest possible reveal point.
6. Add one early seed and one mid-volume reinforcement for each major payoff.

## 2. Reveal Ladder

Use when twists exist but do not feel earned.

1. State what is actually true.
2. State what the protagonist believes.
3. State what the reader is meant to believe for now.
4. Plant an early clue that can be misread fairly.
5. Add a mid-stage clue that narrows interpretations.
6. Define the gate that allows the truth to surface.
7. Check that the reveal does not depend on hidden rules absent from canon.

## 3. Arc Pressure Loop

Use when characters react, but do not evolve.

1. Identify the wound or void.
2. Identify the mask or coping strategy.
3. Identify the external desire.
4. Identify the internal need.
5. Add pressure that makes the mask fail.
6. Force a costly choice.
7. Record the changed self-understanding.

## 4. Serial Retention Loop

Use when chapters are readable but not addictive.

1. Give the scene a concrete objective.
2. Add resistance and a ticking form of pressure.
3. Turn the scene with a reversal, narrowing, or cost.
4. End with a residue question, not an empty tease.
5. Make the next chapter promise legible within one or two beats.

## 5. Setting-to-Story Conversion

Use when lore is interesting but inert.

1. Name the lore element.
2. Define who uses it.
3. Define what it costs.
4. Define the visible symptom.
5. Define the hidden truth.
6. Define the later payoff or disaster it enables.

## 6. Continuity Gate

Use before canon is merged into outlines or drafts.

1. Mark the fixed points.
2. Mark the branch points.
3. Mark the cost already paid.
4. Mark the emotional residue that should still be visible.
5. Mark the downstream consequence that future chapters must inherit.
