## Shared Entry State

- F1이 현재 현실이다.
- 에이든 로엔은 F1에서 국가 영웅으로 등록돼 있으나 자신이 하지 않은 후속 숙청까지 공적으로 붙어 있다.
- F0 동료 관계 다수는 기록상 존재하지 않는다.
- 다렌 모트는 F1에서 에이든의 오랜 전우이며 가족을 가진 현재 시민이다.
- 리아 세른은 F0 전체를 기억하지 않으며, 기억과 증명을 분리한다.
- 세렌 바일 사망은 L001로 영구 잠금. 다른 시간대 버전·재시도·부활 금지.
- 에이든은 F1 시민을 가짜로 취급하거나 즉시 F0 복원을 선언하지 않는다.

## E027 — 추모벽이 된 숙소

- Density: Q / 2장면.
- Goal: 개인 물품과 F0 동료 흔적 확인.
- Required beats: 신분국 이동허가와 동선기록 → 옛 숙소가 서부 희생자 추모구역으로 변함 → 동료 이름 부재 → F0 주장 시 기억오염 격리·권한정지 가능성 확인.
- Choice: 공개 폭로보다 개인 흔적과 물질증거를 먼저 찾는다.
- Cost: 다렌에게 기억불일치를 숨기고 있다는 사실이 드러난다.
- Hook: 이름은 없지만 에이든이 기억하는 동료의 필체가 추모벽에 남아 있다.
- Prohibition: F0 동료를 사망자로 확정하지 않는다. 부재와 사망을 같은 것으로 쓰지 않는다.

## E028 — 같은 암호, 다른 기억

- Density: Q / 2장면.
- Goal: 리아가 F0를 기억하는지 상호검증.
- Required beats: 공개 복도 대신 문서배열 암호 → 리아가 암호에 반응 → 세부 배열과 근무기억은 어긋남 → 일지에는 에이든이 세렌을 2번 만난 기록.
- Agency: 리아는 에이든의 기억을 정답으로 인정하지 않는다.
- Hook: 2번째 만남 기록은 에이든이 기억하는 출발 전날에 놓인다.
- Prohibition: 리아가 F0 전체를 기억한다고 확정하지 않는다. 꿈·파편기억을 예언처럼 쓰지 않는다.

## E029 — 더 많은 생존자

- Density: S / 3장면.
- First full appearance: 마르칸 베르 — F1 방위사령관.
- Goal: F1 체제를 적으로 규정하기 전 실제 운영성과 검증.
- Required beats: F0에서 폐허였던 병원·곡창·주거구 운영 → 생존성과 자료 → 재앙 연대표 대조.
- Opposition benefit: F1은 선전만이 아니라 실제로 더 많은 생존과 운영효율을 만들었다.
- Counter-cost: 회색 재앙의 대규모 시작은 에이든·리아 기억보다 약 20년 앞당겨져 있다.
- Hook: 첫 대규모 발병지는 세렌의 사망지가 아니다.
- Prohibition: F1을 디스토피아 또는 정답 미래로 확정하지 않는다.

## E030 — 현재에 태어난 가족

- Density: X / 5~6장면.
- Goal: 다렌의 현재 생활세계가 역사오류가 아니라 실재하는 사람의 삶임을 보여준다.
- Required beats: 배우자·자녀·이웃 → 에이든이 기억하지 못하는 공동전투 → 가족사진 배경의 F0 적대 문장이 F1 국가구조대 표식 → F0 복원이 가족 출생을 지울 수 있다는 도덕비용.
- Choice: 즉시 복원을 약속하지 않고 현재 사람을 지우지 않는 원칙을 세운다.
- Hook: 다렌은 에이든이 과거에도 미래를 되돌리려 했다고 말한다.
- Prohibition: 다렌 가족을 세뇌·환상·가짜 가족으로 처리하지 않는다.

## E031 — 거짓말로 연 문

- Density: E / 4장면.
- Goal: 고등 기록 접근권 확보.
- Required beats: 영웅 증언회에서 공식서사를 완전 부정하지 않음 → 숙청 공적을 접근 명분으로 사용 → 제한 고등열람 승인 → 동시에 정신오염 정밀검사 명령.
- Cost: 하지 않은 공적과 피해자 기억을 다시 이용한다.
- Exit: 기록소 접근권 획득, 감시 강화.
- Hook: 봉인목록에 `F0`라는 분류명이 에이든 귀환 전부터 존재한다.
- Prohibition: F0의 정체·기원·최초 명명자를 이 회차에서 확정하지 않는다.

## Shared Voice / POV Locks

- 에이든 근접 3인칭. 에이든이 보거나 듣거나 합리적으로 추론할 수 없는 장면은 쓰지 않는다.
- 에이든: 목표·출구·비용 순서. 감정은 계산·호칭·행동 지연으로 드러낸다.
- 리아: `기억한다`와 `증명할 수 있다`를 구분한다.
- 다렌: 과거 회상보다 현재 가족·생활·다음 일정의 숫자를 먼저 말한다.
- 마르칸: 체제 선전이 아니라 운영수치·피해·효용을 동시에 제시한다.
- 숫자는 아라비아 숫자 표기.
- `A가 아니었다. B였다.` 식의 반복 대구를 회차 구조로 사용하지 않는다.

## Subact Exit State

- 에이든은 F0 공개주장을 보류한다.
- F1의 현재 시민을 복원의 부산물로 취급할 수 없다는 비용을 인식한다.
- 영웅 신분을 이용해 고등기록 제한열람권을 얻는다.
- 의료국의 시간오염 정밀검사 대상이 된다.
- `F0`라는 격리분류가 이미 존재한다는 사실을 확인한다.
- 다음 원인: E032에서 절검·소거명부·출발 인장 등 물질증거 검증으로 이동.
