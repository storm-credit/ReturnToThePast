## Shared Entry State

- F1이 현재 현실이다.
- 에이든 로엔은 F1에서 국가 영웅으로 등록돼 있으나 자신이 하지 않은 후속 숙청까지 공적으로 붙어 있다.
- F0 동료 관계 다수는 기록상 존재하지 않는다.
- 다렌 모트는 F1에서 에이든의 오랜 전우이며 가족을 가진 현재 시민이다.
- E027 진입 시 리아 세른의 F1 존재 여부와 기억상태는 아직 검증 전이다. E028에서 직접 확인한다.
- 세렌 바일 사망은 L001로 영구 잠금. 다른 시간대 버전·재시도·부활 금지.
- 에이든은 F1 시민을 가짜로 취급하거나 즉시 F0 복원을 선언하지 않는다.

## E027 — 추모벽이 된 숙소

- Density: Q / 2장면.
- Goal: 개인 물품과 F0 동료 흔적 확인.
- Required beats: 신분국 이동허가와 동선기록 → 옛 숙소 좌표가 서부 희생자 추모구역과 겹침 → 동료 이름 부재 → 과거와 다른 기억을 지속 주장할 경우 기억오염 관찰·권한정지 가능성 확인.
- Choice: 공개 폭로보다 개인 흔적과 물질증거를 먼저 찾는다.
- Cost: 다렌이 에이든의 기억 불일치를 명시적으로 인지하기 시작한다.
- Hook: 이름은 없지만 에이든이 기억하는 동료의 필체가 추모벽에 남아 있고 `이전 원본에서 전사` 표식이 붙어 있다.
- Prohibition: F0 동료를 사망자로 확정하지 않는다. 부재와 사망을 같은 것으로 쓰지 않는다.

## E028 — 같은 암호, 다른 기억

- Density: Q / 2장면.
- Goal: 리아가 과거 기억과 배열 암호에 어떻게 반응하는지 상호검증.
- Required beats: 공개 복도 대신 문서배열 암호 → 리아가 암호의 뜻을 앎 → 세부 배열과 근무기억은 어긋남 → 개인일지에 `에이든이 다시 왔다. 바일은 이번에도 서명하지 않았다.` 문구 존재.
- Agency: 리아는 에이든의 기억을 정답으로 인정하지 않는다. 같은 답·다른 답·판정불가를 분리한다.
- Time Conflict: 일지 문구는 에이든이 기억하는 출발 18시간 전에 기록돼 있지만 장소와 접촉 방식은 적혀 있지 않다.
- Hook: `다시 왔다`는 선행 접촉을 암시하지만 2번째 직접 대면으로 확정하지 않는다.
- Prohibition: 리아가 F0 전체를 기억한다고 확정하지 않는다. 일지 문장만으로 직접 대면·횟수를 확정하지 않는다.

## E029 — 더 많은 생존자

- Density: S / 3장면.
- First full appearance: 마르칸 베르 — F1 방위사령관.
- Goal: F1 체제를 적으로 규정하기 전 실제 운영성과 검증.
- Required beats: 병원·곡창·주거구 실제 운영 확인 → 생존 증가 자료의 원인·오차 검증 → 재앙 연대표 독립기록 교차검증.
- Opposition benefit: F1은 선전만이 아니라 실제로 더 많은 생존과 운영효율을 만들었다.
- Counter-cost: 회색 재앙의 대규모 시작은 에이든·리아 기억보다 약 20년 앞당겨져 있다.
- Hook: 첫 대규모 발병지는 세렌 바일 사망지가 아니다.
- Prohibition: F1을 디스토피아 또는 정답 미래로 확정하지 않는다. 세렌 사망과 재앙 조기화를 곧바로 인과로 연결하지 않는다.

## E030 — 현재에 태어난 가족

- Density: X / 5~6장면.
- Goal: 다렌의 현재 생활세계가 역사오류가 아니라 실재하는 사람의 삶임을 보여준다.
- Required beats: 배우자·자녀·이웃의 현재 생활 → 에이든이 기억하지 못하는 공동전투 → 가족사진 배경의 F0 적대 문장이 F1 국가구조대 표식 → 복원이 가족 출생을 지울 수 있다는 도덕비용.
- Choice: 복원도 비복원도 약속하지 않는다. 가족이 실제로 존재한다는 사실을 본 만큼 어떤 방향도 확인 없이 확정하지 않는다.
- Hook: 다렌은 에이든이 과거에도 미래를 되돌리려 했다고 말한다.
- Prohibition: 다렌 가족을 세뇌·환상·가짜 가족로 처리하지 않는다. 복원 시 가족 소거를 확정된 결과로 쓰지 않는다.

## E031 — 거짓말로 연 문

- Density: E / 4장면.
- Goal: 고등 기록 접근권 확보.
- Required beats: 영웅 증언회에서 공식서사를 완전 부정하지 않음 → 숙청 공적과 그에 연결된 피해기록을 접근 명분으로 사용 → 제한 고등열람 승인 → 동시에 시간임무 귀환자 정밀검사 명령.
- Cost: 하지 않은 공적과 피해자 기록을 접근권 획득에 다시 사용한다.
- Exit: 기록소 접근권 획득, 감시·의료심사 강화.
- Hook: 봉인목록에 `F0`라는 분류명과 복수 파일이 존재한다.
- Prohibition: `F0`의 정체·기원·최초 명명자·최초 등록일을 이 회차에서 확정하지 않는다. 현재 귀환 이전부터 존재했다고 단정하지 않는다.

## Shared Voice / POV Locks

- 에이든 근접 3인칭. 에이든이 보거나 듣거나 합리적으로 추론할 수 없는 장면은 쓰지 않는다.
- 에이든: 목표·출구·비용 순서. 감정은 계산·호칭·행동 지연으로 드러낸다.
- 리아: `기억한다`와 `증명할 수 있다`를 구분한다.
- 다렌: 과거 회상보다 현재 가족·생활·다음 일정의 숫자를 먼저 말한다.
- 마르칸: 체제 선전이 아니라 운영수치·피해·효용을 동시에 제시한다.
- 숫자는 아라비아 숫자 표기.
- 독자용 본문에 `F0/F1/E0xx` 제작용 표기를 노출하지 않는다. 단 E031 마지막 `F0`는 기록소 내부 분류명으로 최초 발견되는 정본 훅이므로 예외다.
- `A가 아니었다. B였다.` 식의 반복 대구를 회차 구조로 사용하지 않는다.

## Subact Exit State

- 에이든은 과거 기억 공개주장을 보류한다.
- F1의 현재 시민을 단순한 복원의 부산물로 취급할 수 없다는 비용이 생긴다.
- 영웅 신분을 이용해 고등기록 제한열람권을 얻는다.
- 의료국의 시간임무 귀환자 정밀검사 대상이 된다.
- `F0`라는 격리분류명과 복수 파일이 현재 기록소에 존재한다는 사실을 확인한다. 생성시점과 명명자는 미확정이다.
- 다음 원인: E032에서 절검·소거명부·출발 인장 등 물질증거 검증으로 이동.
