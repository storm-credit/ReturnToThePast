## Entry State

- 증언도시는 비영토 법적 공동체로 생존.
- 외부국 공동감사가 국경 고정석·귀환망 연결기록을 조사하기 시작함.
- 왕국 방어회랑·군사도로·독점감사권 일부 약화.
- 국경 귀환석에서 공식 사망자 등록번호의 구조신호 수신.
- 구조창 개방 가능 횟수 1회.
- 구조코드가 여러 층으로 겹쳐 있으며 정확 인원 미확정.
- 중앙 수호대의 과거 `미회수 분류`가 잠겨 있음.

## E101 — 죽은 사람이 보낸 신호

- 구조신호 주기·등록번호·사망처리 상태 대조.
- `사망자`가 아니라 `사망 처리된 발신자`로 분류.
- 중앙 요약은 단일 사망요원 잔류 자동신호 가능성을 제시.
- 현장 측정에서는 서로 다른 길이·방향·시간표식의 코드가 겹침.
- 현지어 음성 추정 잔파까지 확인되며 자동신호 단독설명 약화.
- 폐요새를 실제 추적대상으로 선택.

## E102 — 같은 방의 다른 연도

- 요새 접근거리 왜곡.
- 사람·장비 질량 증가가 좌표오차에 영향을 줄 가능성 때문에 4명 소수대 유지.
- 에이든 로엔 / 아이리스 네르 / 네바르 기록관 / 카르둔 안내자 구성.
- 같은 감시실에 서로 다른 연도의 식사·전투·사망 흔적이 동시에 존재.
- 창밖 풍경과 방 내부 시간층이 교차.
- 현재 에이든의 장화와 일치하는 발자국이 선행 시간층 먼지 위에서 발견됨. 생성시점·원인 미확정.

## E103 — 함정이 아니라 거절당한 귀환

- 중앙 수호대는 적대 유인신호 가능성을 제기.
- 네바르 장례판으로 공식 사망처리 요원의 마지막 생체감각을 재생.
- 요원은 현지에서 즉시 사망한 것이 아니라 왕국 귀환실까지 생존 도착.
- 협력자·포로를 동반한 상태에서 망 과부하를 이유로 `수용 거부`됨.
- 수용거부는 개인 이름이 아니라 자동 정책번호로 집행됨.
- 사망시점 자체는 미확정 유지.

## E104 — 한 사람 때문에 전체를 잃을 수 없다

- 중앙 수호대 정책이 단순 악의가 아니라 실제 전체망 보존 기능을 가졌음을 검증.
- 과거 과부하 제한이 의료·계절 귀환망을 유지하고 실제 피해를 줄인 사례 확인.
- 동시에 거부대상에게 기준이 충분히 공개되지 않았고 재구조가 실패·중단된 사례가 존재.
- 에이든은 정책 폐기보다 거부대상·범주·재구조 실적·사람 개입권·효용자료 공개를 요구.
- 구조창 안정구간이 약 하루로 줄어듦.

## E105 — 귀환패의 마지막 용도

- 구조창 한 번을 준비하기 위한 선택: 고립자 주소 고정 vs 적 추적신호 차단.
- 에이든은 고립자 주소 고정을 선택.
- F0 귀환패는 과거 원본 F0가 아니라 현재 존재하는 귀환망을 우선 지시.
- 주소 고정 과정에서 F0 잔류서명 대부분이 소실되어 복원증거가 약해짐.
- 대신 같은 폐요새 안 여러 시간층의 복수 고립자 주소가 분리되기 시작.
- 정확 인원은 미확정.

## E106 — 문이 아니라 얇은 연결

- 완전 귀환창을 열기 전 음성·작은 물질만 통과하는 얇은 연결 시도.
- 공식 사망처리 요원의 현재 음성응답과 등록번호 일치 확인.
- 요원 외 현지 협력자·포로·다른 시간층 고립자 존재 확인.
- 다른 구역 생존자도 있다는 현장 증언 확보, 정확 총인원 미확정.
- 일반 철·보통 카르둔 합금도 시간풍화로 빠르게 손상.
- 직접 진입에는 일반 장비 사용 불가.
- 카르둔 경계갑만 후보로 확인.
- 경계갑은 왕실 보관이지만 카르둔 공동체가 장례·사용권을 주장 → V5 5B 직접 원인.

## Exit State

- 구조대상 생존: 최소 일부 직접 확인.
- 구조대상 범주: 왕국 요원 / 현지 협력자 / 포로 포함.
- 구조창: 여전히 1회, 계속 감소 중.
- 일반 장비 직접진입: 불가.
- F0 귀환패 잔류서명: 대부분 소모.
- 적 추적차단: 선택하지 않음 → 향후 경로 노출 위험 유지.
- 다음 목표: 카르둔 경계갑 사용권·소유권·분해권·장례권 확인.
