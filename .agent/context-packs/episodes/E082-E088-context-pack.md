# Episode Context Pack — E082–E088

Status: DRAFT SUPPORT PACK
Scope: V4 middle — 현재가 부담할 옛 권리

> 정본 대체 아님. main 정본 우선.

- E082: 미라 라디아(C23) 동부 곡창대표 첫 등장. 옛 식량채무는 인정하되 현재 최소배급·종자·재난비축을 침해하지 않는 부담상한과 장기상환 협상. 옛 채권자도 무기한 대기 피해가 있으므로 0원화 금지.
- E083: 토마르 마레이(C28) 남부 항만노조 대표 첫 등장. 항만사용권 상환은 현재 구호선·노동조건·하역비·세관·의료검사 비용을 만든다. 외부지원과 밀수를 구분. 옛 도시의 현재 법적 후계주체 부재 문제 확인.
- E084: 옛 시정부를 복원하지 않고 계약·문화·장례·시민신청·일부 공공자산 기능만 맡는 공동주체를 설계. 영토·군사·강제시민등록·일반세금권 없음. 기능별 정족수.
- E085: 도시 역사명·문화·조합·묘지 이름을 법적으로 복원하되 현재 행정명·사용권을 자동 삭제하지 않음. 옛 조합은 혈통승계가 아니라 현재 규약 재합의. 이름은 돌아오지만 영토는 자동복원되지 않음.
- E086: 증언시민권. 옛 명부·복수증언·물질·현재관계를 여러 경로로 검증하되 본인 신청 필수, 거부·철회권 유지. 자동 혈통시민권 금지.
- E087: 자유해안과 상호감사. 최소정보만 교환하고 원본 소유는 분산. 상대 기록도 상호 검증해 양쪽 오류를 고침. 복원파가 옛 도시 전면복원 시간임무를 공식 제안.
- E088: 전면복원 영향표에 현재 마을·가족·식량·항만·외국계약·백지권 공동체·F2 제도 소실 가능성을 포함. 도시기억자 내부에서도 전면복원/부분권리 반환 입장 분열. 심사대기 유지.

- 과거 채무 인정 = 현재 무제한 상환 아님.

- 도시 법적 주체를 만들더라도 옛 정부·영토주권 자동복원 금지.
- 시민권은 자발적 신청/철회 기반.
- 전면복원은 현재 소실 위험을 명시하고 선택.
