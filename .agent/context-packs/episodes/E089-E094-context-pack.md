- E089: 전면복원을 단일 다수결로 정하지 않음. 현재 존재·가족이 소거될 수 있는 집단에는 강한 거부권, 옛 도시 공동체에는 이미 복구된 역사·문화·시민권을 후대가 일방 삭제하지 못하게 별도 거부권.
- E090: 시간개입 없이 복구 가능한 이름·증언시민권·문화·조합·계약·장례·일부 공공자산·기록 이의권을 실제 권리로 집행. 남는 손실은 완전 영토·시정권·사라진 공동생활 시간.
- E091: 현재 주민 거부와 고위험 소거 기준을 반영해 전면복원 시간임무를 기각. 옛 도시 권리 확대는 현재 법으로 계속 가능하나, 현재를 지우는 통째 원상복구 재시도는 별도 잠금 대상으로 정리.
- E092: L004 실행. `옛 도시의 완전한 영토·지배권을 과거 상태 그대로 현재에 복원`하는 시간개입 포기. 재도약·재시도 금지. 옛 도시 권리는 부분권리·문화·시민·계약·장례로 계속 확대 가능. 복원파 반대의견도 보존.
- E093: 개별 토지청구를 전면복원과 분리. 현재 공동창고·주택·수로를 강제 철거하지 않고 과거 사용권 인정, 장기보상, 공동관리, 향후 우선재협상으로 처리. 시간개입 후속피해를 일반재정에 숨기지 않고 책임기금 항목으로 보이게 함.
- E094: `증언도시` 법적 공동체 성립. 영토·군사·일반세금·강제시민등록·독자 시간임무 승인권 없음. 역사명·자발적 증언시민권·문화·조합·장례·계약·일부 공공자산·기록 이의권을 기능별 대표로 행사. 현재 생활주소와 역사관계 주소 분리.
