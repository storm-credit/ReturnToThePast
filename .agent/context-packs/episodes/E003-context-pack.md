## 2. E002 Carryover

### 에이든

- 여섯 권한의 제한조건 인지
- 불완전 기록·귀환위험 아래 조건부 서명
- 현지 조사·환자 증언은 부목표
- 성당 재검사와 최종 자동확정 전

### 리아

- 감사대상 상태 유지
- 세렌의 존재·활동주소만 제한검증
- 원인·발생일·증언자 목록 상충을 공식 기록
- 세렌의 무죄 또는 유죄를 확정하지 않음

### 귀환석

- 중심층 3갈래 균열
- 예상 체류 5시간 17분
- 최대 오착 18km
- 강제복귀 1회
- 미확인 토양은 공동봉인 상태

### 현재 피해

- 제칠 방벽 마지막 표시 구조 가능 인원: 1,312명
- 서부 구조대 31명 연락두절
- 숫자는 최종 생존자 수가 아니라 현재 구조계산값

Evidence types:

### 압수 도구

- 금지된 시간·주소 의식에 사용된 것으로 분류
- 세렌의 작업장 또는 조사망에서 확보
- 실제 사용 흔적과 피해 현장의 연관성이 존재
- 단순 조작품으로 무효화하지 않음

### 희생자 기록

- 세렌의 의식·폭로·시설침입 전후 실제 사망·실종자가 존재
- 피해를 전부 왕실 조작으로 돌리지 않음
- 세렌은 무고한 성인이 아니라 위험한 불법행위와 과격한 판단을 한 인물

### 왕실 명령서

- 세렌의 체포·시설폐쇄·자료압수 명령
- 당시 행정·치안 기준으로 일정한 합법성과 증거절차가 있음
- 왕실이 전부 거짓인 단순 구조 금지

### 생존 증가 계산

- 세렌 제거 시 F0 안정권 생존자 약 19만 증가 예상
- 객관적 미래확정이 아니라 생존선별실 모델의 예측
- 계산에는 공개된 기록과 누락된 지방·무명종 비용의 한계가 있을 수 있음
- E003에서는 모델의 치명적 결함을 아직 확정하지 않음

## 5. Character State

### 에이든 로엔

- 목표: 의심이 임무 중단 수준인지 판단
- 내적 압박: 귀환창이 짧아져 현지 검증 여유가 줄어듦
- 전문: 증거의 출처·현장 사용흔적·피해 인과를 질문
- 오류 가능성: 큰 생존수치와 실제 압수품을 ‘행동해야 할 충분조건’으로 받아들임
- 금지: 세렌을 곧바로 무죄라고 믿거나 본부 전체를 적으로 판단

### 리아 세른

- 역할: 증거를 부정하는 사람이 아니라 출처·시간·봉인층을 구분
- 독립 목표: 증거가 실제라는 사실과 해석이 틀릴 수 있다는 사실을 동시에 남김
- 제한: 감사표식과 원본층 접근제한
- 금지: 결정적 반증을 숨기고 있는 것처럼 연출

### 생존선별실 분석 담당

- 새 핵심 이름을 즉석 확정하지 않음
- 실제 배급·병원·방어망 데이터를 사용
- 계산의 효용과 한계를 모두 가짐
- 악의적 숫자조작자·냉혈한 caricature 금지

## 6. Mystery / Information Ceiling

Active mysteries:

- M02 세렌은 왜 재앙 창시자로 기록됐는가
- M05 빈 장부와 비용배분의 초기 흔적
- M12 조작을 한 한 명의 흑막이 있는가

Reader may know:

- 세렌에 대한 증거는 완전한 날조가 아님
- 날짜와 증언자 목록은 서로 충돌
- 삭제 흔적은 최근 즉석조작이 아닐 가능성
- 생존모델은 큰 숫자로 에이든을 설득할 실제 힘이 있음

Reader must not know yet:

- 세렌이 지방 소거를 늦췄다는 전체 기능
- 누가 어떤 이유로 책임을 뒤집었는지
- 삭제된 증언자의 정체
- 왕실·성당·본부 중 어느 기관이 주범인지
- 19만 계산의 최종 오류구조

Final hook:

- 삭제된 증언자의 사망일이 세렌의 범행일보다 앞섬
- 의미: ‘세렌이 증언자를 죽여 기록을 지웠다’는 쉬운 해석에 시간 모순 발생
- 금지: 이 한 단서로 세렌 무죄 확정

## 8. Scene Values

### Scene 1 — 증거실

- Entry: 기록은 상충하므로 세렌 혐의도 약할 수 있음
- Evidence: 압수 도구·피해 흔적·왕실 명령서의 실제성
- Exit: 세렌이 위험한 불법행위를 했다는 사실은 강해짐

### Scene 2 — 피해 계산실

- Entry: 증거가 있어도 제거의 효과는 불확실
- Evidence: 병원·배급·방벽 데이터를 이용한 19만 증가 모델
- Exit: 실행하지 않는 선택도 대규모 사망을 만든다는 압박 강화

### Scene 3 — 폐기기록 보관대

- Entry: 삭제 증언자는 세렌 측이 제거했을 수 있음
- Evidence: 오래된 물리 절단과 사망일
- Exit: 공식 유죄서사에 해결되지 않는 시간모순 발생
