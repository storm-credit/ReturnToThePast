## Entry State

- 시간폭풍 요새의 일부 고립자 생존을 얇은 연결로 직접 확인.
- 왕국 요원·현지 협력자·포로가 함께 고립.
- 일반 철·보통 카르둔 합금 모두 시간풍화로 직접진입 불가.
- 카르둔 경계갑만 직접진입 후보.
- 경계갑은 왕실 보관자산이지만 카르둔 공동체가 사용·장례·분해권을 주장.
- 구조창은 1회이며 감소 중.

## E107 — 장비가 아닌 공동묘지

- 경계갑 제작법·사용이력·장례목록 확인.
- 갑옷 안쪽에 지워진 묘지 경계석 계열 재료와 이름판 존재.
- 경계갑은 시간풍화를 막는 것이 아니라 대신 받으며, 착용자의 공적 주소를 연료로 소모.
- 시험착용에서 왕국 공적기록 한 줄의 수행자 이름이 실제로 흐려짐.
- 가족기억보다 공적·법적 연결이 먼저 흔들릴 수 있음.
- 경계갑 내부 기록에 에이든 현재 공적등록과 일부 일치하는 연결흔적 발견, 원인 미확정.

## E108 — 구매한 것과 소유한 것

- 왕실 구매증: 대금·완제품·보관 이전 모두 실제 성립.
- 카르둔 문서: 묘지재료 장례권·분해권을 왕실에 포기한 문구 없음.
- 법적 소유 주장과 문화·장례권 주장을 동시에 유효 상태로 둠.
- `소유권 / 사용권 / 분해권 / 거부권 / 보관의무 / 반환청구권`을 분리한 계약구조 설계.
- 에이든은 법적 소유만으로 강제사용하지 않음.
- 공방 내부 구조 찬성·반대 의견이 분리돼 있으며 단일한 ‘카르둔의 뜻’으로 만들지 않음.
- 중앙군이 구조창 종료를 이유로 경계갑 즉시 확보 명령 발동.

## E109 — 지연의 이유

- 공방 뒤 결정화 벽에서 과거 강제착용자들의 결정화 사망과 공적이름 소실 기록 확인.
- 전시징발법상 합법이었던 사례와 개별동의 부재가 동시에 존재.
- 경계갑 핵심재가 시간선에서 지워진 카르둔 공동묘지 경계석임을 확인.
- 묘지 정리는 협의·보상·강제·무주물처리 등 사례가 서로 달라 단일 피해서사로 축약하지 않음.
- 고립자 중 한 왕국 요원이 카르둔 북서 묘역 정리 지원 임무에 참여했다는 기록 발견.
- 해당 요원의 실제 역할·명령거부 여부는 미확정.

## E110 — 갑옷을 가져가려는 군대

- 중앙군은 살상공격이 아니라 출입권 변경·전략자산 회수명령으로 공방을 압박.
- 에이든·공방·현지 경비는 사람을 죽이지 않고 출입인장·회수인장·동력·수레로 비살상 방어.
- 중앙군 현장장교도 타격금지를 지시하며 개인 악역화 금지 유지.
- 유족대표 도착 직전 구조창이 예상보다 빨리 자동개방 단계로 진입.
- 계약 미완 상태에서 고립자 1명이 현재 공방에 반쯤 겹쳐 나타남.
- 강제착용을 피하려면 실제 착용자의 자발동의가 즉시 필요해짐.

## E111 — 반환되고 분해될 갑옷

- 최종 사용계약 성립: 1회 구조 사용 / 즉시 공방 반환 / 왕실 연구입회 / 공동 분해심사 / 공방·유족 재출동 거부권 / 개인전유 금지 / 기록부식 공개 / 허위 공적보충 금지 / 묘지재료 출처보존 / 구조와 책임판정 분리.
- 반대 장인의 반대서명도 삭제하지 않고 계약에 병존.
- 에이든이 자발 착용자로 결정.
- 시험착용 중 왕실 공적명부의 첫 공로항목에서 에이든 이름 실제 소실.
- 새 증언으로 재등록 가능하더라도 원래 기록 복구와 동일하지 않다는 구분 유지.
- 갑옷 안쪽에 `에이든 로엔` 이름이 있으나 현재 F2/F1/F0와 다른 등록형식. 출처·정체 미확정.

## E112 — 폭풍 속의 버려진 표식

- 경계갑과 얇은 연결로 시간폭풍 요새 직접진입.
- 일반 안전밧줄은 즉시 시간풍화되어 물리연결 해제.
- 공식 사망처리 요원과 현지 협력자·포로 직접 접촉.
- 다른 시간층의 추가 요원·현지인 확인.
- E109의 카르둔 묘역 정리 지원 요원은 본인이 참여·비동의 운반을 인정하나 책임판정은 구조 후로 분리.
- 구조신호의 겹친 코드들이 여러 고립자가 같은 기본박자에 추가한 신호라는 설명 일부 확인.
- 요새 벽에서 서로 다른 시기의 귀환거부 인장 수십 개 발견.
- 개별 사고가 아니라 장기 정책사용 흔적이라는 상태로 전환.
- 가장 최근 거부표식 날짜가 현재보다 미래. 날짜층·원인·주체는 미확정.

## Exit State

- 직접진입 성공.
- 일부 구조대상 위치·상태 직접 확인.
- 경계갑 사용에 따른 에이든 공적신분 부식 시작.
- 카르둔 장례·문화재 권리는 구조와 동시에 살아 있음.
- 귀환거부 체계가 장기간 반복 사용됐다는 물질기록 확보 필요.
- 다음 목표: 누가 버려졌고 어떤 정책·기록삭제·구두명령이 결합됐는지 명단과 결재흐름 확보.

## Information Ceiling

- 다른 등록형식의 `에이든 로엔`을 다른 시간선 본인으로 확정하지 않는다.
- 현재보다 미래 날짜의 거부인장을 미래의 누가 보낸 명령인지 확정하지 않는다.
- 중앙 수호대 전원을 가해자로 묶지 않는다.
- 카르둔 공동체 전원을 구조 반대/찬성 한쪽으로 묶지 않는다.
- 경계갑 기록부식을 치료·복구 가능한 임시상태로 만들지 않는다.
