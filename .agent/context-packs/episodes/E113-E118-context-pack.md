## Entry

- 에이든은 경계갑으로 시간폭풍 요새 직접진입 중.
- 일부 고립자 생존 직접 확인.
- 요새 벽에 수십 개 귀환거부 인장 존재.
- 가장 최근 인장 날짜는 현재보다 미래.
- 에이든 공적신분 부식 진행.

## E113 — 서명 없는 명령
- 귀환거부 명령 대부분 개인서명 없이 정책번호로 집행.
- 자동 임계치 + 현장 수동재심 + 기록삭제/비공개 + 중앙 구두명령이 결합된 구조 확인.
- 동일 인물도 피해자·집행자 범주를 동시에 가질 수 있음.
- 구조대상·사망처리·현지협력자·포로를 분리한 명단 작성.
- 미래 날짜 명단에 에이든 호출명 계열 발견. 동일인 여부 미확정.

## E114 — 모두 같은 가해자가 아니다
- 현직 수호자들을 집행·재심·삭제·사본보존·비밀통로 인지 등 실제 행동으로 분류.
- 집행자 중 재심자도 있고 삭제자 중 불법 사본보존자도 존재.
- 집단처벌 대신 사실증언·구조협력을 조건으로 임시보호 제안, 면책은 없음.
- 비밀 대피통로 끝에 적대세력 표식 발견.

## E115 — 독점이 사라지면 생기는 틈
- 지역 분산망 과거 실패: 좌표충돌·수용책임 공백·적 침투/경로노출.
- 중앙 독점 폐지가 자동 정의가 아님을 확인.
- 고립자 중 실제 적대세력 첩자 1명 검증.
- 첩자는 구조 후 포로·정보범으로 분리하며 유기하지 않음.
- 첩자가 현재보다 뒤 날짜의 미래 임무표 일부 제출. 진위 미확정.

## E116 — 기억을 선전으로 쓰는 사람들
- 복원파가 리아 세른의 실제 F0 기억 발언에서 `확실성·증명불가` 문장을 잘라 선전화.
- 원본 대조로 선택편집 확인.
- 반박자료는 원본·편집본·잘린 문장·반론·피해자 증언·미확정 항목을 함께 제공.
- 미래 귀환거부 명단에 `에이든 로엔` 이름 발견, 등록번호 불일치로 동일인 여부 미확정.
- 같은 미래 기록층에 구조 후 내전 날짜 존재. 현재 구조와 인과 미확정.

## E117 — 진실을 들은 병사들의 선택
- 요새 병사·수호자에게 정책 효용·버려진 피해·첩자 존재·미래 내전 문서까지 모두 공개.
- 강제 충성 대신 정보 기반 선택 허용.
- 구조참여 / 중앙정책 우선 구조반대 / 중립 의료로 자발 분열.
- 정책지지 수호자가 보조단말로 중앙 폐쇄코드 발신.

## E118 — 폐쇄될 요새
- 귀환거부 사례를 외부 감사단·증언도시·지역망·중앙 기록소에 범위별 송출.
- 자동정책 설계/임계치 수정/현장집행/수동재심/기록삭제/사본보존/비밀대피/구두명령/적대정보 제공을 분리해 책임범주 작성.
- 중앙은 적대경로 노출·시간층 붕괴를 이유로 요새 주소 폐쇄 명령.
- 중앙망으로 폐쇄 전 전원 구조 불가.
- 대안: 서로 다른 지역 고정석 3곳 동시 서명 분산귀환.
- 첫 지역은 수확기 계절고정 위험과 `중앙이 버린 사람 비용을 왜 지역이 부담하나`는 이유로 거부.
