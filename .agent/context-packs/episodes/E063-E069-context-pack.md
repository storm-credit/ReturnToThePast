# Episode Context Pack — E063–E069

Status: DRAFT SUPPORT PACK
Scope: V3 / Subact 3C–3D

> 정본 대체 아님. main 정본과 장면밀도 지도를 우선한다.

- E063 `본부가 아닌 시민에게` — 귀환 후 격리구역에서 증인 분리 전 공개 경로를 정한다. 본부 내부고발은 봉인 위험이 있어 공공 기록망을 택하고, 기록망 운영자의 복원파 비밀 거래를 확인한다. 단일 채널에 의존하지 않고 다중 출처 검증 구조를 만든다. 운영자는 원본 제공 대가로 원래 시간선 복원 좌표를 요구한다.
- E064 `공개하면 굶는 사람들` — 국가 신뢰 붕괴가 곡창·병원·귀환망을 실제로 멈출 수 있음을 배급지도에서 확인한다. 사실·추론·미확정을 나누고 지역 검증 시간을 두는 단계공개안을 만든다. 마르칸 베르의 즉시 전면공개 사망예측표가 첫 임무의 사망자 계산법과 같은 편향을 가진다는 점을 확인한다.
- E065 `은폐자가 지키는 곡창` — 마르칸의 비상배급 운영이 실제 생존효용을 가진다는 점과 지방 소거·기록조작 책임을 분리해 본다. 복원파가 빈 장부 사본을 탈취해 현재 전체가 잘못된 미래라는 선전에 사용하고, 현재 주민을 `복구 대상`으로 재분류한 명단을 퍼뜨린다.
- E066 `원본과 반대 증언` — 복원파 편집본의 사실 부분을 인정하면서 누락된 반대증언·불확실성·현재 피해를 한 묶음으로 송출 준비한다. 다렌 모트가 공개망 차단 명령을 받고 에이든의 위치를 직접 찾아온다. 다렌이 지키려는 현재 가족·시민의 위험을 악역화 없이 포함한다.
- E067 `몇 분의 배신` — 방송실에서 다렌과 대치한다. 원래 시간선 복원 가능성을 과장하지 않고 다렌 가족과 현재 시민의 소거 가능성도 숨기지 않는다. 다렌은 편을 바꾸지 않지만 차단을 몇 분 늦춰 검증자료가 분산되게 하고, 이후 차단·추적 임무를 계속한다.
- E068 `모두에게 불리한 진실` — 에이든의 살인 오류, 세렌 바일의 불법행위, 본부의 실제 효용과 은폐, 원래 시간선 복원 비용을 함께 송출한다. 지역별 요구가 갈리고 복원파와 생존선별파가 서로 다른 명분으로 동시에 본부 장악을 시작한다. 귀환실과 기록소에서 서로 다른 시간임무 승인 신호가 켜진다.
- E069 `정권보다 먼저 지킬 것` — 기록소·배급소·귀환실이 각기 다른 세력에 포위된다. 에이든은 지도부 구출보다 민간 귀환망과 환자구역 방어를 우선한다. 복원파가 원래 시간선 좌표를 장치에 강제로 주입하고, 생활 고정망의 에너지가 빠지면서 병실 환자 이름이 실시간으로 바뀌기 시작한다.

## Information Ceiling
- 기록망 운영자의 비밀 거래는 확인하되 최종 배후로 확정하지 않는다.
- 마르칸을 단순 은폐자나 최종 악역으로 축소하지 않는다.
- 복원파 주장의 사실 부분과 현재 전체를 지워도 된다는 결론을 분리한다.
- 다렌은 합류하지 않는다. 몇 분의 지연만 허용한다.
- 원래 시간선 복원이 실제로 누구를 되살리고 누구를 지우는지 확정하지 않는다.
- E069에서 강제좌표 가동의 즉시 비용까지만 보여 주고 다음 회차의 공통자원 차단 해결을 당겨 쓰지 않는다.

## Exit
E069 종료 시 중앙 권위는 흔들리고 두 진영이 서로 다른 시간임무를 강제하려 한다. 민간 생존기능과 시간장치가 같은 자원을 공유한다는 위험이 실제 환자 변화로 드러난다.
