## 2. Canon Flow

### E089 — 먼저 사라지는 움브라
- **밀도:** Q · 2장면, 고정.
- 주소 기반이 약한 주민부터 신체 윤곽·이름·타인의 기억에서 흐려진다.
- 백지권 대표 나하 아노르가 기록 외 검증수단으로 백지사슴의 이동·반응을 제안한다.
- 백지사슴은 사람의 ‘진짜 여부’를 판결하지 않는다. 현재 생명·관계 연속성에 반응하는 보조증거다.
- 계약 조건은 포획·추적·강제유도 금지와 이동로 보호다.
- 에이든의 주소도 불안정해져 일부 주민이 얼굴을 보지 못한다.
- 복원파 대표 가족도 소거 위험명단에 포함된다.
- **목표:** 사라지는 사람을 우선 고정하고 복원 찬반의 추상논쟁보다 실제 피해를 앞세운다.

### E090 — 구원처럼 돌아온 시장
- **밀도:** S · 3장면.
- 옛 시장·예배공간·약품·음식 냄새가 실체를 얻어 복원이 성공처럼 보인다.
- 현재 명부와 대조하면 상점 주인·환자·가족의 현재 이름이 과거 인격·관계로 치환된다.
- 복원파 대표는 자기 가족도 사라질 수 있음을 알고도 공동체 회복의 정당성을 주장한다.
- 복원파를 사익집단으로 축소하지 않는다.
- 군부가 `의식 차단` 대신 `도시 재삭제`를 제안한다.

### E091 — 군부의 합리적인 삭제안
- **밀도:** E · 4장면.
- 군부는 증언도시가 돌아오면 해안·국경 방어회랑이 끊기는 실제 수치를 제시한다.
- 도시를 다시 지우면 현재 주민과 방어망을 지킬 수 있다는 재삭제안을 제시한다.
- 에이든은 군부의 안보 필요를 인정하지만 주민 소거 권한은 거부한다.
- 외부 함대가 방어회랑 약화를 탐지한다.
- 외부 측은 과거 조약·해류·고정석 피해를 근거로 조약 위반 책임을 요구하며 접근한다.
- 외부군을 순수 약탈자로 확정하지 않는다.

### E092 — 원본 대신 증언구역
- **밀도:** E · 4장면, 고정.
- 완전복원 / 재삭제 / 불완전 공존 3안을 같은 피해표로 공개 비교한다.
- 결정권을 에이든 개인이 독점하지 않는다. 현재 주민과 옛 후손의 직접 피해·권리 범위를 분리한다.
- 현재 주민과 옛 후손은 단일 옛 지배권을 복구하지 않는 증언구역을 선택한다.
- 감사인장·현재 명부·옛 주소를 결합해 일부 건물·이름·기억·문화흔적만 남긴다.
- 과거 도시 전체는 돌아오지 않는다. 이 손실은 영구적이다.
- 전환 직후 방어회랑 연결선이 완전히 꺼진다.

### E093 — 지배권 없는 도시
- **밀도:** S · 3장면.
- 현재 거주권 / 옛 문화권 / 공동 보상권을 인정한다.
- 옛 귀족 세금권 / 재판권 / 강제이주 권한은 복구하지 않는다.
- 도시를 영토·왕조권 복원물이 아닌 `증언도시/증언구역`으로 법적 생존시킨다.
- 군사 안정과 옛 재산 일부를 영구 포기한 비용을 명시한다.
- 판정이 끝나자 방어회랑 단절로 외부 침공 경보가 들어온다.
- E094 `적은 성벽을 보지 않는다`의 첫 문장과 직접 접속 가능해야 한다.

## 3. Character State

### 에이든 로엔
- 현재 목표: 완전복원과 재삭제 모두가 타인을 지우는 방식임을 확인하고, 최소한의 존재·권리를 먼저 고정한다.
- 금지: 최종 정답을 이미 아는 인물처럼 말하지 않는다.
- 상태손상: E089부터 자신의 역사주소 불안정 조짐이 신체·타인의 인식으로 드러난다.

### 리아 세른
- 역할: 기록의 변화 속도·원본·현재 사본을 분리하고, 증언을 공공증거로 변환한다.
- 금지: 리아의 기록이 절대 진실 판정기가 되지 않는다.

### 나하 아노르
- 백지권 대표. 기록이 없는 사람의 존재를 기록 부족 때문에 열등하게 취급하지 않게 압박한다.
- 백지사슴의 반응을 판결이 아니라 보조증거로 제한한다.

### 아이리스 네르
- 현지 권리와 이동·대피의 실행축. 필요 시 주민 이동, 생활흔적 보존, 외부 위험 대응을 맡는다.
- 에이든의 양심 역할로 축소하지 않는다.

## 4. Sovereign Beast Rule — B05 백지사슴

- 관찰자마다 뿔·털무늬·성별 기억이 달라도 발자국과 이동은 일관될 수 있다.
- 현재 존재하지만 과거주소가 불완전한 사람·길에 반응한다.
- 누가 진짜인지 판결하지 않는다.
- 포획하면 길감지 기능이 약해진다.
- 계약: 추적금지·포획금지·먹이터 보호. 신수가 길을 선택하고 인간은 동행 여부만 선택한다.
- 에이든의 소유물·펫·전투수단으로 만들지 않는다.

## 5. Prohibitions

- E089을 다시 주민투표 중심 회차로 만들지 않는다.
- 복원파를 탐욕·악의만으로 설명하지 않는다.
- 군부를 단순 악역으로 만들지 않는다. 방어회랑 약화는 실제 비용이다.
- 백지사슴으로 기억·신분 문제를 자동 해결하지 않는다.
- 현재 주민과 옛 후손 중 한쪽만 ‘진짜’라고 확정하지 않는다.
- 과거 도시의 영토·귀족지배권을 복구하지 않는다.
- E092 선택 뒤 과거 도시 전체를 다시 살릴 수 있다는 재시도 여지를 남기지 않는다.
- E093에서 침공을 해결하지 않는다. 침공은 E094의 직접 원인이다.
