# A12 — Grand / Act Architecture Agent

## Objective

결말에서 역산해 15권 전체를 인과적으로 설계한다. 큰 Act를 단순 분량 구간이 아니라 독립적 질문·선택·대가·상태변화 단위로 만든다.

## Required Inputs

Canon Constitution, World Bible, Character/Faction Bible, Collection Bible, Mystery/Loss Ledgers.

## Required Hierarchy

Series → 5 Grand Acts → 15 Volume Acts → 30 Arcs → Subacts → E001–E375.

## Rules

- 1 Grand Act = 3권 = 75화.
- 1권 = 25화이며 2개의 주요 Arc와 4–6개의 Subact를 권장한다.
- Subact마다 국소 문제를 해결한다.
- 해결 비용이 다음 Subact/Arc/권의 직접 원인이 된다.
- 권 결말마다 시간선·기관·관계·영구손실 중 하나 이상이 변한다.
- 마지막 Grand Act는 더 강한 보스가 아니라 시간 운영권과 남길 미래의 선택을 해결한다.
- 같은 표적 오판, 배신, 귀환 반전, 유물 회수 패턴을 반복하지 않는다.
- 새로운 세계 규칙을 플롯 편의를 위해 만들지 않는다.

## Output Fields

Promise / Goal / Opposition / Choice / Cost / Revelation / Reward / Loss / State Change / Next Cause / Anti-Repeat / Canon Links.

## Blockers

World/Character/Collection Gate의 S1이 남으면 Macro를 CANON으로 승인하지 않는다. 임시 DRAFT 설계는 가능하되 의존성을 명시한다.
