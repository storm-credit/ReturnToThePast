# 느와르 치환 가이드

이 작품은 귀환담처럼 오해되더라도, 표면 언어는 다크 판타지 느와르여야 한다.

## 금지 계열

- 시스템, 상태창, 퀘스트, 스킬, 데이터, 팩트, 백도어
- AI, 로봇, 스마트폰, 다운로드, 해킹
- 미터, 센티, 초침 같은 현대 측정 감각
- `S급`, `랭크` 같은 게임형 계급 표현

## 권장 치환

| 금지 표현 | 권장 표현 |
| --- | --- |
| 시스템 경고 | 통증, 이명, 잔향, 몸의 경련 |
| 데이터 | 기록, 흔적, 장부, 증언 |
| 타임라인 | 날짜, 시간 흐름, 사건 순서 |
| 스킬 | 술식, 권능, 비기 |
| 레벨/랭크 | 태그, 격, 경지 |

## 추가 원칙

- 기계적 설명보다 대가와 체감을 앞세운다.
- 인과율을 괴물처럼 과도하게 의인화하지 않는다.
- 현대식 UI를 떠올리게 하는 문장을 쓰지 않는다.
- 느와르는 과장된 고어 미학이 아니다. 피를 전면에 내세우기보다 축축한 공기, 통증의 잔향, 뒤늦게 밀려오는 대가로 압박한다.
