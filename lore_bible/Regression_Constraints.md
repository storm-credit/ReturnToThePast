# 표면 회귀 제약 조건

> **핵심 법칙 1**: 시간은 공짜로 열리지 않는다.
> **핵심 법칙 2**: 바꾼 결과는 반드시 다른 곳에서 값을 받아 간다.

> **제작자 메모**
> 에이든과 독자는 이 현상을 오랫동안 `회귀`라고 부른다.
> 하지만 구조의 진실은 멸망한 미래에서 에이든의 의식이 과거 육체로 강제로 되밀려 오는 비극적 시간여행이다.
> 에이든은 시전자가 아니라 대상이다.

---

## 1. 발동 조건

| 조건 | 설명 |
|------|------|
| **트리거** | 에이든의 완전한 죽음 혹은 의식 소멸 |
| **귀환 시점** | 같은 출발점으로 보이지만, 인과 오차 때문에 세부는 미세하게 어긋날 수 있음 |
| **체감** | 동전이 바닥을 긁는 듯한 소리, 영혼이 뜯겨 나가는 통각, 이어지는 강제 귀환 |

> **핵심 제한**
> 육체는 출발 시점의 허약한 상태로 돌아간다.
> 기억은 모두 또렷이 남지 않고, 오래된 죽음은 통각과 기시감, 패턴 감각으로 마모되어 남는다.

---

## 2. 대가의 층위

> 작은 개입은 감정을 깎고, 큰 개입은 관계와 신체를 깎고, 금기는 존재를 갉아먹는다.

| 층위 | 주로 잃는 것 | 적용 예시 |
|------|--------------|-----------|
| **감정** | 설렘, 유대, 애착, 안식 | 누군가를 살리거나 운명을 미세하게 틀었을 때 |
| **관계** | 타인의 기억 속 자리, 관계의 결 | 동료를 지키기 위해 인과를 도려낼 때 |
| **신체** | 수명, 감각, 회복력, 미래 기억의 선명도 | 권능을 억지로 끌어쓸 때 |
| **존재** | 이름, 흔적, 인과적 좌표 | 금기와 봉인을 정면으로 건드릴 때 |

## 3. 확정된 대가

| 행위 | 대가 | 비고 |
|------|------|------|
| **리아 구출** (Vol. 1) | 리아에 대한 설렘과 떨림 약화 | 소중함은 아는데 가슴이 먼저 뛰지 않는다 |
| **아이리스 생존** (Vol. 2) | 아이리스와의 유대감 약화 | 머리로는 신뢰하지만 감정이 따라오지 않는다 |
| **황제의 죽음 시각 조작** (Vol. 5) | 황제에게 받았던 유일한 인정의 온기 마모 | 정치적 이득을 얻은 대신 인간적 잔열이 흐려진다 |
| **괴수전 돌파** (Vol. 7) | 동료들과의 따뜻한 기억 다수 마모 | 관계가 논리로만 유지되기 시작한다 |
| **동료 보호용 기억 덮어쓰기** (Vol. 8) | 타인의 기억 속 에이든 존재 소거 | 감정 대가를 넘어 존재가 가격이 된다 |
| **찰나 사용** (Vol. 9 이후) | 수명 1년 + 앞으로 생겨날 기억의 윤곽 한 겹 | 과거는 선명하고 아직 오지 않은 날들은 점점 흐릿해진다 |

---

## 4. 인과의 채권

> 잔향은 빚을 받으러 온다.

- **채권자**: 잔향, 나중에 영시와 연결되는 존재
- **채무**: 에이든이 시간을 비틀 때마다 세계에 남기는 반작용
- **증상**:
  - 세계 채도 저하
  - 얼굴과 풍경이 흐릿하게 보이는 인식 왜곡
  - 잔향과 항체의 개입
- **파산 상태**: 빚이 한계를 넘으면 대균열이 발생하고 시간 구조가 뒤집힌다

---

## 5. 절대 제한

| 조건 | 이유 |
|------|------|
| **자해로 우회하기** | 일반 시간선에서는 더 나은 출발점을 고를 수 없다. 제 손으로 죽음을 택해도 빚만 깊어지고 영혼 손상만 심해진다 |
| **영시 소멸** | 채권자 구조가 무너지면 귀환 체계도 끝에 가까워진다 |
| **인과 핵심 파괴** | 시간 구조 자체가 무너질 위험이 있다 |

## 6. 예외 조건

| 예외 | 설명 |
|------|------|
| **시간의 감옥** | 감옥 내부의 죽음은 탈출이 아니라 같은 하루로 다시 묶이는 국지 반복이다. 감옥이 영혼 파편을 아침마다 강제로 꿰매므로 바깥의 귀환과는 다르다 |
| **발타자르** | 인과에 새겨진 존재라 인간형 기억 조작의 영향에서 부분적으로 비껴간다 |
| **찰나** | 빚을 한꺼번에 치르는 권능. 강하지만 수명과 미래 기억을 깎는다 |
| **망한 시간선 소환** | 이미 파산한 세계의 무기를 빌려오므로 이자가 극단적으로 크다 |
