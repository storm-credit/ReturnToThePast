# 강제 귀환 잔재 문법

이 문서는 강제 귀환 이후 인물과 세계에 남는 잔재를 어떤 규칙으로 읽는지 정리한다.

핵심은 이것이다.

- 잔재는 `능력`이 아니다.
- 잔재는 `강제 귀환이 남긴 실패 흔적`이다.
- 따라서 잔재는 편의보다 비용, 통찰보다 마모, 이득보다 어긋남을 먼저 만든다.

## 기본 원칙

1. 잔재는 항상 `몸의 늦음`이나 `감각의 어긋남`으로 먼저 나타난다.
2. 잔재는 미래 지식을 공짜로 주지 않는다.
3. 잔재가 강할수록 감정 마모, 기억 혼탁, 판단 지연이 함께 온다.
4. 후영, 영시, 기억 파편, 항체 반응은 서로 분리된 현상이 아니라 같은 구조의 다른 표면이다.

## 잔재의 종류

### 1. 후영

- 정의:
  - 실패한 강제 귀환의 흔적층
- 효과:
  - 공포, 멈춤, 판단 흐림, 뒤늦은 반응
- 금지 해석:
  - 정답을 주는 예지체

### 2. 영시

- 정의:
  - 고정점 압력과 강제 귀환 구조가 가장 선명하게 드러나는 시각
- 효과:
  - 사건의 본질이 아니라 `사건을 견디는 비용`을 더 선명하게 보여 준다
- 금지 해석:
  - 무엇이든 볼 수 있는 전지 시점

### 3. 기억 파편

- 정의:
  - 한 번에 읽히지 못한 체험이 뒤늦게 몸에 긁히는 현상
- 효과:
  - 도움이 될 수는 있으나, 항상 타이밍 지연과 고통을 동반한다
- 금지 해석:
  - 반복 회차의 공략 기억

### 4. 밀린 박자

- 정의:
  - 몸과 감각, 판단이 같은 시각에 도착하지 못하는 후유증
- 효과:
  - 전투/잠입/판단에서 미세하게 늦는다
- 금지 해석:
  - 약한 초능력의 초기 단계

## 항체와의 관계

- 항체는 단순 추적자가 아니다.
- 잔재가 큰 자일수록 항체와 더 강하게 물린다.
- 즉 항체는 제거기이면서, 동시에 `강제 귀환 적합성`을 가려내는 냉혹한 필터로 읽힌다.

## 의식/봉인과의 관계

- 성전 정화 의식 일부는 치료보다 `잔재 둔화`에 가깝다.
- 봉인 구역 일부는 괴물 보관고이면서 동시에 `강제 귀환 흔적 은폐` 장치일 수 있다.
- 따라서 의식과 봉인은 선의/악의로만 나뉘지 않는다.

## 집필 메모

- 잔재는 설명보다 증상으로 먼저 보여 준다.
- 좋은 판단을 돕더라도, 반드시 늦음이나 마모를 함께 남긴다.
- 독자는 `도움이 된다`보다 `점점 사람을 깎아 먹는다`를 먼저 체감해야 한다.
