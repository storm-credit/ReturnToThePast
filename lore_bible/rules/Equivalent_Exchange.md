# 등가교환 규칙

시간을 비틀면 반드시 값을 낸다.
이 문서는 각 권에서 무엇을 얻고 무엇을 잃는지 고정하는 기준표다.

## 대원칙

- 작은 개입은 감정을 깎는다.
- 큰 개입은 관계와 신체를 깎는다.
- 금기는 존재와 미래를 갉아먹는다.
- 여러 대가가 겹칠 수 있어도, `이번 개입의 본값`은 문서마다 하나로 고정한다.
- 대가 없는 승리는 금지한다.

## 대가의 층위

| 층위 | 설명 |
| --- | --- |
| **감정** | 설렘, 애착, 전우애, 안식 같은 인간적 온기 |
| **관계** | 타인의 기억 속 자리, 서로를 이어 주는 결 |
| **신체** | 수명, 감각, 회복력, 아직 오지 않은 날을 느끼는 힘 |
| **존재** | 이름, 흔적, 인과적 자리 자체 |

## 확정된 대가

| 권 | 행위 | 상실 |
| --- | --- | --- |
| Vol.1 | 리아를 구함 | 리아에 대한 설렘과 떨림 |
| Vol.2 | 아이리스를 살림 | 아이리스와의 전우애 |
| Vol.5 | 황제의 죽음을 정치적으로 비틂 | 황제에게 받았던 유일한 인정의 온기 |
| Vol.7 | 제국을 구함 | 동료들과의 따뜻한 기억 |
| Vol.8 | 동료를 지킴 | 자신에 대한 타인의 기억 |
| Vol.9 | 찰나 사용 | 수명 1년 + 앞으로 생겨날 기억의 윤곽 한 겹 |

## 집필 체크

- 이번 화에서 에이든은 무엇을 얻었는가
- 그 대가로 무엇을 잃었는가
- 이미 잃은 감정이나 관계를 다시 멀쩡하게 느끼고 있지 않은가
- 대가를 시스템 메시지처럼 설명하지 않았는가
