# 같은 사건의 다른 이름 장부

이 문서는 제국의 서로 다른 기관이 `같은 사건`을 어떻게 `다른 이름`으로 기록하는지 정리한 장부다.

목적은 세 가지다.

- 같은 사건이 시대와 기관에 따라 다른 이름으로 불린다는 층을 고정한다.
- 후반부 기록 반전과 조직 기원 반전을 준비한다.
- 독자가 나중에 `서로 다른 사건인 줄 알았던 것`이 사실 하나의 사건임을 공정하게 따라가게 만든다.

## 운용 규칙

- `황궁`: 정치적 사건명, 의전 언어, 체면 보존
- `상아 의정회`: 통제/징수/기록 언어
- `학회`: 실험/현상/관측 언어
- `성전`: 징조/모독/봉인 언어
- `하층`: 소문/속칭/생활 언어

## 핵심 사건

### 1. 황제의 정시 사망

- 황궁: `정시 붕어`
- 상아 의정회: `왕좌 이행`
- 학회: `시각 변조 사건`
- 성전: `왕조 단절의 징후`
- 하층: `왕이 제시간에 죽은 밤`

설명:

정치적으로는 단순한 붕어와 계승으로 처리되지만, 다른 기관은 이 사건을 `시간이 어긋난 죽음`으로 본다.

### 2. 강제 귀환 술식의 최초 발동

- 황궁 비록: `기록 불능의 밤`
- 상아 의정회: `금기 개문`
- 학회: `인과 접속 사고`
- 성전: `시간 모독`
- 하층: `죽은 시간이 되돌아친 밤`

설명:

각 기관은 이 사건의 본질을 숨기기 위해 자기 언어로 갈라 기록한다.
후반에는 이 다섯 이름이 모두 같은 밤을 가리킨다는 사실이 드러난다.

### 3. 하늘의 균열 최초 관측

- 황궁: `북문 상공 이상광`
- 상아 의정회: `징수 개시 징조`
- 학회: `천공 균열 현상`
- 성전: `성흔의 개열`
- 하층: `하늘에 금 간 날`

설명:

겉으론 기상 이상이나 불길한 징조처럼 다뤄지지만, 실제로는 세계 단위 고정점 압력이 밖으로 새기 시작한 사건이다.

### 4. 해방자 첫 투입

- 황궁: `특수 병기 실전 사용`
- 상아 의정회: `부채 촉발 사례`
- 학회: `금지 개체 전장 배치`
- 성전: `사람 아닌 칼의 표식`
- 전선군: `해방자 투입전`

설명:

영웅 서사가 아니라, `세계 규칙을 더럽히는 도구`를 각 기관이 서로 다른 책임 언어로 감추는 사건이다.

### 5. 대재앙 / 전면 붕괴 개시

- 황궁: `전시 체제 전환`
- 상아 의정회: `장부 회수 국면`
- 학회: `항체 범람`
- 성전: `말세 전조`
- 하층: `세상이 무너진 날`

설명:

모든 기관이 `같은 파국`을 자기 언어로 축소하거나 왜곡한다.
이 장부는 후반 기록층 교차 장면의 기준 문서로 쓴다.

## 집필 메모

- 초반에는 각 기관 언어를 섞되, 독자가 즉시 같은 사건으로 알아보지 못하게 한다.
- 중반에는 같은 날짜, 같은 냄새, 같은 흔적을 반복해 겹친다.
- 후반에는 사건명이 아니라 `흔적과 기록물`로 먼저 묶은 뒤 이름을 뒤늦게 합친다.
