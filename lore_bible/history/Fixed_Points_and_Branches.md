# 고정점과 분기점

이 문서는 시간여행 패러독스 감사에서 반드시 확인해야 할 기준표다.

## 사용 원칙

- **고정점**: 쉽게 바뀌지 않는 큰 흐름
- **분기점**: 에이든의 개입으로 결과와 여파가 크게 달라질 수 있는 사건
- 아웃라인과 타임라인은 이 표를 어기면 안 된다.

## 현재 잠금된 고정점

| 구분 | 내용 | 비고 |
| :--- | :--- | :--- |
| **고정점** | 황제의 죽음 | 시각과 방식은 흔들 수 있어도 죽음 자체는 쉽게 지워지지 않음 |
| **고정점** | 세계가 파국으로 기울어 있다는 큰 흐름 | 부분 지연은 가능해도 전체 붕괴 압력은 남음 |
| **고정점** | 시간 개입에는 대가가 따른다 | 공짜 개입 금지 |

## 현재 확인된 분기점

| 구분 | 내용 | 비고 |
| :--- | :--- | :--- |
| **분기점** | 리아 구출 방식과 시점 | 감정 대가와 이후 관계에 영향 |
| **분기점** | 아이리스 계약 성사 방식 | 유대와 전우애 손실에 영향 |
| **분기점** | 멸망 시간선 무기 사용 여부 | 항체와 전쟁 규모에 영향 |
| **분기점** | 기억 덮어쓰기 금기 사용 | 에이든의 사회적 존재와 후반 신뢰선에 영향 |
| **분기점** | 영시가 되느냐 인간으로 돌아가느냐 | 최종 결말 선택 |

## 감사 메모

- 새로운 권을 설계할 때는 이 사건이 고정점인지 분기점인지 먼저 표시한다.
- 분기점은 반드시 대가, 후유증, 다음 권 여파까지 기록한다.
