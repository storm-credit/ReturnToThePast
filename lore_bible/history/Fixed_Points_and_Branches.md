# 고정점과 분기점

이 문서는 시간여행 패러독스 감사에서 반드시 확인해야 할 기준표다.

## 사용 원칙

- **고정점**: 쉽게 바뀌지 않는 큰 흐름
- **분기점**: 에이든의 개입으로 결과와 여파가 크게 달라질 수 있는 사건
- 아웃라인과 타임라인은 이 표를 어기면 안 된다.

## 현재 잠금된 고정점

| 구분 | 내용 | 비고 |
| :--- | :--- | :--- |
| **고정점** | 황제의 죽음 | 시각과 방식은 흔들 수 있어도 죽음 자체는 쉽게 지워지지 않음 |
| **고정점** | 세계가 파국으로 기울어 있다는 큰 흐름 | 부분 지연은 가능해도 전체 붕괴 압력은 남음 |
| **고정점** | 시간 개입에는 대가가 따른다 | 공짜 개입 금지 |

## 현재 확인된 분기점

| 구분 | 내용 | 비고 |
| :--- | :--- | :--- |
| **분기점** | 리아 구출 방식과 시점 | 감정 대가와 이후 관계에 영향 |
| **분기점** | 아이리스 계약 성사 방식 | 유대와 전우애 손실에 영향 |
| **분기점** | 멸망 시간선 무기 사용 여부 | 항체와 전쟁 규모에 영향 |
| **분기점** | 기억 덮어쓰기 금기 사용 | 에이든의 사회적 존재와 후반 신뢰선에 영향 |
| **분기점** | 영시가 되느냐 인간으로 돌아가느냐 | 최종 결말 선택 |

## 후반부 고정점 요약

| 구분 | 내용 | 비고 |
| :--- | :--- | :--- |
| **고정점** | 제12권 영시의 정체 공개 | 공개 경로와 목격자 구성은 흔들려도, 채권자의 진실이 드러나는 축은 남아야 한다 |
| **고정점** | 제13권 대균열 발생 | 장소와 전장 모양은 달라져도, 미지급 하중이 세계 단위 파열로 번진다는 사실은 남는다 |
| **고정점** | 제15권 최종 선택 | 무엇을 붙들고 무엇을 포기하는지의 모양은 달라질 수 있어도 마지막 대가 지불은 빠질 수 없다 |

## 후반부 주요 분기점

| 구분 | 내용 | 비고 |
| :--- | :--- | :--- |
| **분기점** | 제12권 진실 공개 순서 | 에이든, 리아, 아이리스, 독자가 무엇을 어떤 순서로 아는지에 따라 정서 충격이 달라진다 |
| **분기점** | 제13권 생존권 배분 | 누가 균열 속에서 살아남고 무엇을 잃는지에 따라 후반 정서선이 달라진다 |
| **분기점** | 제14권 인간 잔여 보존 여부 | 관계, 기억, 이름 중 무엇을 끝까지 붙드는지에 따라 엔딩의 결이 갈린다 |
| **분기점** | 제15권 귀환 후 잔흔 | 세계가 얼마나 원상을 회복하는지보다, 누가 빚의 흔적을 떠안는지가 더 중요하다 |

## 감사 메모

- 새로운 권을 설계할 때는 이 사건이 고정점인지 분기점인지 먼저 표시한다.
- 분기점은 반드시 대가, 후유증, 다음 권 여파까지 기록한다.
- 후반부는 `무엇이 밝혀지는가`보다 `누가 그 값을 대신 치르는가`를 함께 적는다.
