# 🏙️ 크로니아 제국 수도 - 세라핌 (Seraphim) 전체 구역도

> **제국**: 크로니아 제국 (Empire of Chronia)
> **수도**: 세라핌 (Seraphim). 이명: '멸망의 요람'
> **구조**: 수직형 다층 도시. 총 10개 행정 구역.

---

## 🏗️ 수직 구조 (The Vertical Structure)


## 📍 구역 상세 (Zone Details)

### [최상층] 제1구역 - 황궁 지구
| 항목 | 내용 |
|------|------|
| **명칭** | 왕관 정원 |
| **거주민** | 황족, 근위대 |
| **특징** | 마법 결계로 외부인 출입 불가. 마나열병 완전 차단. |
| **핵심 장소** | **제3 하역문**: 하급 시종과 물자 출입용 뒷문. 출입 시 핵심 마도문 감식을 거침. |
| **비고** | 병든 황제가 칩거 중. 실권은 상아 의정회에. |

### [최상층] 제2구역 - 대귀족 지구
| 항목 | 내용 |
|------|------|
| **명칭** | 황혼의 첨탑 |
| **거주민** | 대귀족, 고위 관료, 기사단 본부 |
| **특징** | 공중 정원, 마법 가로등. 1년 내내 쾌적한 기후 유지. |
| **비고** | 에이든의 눈(인과율 시선)에는 금이 가고 뒤틀린 형상으로 보임. |

### [중층부] 제3구역 - 학회/상업 지구
| 항목 | 내용 |
|------|------|
| **명칭** | 종루 광장 |
| **거주민** | 중산층, 학생, 상인 |
| **특징** | 제국 아카데미, 도서관, 상점가. 방벽으로 하층부와 격리. |
| **핵심 장소** | **외곽 도살장 뒷골목**: 장물아비 '얼굴 없는 토마스'의 은밀한 거래 거점. |
| **비고** | 검문이 삼엄. 하층부 출신은 통행증 없이 출입 불가. |

### ☠ [붕괴층] 제4구역 - 폐쇄 구역
| 항목 | 내용 |
|------|------|
| **명칭** | 철의 묘지 (Iron Graveyard) |
| **과거** | 원래 중층부였으나, 내전 당시 전략 폭격으로 **통째로 붕괴**. |
| **현재** | 하층부로 추락하여 빈민가의 일부가 됨. 녹아내린 철골만 남은 폐허. |
| **지배** | **펜리르 (Fenrir)** 본거지. 류드의 지휘소 = 무너진 시계탑. |
| **위험** | 출입 시 즉시 포위당함. 늑대 가면의 보초가 상시 감시. |

### [중층부] 제5구역 - 연금술 학회 본부
| 항목 | 내용 |
|------|------|
| **명칭** | 백탑 |
| **거주민** | 연금술사, 연구원, 학회 소속 기사 |
| **특징** | 지상: "마나열병 치료제 개발" 홍보. 지하: **마나열병 강화 실험**. |
| **비고** | 지하 7층에 '0호 실험실' 존재. (리아 감금 장소였음) |

### [하층부] 제6구역 - 입구/검문 지구
| 항목 | 내용 |
|------|------|
| **명칭** | 경계문 |
| **거주민** | 용병, 밀수업자, 뇌물 담당 경비 |
| **특징** | 상층부와 연결된 유일한 승강기. 통행료(뇌물) 필수. |

### [하층부] 제7구역 - 검은 시장 / 녹투르 공방 일대
| 항목 | 내용 |
|------|------|
| **명칭** | 검은 시장 |

| **핵심 장소** | **녹투르 공방** — 에이든의 거점. 지하에 연금술 설비. |

### [하층부] 제8구역 - 환락/정보 지구
| 항목 | 내용 |
|------|------|
| **명칭** | 붉은 골목 |
| **거주민** | 도박사, 매춘부, 정보상 |
| **특징** | 검은 개 부대 영향권. 투기장 `혈투장` 소재. |
| **핵심 장소** | **검은 개의 소굴** — 암살 의뢰 창구. |

### [하층부] 제9구역 - 빈민/격리 지구

| **특징** | 마나열병 격리 구역. 환자들이 시체처럼 방치. 구울(Ghoul) 출몰 위험. |
| **비고** | 들개들이 최소한의 치안 유지. |

| 항목 | 내용 |
|------|------|

| **거주민** | 없음 (공식적으로) |
| **특징** | 검은 개의 비밀 통로가 거미줄처럼 연결. 학회 지하 실험실 접근 루트. |
| **위험** | 마나열병 변이체(구울) 서식. 고대 문명의 함정. |

## ⚠️ 위험 요소

1.  **마나열병 (Mana Fever)**: 마나 거부 반응. 신체가 돌처럼 굳어감. (속칭: 회색 역병)
2.  **검은 곰팡이**: 건물 벽면 기생. 마나 흡수. 피부 괴사 유발.
3.  **앰플 (Ampoule)**: 마법사 필수품이자 마나열병 매개체. 빈민가에서 마약처럼 유통.
