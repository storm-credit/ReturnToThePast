# 💰 경제 및 화폐 시스템 (Economy & Currency)

> 제국 표준 화폐 체계

---

## 🪙 화폐 단위

| 화폐 | 가치 | 비고 |
|------|------|------|
| **동화 (Copper)** | 1c | 서민의 최소 거래 단위 |
| **은화 (Silver)** | 1s = 100c | 일반적인 거래 단위 |
| **금화 (Gold)** | 1g = 100s | 고가품, 장비 거래 |
| **백금화 (Platinum)** | 1p = 100g | 국가 간 거래, 보물 |

---

## 🍞 물가 예시

| 품목 | 가격 | 비고 |
|------|------|------|
| **빵 1개** | 5c | - |
| **맥주 1잔** | 10c | - |
| **여관 1박 (일반)** | 50c ~ 1s | 식사 포함 |
| **철제 검 (일반)** | 5g | 병사 지급용 |
| **상급 포션** | 50g | 생명 30% 회복 |
| **아카데미 학비** | 1,000g / 년 | 장학금 없으면 거액 |
| **귀족 저택** | 10,000g ~ | 수도 기준 |

## ⚖️ 에이전트 지침

```
[RULE: ECONOMY_SCALE]
- 1골드 = 현대 가치 약 10만원 정도의 체감.
- 에이든이 초반에 가난한 이유: 학비 + 포션값.
- "엄청난 돈" = 100골드 이상.
```
