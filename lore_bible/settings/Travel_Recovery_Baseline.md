# 이동과 회복 기준선

이 문서는 권별 타임라인의 개연성을 점검할 때 쓰는 기준선이다.
구체적 사건 문서가 있으면 그 문서를 우선하고, 없으면 이 기준선을 사용한다.

## 이동 기준

| 상황 | 기준선 |
| :--- | :--- |
| 같은 구역 내 이동 | 같은 날 처리 가능 |
| 수도 내부 장거리 이동 | 반나절에서 하루 |
| 수도 외곽 왕복 | 최소 하루 이상 |
| 북부 전선급 장거리 이동 | 수일 이상 전제 필요 |
| 부상자/장물/금기 병기 동반 이동 | 평시 이동의 1.5배 이상 잡는다 |
| 검문/봉쇄가 걸린 수도 이동 | 뇌물, 우회, 야간 이동까지 포함해 하루 이상 여유를 둔다 |
| 전선 재배치 | 병력보다 보급마차와 부상자 수송 속도에 맞춰 계산한다 |

## 보급 기준

| 상황 | 기준선 |
| :--- | :--- |
| 전시 전선의 식량/약품 | 보급선이 끊기면 3일 안에 체감 부족이 시작된다 |
| 에테르/진통제/소독약 | 일반 식량보다 먼저 바닥나기 쉽다 |
| 금기 병기 운용 | 사용 자체보다 운반, 보정, 은폐에 시간이 더 든다 |
| 민간인 후송 동반 전선 | 전투 속도보다 후송 속도가 전체 진격 속도를 늦춘다 |
| 폐허/붕괴 지형 | 지도상 거리보다 우회와 잔해 정리에 더 많은 시간이 든다 |

## 회복 기준

| 상태 | 기준선 |
| :--- | :--- |
| 경미한 타박상/열상 | 다음 날 행동 가능하나 통증 잔존 |
| 중간급 부상 | 수일간 전투력 저하 반영 필요 |
| 골절/심부 자상/장기 손상급 | 즉시 전력 복귀 금지 |
| 금기 사용 후 반동 | 육체뿐 아니라 감정/기억/집중력 저하까지 반영 |
| 절단/절제 | 당일 지혈·소작·고정은 가능하나, 이후 수일간 고열·환지통·실혈 반응을 반영한다 |
| 수면 박탈 + 각성제 버팀 | 판단 속도는 유지돼도 손 떨림, 구토감, 감정 둔화가 쌓인다 |
| 기억 소거/정체성 훼손 계열 금기 | 육체보다 방향감각, 자기 확신, 대인 반응의 지연을 우선 반영한다 |

## 운영 원칙

- 타임라인은 이동, 준비, 잠복, 회복을 모두 계산해야 한다.
- 전투 직후 다음 전투로 넘어갈 때는 부상과 자원 소모를 무시하지 않는다.
- 등가교환 대가는 감정만이 아니라 행동 속도와 판단력에도 영향을 줄 수 있다.
- 전쟁 권에서는 `누가 싸우는가`만큼 `누가 옮기고, 누가 치료하고, 누가 굶는가`를 같이 계산한다.
- 장면 사이에 며칠이 비면, 그 사이에 있었던 보급 재편·야전 처치·검문 우회 같은 압박을 한 줄이라도 남긴다.
