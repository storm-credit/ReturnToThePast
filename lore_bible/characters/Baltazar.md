# 🎭 발타자르 — 안내자 / 각인된 자

> *"시간의 법칙 앞에서 겸손해라, 소년. 나도 한때 그걸 배웠다."*

## 1. 프로필

| 항목 | 설정 |
|------|------|
| **이명** | 이단 연금술사, 각인된 자 |
| **표면 신분** | 학회 출신 배반자. 에이든의 스승 |
| **진실** | 영시(0회차)가 만든 **"각인된 존재"**. 인과율의 틈새에 박힌 안내자 |
| **외모** | 은발에 깊은 주름. 한쪽 눈이 의안(유리안). 깡마른 체격. |

## 2. 서사 역할: 미끼 단서의 중심

> 독자가 "이 사람이 '잔향'이다"라고 확신하게 만드는 장치

*   **제6권**: 학회 암살자의 시간 술식을 해독하며 **"내 이론이다"**라고 발언. (사실은 0회차의 지식)
*   **제8권**: **기억 덮어쓰기 면역**. 에이든이 기억을 지워도 그를 기억함.
    *   독자: "아! 흑막이라서 기억하는구나!"
    *   진실: **인과에 각인된 존재**라서 인간의 정신 마법이 통하지 않음.
*   **제11권**: 탑에서 사망하며 유언. **"나는 안내자였을 뿐이다. 거울을 봐라."**

## 3. 정체: 각인된 존재
*   ~~프로그램~~ → **각인된 자 / 인공 생명(호문클루스)**
    *   영시가 자신의 권능으로 빚어낸 호문클루스.
    *   오직 '에이든을 인도한다'는 목적만 입력되어 있음.
    *   그래서 감정 대가의 영향을 받지 않음. (영혼이 없으므로)

## 4. 진정한 충성
*   발타자르는 자신이 만들어진 존재임을 안다.
*   하지만 영겁의 시간선 끝에서 감정을 잃어버린 에이든을 가르치며 **진짜 스승으로서의 애정**을 느낌.
*   제11권에서 에이든 손에 죽는 것은, **제자가 스승(가짜 껍질)을 깨고 나아가게 하려는** 마지막 수업.

## 5. 미끼 단서 기능

- 발타자르는 충분한 의심을 짊어지되, 진실 전체를 혼자 먹어 치우면 안 된다.
- 그는 핵심을 쥔 주인이 아니라, 기관 가까이 묶인 존재라서 법칙의 파편을 설명할 수 있어야 한다.
- 독자는 그를 정당하게 과대평가했다가, 나중에 유도된 도구로 다시 읽게 되어야 한다.

## 6. 에이든과의 관계

- 겉모습: 수상한 스승
- 숨은 역할: 주인공을 이끌도록 새겨진 안내자
- 감정 기능: 법칙의 파편을 가르치되, 진짜 인간 스승을 대신하지는 못함
- 최종 쓰임: 정복이 아니라 인계
