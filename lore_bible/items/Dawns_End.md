# 💀 새벽의 종말 (Dawn's End) — 시온의 검

> **등급**: 전설급 → 재앙급 (타락)
> **소유자**: 시온 노스트론
> **의미**: 타락한 영웅의 상징

---

## 📋 기본 정보

| 항목 | 내용 |
|------|------|
| **정식 명칭** | 새벽의 종말 (Dawn's End) |
| **원래 이름** | 새벽의 유산 (황혼의 유산과 쌍검) |
| **외형** | 검은 금속 대검, 붉은 룬 문자, 검은 안개 |
| **상태** | 마력에 오염됨 |

---

## ⚔️ 능력

### 타락 전
| 능력 | 효과 |
|------|------|
| 혈통 인식 | 노스트론 혈통만 사용 |
| 빛의 검기 | 밝은 검기 발사 |

### 타락 후
| 능력 | 효과 |
|------|------|
| **어둠 흡수** | 적의 마나/생명력 흡수 |
| **공포 방출** | 주변에 공포 효과 |
| **영혼 절단** | 물리적 방어 무시, 영혼에 상처 |
| **재생 불가** | 이 검에 베인 상처는 치유 어려움 |

---

## 📜 스토리 역할

| 권 | 역할 |
|----|------|
| 8권 | 카엘과의 첫 대결, 카엘의 검 파괴 |
| 14권 | 시온의 마지막 무기 |
| 14권 말 | 시온 사망 후 정화, 두 검 융합 |

---

## 💫 형제의 융합

> 시온이 죽으면서 검의 저주가 풀림.
> 새벽의 종말 + 황혼의 유산 = **완전체 "여명의 검"**
> 카엘이 계승.
