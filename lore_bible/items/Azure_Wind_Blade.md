# 🌸 청풍검 (Azure Wind Blade) — 한소정의 검

> **등급**: 영웅급
> **소유자**: 한소정
> **의미**: 청풍검파의 유일한 유물

---

## 📋 기본 정보

| 항목 | 내용 |
|------|------|
| **정식 명칭** | 청풍검 (靑風劍, Azure Wind Blade) |
| **외형** | 청록색 빛나는 곡선형 검, 동방식 |
| **길이** | 100cm (도검) |
| **역사** | 청풍검파 초대 장문인이 사용 |

---

## ⚔️ 능력

| 능력 | 효과 |
|------|------|
| **바람 베기** | 검기에 바람 속성 부여 |
| **속도 증폭** | 사용자 공격 속도 증가 |
| **경공 보조** | 경공(輕功) 사용 시 마나 효율 증가 |
| **연환검** | 연속 공격 시 위력 누적 |

---

## 📜 스토리 역할

| 권 | 역할 |
|----|------|
| 4권 | 첫 등장 (동방 편 삭제 시 조정) |
| 8권 | 천왕 중 한 명과의 복수전 |
| 14권 | 최종 전쟁에서 활약 |

---

## 💫 배경

> 청풍검파가 멸문당할 때 유일하게 살아남은 유물.
> 한소정의 스승이 죽으며 물려줌.
> "파의 맥을 이어라"는 유언과 함께.

---

## 🗣️ 특수 기술

검에 담긴 청풍검법 비급:

| 초식 | 효과 |
|------|------|
| **청풍일섬** | 바람처럼 빠른 일격 |
| **천풍만검** | 수십 개의 검기 동시 발사 |
| **폭풍의 눈** | 자신 중심 회오리 방어 |
