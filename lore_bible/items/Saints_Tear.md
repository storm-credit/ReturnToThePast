# 성녀의 눈물 - 리아의 목걸이

> **등급**: 희귀급 → 전설급 (각성 후)
> **소유자**: 리아
> **용도**: 보호 + 정체 증거

---

## 📋 기본 정보

| 항목 | 내용 |
|------|------|
| **정식 명칭** | 성녀의 눈물 |
| **외형** | 은색 사슬, 투명한 물방울 모양 보석 |
| **기원** | 리아 가문 대대로 전해진 유물 |
| **진실** | 초대 시간의 성녀가 남긴 유물 |

---

## ⚔️ 능력

### 기본 상태 (1~6권)
| 능력 | 효과 |
|------|------|
| **치유 증폭** | 치유와 안정화의 효율이 크게 높아진다 |
| **보호막** | 위험 시 자동 보호막 발동 (1회) |
| **정화** | 약한 저주/독 해제 |

### 각성 후 (11권~)
| 능력 | 효과 |
|------|------|
| **시공 감응** | 시간 흐름 감지 |
| **성녀 인증** | 시간의 성녀임을 증명 |
| **에이든 연결** | 에이든의 위치/상태 감지 |

---

## 📜 스토리 역할

| 권 | 역할 |
|----|------|
| 1권 | 에이든이 리아에게 선물 (마법 각인 추가) |
| 4권 | 성전에서 "성녀 증거"로 인정 |
| 11권 | 리아의 진짜 능력 각성과 함께 변화 |
| 15권 | 인과율 소멸 후 평범한 보석이 됨 (추억으로) |

---

## 💫 숨겨진 의미

> 이 목걸이는 "시간의 성녀"가 자신의 시간을 바칠 때 흘린 눈물이 굳은 것.
> 리아가 에이든을 살리기 위해 희생했을 때와 같은 행위.
> 즉, 리아의 운명을 암시하는 복선.

## 5. 서사 기능

*   성녀의 눈물은 단순 보호 장신구가 아니라, 리아가 `성녀의 자리`와 이미 연결돼 있다는 조용한 증거다.
*   초반엔 그저 귀한 유물처럼 보이지만, 후반으로 갈수록 리아의 정체를 말없이 떠받치는 물건이 된다.
*   따라서 이 목걸이는 크고 화려한 힘보다, `리아가 누구인지`를 조용히 증명하는 방향으로 쓰는 편이 맞다.

## 6. 장면 규칙

*   목걸이가 발동할 때는 시스템 메시지처럼 보이지 않는다.
*   빛, 체온, 맑아지는 감각, 보호막의 무게 같은 감각으로 먼저 드러난다.
*   리아와 에이든의 관계선이 깊어질수록 장신구 이상의 의미가 읽혀야 한다.
