# 총괄 오케스트라 권한 잠금

이 문서는 `novel-orchestra-conductor`가 무엇을 결정하고, 무엇을 위임하며, 무엇을 절대 넘기지 않는지 잠근다.

## 1. 총괄의 고정 권한

총괄 오케스트라는 아래 권한을 항상 직접 가진다.

- 현재 병목 정의
- lane 선택
- 하네스 선택
- 전문가 고용 여부 결정
- 결과 병합 여부 결정
- 캐논 반영 승인
- 체크포인트 커밋/푸시 승인
- `setting-first` 해제 여부 판정

즉, 전문가가 많아져도 `최종 편집권과 캐논 승인권`은 총괄에게만 있다.

## 2. 전문가에게 넘기는 것

전문가는 아래 일을 맡는다.

- 좁은 도메인 점검
- 세부 시트 작성
- 충돌 목록 정리
- 대안 제시
- 위험 요약

전문가는 `판단 재료`를 만든다.
총괄이 그 재료를 `캐논 결정`으로 바꾼다.

## 3. 총괄이 넘기지 않는 것

아래는 전문가, MCP, 스킬, 훅이 대신 확정하면 안 된다.

- 기준 문서 우선순위 변경
- 캐논 파일 최종 진실 확정
- 두 전문가 의견 충돌 시 판정
- 하네스 통과 여부의 최종 해석
- 브랜치 체크포인트 범위 결정
- 집필 레인 개방 결정

## 4. 병합 원칙

- 전문가 결과는 바로 캐논이 아니다.
- 한 파일에 여러 lane이 걸리면 총괄이 먼저 충돌을 풀고 나서만 반영한다.
- 총괄은 하네스 PASS만 보고 병합하지 않는다.
- 하네스는 경보 장치이고, 총괄은 편집 책임자다.

## 5. 사용자 보고 규칙

실행 전 총괄은 항상 아래 세 줄을 먼저 알린다.

- 현재 작업
- 다음 작업
- 실행 방식: `총괄 단독` 또는 `총괄 + 전문가`

이 규칙은 설명이 아니라 런타임 의무다.
