# 제3권 7~8화 체크포인트

## 상태
- 판정: `PASS`
- 범위:
  - `Drafts/Vol_3/Vol_3_Chapter_7.md`
  - `Drafts/Vol_3/Vol_3_Chapter_8.md`

## 분량
- 제7화: 공백 제외 `3726자`
- 제8화: 공백 제외 `3506자`
- 전부 금지 표면어 검사 통과

## 이번 체크포인트에서 잠근 것
- `제7화`는 아레시온을 `암살자`가 아니라 `하루의 순서를 먼저 망가뜨리는 자`로 확정한다.
- `제8화`는 사람 미끼가 아니라 `약탕선 / 기록선 / 확인 절차`를 미끼로 쓰는 방향을 고정한다.
- 두 화는 `같은 규칙을 읽는 적`과의 첫 두뇌전 입구 역할을 한다.

## 잘 된 점
- 상층과 하층이 같은 손에 의해 동시에 흔들린다는 감각이 살아 있다.
- 에이든은 여전히 정답을 쥔 사람이 아니라, 더러운 규칙을 뒤늦게 따라잡는 사람으로 남아 있다.
- 아이리스는 칼보다 사람의 반응과 박자를 읽는 쪽으로 조금씩 이동하고 있다.

## 워치포인트
- 제9화는 반드시 `역함정`이어야 하며, 함정 쾌감보다 반격의 비용이 먼저 보여야 한다.
- 발타자르는 해설자가 아니라 확인 가능한 줄만 짚는 분석자로 유지해야 한다.
- `검문선` 같은 작업 표면어는 권 단위 검수에서 `검문소 / 차단선 / 통제선 / 검문 구간`으로 정리한다.
