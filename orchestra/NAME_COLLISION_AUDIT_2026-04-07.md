# Name Collision Audit — 2026-04-07

## 이번 패스 목표

- 의미보다 설명처럼 들리던 이름을 줄인다.
- 음이 지나치게 가까워 독자 기억에서 충돌할 이름을 벌린다.
- 판타지 어감과 실제 사용성을 같이 챙긴다.

## 반영한 핵심 변경

- `이레이저` -> `아레시온`
  - 설명형 코드명 느낌이 강했던 표면을 판타지형 고유명으로 교체했다.
  - 제1권, 제3권, 제13권, 의정회 문서, 회귀 기록, 위치 문서까지 동기화했다.

- `루키아` -> `루세아`
  - `루치안`과 음이 너무 가까워 구분이 흐리던 문제를 줄였다.
  - 루미나 성전, 권역별 얼굴 배치 문서, 인덱스, 진입점까지 동기화했다.

- `토마스` -> `토마르`
  - 지나치게 평범한 표면을 한 단계 판타지 쪽으로 눌렀다.
  - 하층 거래망, 황궁 잠입, 측면 목격 레인 문서까지 같이 맞췄다.

## 이번 판단 기준

- 이름이 설명문처럼 들리지 않는가
- 같은 권역 인물끼리 음이 지나치게 비슷하지 않은가
- 한글 표면으로 읽었을 때 고풍한 판타지 결이 살아 있는가
- 기존 기능과 감정을 해치지 않으면서 바꿀 수 있는가

## 현재 판정

- `아레시온`: 사용 가능
- `루세아 / 루치안`: 구분 가능
- `토마르`: 사용 가능

## 다음 점검 후보

- 상층 귀족 / 황궁 인물 이름 계통을 한 번 더 묶어 볼 수 있다.
- 장소 고유명과 건물 고유명의 어근 계열도 더 정교하게 맞출 수 있다.
