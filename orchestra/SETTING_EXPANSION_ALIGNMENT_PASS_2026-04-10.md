# 설정집 확장 구조 정렬 패스

## 목적

후반 확장 구조 1순위로 잠근 `사람 -> 기록층 -> 조직 기원` 순서를
실제 핵심 문서 네 곳에 같은 문법으로 반영한다.

대상 문서:

- `lore_bible/Relationship_Map.md`
- `lore_bible/Secrets_Activation.md`
- `lore_bible/Ending_Convergence_Map.md`
- `lore_bible/Front_Half_Foreshadow_Map.md`

## 전문가 로그

- `Aquinas`: 관계 시간축 재배치, 기록층 반전, 조직 기원 반전 의무 승격 제안
- `Confucius`: 관계를 분류표가 아니라 살아 있는 사람 기준으로 다시 잠글 것 제안
- `Avicenna`: 후영/영시/기억 파편/밀린 박자를 `강제 귀환 실패 잔재` 문법으로 묶을 것 제안
- `Locke`: 수정량 대비 효과 기준으로 `비밀 발동 -> 전반부 복선 -> 엔딩 수렴 -> 관계도` 순 점검 제안

## 핵심 반영

### 1. 사람 축 선행

- `Relationship_Map.md`에 관계별 `초기 오해 -> 중반 위치 이동 -> 후반 진실 자리` 3단 구조 추가
- 리아/아이리스/발타자르/후영-영시 축을 후반 재배치 문법으로 명시

### 2. 기록층 승격

- `Secrets_Activation.md`에 `같은 사건의 다른 이름` 비밀 추가
- `Front_Half_Foreshadow_Map.md`에 `같은 사건의 다른 이름` 행 추가
- `Ending_Convergence_Map.md` 제12권 수렴 의무에 기록층 회수 추가

### 3. 조직 기원 반전 의무화

- `Secrets_Activation.md`에 `조직 기원 반전` 항목 추가
- `Front_Half_Foreshadow_Map.md`에 `조직 기원 반전` 행 추가
- `Ending_Convergence_Map.md` 제13권 수렴 의무에 조직 기원 반전 명시

### 4. 회귀 오염 정리

- `Front_Half_Foreshadow_Map.md`의 `가짜 회귀`를 `거짓 귀환 감각`으로 치환
- `Secrets_Activation.md`의 메타성 강한 반복/회귀 표현을 현재 캐논 결에 맞게 정리

## 결과 판정

- 후반 확장 구조의 1차 핵심 문서 정렬 완료
- 설정집은 이제 `관계 -> 기록 -> 조직` 순으로 같은 진실을 읽게 된다
- 이후 초안 환류는 이 새 기준과 직접 충돌하는 부분만 좁게 처리한다
