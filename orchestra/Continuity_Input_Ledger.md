# 연속성 입력 장부

> 이 문서는 직전 초안이 없거나, 초안 파일이 비어 있거나, 초안이 삭제된 상태에서
> 무엇을 먼저 읽고 연속성을 이어받을지 잠그는 입력 기준표다.

---

## 1. 목적

집필은 늘 `직전 초안`이 있을 거라고 가정하면 안 된다.

RTTP는 설정집을 먼저 닫았고, 초안은 나중에 다시 열 수 있으므로
초안이 없어도 장면 입력이 흔들리지 않는 기준이 필요하다.

## 2. 기본 우선순위

1. `00_CANON.md`
2. `outline/Series_Roadmap.md`
3. 현재 권 `outline/Vol_X_Outline.md`
4. 현재 권 `outline/Vol_X_Timeline.md`
5. 현재 화 관련 `lore_bible` 캐릭터/세력/장소/규칙 문서
6. `orchestra/Vol_1_Core_Pressure_Grid.md` 같은 장면 압력표
7. 직전 화 사전 패킷 또는 연속성 메모
8. 직전 초안

## 3. 직전 초안이 없을 때

- 직전 사건은 `Outline`의 직전 화 행을 기준으로 잡는다.
- 직전 감정선은 `타임라인 + 관련 인물 파일 + 감정 연속성 문서`를 기준으로 잡는다.
- 직전 공간 상태는 `장소 지도 문서`를 기준으로 잡는다.
- 직전 부상과 대가는 `규칙 문서 + 캐릭터 파일`을 기준으로 잡는다.

## 4. 최소 입력 묶음

제1화처럼 시작 지점이거나 초안이 없는 화는 최소한 아래를 읽는다.

- `Guidelines/Prompt_Quick_Reference.md`
- `outline/Vol_X_Outline.md`
- `outline/Vol_X_Timeline.md`
- `lore_bible/characters/Protagonist.md`
- 해당 화 핵심 장소 문서
- 해당 화 핵심 적대축 문서

## 5. 총괄 메모

- 초안이 없다고 해서 설정을 즉석 발명하지 않는다.
- 입력이 부족하면 먼저 `연속성 메모`나 `사전 패킷`을 만든 뒤 집필 레인으로 넘긴다.
