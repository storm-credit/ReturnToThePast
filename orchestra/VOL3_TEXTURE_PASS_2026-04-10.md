# 제3권 질감 반복 완화 패스

## 목적

- 제3권 11~15화에서 반복되던 `기록/장부/기록선` 중심 질감을 완화한다.
- 동일한 정보량을 유지하되, `문서 해설`보다 `현장 공기`, `행동`, `몸 반응`, `권력 공포`가 먼저 읽히게 조정한다.
- 수정 화수는 전부 공백 제외 4,000자 하드룰을 유지한다.

## 전문가 의견 반영

- `Aquinas`
  - 11~12화는 기록 해석보다 현장 호러와 혐오 질감을 밀 것
  - 13화는 정치 실무 압박을 더 앞에 둘 것
  - 14화는 궁 안 눈치와 책임 공포를 더 선명하게 둘 것
  - 15화는 권력 퍼즐보다 사람 삭제 위험을 먼저 둘 것
- `Confucius`
  - 설명 길이가 늘어지는 구간에 `손놀림`, `소리`, `숨`, `위층 수색 기척`을 추가해 박자를 살릴 것

## 결과

- 제3권 11~15화의 반복 질감이 `기록 읽기` 일변도에서 `현장/몸/권력` 삼중 질감으로 분산됐다.
- 설정 충돌 없이 리듬만 조정했다.
- 다음 환류 우선순위는 여전히 `남은 4,000자 미달 재작성 부채 5화`다.
