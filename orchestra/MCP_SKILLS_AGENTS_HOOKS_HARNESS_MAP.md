# MCP · 스킬 · 에이전트 · 훅 · 하네스 역할 맵

이 문서는 RTTP 엔진에서 각 층이 무엇을 하고, 어디까지 책임지는지 분리해서 잠근다.

필수 전문가 목록과 하네스별 기본 조합은 `REQUIRED_EXPERT_LOCK.md`를 우선 참조한다.

## 1. MCP

`MCP`는 외부 도구와 데이터 접근층이다.

- 역할:
  - 외부 정보 읽기
  - 리소스 조회
  - GitHub/Notion 같은 연결 도구 사용
  - 자동화/앱 연계
- 하지 않는 일:
  - 캐논 결정
  - 문체 판정
  - 구조 설계 확정

MCP는 `손과 눈`이지 `편집권`이 아니다.

## 2. 스킬

`스킬`은 작업 방식이 적힌 로컬 플레이북이다.

- 역할:
  - 반복 절차 표준화
  - 특정 도메인 수행 방식 고정
  - 에이전트가 따라야 할 체크리스트 제공
- 하지 않는 일:
  - 프로젝트 진실 우선순위 변경
  - 총괄 승인 생략

스킬은 `방법`을 고정한다.
무엇을 최종 반영할지는 총괄이 정한다.

## 3. 에이전트

`에이전트`는 좁은 범위를 맡는 실행자다.

- 역할:
  - 세부 도메인 감사
  - 보강 초안
  - 위험/대안 목록
  - 시트/지도/세부 표 작성
- 하지 않는 일:
  - 최종 캐논 확정
  - 무제한 동시 수정
  - 총괄 없는 직접 병합

에이전트는 `전문 작업자`이지 `최종 편집자`가 아니다.

## 4. 훅

`훅`은 반복 실행과 체크포인트 진입 장치다.

- 역할:
  - 감사 자동 시작
  - 체크포인트 알림
  - 주간/중간 점검 트리거
  - 패킷 생성 시작점
- 하지 않는 일:
  - 단독 병합
  - 단독 커밋 의사결정
  - 캐논 수정 승인

훅은 `트리거`이고, 판단은 총괄이 한다.

대표 훅 목록은 [HOOK_CATALOG.md](HOOK_CATALOG.md)를 우선한다.

## 5. 하네스

`하네스`는 실행 경로와 점검 규칙을 묶는 게이트다.

- 역할:
  - 어떤 감사 흐름을 탈지 고정
  - 빠진 문서와 충돌 후보를 드러냄
  - 체크포인트 전 재검증
- 하지 않는 일:
  - 서사 미학 최종 판정
  - 전문가 의견 충돌 판정
  - 단독 승인

하네스는 `게이트`이지 `심판`이 아니다.

하네스별 훅 조합은 [HARNESS_HOOK_MATRIX.md](HARNESS_HOOK_MATRIX.md)를 우선한다.
하네스별 기본 전문가는 [REQUIRED_EXPERT_LOCK.md](REQUIRED_EXPERT_LOCK.md)를 우선한다.

## 6. 총괄 오케스트라

총괄은 위 다섯 층을 묶는 유일한 편집권자다.

- MCP를 선택한다
- 어떤 스킬을 쓸지 정한다
- 어떤 에이전트를 붙일지 정한다
- 훅 결과를 받을지 미룰지 정한다
- 하네스 결과를 해석하고 병합한다

따라서 RTTP 엔진에서 `권한의 중심`은 언제나 총괄이다.
