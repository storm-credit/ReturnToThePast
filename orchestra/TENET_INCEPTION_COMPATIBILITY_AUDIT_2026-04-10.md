# Tenet / Inception 적합성 감사

이 문서는 RTTP가 `12 Monkeys형 강제 시간여행 비극`을 코어로 유지하면서,
`Tenet`, `Inception` 계열 감각을 어디까지 빌려 쓸 수 있는지 잠그는 감사 문서다.

결론부터 적는다.

- `Tenet`: 20~30% 이하 보조 차용 가능
- `Inception`: 10~15% 이하 보조 차용 가능
- 코어는 끝까지 `12 Monkeys형 강제 시간여행 패러독스 비극`이다

즉, 둘 다 `향신료`로는 가능하지만 `주재료`로 쓰면 안 된다.

## 1. 총괄 판정

### 유지할 코어

- 강제 시간여행
- 고정점 / 분기점
- 시간 개입의 대가
- 닫힌 인과 압박
- 관계 손실과 감정 마모
- 비극적 시간 스릴러

### 보조로만 차용할 것

- `Tenet`
  - 같은 시간 규칙을 쓰는 적
  - 나중에 이해되는 작전 구조
  - 현재 행동이 이미 미래와 맞물려 있었다는 압박

- `Inception`
  - 기억/후영/환시를 통한 심리 침투
  - 층층이 늦게 열리는 진실
  - 누군가의 머릿속에 공포나 확신이 먼저 심겨 있는 감각

## 2. 그대로 가져오면 좋은 점

### Tenet 쪽 장점

- 적도 같은 시간 문법을 쓴다는 공포
- 순서가 먼저 무너지는 전투
- 뒤늦게 연결되는 시간 전술

### Inception 쪽 장점

- 후영을 단순 괴물보다 심리적 흉터로 밀 수 있음
- 진실 공개를 한 층씩 미루는 설계 강화
- 현실 행동을 비트는 감정/기억 개입 강화

## 3. 그대로 가져오면 위험한 점

### Tenet 쪽 위험

- SF 규칙 브리핑이 길어짐
- 감정보다 메커니즘이 앞섬
- 역행/대칭 작전이 많아져 퍼즐물처럼 보임
- 스마트한 작전 영화 톤으로 미끄러짐

### Inception 쪽 위험

- 현실층과 정신층의 위계가 흐려짐
- 모든 사건이 해석 놀이나 상징 놀이처럼 보일 위험
- 책임과 대가가 꿈층 장치에 묻힘
- 몽환적 장관이 다크 판타지 느와르의 흙냄새를 덮음

## 4. 변형해서만 쓸 것

### Tenet는 이렇게만 쓴다

- `역행 물리` 그대로 사용 금지
- `같은 규칙의 적` 감각만 사용
- `미래가 현재를 먼저 건드린다`는 압박만 사용
- `순서가 죽는 전투` 정도의 체감만 사용

### Inception은 이렇게만 쓴다

- `꿈 설계` 그대로 사용 금지
- 후영/환시/기억 오염/거짓 양성 감각만 사용
- 심리 침투와 감정 잔재 정도로만 사용
- 현실의 행동과 선택을 비트는 장치로만 제한

## 5. 절대 금지

- 새 시간 규칙을 기존 코어 규칙과 동급으로 올리는 것
- 역행을 고정점을 우회하는 해법처럼 쓰는 것
- 꿈층/정신층을 현실보다 우위 규칙으로 쓰는 것
- 설명 쾌감, 퍼즐 자랑, 작전 간지를 전면에 세우는 것
- 시간 장치를 멋있는 능력처럼 다루는 것

## 6. 논리적 금지선

아래 다섯 가지는 구조적 혼선으로 본다.

1. 핵심 규칙이 둘 이상 주인공이 되는 것
2. 현실층과 비현실층의 위계가 흐려지는 것
3. 고정점 문법을 새 장치가 우회하는 것
4. 정보 우위가 치트처럼 보이는 것
5. 결말의 책임 소재가 장치로 흐려지는 것

## 7. RTTP에 맞는 번역어

- `역행`보다는 `순서 붕괴`, `한 박자 늦는 세계`, `시간의 오작동`
- `꿈층`보다는 `후영`, `환시`, `기억 파편`, `의식 침식`
- `미션/작전 설계`보다는 `배치선`, `기록선`, `후송선`, `봉인선`

즉, 가져오더라도 RTTP의 언어로 번역해서 써야 한다.

## 8. 초안 수정 원칙

지금 당장 초안을 이 이유만으로 다시 쓰진 않는다.

대신 앞으로 아래를 지킨다.

- Tenet/Inception 개념은 새 설정 코어로 승격하지 않는다
- 후영/항체/강제 귀환술/고정점 체계 안으로만 흡수한다
- 후반부 구조 보강 시 `드라마판 12 Monkeys 모티브 갭 감사`에 우선권을 둔다

## 9. 최종 판정

- `Tenet`: 부분 차용 가능
- `Inception`: 제한 차용 가능
- `드라마판 12 Monkeys`: 후반 구조 보강의 주 참조축

한 줄 결론:

`Tenet는 전술 압박용, Inception은 심리 침식용, 코어는 끝까지 12 Monkeys형 비극적 시간여행이다.`
