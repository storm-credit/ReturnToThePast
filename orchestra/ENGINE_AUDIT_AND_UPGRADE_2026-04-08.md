# 엔진 점검 및 업그레이드 - 2026-04-08

## 목적

RTTP 엔진이 이미 돌아가고는 있지만, 총괄 권한과 런타임 규약이 암묵적으로만 존재하던 부분을 명시 문서로 잠근다.

## 이번 업그레이드

- 총괄 오케스트라 권한 문서 추가
- MCP / 스킬 / 에이전트 / 훅 역할 경계 문서 추가
- 하네스 런타임 잠금 문서 추가
- RTTP 엔진 개요와 실행 프로토콜에 새 잠금 문서 연결

## 왜 필요한가

- 전문가가 많아질수록 총괄 권한이 더 선명해야 한다.
- 하네스가 있어도 런타임 규칙이 없으면 레인 겹침과 역할 혼선이 생긴다.
- 같은 시스템을 다른 작품으로 옮길 때도 이 경계 문서가 재사용 코어에 가까운 역할을 한다.

## 현재 판정

- RTTP 엔진은 이제 `작문 알고리즘 모음`을 넘어 `지휘 규약이 잠긴 운영 엔진`으로 볼 수 있다.
- 남은 업그레이드는 선택적 자동화 훅 보강과 템플릿 고도화에 가깝다.
