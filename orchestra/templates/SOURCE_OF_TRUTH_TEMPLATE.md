# SOURCE OF TRUTH 템플릿

> 새 소설 프로젝트의 문서 우선순위를 잠그는 기본 틀.

## 1. 최상위 기준

1. `00_CANON`
2. `Start_Here`
3. `Series_Roadmap`

## 2. 설계 문서 우선순위

1. 권별 아웃라인
2. 권별 타임라인
3. 인물 / 세력 / 장소 캐논
4. 작명 / 문체 / 금지선 가이드

## 3. 장면 단위 문서 우선순위

1. 복선 장부
2. 엔딩 수렴 지도
3. 감정 연속성 지도
4. 측면 인물 목격 지도
5. 권역별 얼굴 배치 지도

## 4. 충돌 처리 원칙

- 아래 문서가 위 문서를 뒤집지 않는다.
- 표면 표현이 충돌하면 상위 문서를 따른다.
- 새 사실을 추가할 때는 먼저 상위 문서에 잠근다.
- 하위 문서에서 먼저 등장한 설정은 캐논으로 확정하지 않는다.

## 5. 오케스트라 지침

- 총괄자는 먼저 이 문서의 우선순위를 확인한다.
- 전문가 lane은 상위 문서를 먼저 읽고 하위 문서를 검증한다.
- 충돌이 보이면 prose보다 canon repair를 먼저 수행한다.
