# 제3권 활성 고정점 카드

날짜: `2026-04-09`
상태: `ACTIVE`
범위: `제3권 제1화~제25화`

## 이번 권의 역할

- `제3권`은 제2권 말미의 정치 충격이 `반작용`과 `시간 전쟁의 실무 징후`로 되받아치는 권이다.
- 초반부는 `적의 정체 설명`보다 `장부 / 검진패 / 교대표 / 봉쇄 / 확인선`의 어긋남으로 시작한다.
- 중반부터는 `같은 규칙을 읽는 적`과의 두뇌전으로 넘어가야 한다.

## 이번 권의 활성 고정점

| 구분 | 내용 | 이번 권에서 흔들 수 없는 것 |
| :--- | :--- | :--- |
| `고정점` | 시간 개입에는 즉시 반작용이 남는다 | 작은 개입도 반드시 다른 줄을 흔든다 |
| `고정점` | 아레시온은 사람보다 먼저 하루의 순서를 망가뜨리는 적이다 | 단순 암살자나 정면 승부형 적으로 보이면 안 된다 |
| `고정점` | 에이든은 승리보다 비용과 오염을 먼저 떠안는다 | 공략물 쾌감이나 먼치킨 우위감 금지 |
| `고정점` | 제3권은 시간 전쟁의 문법을 `흔적`으로 체감시키는 권이다 | 세계관 강의형 설명으로 넘어가면 안 된다 |

## 이번 권의 활성 분기점

| 구분 | 내용 | 흔들 수 있는 것 | 반드시 남겨야 하는 것 |
| :--- | :--- | :--- | :--- |
| `분기점` | 하멜/정보선 보호 방식 | 누구를 어디까지 살려 내는지 | 다른 줄 하나가 더 흔들리는 값 |
| `분기점` | 아이리스의 교전 방식 | 부상 시점, 개입 강도 | 소진과 과부하 전조 |
| `분기점` | 발타자르 활용 방식 | 정보 공개 순서, 개입 시점 | 분석자 톤, 해설자 금지 |
| `분기점` | 아레시온 추적 방식 | 미끼, 역함정, 추적 경로 | `같은 규칙의 적`이라는 감각 |

## 초반부 체크포인트

### `제1화~제3화`

- 봉쇄, 장부, 검진, 확인선이 먼저 압박으로 와야 한다.
- 아레시온은 이름보다 `순서를 만지는 손`으로 먼저 체감되어야 한다.

### `제4화~제6화`

- 역나비효과는 공짜 기술이 아니라 `더 크게 번진 반작용`으로 읽혀야 한다.
- `시간의 지문`은 이론 설명이 아니라 `흔적 판독`으로 다뤄야 한다.

### `제7화~제9화`

- `같은 규칙을 읽는 적`이라는 감각이 선명해져야 한다.
- 두뇌전은 공략집이 아니라 `누가 먼저 빈칸을 찾느냐`의 전쟁으로 보여야 한다.

## 금지 오염

- 회귀 공략물 톤
- 장엄한 인과율 독백
- 악역 브리핑형 설명
- `이것도 계산 안이다` 식 우위감
- 파멸을 멋으로 소비하는 서술

## 총괄 메모

`제3권`은 정보량보다 `체감`이 먼저여야 한다.
이 권에서 독자가 배워야 하는 것은 새 규칙이 아니라, 이미 작동 중이던 더러운 규칙의 모양이다.
