# 드라마판 12 Monkeys 모티브 갭 감사 계획

이 문서는 현재 프로젝트가 `드라마판 12 Monkeys 모티브`를 어디까지 품고 있고,
어디가 아직 약한지를 감사하기 위한 오케스트라 계획서다.

중요한 전제:

- 이 작품은 복제품이 아니다
- 하지만 모티브를 가져왔다면, `시간선의 닫힘`, `가까운 인물의 위치 전환`,
  `조직 기원 반전`, `현재/미래의 왕복 압력`, `공정한 진실 공개`는 반드시 점검해야 한다

## 1. 감사 핵심 질문

1. 후반부 사건이 `닫힌 인과 고리`로 읽히는가
2. 미래 멸망선이 현재 사건을 실제로 밀고 되받아치는가
3. 조직/의식/재앙의 기원 반전이 충분한가
4. 가까운 인물이 다른 시간선에서 다른 위치를 차지하는 반전이 충분한가
5. 같은 사건이 시대마다 다른 이름으로 기록되는 구조가 있는가
6. 독자가 `그 흔적이 처음부터 있었다`고 납득할 만큼 기록층이 쌓여 있는가

## 2. 현재 판정

### 이미 있는 것

- 고정점/분기점 문법
- 강제 귀환술
- 미래 멸망선과 현재 선택의 연결
- 후영/영시 축
- 채권자/대가/반작용 구조

### 아직 약한 것

- 조직 기원 반전
- 같은 사건의 다른 이름 장부
- 중간 다중 시점 운용
- 가까운 인물의 시간축 위치 전환
- 후반부 계보형 인과 반전

## 3. 이번 감사에 투입할 전문가

### 기본 세트

- `novel-orchestra-conductor`
- `structure-architect`
- `timeline-historian`
- `chrono-weaver`
- `foreshadow-bookkeeper`
- `reveal-choreographer`
- `plausibility-warden`

### 보조 세트

- `arc-psychologist`
- `world-rule-keeper`
- `faction-strategist`
- `character-architect`
- `ritual-liturgist`

## 4. 실제 서브에이전트 매핑

- `Aquinas`: 구조/패러독스/시간선
- `Confucius`: 감정선/거리감/비극 정조
- `Avicenna`: 의식/항체/오염/후영
- `Erdos`: 논리/정합성
- `Locke`: 하네스 운영/배치 순서
- `Ampere`: 병렬 레인/재작성 큐/체크포인트

## 5. 하네스 순서

1. `Lore Audit`
   - 강제 귀환술
   - 고정점/분기점
   - 조직/의식/기원 구조
2. `Foreshadow`
   - 영시/후영/발타자르 공개 사다리
   - 같은 사건의 다른 이름
   - 흔적/기록/은폐 장부
3. `Storycraft`
   - 가까운 인물 위치 전환
   - 다중 시점 도입 필요성
   - 후반 감정 수렴
4. `Smoke`
   - 회귀 오염
   - 과설명
   - 스포일러 과다

## 6. 초안에 대한 원칙

이번 감사가 끝나기 전에는 초안을 전면 수정하지 않는다.

예외는 아래뿐이다.

- 설정집 감사 결과가 이미 집필된 화와 직접 충돌할 때
- 후반 구조를 깨는 명시적 문장이 있을 때
- 회귀 오염이나 제목/소개글 오염처럼 즉시 수정이 필요한 입구 요소

## 7. 기대 산출물

- `들어가 있음 / 약함 / 없음` 표
- 후반 보강 대상 5개 이하
- 초안 환류 대상 화수 목록
- 제목/소개글/패러독스 프레임 재동기화 필요 여부
