# E026 State Mutation — 환영받는 낯선 사람

Status: AUTHOR REVIEW — FIRST DRAFT

## Body / Medical Record
- F1 의료진은 에이든 로엔의 기존 흉터·골절 흔적을 과거 임무 후유증으로 알고 있음.
- 실제 몸의 흉터 위치와 현재 의료기록은 물리적으로 정합하지만 에이든의 기억 속 원인과 다름.
- 의료기록에는 치료과정과 다렌 모트의 동행 기록까지 연결돼 있어 관계가 공적 영웅기록 하나에만 존재하는 상태가 아님.
- 에이든은 장기 관계 기억 불일치를 의료진에게 즉시 공개하지 않고 현재 기록을 더 수집함.

## Hero Narrative / Public Space
- 공개 전시회랑에 `서부 안정화 작전`, `현장 지휘: 에이든 로엔`, 서부 숙청·중앙 기록망 재통합이 하나의 공적 계보로 전시됨.
- 숙청 뒤 병원·배급 인프라가 실제 개선된 자료도 함께 존재해 F1 보상을 가짜 선전으로 처리하지 않음.
- 숙청과 민간 피해 자체가 숨겨진 금지어가 아니라 세부기록으로 분리돼 있음.
- 에이든은 자기 서명이 붙은 복제문서를 보고 원본 열람을 신청함.

## Daren Mott
- 다렌 모트는 결혼식·출산 당시 병원 앞 대기 등 사적 공동기억을 자연스럽게 이야기함.
- 배우자·자녀의 정본 미확정 고유이름은 새로 만들지 않음.
- 다렌은 모든 공동기억을 완벽하게 외우지 않고 기억나는 것과 잊은 것이 섞인 실제 인간 기억을 보임.
- 에이든은 관계의 깊이를 질문하지만 자신의 기억 불일치 전체는 공개하지 않음.

## Purge List / Hook
- 에이든은 공로자 권한으로 `서부 안정화 작전` 원본 계열을 열람함.
- 지휘명령은 초안→검토→현장승인→최종 지휘승인 구조를 갖고 있어 단순 위조문서로 즉시 판정할 수 없음.
- `서부 정리 대상 명단` 맨 위 이름이 `아벨 네르`로 나타남.
- 아벨의 최종 생사·처분은 열람 제한으로 가려져 있으며 에이든이 가림 해제 요청을 제출함.
