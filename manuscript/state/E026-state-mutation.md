# E026 State Mutation — 내가 모르는 영웅담

Status: AUTHOR REVIEW — FIRST DRAFT

## F1 Body / Medical Record
- F1 의료진은 에이든 로엔의 기존 흉터·골절 흔적을 과거 임무 후유증으로 알고 있음.
- 실제 몸의 흉터 위치와 F1 의료기록은 물리적으로 정합하지만 에이든의 F0 기억 속 원인과 다름.
- 다렌 모트가 과거 부상기록 동행자로도 등장해 F1 관계가 공적기록에만 있는 것이 아님을 강화.
- 에이든은 장기 관계 기억 불일치를 의료진에게 즉시 공개하지 않고 기록을 더 수집.

## Hero Narrative / Public Space
- F1 공개 전시회랑에 `서부 안정화 작전`, `현장 지휘: 에이든 로엔`, `주요 소거거점 7곳 제거`, `중앙 기록망 재통합`이 공적으로 전시됨.
- 동시에 안정화 뒤 서부 병원·생활 인프라가 실제 개선된 자료가 존재해 F1 보상을 가짜 선전으로 처리하지 않음.
- `서부 숙청과 재정착`이라는 표현도 공식 전시에서 숨기지 않음.

## Daren Mott
- 다렌 모트는 결혼식, 첫째 출산 당시 병원 앞 밤샘 등 사적 공동기억을 자연스럽게 이야기함.
- 모든 대사를 완벽히 기억하지 못하고 생활기억 일부만 선명해 실제 인간 기억처럼 유지.
- 에이든은 다렌의 가족 세부를 질문하며 관계의 깊이를 확인하지만 기억 불일치 전체는 공개하지 않음.

## Purge List / Hook
- 에이든은 영웅등급 권한으로 `서부 안정화 작전` 원본계열을 열람.
- 지휘명령은 초안→검토→현장승인→최종 지휘승인 구조를 갖고 있어 단순 위조문서로 처리할 수 없음.
- `서부 정리 대상 명단` 첫 확인 이름이 `아벨 네르`로 나타남.
- 아벨의 최종 생사·처분은 개인정보 제한으로 가려져 있으며 에이든이 가림해제 요청을 제출.
