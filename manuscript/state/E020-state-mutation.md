# E020 State Mutation — 검증할 시간, 돌아갈 시간

Status: AUTHOR REVIEW — FIRST DRAFT

## Three Clocks
- 귀환표식까지 이동: 40분.
- 포위 돌파 최소: 25분에서 왕실 단계적 진입 뒤 약 30분으로 상승.
- 세렌 장부 인과 검증 최소: 1시간.
- 세 목표의 합이 남은 귀환 안전여유를 초과함을 실제 계산으로 확정.
- 부상·환자 수레·추가 검문 같은 현실 변수는 계산을 더 악화시키며 마법·장비로 시간을 단축하지 않음.

## Negotiation
- 에이든 로엔은 세렌 바일에게 장부와 봉쇄권을 넘기면 생존을 돕겠다고 제안.
- 세렌은 주민 주소 보호를 현지에서 검증할 수 없는 미래 약속에 맡길 수 없다며 거부.
- 지방연맹·성당·왕실 어느 기관도 즉시 완전한 이전처가 되지 못한다는 각자의 한계가 협상에서 재확인됨.
- 에이든의 `미래에서 확인한다`는 보증 역시 현재 주민이 검증할 수 없다는 약점 노출.

## External Pressure
- 왕실군은 무차별 돌격 대신 창고·치료실 등 구역을 단계적으로 봉인하며 안쪽으로 진입.
- 본부는 `강제 귀환 준비 단계 진입 권고`를 전송. 즉시 강제귀환 실행은 아님.

## Seren Organization
- 세렌은 협상 중 부하들의 이동 준비를 공개하지 않음.
- 조직원들이 기록상자·환자용 담요·위조 통행패를 지하로 옮기기 시작.
- 이것이 도주인지 대피인지 E020에서는 확정하지 않음.

## Next Cause
- E021에서 무기·위조신분 때문에 반란/도주처럼 보이는 이동이 실제로는 삭제예정 주민 대피와 연결돼 있음을 확인하고, 에이든은 장부 추적과 환자 대피 중 우선순위를 다시 선택하게 됨.

## Canon Guard
- 세렌의 장부 실제 최종 내용·비용전가 구조는 선취하지 않음.
- 세렌 조직 이동을 단순 도주로 확정하지 않음.
- `HUMAN PROSE PASS` 부여하지 않음.
