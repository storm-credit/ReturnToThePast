# E010 State Mutation — 구휼과 분류

Status: AUTHOR REVIEW — FIRST DRAFT

## Institutions / Relief
- 아홉 상처 대성당 계열 성당 구휼기사단이 실제 약품·식량·침상·호송 인력을 공급해 격리촌 생존 여건을 개선함.
- 동시에 몸 상태뿐 아니라 기록 불일치 지속 여부를 재심 분류 기준으로 사용.
- 분류가 없으면 침상·물·신규 환자 수용 계산이 무너지는 실제 제약 확인.

## Character / Registration
- 에이든 로엔은 기사단과 충돌하지 않고 치료 수송 참여를 선택.
- 기사단 명부에 `외지 치료보조 에이든`으로 기한부 등록돼 이후 추적 가능한 상태가 됨.
- 목적지 세부주소는 받지 못하지만 도착·인계 직책 확인 권한을 조건으로 확보.
- 아이리스 네르는 에이든의 협상에 감화되지 않고 격리촌에 남아 가족과 수레 귀환을 관찰하기로 함.

## Patient State
- 아벨 네르를 포함한 기록 불일치 환자 일부가 별도 재심 수레에 편성됨.
- 가족들은 과거 별도 수레 탑승자가 돌아오지 않은 사례를 직접 주장함.

## Mystery / Hook
- 재심 수레 바퀴에 정규 경로와 다른 서쪽 수로 진흙이 묻어 있음.
- 진흙 위 눌린 흔적이 세렌 바일 조직 관련 압수품 문양과 유사.
- 환자를 `빼돌리는 것`이 구조인지 범죄인지 확정하지 않음.

## Next Cause
- 등록된 치료보조로 환자 수송에 묶인 에이든이 E011 붕괴 다리에서 표적 추적과 환자·기록상자 구조 중 선택해야 함.

## Canon Guard
- 구휼기사단을 평면적 악역으로 처리하지 않음.
- 분류 기준을 마나열병의 최종 정답으로 설명하지 않음.
- 세렌 조직의 환자 이동 목적 확정 금지.
- `HUMAN PROSE PASS` 부여하지 않음.
