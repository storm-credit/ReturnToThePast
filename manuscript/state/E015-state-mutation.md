# E015 State Mutation — 병원처럼 보이는 실험실

Status: AUTHOR REVIEW — FIRST DRAFT

## Facility / Evidence
- 세렌 바일 조직 은신처는 실제 치료·식수·가족 대피 기능과 마력 실험·봉인실 기능을 동시에 가짐.
- 감염자 목록처럼 보이던 명단은 삭제예정지 주민·족보·벽흔·묘표·가족노래·공동식사 순번 등 존재증명 목록으로 확인.
- 조직은 기록 소거 전 주민을 외부로 대피시키고 있음.
- 동시에 동의 없는 기억채취 사례와 기록이 존재해 조직을 무고한 저항세력으로 확정할 수 없음.

## Character
- 에이든 로엔: 초기 `불법 실험실` 해석이 일부 무너지지만 세렌 바일 무죄 결론으로 이동하지 않음.
- 아이리스 네르: 증거 확보보다 환자 탈출로를 우선해 에이든과 다른 통로로 움직임. 불신이 아니라 우선순위 차이로 분리.

## Mystery / Hook
- 세렌 조직의 건국력 640년 실험기록에서 에이든의 F0 출발 인장과 거의 같은 구조를 발견.
- E007 회색 종 표면의 미완성 흔적과도 계통상 유사.
- 조직이 구조를 어떻게 알았는지, 세렌이 시간여행자인지 여부는 확정하지 않음.

## Next Cause
- 출발 인장 구조의 출처와 주민 소거 대피의 목적을 확인하기 위해 E016에서 세렌 조직과 직접 접촉하고 3개 세력이 같은 기록을 노리는 충돌로 진입.
