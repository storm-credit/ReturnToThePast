# E022 State Mutation — 명단을 받은 살인자

Status: AUTHOR REVIEW — FIRST DRAFT

## Escape Route / Time Cost
- 첫 환자 수레가 왕실군에게 정지된 상태에서 에이든 로엔이 왕실과 정면 교전하지 않고 기록수레 통로의 고정기둥을 제거하는 최소 탈출로를 협상·개방.
- 에이든은 시설 손상 책임을 자기 임시 통행기록에 남기는 조건을 수용.
- 첫 환자 수레 1대가 왕실 검문선을 빠져나감.
- 이 행동에 사용한 시간만큼 표적 추적·설득 여유가 더 줄어듦.
- 아이리스 네르의 귀환 연결은 유지되지만 나머지 수레 전체를 구한 것으로 처리하지 않음.

## Seren List
- 세렌 바일은 자기 사망 뒤 왕실망 진입 시 우선 위험해질 마을·가족·환자 명단을 에이든에게 전달.
- 명단에는 아벨 네르 가족과 앞서 확인한 기록 충돌 마을이 포함됨.
- 명단은 `전부 사라진다`는 확정 사망목록이 아니라 봉쇄가 막고 있는 갱신요청 순서 기반 위험목록.
- 전체 주소·갱신자료는 주민 사생활/권리 때문에 세렌이 넘기지 않음.

## Final Negotiation Failure
- 에이든은 봉쇄권 이전을 다시 요구하고 세렌 생존을 돕겠다고 제안.
- 세렌은 미래 기관의 약속을 현지 주민이 검증할 수 없고, 에이든과 자신이 책임지는 대상이 다르다는 이유로 거부.
- 에이든도 세렌이 거짓말한다고 보지 않으며, 세렌 역시 에이든의 미래 위기·19만·11일 수치를 거짓말로 취급하지 않음.
- 합의 실패 원인은 악의나 사기가 아니라 서로 다른 책임대상과 검증 불가능성으로 고정.

## Irreversible Setup / Hook
- 세렌과 에이든이 각각 무기를 뽑음.
- 회색 종이 한 번 울리고 에이든 귀환석이 붉은 마지막 단계로 진입.
- 에이든은 한 손에 칼, 다른 손에 세렌이 건넨 명단을 든 상태.

## Next Cause
- E023에서 몇 분 안에 좁은 기록실 전투와 최종 선택이 발생하고 세렌 사망이 영구 잠김.

## Canon Guard
- 세렌이 자기 무죄를 주장하거나 성인화된 순교 대사를 하지 않음.
- 위험명단을 확정 소거·사망 예언으로 취급하지 않음.
- `HUMAN PROSE PASS` 부여하지 않음.
