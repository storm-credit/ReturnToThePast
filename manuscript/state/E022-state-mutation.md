# E022 State Mutation — 명단을 받은 살인자

Status: DRAFT PENDING AUTHOR REVIEW

## Rescue / Time Cost
- 에이든 로엔이 첫 환자 수레를 위해 왕실군과 전면전 없이 1개 방향의 최소 탈출로를 엶.
- 환자·물자 도보 이동은 방해하지 않되 왕실군 호위는 없는 조건.
- 그 시간만큼 표적 추격·설득·귀환 여유 감소.
- 아이리스 네르는 열린 길을 사용하며 E021 최후통첩을 반복하지 않음.

## Final Negotiation
- 에이든이 봉쇄권 이전을 마지막으로 요구.
- 에이든의 미래 기관 보호 약속은 현지에서 검증·강제할 수 없다는 이유로 세렌 바일이 거부.
- 양측 모두 상대 사망자가 실재한다는 사실을 인정하지만 책임 대상이 다름:
  - 에이든: F0의 42만과 잔여일 11일.
  - 세렌: 현재 명단의 마을·가족·환자.
- 합의 가능성 소멸.

## Asset / Responsibility Transfer
- 세렌이 자기 사망 뒤 소거될 가능성이 높은 사람 명단을 에이든에게 인계.
- 명단은 세렌 무죄 증거가 아니며 결과 확정표도 아님.
- 에이든이 명단을 물리적으로 소유하게 되어 결과 책임 부채 시작.

## Return / Combat State
- 회색 종 1회 반응.
- 귀환창 `최종 단계` 진입.
- 에이든이 무기를 뽑고 세렌도 저항 준비. E023에는 논쟁이 아니라 몇 분짜리 실행만 남음.
