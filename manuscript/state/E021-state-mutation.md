# E021 State Mutation — 도주처럼 보이는 대피

Status: AUTHOR REVIEW — FIRST DRAFT

## Reinterpreted Evidence
- 지하창고의 무기·다량 위조신분·포위 중 이동은 처음에는 도주·반란 준비로 읽힘.
- 아이리스 네르가 현지 자료와 수레 배치를 대조해 위조신분은 삭제 예정 주민의 새 주소, 무기는 환자·가족 수레 호송 방어용임을 확인.
- 그러나 위조문서 제작·무장·세렌의 사전 비공개 자체는 실제 불법/결함으로 유지.

## Character Choice / Cost
- 에이든 로엔은 정보 해석을 `도주`에서 `대피`로 정정함.
- 그럼에도 배정한 장부 검증 시간을 우선해 환자 수레 대피를 직접 돕지 않음.
- `정보를 정확히 알게 됨`과 `선택이 정당해짐`을 동일시하지 않도록 상태 분리.

## Iris Refusal Right
- 아이리스는 E012의 기존 거부권을 집행 조건으로 재확인.
- 에이든이 환자 수레가 막힌 상황을 외면한 채 장부·표적만 선택하면 귀환표식 연결을 끊겠다고 선언.
- 새 협박 카드가 아니라 현지 앵커가 가진 기존 조건부 연결권 행사임.

## Hook
- 첫 환자 수레가 왕실군 단계적 진입선에 발견됨.
- 왕실군은 환자 수레에 정지·신분표 확인·하차를 명령.
- 수레 안 환자들이 즉시 하차할 수 없는 상태라 충돌이 직접 발생.

## Next Cause
- E022에서 에이든이 최소 탈출로를 열어 첫 수레를 빼내며 표적 추적·장부 검증 시간을 더 잃고, 세렌에게서 사망 뒤 소거될 마을·가족·환자 명단을 받음.

## Canon Guard
- 세렌 조직의 무기와 위조신분을 전부 선의로 세탁하지 않음.
- 새 주소 목록 전체 규모·정체 공개 금지.
- `HUMAN PROSE PASS` 부여하지 않음.
