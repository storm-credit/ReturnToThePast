# E021 State Mutation — 도주처럼 보이는 대피

Status: DRAFT PENDING AUTHOR REVIEW

## Interpretation
- 개혁가 조직의 포위 중 이동은 단순 도주가 아니라 삭제 예정 주민 대피가 주목적임을 확인.
- 위조신분 = 삭제 예정 주민의 새 주소 문서.
- 무기 = 환자·주민 수레 호송 방어용.
- 단, 위조·무장·세렌의 준비 은폐라는 불법·결함 자체는 유지.

## Aiden
- 오해 정정 사실을 수용.
- 그럼에도 남은 시간을 장부 확보에 우선 배정하고 환자 대피를 직접 돕지 않음.
- 정확한 정보와 선택의 정당성을 분리하지 못하는 오류 상태 활성화.
- 사람을 `환자·주민·표적` 역할명으로 부르는 경향이 압박 아래 재증가.

## Iris / Anchor
- 아이리스 네르는 E012 조건을 재확인: 에이든이 장부·표적 목표를 환자 안전보다 앞세우면 현지 보증·귀환표식 연결을 끊음.
- 선언은 조건 변경이 아니라 기존 거부권 집행 예고.

## External Pressure
- 첫 환자 수레가 왕실군 차단선에 발견됨.
- 왕실군은 문서 확인과 길 차단을 먼저 실행하며 학살 목표로 단순화하지 않음.

## Next Cause
- E022에서 에이든이 최소 탈출로를 열어 주는 대신 추격시간을 더 잃고, 세렌이 자기 사망 뒤 소거될 주민 명단을 건네며 최종 책임 협상이 시작됨.
