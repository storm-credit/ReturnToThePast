# E025 State Mutation — 영웅의 귀환

Status: DRAFT PENDING AUTHOR REVIEW

## Volume 1 Resolution
- 에이든 로엔이 Era N 임무에서 귀환.
- 귀환 미래는 출발했던 F0가 아니라 **F1**.
- 세렌 바일 영구사망 유지.
- 임무는 F1 공식 기록에서 성공으로 고정.
- 에이든은 `서부 구원 공로자 / 영웅`으로 기록됨.
- F0 완전복원·리셋·재시도 없음.

## F1 Institutional State
- 귀환시설 공식 명칭이 에이든의 F0 기억과 다름.
- 귀환실 승인선·본부 내부 기능배치·근무조 구성이 달라짐.
- F0에서 익숙했던 본부 명칭은 현행·옛 명칭·폐기 명칭 색인에서 발견되지 않음.
- 세렌 제거 전 F0 원본 임무계보도 현재 기록에서 발견되지 않음.
- 삭제 이력도 확인되지 않아 `삭제`로 확정하지 않음.

## Character / Relationship
### 에이든 로엔
- F0 기억을 유지하지만 현재 기록과 다수 불일치.
- E024에서 빈칸으로 관측된 F0 동료 1명의 얼굴·근무 기억은 남아 있으나 이름만 회상하지 못함.
- F1 인사망에는 에이든과 가장 가까운 현장 동료 관계가 별도로 존재. 해당 인물 이름은 현재 정본 미확정 상태를 유지하며 원고에서 새로 고정하지 않음.
- 영웅 기록을 자기 기억보다 우선하지 않고 원본 계보 검증을 선택.

### 리아 세른
- F1에서 생존 확인.
- 임무기록실에서 에이든과 함께 최초 제거 명령 원문·작성자·근거계보를 조회.
- F0 기억 보존 범위·개인 관계 변화는 아직 확정하지 않음.
