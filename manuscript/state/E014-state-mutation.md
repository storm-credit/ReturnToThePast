## TIMELINE_STATE

- Era N / CY 640 / 안개월 4일 연속. 지방 기록소 세금대장실에서 칠구 열둘 마지막 납세일이 안개월 5일로 확인된 직후, 에이든은 원본 열람을 요구함
- 지방 기록소 원본 열람은 네르 대표 보증패만으로 열리지 않음. 원본실 책임자가 격리촌 약품 인계표까지 맡고 있어, 에이든은 귀환용 응급약 일부를 환자 약품으로 인계하는 조건으로 서기 교대 전 원본 열람시간을 확보함
- 격리촌 약품 인계지점에서 에이든의 귀환용 응급약갑 약포 6개 중 3개가 성당 구휼 확인 아래 환자 안정용 보조약으로 전환됨. 약은 기록소나 서기에게 가지 않고 격리촌 약장에 보관됨
- 원본 열람실에서 왕실 피해보고서 원본을 제한 열람함. 서명란·주민명·증언자 이름은 가려진 상태 유지
- 원본에는 금지의식 혐의 요약, 기억 관련 피해 줄, 동의 여부 확인 불가 표현, 피해 수치 마지막 두 자리의 먹색 차이와 같은 시간 작성 판정 불가가 확인됨
- 원본의 사건일은 안개월 3일 저녁 종 뒤로 확인됨. 원본 작성 시작일은 안개월 2일 첫 종 뒤로 확인되어 보고서 작성일이 사건일보다 하루 빠른 단서가 열림
- 확인문은 기록소 보관으로 남고 외부 반출되지 않음. 에이든은 장부 번호와 숫자 순서만 기억으로 들고 나감

## RELATIONSHIP_MUTATIONS

- 에이든 ↔ 아이리스: 아이리스가 에이든의 약품 인계가 실제 환자 줄에 남는지 확인함. 에이든은 환자를 단순 표적 접근 수단으로만 쓰지 않는 선택을 하나 보이지만, 아이리스는 조수나 전면 협력자로 전환하지 않음
- 에이든 ↔ 지방 기록소: 제한 열람자 → 원본 제한 열람자. 원본 열람은 약품 인계 확인과 원본실 책임자 동행 아래 한시적으로 열렸으며, 확인문 반출은 불가함
- 에이든 ↔ 격리촌 환자 쪽: 에이든의 귀환용 응급약 일부가 환자 안정용 보조약으로 넘어감. 환자 치료 결과나 병의 원인은 확인되지 않음
- 아이리스 ↔ 지방 기록소: E013 보증패 묶임 상태 유지. 아이리스는 보증을 추가로 제공하지 않고 약품 인계 절차의 환자 귀속 여부만 확인함
- 지방 기록소 ↔ 성당 구휼: 원본 열람시간 연장의 조건으로 격리촌 약품 인계 확인이 기록됨. 기록소가 약을 수령하지 않고 성당 구휼 확인 아래 환자 보관으로 남김
