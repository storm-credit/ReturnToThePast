# E014 State Mutation — 약품으로 산 열람시간

Status: AUTHOR REVIEW — FIRST DRAFT

## Cost / Transaction
- 지방 기록소 원본 열람은 뇌물로 성립하지 않음.
- 에이든 로엔은 귀환 후 신체 안정에 사용할 응급자원 2병을 성당 보관으로 넘기고, 그에 대응해 격리촌 현지 약품 배정을 늘림.
- 아이리스 네르와 메이라 솔이 약품이 실제 환자에게 인계되는 것을 확인.
- 원본이 회수돼도 지방에 남도록 허용 범위 사본 제작을 조건으로 원본 열람시간 확보.

## Evidence
- 왕실 피해보고서 본문 작성일이 사건 발생일보다 앞섬.
- 피해수치 부분은 본문과 다른 물리층으로 나중에 덧씌워진 흔적이 있으며, 피해집계 확정 뒤 수치 보충이라는 수정기록도 존재.
- 금지의식 혐의·왕실 명령 불복종 자체는 원본에서 사라지지 않음.
- 보고서 작성자 서명란의 기록관은 보고서 작성일 전에 이미 사망한 기록으로 확인됨.
- 동명이인·인장도용 가능성은 열어 두며 원인·작성자 확정 금지.

## Character
- 에이든은 자기 귀환 안전 자원을 증거 접근 비용으로 처음 직접 지불.
- 아이리스는 에이든의 목적을 신뢰하지 않지만 약품이 실제 환자에게 간 것을 확인하고, 그가 사람을 비용표로만 다루지 않는다는 관측을 추가.

## Next Cause
- 원본의 시간층 모순과 세렌 혐의가 동시에 남아 E015에서 표적 조직 시설을 직접 확인할 필요가 커짐.

## Canon Guard
- 죽은 서명자를 E003 삭제 증언자와 동일인으로 확정하지 않음.
- 세렌 바일 무죄 확정 금지.
- `HUMAN PROSE PASS` 부여하지 않음.
