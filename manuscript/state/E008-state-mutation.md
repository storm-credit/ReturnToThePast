# E008 State Mutation — 이름 없는 검문

Status: AUTHOR REVIEW — FIRST DRAFT

## Identity / Access
- 에이든 로엔의 F0 제작 신분문서는 위조 판정이 아니라 현행 형식 `처리 불가`로 분류됨.
- 검문은 통행증·가족관계·세금표를 통해 책임 귀속을 확인하는 절차로 드러남.
- 에이든은 파손 수레 수리를 책임지는 조건으로 `에이든` 이름의 임시 노역표를 받아 기한부 등록 상태가 됨.
- 정식 도시 진입권은 아직 없음.

## Local / Equipment
- 미래식 공구를 사용하지 않고 현지 막대·가죽끈·칼만으로 수레 축을 임시 수리.
- 수리 방식·발음·얼굴이 검문선과 현지인에게 노출됨.
- 임무 시간은 환자 호송 일정에 더 묶임.

## Characters
- 아벨 네르: 같은 가족 내 열 증상과 함께 존재하지 않는 가족·집 위치를 구체적으로 말함. 에이든을 처음 보면서 `두 번째로 늦게 왔다`고 말함.
- 메이라 솔: 구휼사로 첫 등장. 이름→날짜→장소 순으로 확인하고 감염 여부를 확정하지 않은 채 격리와 재심을 함께 진행.
- 아이리스 네르: 첫 대면. 에이든의 발음·수리기술·숨긴 공구를 관찰하며 왕실 첩자·기록밀수자·질병원 가능성을 의심. 협력하지 않고 환자 행렬 순번을 현지인 동의 아래 재배치.

## Mystery
- 같은 가족 안의 유사 발병을 최초 관측하지만 감염 여부는 미확정.
- 아벨의 존재하지 않는 가족·집 기억과 `두 번째로 늦게 왔다` 발언의 의미 미확정.
- E009에서 아벨의 출생증명 2장을 대조하는 원인이 됨.

## Canon Guard
- 마나열병 기전 확정 금지.
- 아벨을 예언자로 처리하지 않음.
- 아이리스 네르를 안내자·자동 협력자로 처리하지 않음.
- `HUMAN PROSE PASS` 부여하지 않음.
