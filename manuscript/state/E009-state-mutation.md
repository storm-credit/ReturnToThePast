# E009 State Mutation — 두 개의 출생증명

Status: AUTHOR REVIEW — FIRST DRAFT

## Character
- 에이든 로엔: 같은 가족의 발열을 근거로 감염·분리를 우선했으나, 실제 관측이 가설과 어긋나자 `모른다`는 상태를 인정하고 관찰 조건을 다시 나눔.
- 아이리스 네르: 아벨 네르의 출생증명 2장을 반증으로 제시. 에이든의 판단 근거를 계속 검증하며 협력 관계로 확정되지 않음.
- 메이라 솔: 격리와 기록재심을 함께 유지하며 진단을 확정하지 않음.

## Evidence
- 아벨 네르 명의의 출생증명 2장 확인.
- 두 문서의 부모·생일·고향이 서로 다름.
- 두 문서 모두 인장 진품, 한쪽만 최근 위조됐다는 종이·잉크 흔적 없음.
- 두 번째 문서의 세금등록 번호는 현재 조회 불가.

## Symptom Observation
- 첫 번째 출생증명 낭독에는 큰 변화 없음.
- 두 번째 출생증명의 고향·부모 정보를 읽을 때 열·마력 반응 악화.
- 문서를 치우고 가족이 손을 잡자 안정.
- 감염 여부·마나열병 기전은 미확정.

## Mystery / Hook
- 두 번째 출생증명에 적힌 고향은 서부 공식 지도·옛 지명·폐촌·세금면제지 목록에서 찾을 수 없음.
- 아벨은 지도상 빈 공간을 자기 집이라고 지목.
- 회색 종이 환자 가까이에서 울고 에이든의 귀환석도 미세하게 반응했으나 원리 미확정.

## Next Cause
- 기록 불일치 환자들을 성당 구휼기사단이 실제 치료하면서 별도 분류하기 시작해 E010의 치료/강제분류 충돌로 이어짐.

## Canon Guard
- 두 출생증명 중 하나를 위조로 확정하지 않음.
- 마나열병을 비감염성으로 확정하지 않음.
- 존재하지 않는 마을의 삭제 주체·원인 확정 금지.
