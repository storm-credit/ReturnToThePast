# E011 State Mutation — 한 번 늦어진 임무

Status: AUTHOR REVIEW — FIRST DRAFT

## Choice / Cost
- 다리 분기점에서 본부 잔여시간 신호는 표적 추적로 즉시 이동을 권고.
- 다리 붕괴로 환자와 기록상자가 동시에 위험해지자 에이든 로엔은 `사람 → 기록상자` 순서로 구조.
- 구조·우회 비용으로 표적 접촉 가능 시간이 반나절 감소.
- 구조행위를 영웅적 보상으로 처리하지 않고 임무 지연 비용을 동시에 유지.

## Equipment Exposure
- 강물에 들어가 기록상자를 건지는 과정에서 숨겨 둔 미래 장비 일부가 물에 잠기고 보호표식의 푸른빛이 노출됨.
- 아이리스 네르가 이 노출을 직접 봄.
- 장비를 즉석 수리하거나 구조 해결 수단으로 사용하지 않음.

## Relationship
- 아이리스는 에이든이 사람을 먼저 구한 순서를 확인하지만 그를 신뢰·협력자로 자동 전환하지 않음.
- 미래 장비 정체를 계속 의심.

## Mystery / Hook
- 구조한 기록상자에서 `건국력 664년 장야월 24일` 작성일 문서를 발견.
- 에이든의 F0 출발일 `건국력 664년 장야월 21일`보다 3일 뒤 날짜임.
- 현재 Era N은 건국력 640년이므로 문서의 존재 이유·작성자·오기 여부는 미확정.

## Next Cause
- E011 구조행위와 치료호송 참여가 E012 임시 통행권 발급 근거가 됨.
- 아이리스는 현지 신원 보증/귀환표식 협조에 환자 이용 금지 조건을 걸 준비 상태.

## Canon Guard
- 미래 날짜 문서를 시간개입의 결정적 증거로 확정하지 않음.
- 아이리스가 문서의 의미를 알고 있는 것으로 처리하지 않음.
- `HUMAN PROSE PASS` 부여하지 않음.
