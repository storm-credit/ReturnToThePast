# E013 State Mutation — 한쪽 장부에만 있는 마을

Status: AUTHOR REVIEW — FIRST DRAFT

## Access / Cost
- 아이리스 네르의 3일 신원 보증을 사용해 지방 기록소 세금대장실 열람.
- 에이든 로엔의 조회 목적과 열람 이력이 지방 기록소에 남음.
- 열람시간은 서기 교대 전 약 2시간으로 제한.

## Evidence
- 왕실 피해보고서: 해당 마을을 세렌 바일 사건 뒤 폐허·세금기반 상실로 기록.
- 지방 세금대장: 피해보고서 이후에도 곡물세·우물 유지분·도로 공동부담·장례기금 납부가 계속됨.
- 운반인 기록: 해당 마을 주소를 사용한 실제 운반 기록 다수 존재.
- 왕실 지도와 지방 구획도는 같은 마을의 상태·위치를 다르게 표시.
- 주민 여러 명이 마을의 풍습·묘지·우물·가족노래를 구체적으로 기억하지만 길 방향은 서로 다르게 지목.

## Hook
- 최신 세금대장의 마지막 납부기록이 현재보다 하루 뒤인 `내일 날짜`로 이미 수령확인까지 완료됨.
- 선납·오기·시간 이상 중 어느 쪽인지 미확정.

## Character
- 에이든은 지방 기록이 왕실 기록보다 옳다고 즉시 뒤집지 않고 서로 다른 작성 목적·권한을 유지한 채 충돌만 확인.
- 세렌 바일의 무죄·유죄는 여전히 확정하지 않음.

## Next Cause
- 왕실 보고서의 작성시점과 후대 덧씌움 여부를 원본에서 확인하기 위해 E014 원본 열람 협상으로 이동.

## Canon Guard
- 빈 세금장부의 최종 비용배분 의미 선취 금지.
- 미래 날짜 납부를 새 시간법칙으로 설명하지 않음.
- `HUMAN PROSE PASS` 부여하지 않음.
