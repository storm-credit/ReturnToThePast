# E013 State Mutation — 한쪽 장부에만 있는 마을

Status: DRAFT PENDING AUTHOR REVIEW

## Access / Characters
- 두 역사의 라베른 지방 기록소 접근 개시.
- 지방 기록관 **엘사 네르(C12)** 첫 핵심 등장.
- 아이리스 네르의 신원 보증이 기록소 문턱에서 실제 사용됨.
- 에이든의 조회 이력과 임시 통행권 사용이 도시 기록에 남음.

## Evidence
- 왕실 피해보고서: 대상 마을 `폐허/기능 상실`.
- 현지 세금대장: 같은 마을의 납부 기록 지속.
- 왕실 지도: 마을 표시는 폐허로 갱신됐지만 주변 지형선·길은 기존 상태.
- 주민: 마을을 기억하지만 길 방향은 서로 다르게 지시.
- 마지막 납부 항목: 아직 오지 않은 **내일 날짜**로 확인.

## Interpretation Lock
- 어느 문서도 위조로 확정하지 않음.
- 마을 소거 원인·주체, 세렌 바일의 실제 기능은 미확정.

## Next Cause
- 불일치의 작성 시점과 원본을 확인하려면 엘사 네르가 관리하는 추가 기록 접근이 필요해 E014 거래로 이어짐.
