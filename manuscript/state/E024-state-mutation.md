# E024 State Mutation — 성공 판정

Status: AUTHOR REVIEW — FIRST DRAFT

## Return Registration
- 귀환표식까지 이동하며 E020의 이동시간 제약이 실제로 소모됨.
- 등록되지 않은 사람·물건은 귀환할 수 없고 강제 추가등록은 귀환 실패 위험을 높이는 안전규칙 유지.
- 세렌 바일의 부러진 짧은 검(절검 R03)을 현지 물품으로 동반 등록.
- 세렌이 E022에서 건넨 소거 위험명부 전체는 등록 용량을 초과.
- 에이든 로엔은 직접 확인한 가족·마을·환자 항목 중심의 일부만 등록하고 나머지는 현지에 남김.
- 가져가지 못한 명단은 아이리스 네르가 한곳에 두지 않고 분산 보관하기로 함.

## Asset / Ownership
- 절검은 전리품이 아니라 세렌 사망·기록봉쇄 사건의 물질 증거와 부채로 취급.
- 에이든 보유는 임시 증거 보유일 뿐 기능·최종 소유권을 확정하지 않음.
- 현지 공동체·유족 권리를 삭제하지 않음.

## Iris Separation
- 아이리스는 귀환하지 않고 남은 환자 수레·현지 기록을 택함.
- 에이든에게 `명단을 버리지 말 것`, `이름을 숫자로만 바꾸지 말 것`을 요구.
- 아이리스는 에이든의 선택을 용서하거나 정당화하지 않음.
- 귀환 연결은 E022 첫 환자 수레 길을 실제로 열었다는 기존 조건 충족에 따라 끊지 않음.

## Headquarters Verdict
- 본부 신호는 `표적 제거 완료`, `연대기 접근 차단 완료 판정`, `현장 임무 성공`을 회계식 상태값으로 표시.
- 성공 판정의 의미와 에이든의 도덕적 판단을 동일시하지 않음.

## Timeline Shift Hooks
- 귀환 좌표 명칭이 출발 때와 다른 `최후 연대국 중앙 귀환실`로 표시됨.
- 출발 인장의 교대 확인자 이름 칸이 빈칸으로 바뀜.
- 사라진 F0 동료의 신규 이름을 임의로 만들지 않음.

## Next Cause
- E025에서 에이든이 변경된 F1 본부에서 깨어나고, 익숙한 관계·기관·영웅기록이 다른 상태임을 확인.

## Canon Guard
- F1의 전체 성격과 변경 원인을 E024에서 설명하지 않음.
- 아이리스의 거부권을 로맨스나 용서로 변환하지 않음.
- 절검 후대 기능 선취 금지.
- `HUMAN PROSE PASS` 부여하지 않음.
