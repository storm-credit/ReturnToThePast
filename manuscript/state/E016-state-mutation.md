# E016 State Mutation — 세 편이 노리는 기록

Status: AUTHOR REVIEW — FIRST DRAFT

## Three-Faction State
- 왕실 추적대: 환자 살해보다 기록 회수를 우선하며 중앙 보관·법적 지휘 논리 유지.
- 지방연맹: 기록 공개를 요구하지만 서부 귀족 피해를 제외하는 선택적 공개 한계 유지.
- 세렌 바일 조직: 삭제예정지 주민 주소·증언 보존을 위해 기록을 여러 상자와 주민에게 분산.
- 어느 세력도 전체 기록을 확보하지 못함.

## Character
- 에이든 로엔: 어느 편에도 정체를 밝히지 않고 세렌 접근을 우선. 그 결과 왕실·지방연맹·개혁가 어느 쪽의 보증도 얻지 못함.
- 아이리스 네르: 지방연맹의 실제 기능과 한계를 설명하되 에이든 편으로 전환하지 않고 환자·주민 쪽 행동을 지속.
- 세렌 바일: E016에서 에이든과 첫 직접 대면. 도주보다 에이든의 출발 인장을 확인하는 행동을 선택.

## Mystery / Hook
- 세렌은 에이든 손목의 출발 인장 구조를 알아봄.
- `미래 본부`라는 표현을 직접 사용하지만 미래의 규모·명령 발신 주체·자기 미래 기록은 모르는 상태 유지.
- 세렌의 질문: `당신들의 명령문은 누가 살아남긴 기록인가.`
- 세렌이 출발 인장 구조와 미래 본부 존재를 어떻게 알았는지는 미확정.

## Next Cause
- 왕실 추적대가 지하로 진입하면서 E017에서 에이든이 세렌을 제압하고도 즉시 살해하지 않은 채 단독 대화를 선택하게 됨.

## Canon Guard
- 세렌을 모든 진실을 아는 예언자로 처리하지 않음.
- 어느 세력도 정답 진영으로 확정하지 않음.
- `HUMAN PROSE PASS` 부여하지 않음.
