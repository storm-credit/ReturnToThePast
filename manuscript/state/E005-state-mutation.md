# E005 State Mutation — 제거와 차단

Status: DRAFT PENDING AUTHOR REVIEW  
Applies only if/when E005 is accepted and merged.

## Mission
- 목표를 `세렌 바일 제거`와 `연대기 접근 차단` 2개로 확정.
- 대규모 구조·광범위 현지 조사·환자 증언 확보를 임무 범위에서 제외.
- E004의 살아 있는 현지 앵커 미확보·최대 오착 18km·강제복귀 1회 조건 유지.

## Character
### 에이든 로엔
- 목표 축소가 현지에서 도울 권한까지 줄인다는 사실을 인지하고 확정.
- 서명 동기를 `미래를 구한다는 확신`이 아니라 남겨질 사람들의 얼굴을 피하지 못한 선택으로 스스로 낮춰 평가.
- 리아의 개인 경고를 믿거나 기각하지 않고 장갑 안쪽에 보관.

### 리아 세른
- 새 공식 반증 없음.
- `기록이 틀렸다는 뜻이 아니라 기록이 살아남은 이유를 보라.`는 판단 기준만 개인 경고로 전달.
- 결정권은 에이든에게 남김.

## Mystery
- 출발 인장의 정상 표적명은 `세렌 바일`.
- 결속 과정에서 다른 2단어 이름이 순간 판독됐다는 사실만 관측.
- 다른 이름의 실제 문자열·정체·시대·주체는 미확정.
- 재현 시도에서는 세렌 바일로 정상 판독.
