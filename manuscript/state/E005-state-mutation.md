# E005 State Mutation — 제거와 차단

Status: AUTHOR REVIEW — FIRST DRAFT

## Mission
- 최종 임무 목표를 `세렌 바일 제거`와 `연대기 접근 차단` 2개로 축소.
- 현지 피해 조사, 환자 증언 확보, 서부 구조 지원, 기록 원본 회수는 임무 목표에서 제외.
- 귀환석 조건: 3갈래 균열 / 예상 체류 5시간 17분 / 최대 오착 18km / 강제복귀 1회 유지.
- 살아 있는 현지 앵커 없음.

## Character
- 에이든 로엔: 제외한 목표를 삭제하지 않고 임무표에 남겨 자신의 선택을 기록함.
- 리아 세른: 공식 반증 없이 개인 경고 `기록이 틀렸다는 뜻이 아니라 기록이 살아남은 이유를 보라.`를 암호 형태로 전달.
- 에이든은 경고를 제출하지도 버리지도 않고 장갑 안쪽에 보관.

## Mystery
- 출발 인장 판독 중 세렌 바일의 이름 아래 다른 이름이 잠깐 겹쳐 나타남.
- 다른 이름의 정체, 시간층, 원인은 확정하지 않음.
- 정본 해석상 세렌의 개인주소와 사건주소 불일치 전조로만 유지.

## Next Cause
- 목표 축소와 출발 인장 확인이 끝나면서 E006 최종 동기화·실제 도약으로 진행 가능.

## Canon Guard
- 세렌 바일의 유죄·무죄 확정 금지.
- 연대기의 최종 정체·소재·권수 확정 금지.
- 리아의 경고를 증거 또는 예언으로 취급하지 않음.
- `HUMAN PROSE PASS` 부여하지 않음.
