# E007 State Mutation — 회색 종 곁의 외지인

Status: AUTHOR REVIEW — FIRST DRAFT

## Character / Identity
- 에이든 로엔: 미래 장비의 문양·열·구조를 흙과 천으로 가리고, 환자 행렬의 운반인으로 섞임.
- 현지 방언의 뜻은 이해하지만 계급·생활 호칭을 잘못 사용해 외지인 표지가 생김.
- 공식 신분·통행보증은 여전히 없음.

## Equipment / Return
- 귀환석 냉각에 귀환용 마력 일부를 사용.
- 잠긴 기록계열 장비는 계속 사용 불가.
- 미래식 소형 공구는 노출하지 않고 헝겊으로 감아 은폐.
- 강제복귀 1회 미사용.

## Local State
- 격리촌으로 향하는 환자 행렬에 합류.
- 운반 노동은 실제 인원 부족 때문에 허용됐으며, 행렬 구성원은 에이든을 협력자로 신뢰한 상태가 아님.

## Mystery
- 폐종루의 회색 종이 에이든과 귀환석이 가까워질 때 낮게 반응하는 현상 확인.
- 종 표면의 비어 있는 타원형 흔적이 F0 본부 현장 등록표식과 계통상 유사해 보임.
- 공명 원인과 종의 감지대상은 확정하지 않음.
- 아이리스 네르는 회색 종과 귀환석 반응을 관측하고 에이든 추적을 시작하는 독립행동 상태이나, E007에서 에이든과 접촉하지 않음.

## Next Cause
- 환자 행렬이 격리촌 검문선으로 이동하면서 에이든의 불일치 신분문서와 현지 가족·세금 증명 규칙이 직접 충돌함.

## Canon Guard
- 회색 종을 예언도구·열쇠·무기로 격상하지 않음.
- 아이리스 네르를 운명적 안내자로 처리하지 않음.
- `HUMAN PROSE PASS` 부여하지 않음.
