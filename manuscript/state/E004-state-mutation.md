# E004 State Mutation — 지연의 사망자

Status: AUTHOR REVIEW — FIRST DRAFT

## Character
- 에이든 로엔: 추가 검증의 필요성을 인정한 상태에서, 지연이 실제 약품 중단 대상자를 만든다는 점을 확인하고 고위험 출발 책임서에 서명.
- 리아 세른: 살아 있는 현지 앵커 부재를 근거로 연기를 요구했고, 요구와 기각 사실을 기록으로 남김.
- 아르덴 케르: 선별실 배분이 실제 생존 증가와 다른 구역 피해를 동시에 만든다는 점을 숨기지 않고 제시.

## Mission
- 역사주소 앵커: 세렌 바일 사건기록 + 회색 종 잔향 + 서부 세무층 기록으로 성립.
- 살아 있는 현지 앵커: 미확보.
- 에이든은 현지 신분·통행보증 부재, 귀환표식 불안정, 현지 변화 실시간 확인 불가 위험을 인지하고 출발 요청에 서명.
- 실제 출발은 아직 일어나지 않음.

## Props / Evidence
- 하루 지연 시 약품 중단 대상 명단: 에이든 열람.
- 리아의 앵커 공백 의견: 기록 보존.
- 책임서/출발표: 에이든 로엔 서명 완료.
- 등록 가능 장비와 두고 갈 개인 물품 구분 시작.

## Hook / Continuity
- 목표 시대 귀환점 목록에서 접속 가능한 칸이 연속으로 사라지는 현상을 관측.
- 원인은 E004에서 확정하지 않음.
- 다음 회차 E005에서 출발 가능성을 유지하기 위해 임무 범위를 ‘개혁가 제거’와 ‘연대기 접근 차단’으로 좁히는 압박으로 이어짐.

## Canon Guard
- 세렌 바일의 실제 기능·무죄/유죄 결론 미확정.
- 귀환점 감소 원인 미확정.
- 역사주소 앵커와 살아 있는 현지 앵커를 동일 개념으로 처리하지 않음.
- `HUMAN PROSE PASS` 부여하지 않음.
