## Character

### 에이든 로엔
- 추가 검증을 기다리는 선택에도 현재 사망 위험이 발생함을 확인.
- 살아 있는 현지 앵커가 없는 고위험 출발 조건을 인지.
- 위험 인지 책임서/출발표에 본인 이름으로 서명.
- 리아 세른의 연기 의견을 삭제하지 않고 출발 기록에 남김.
- 현지 추가검증 의도는 유지.

### 리아 세른
- 살아 있는 현지 앵커 정보 부재를 근거로 출발 연기 의견 제출.
- 의견은 출발 기록에 보존됨.
- 세렌 바일의 유죄·무죄를 확정하지 않음.

## Institution / Procedure

- 역사주소 앵커는 세렌 바일 사건기록·회색 종 잔향·서부 세무층으로 성립.
- 살아 있는 현지 앵커는 미확보 상태.
- 수용 위험: 최대 오착 18km / 현지 신분·통행보증 없음 / 귀환창 단축 가능 / 현지 협력 확보 전 귀환표식 불안정 / 강제복귀 1회.
- 하루 지연 시 약품 공급 중단 대상 명단의 사본을 출발 기록에 첨부하도록 요청.

## Mystery / Operational State

- 목표 시대 귀환점 목록에서 항목이 순차적으로 사라지는 현상을 관측.
- 원인·주체·조작 여부는 미확정.
- 잔여 귀환점 수를 새로 확정하지 않음.
