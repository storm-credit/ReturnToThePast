# E023 State Mutation — 미래를 위한 한 번의 칼

Status: AUTHOR REVIEW — FIRST DRAFT

## Permanent Death
- 에이든 로엔이 좁은 기록실에서 세렌 바일을 직접 치명상 입혀 살해.
- 세렌은 도주보다 대피 시간을 벌기 위한 지연전을 선택.
- 전투는 장부·환자 통로를 파괴하지 않는 제약 아래 진행.
- 세렌 바일 사망은 L001 영구손실로 잠금: 부활·재시도·다른 시간대 버전 대체 금지.

## Aiden Responsibility
- 살해 근거는 세렌이 거짓말쟁이라는 결론이 아니라 `F0 19만 예측 + 표적 생존 시 11일 + 귀환시한` 우선.
- 에이든은 자기 판단이 틀릴 가능성을 알고도 살해함.
- 본부 명령·숫자가 대신 칼을 쥔 것으로 면책하지 않음.
- L003 첫 살인 책임 잠금.

## Biolock / Institutional Reaction
- 세렌 치명상 → 사망 → 생체인장 소실 순서 유지.
- 생체인장 소실 뒤 서부 기록봉쇄가 풀림.
- 이미 대기하던 왕실 기록망이 서부 기록층으로 신속히 진입.
- 에이든은 왕실망을 즉시 차단할 방법을 갖고 있지 않음.

## Local Temporal Effect / Hook
- 도시 곳곳 회색 종이 거의 동시에 울림.
- 세렌이 건넨 위험명단과 주민목록 일부에서 이름·주소가 국소적으로 흐려지기 시작.
- 시간선 확정 지연 규칙에 따라 세계 전체가 즉시 완전히 덮어써지지 않고 1단계 국소 잔향만 나타남.
- 본부는 `임무 목표 1: 완료 — 세렌 바일 제거`를 표시.

## Next Cause
- 귀환표식이 잠시 열린 상태에서 E024 등록 용량 제한 아래 절검과 소거명부 일부만 회수하고, 아이리스 네르는 환자 호송을 선택함.

## Canon Guard
- 세렌의 전체 역사적 기능·창시자 기록 이유 공개 금지.
- 세렌 사망을 되돌릴 가능성 암시 금지.
- 주민 이름 흐림의 최종 범위·원인 전부 확정 금지.
- `HUMAN PROSE PASS` 부여하지 않음.
