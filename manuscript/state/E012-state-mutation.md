# E012 State Mutation — 조건부 통행권

Status: DRAFT PENDING AUTHOR REVIEW

## Subact 1B Resolution
- `신분 없음` 문제는 임시 통행권으로 국소 해결.
- 새 문제는 `조건부 신분 + 위치 추적 + 짧아진 시한 + 현지 앵커 거부권`으로 교체.
- Subact 1C 지방 기록소 조사 경로 개방.

## Access / Registration
- 치료노역·붕괴 구조 실적을 근거로 아홉 상처 대성당 사무소가 임시 통행권 발급.
- 통행권은 도시 내 위치기록·구역제한을 포함하며 완전 신분 아님.
- 아이리스 네르의 신원 보증으로 지방 기록소 접근 가능 조건 성립.

## Local Anchor
- 아이리스 제공: 도시 안내 + 현지 신원 보증.
- 조건: 환자 안전을 에이든의 표적 접근 목적보다 뒤로 밀면 보증·귀환표식 연결을 끊음.
- 아이리스의 귀환표식 차단권 유지. 자동 강제귀환 가능성에 실질 영향.
- 신뢰/로맨스가 아니라 상호 거부권 관계로 시작.

## Deadline / Hidden Debt
- 본부가 E011 지연을 반영해 제거 시한을 앞당김.
- 에이든은 시한 단축을 아이리스에게 공개하지 않음.
- 이 정보 비대칭이 1C의 상호 불신 부채로 시작됨.

## Mystery
- 도시 종루의 회색 종은 울리지 않았으나 아벨 네르 포함 환자 집단이 동시에 귀를 막음.
- 에이든과 귀환석은 대응 반응 없음.
- 원인·감지 대상 미확정.
