# E012 State Mutation — 조건부 통행권

Status: AUTHOR REVIEW — FIRST DRAFT

## Access / Identity
- E010 치료노역과 E011 구조행위가 실제 문서상 근거로 환산됨.
- 에이든 로엔은 성당 사무소에서 7일짜리 임시 통행권을 발급받아 도시 안쪽에 진입.
- 통행권은 완전 신분이 아니며, 도시 내 에이든 위치가 기록되기 시작함.

## Living Local Anchor / Iris
- 아이리스 네르는 도시 안내와 현지 신원 보증을 3일 조건으로 제공.
- 조건: 에이든이 환자·환자 명부를 자기 목표 접근 수단으로 사용하면 귀환표식 연결을 끊을 수 있음.
- 에이든은 조건을 수용했으나 임무 목적 전체는 공개하지 않음.
- 상호 신뢰가 아니라 양쪽 거부권을 가진 조건부 협력 상태 성립.

## Headquarters Deadline
- 본부는 목표 접근 지연과 귀환점 감소를 반영해 제거 시한을 앞당김.
- 에이든은 이 시한 단축 사실을 아이리스에게 공개하지 않음.
- 아이리스는 에이든이 잔여시간의 구체적 수치를 숨겼다는 사실을 인지함.

## Mystery / Hook
- 도시 종루의 회색 종은 실제로 울리지 않았고 에이든 귀환석도 반응하지 않음.
- 그러나 관문을 지난 환자들이 거의 동시에 귀를 막음.
- 아벨 네르는 `시끄러워` 뒤 `이름이`라고 말함.
- 환자들이 무엇을 들었는지, 회색 종·주소 불일치와 어떤 관계인지 확정하지 않음.

## Subact Transition
- 1B `격리촌의 통행증` 국소 해결.
- 신분 없음 → 조건부 신분/현지 보증 확보로 변환.
- E013부터 1C 기록 검증·표적 혐의 현장조사로 진입.

## Canon Guard
- 아이리스가 에이든의 시간여행 정체·임무 목적을 간파한 것으로 처리하지 않음.
- 환자의 동시 반응을 마나열병 기전의 정답으로 설명하지 않음.
- `HUMAN PROSE PASS` 부여하지 않음.
