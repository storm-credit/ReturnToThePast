# E019 State Mutation — 죽으면 열리는 봉쇄

Status: DRAFT PENDING AUTHOR REVIEW

## Disclosure
- 에이든 로엔이 세렌 바일에게 자신의 임무가 `세렌 제거`임을 명시.
- 미래 안정구역 생존자 42만, 제거 시 19만 증가라는 본부 예측을 다시 공개.
- 귀환창이 줄었다는 사실은 공개하되 정확 잔여시간은 공개하지 않음.

## Seren / Blockade
- 세렌 바일의 생체인장이 서부 기록망 봉쇄의 강제키라는 사실 활성화.
- 세렌 생체신호가 끊기면 봉쇄 유지선도 끊어진다는 현지 구조를 아이리스 네르가 독립 확인.
- 세렌이 죽으면 봉쇄가 내려간다는 핵심은 확인.
- 왕실이 그 뒤 기록망을 장악한다는 세렌 주장은 이 회차 장치판만으로는 완전 확인되지 않음.
- 세렌은 후임 감사구조·권한 분산을 완성하지 못했고 봉쇄권을 혼자 보유 중.

## Decision State
- 세렌 살해 = 현지 기록망 봉쇄 해제 비용 발생.
- 세렌 생존 = 위험한 단일 권한 독점 유지.
- 에이든은 즉시 제거·즉시 임무취소 모두 하지 않고 봉쇄권 처리 가능성을 다음 검증 대상으로 올림.
