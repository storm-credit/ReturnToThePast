# E019 State Mutation — 죽으면 열리는 봉쇄

Status: AUTHOR REVIEW — FIRST DRAFT

## Siege / Local State
- 왕실군 포위가 완성돼 환자 대피로가 사실상 차단됨.
- 환자 수레 화재는 진압됐지만 남쪽·서쪽·북쪽 주요 통로가 통제 상태.

## Seren / Biolock
- 세렌 바일은 자신의 생체인장이 서부 기록봉쇄의 강제키임을 공개.
- 세렌이 죽으면 생체인장 연결이 꺼지고 왕실 기록망이 서부에 진입한다는 현지 인과를 제시.
- 아이리스 네르가 현지 연결판을 확인해 `세렌 사망 시 봉쇄 연결 종료`, `왕실망 대기`라는 핵심 구조를 검증.
- 세렌의 주장은 이 부분에서 사실로 확인됨.
- 생체인장 복제·즉시 이전·부분분리는 현재 불가능하며 간편 절차를 새로 만들지 않음.

## Moral / Authority State
- 세렌은 왕실 독점을 막으려다 봉쇄권을 자기 생체인장에 집중시킨 사실과, 이를 자발적으로 내려놓지 않은 사실을 인정.
- 세렌을 순수 희생자로 처리하지 않음: 선의와 위험한 권한 독점이 동시에 존재.
- 에이든이 그 권한을 대신 소유하는 해법 역시 제시하지 않음.

## Future Disclosure / Headquarters
- 에이든 로엔은 세렌에게 자기 임무가 `세렌 제거 + 연대기 접근 차단`임을 추가 공개.
- 본부는 `표적 생존 조건 재산정` 결과 `F0 잔여 예상일 11일`을 전송.
- 이 수치는 선별계열 예측값이며 객관적 확정 미래로 취급하지 않음.
- 아이리스와 세렌 모두 본부가 현지 봉쇄 구조를 직접 보지 못한다는 점을 인지.

## Next Cause
- `세렌 생존 → F0 11일 예측`과 `세렌 사망 → 서부 봉쇄 해제`가 동시에 사실인 상태에서 E020 시간·장부·귀환 계산으로 진입.

## Canon Guard
- 세렌 사망 뒤 실제 재앙 가속 결과는 아직 공개하지 않음.
- 봉쇄 해제는 E023 사망 순간까지 실제 실행하지 않음.
- 세렌 바일 무죄 확정 금지.
- `HUMAN PROSE PASS` 부여하지 않음.
