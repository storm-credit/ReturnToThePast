# E018 State Mutation — 하루가 줄어든 증거

Status: AUTHOR REVIEW — FIRST DRAFT

## Verified Offenses
- 세렌 바일의 금지된 시간·주소 의식 시행 사실 유지.
- 동의 없는 기억채취 사실 유지.
- 왕실 명령 불복종 사실 유지.
- 따라서 왕실 기록의 행위 축 혐의는 날조로 뒤집히지 않음.

## Causal / Date Conflict
- 환자 발생일, 왕실 보고서 작성일, 마을 주소 이상일, 세금 납부 지속시점이 한 방향으로 정렬되지 않음.
- 첫 환자는 공식 사고일보다 먼저 증상이 시작됐고, 다른 환자는 그 뒤에 시작됨.
- 마을 주소 이상은 공식 사건순서보다 앞서며 세금은 폐허 판정 뒤에도 이어짐.
- 한 날짜를 고치는 방식으로 인과가 복구되지 않음.
- 날짜층을 누가 바꿨는지, 마나열병 기전, 세렌의 전체 기능은 미확정.

## Headquarters Reaction / Return
- 에이든 로엔은 `혐의 3항목 현지 재확인`과 `결과 인과 불일치`, `제거 전 기록 계보 추가 검증`을 본부에 전송.
- 본부는 요청을 거부하지 않고 `시간오염 가능성 분류 상향`으로 처리.
- 절차적 재산정 결과 귀환창이 1일 단축됨.
- 본부 반응을 악의적 방해나 음모로 확정하지 않음.

## Relationship
- E012에서는 정확한 시한을 숨겼으나 E018에서는 아이리스 네르에게 `하루 줄었다`는 사실을 알림.
- 아이리스는 본부가 현지를 실시간으로 보지 못한 채 절차상 결정을 내린다는 점을 확인하지만 에이든의 양심 대변자나 자동 동맹으로 전환하지 않음.

## Hook / Local Threat
- 귀환창이 1일 줄어든 직후 왕실군이 `오염 기록물 운반 수레`라는 이유로 은신처 외곽 환자 수레에 불을 놓음.
- 수레 안에는 실제 환자가 남아 있음.
- 방화 주체는 현장 왕실군으로 관측되지만 더 큰 지시 주체·의도는 이 회차에서 확정하지 않음.

## Subact Transition
- 1C `증거가 맞고 진실이 틀릴 때` 종료.
- 상태: 세렌의 행위 유죄는 확정 / 미래 재앙 인과는 미확정 / 본부와 현지 어느 한쪽도 완전히 신뢰할 수 없음.
- E019부터 1D 저항·제거·귀환 구간으로 진입.

## Canon Guard
- 세렌 바일 무죄 확정 금지.
- 날짜 위조 주체 확정 금지.
- 마나열병 비감염성 확정 금지.
- 세렌의 생체인장과 서부 봉쇄 관계는 E019 전까지 공개하지 않음.
- `HUMAN PROSE PASS` 부여하지 않음.
