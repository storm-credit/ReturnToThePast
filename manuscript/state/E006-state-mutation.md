## Mission / Time

- Era N 잿빛 변경 서부 도착 성공.

- 실제 공간오차는 상한 18km에 근접한 수준으로 실현되며 예정 도시 내부가 아닌 서부 격리촌 외곽 수로에 착지.

## Aiden / Assets
- 에이든 로엔: 도약 후 왼손 운동 반응 지연을 확인.
- 일부 장비가 시간 오차로 잠김. 구체 장비 기능을 새 정본으로 확정하지 않음.
- 현장 기록판 지도·현재 위치 판정이 정상 작동하지 않음.
- 신분문서는 물리적으로 온전하지만 현지 법의 통행 인장 형식과 불일치.
- 강제복귀 1회는 미사용 상태 유지.
- 리아의 개인 경고는 장갑 안쪽 미신고 반입물로 유지.

## Mystery

- 원리·감지 대상·관측자 해석은 미확정.
