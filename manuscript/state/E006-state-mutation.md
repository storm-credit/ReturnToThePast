# E006 State Mutation — 빗나간 도착

Status: AUTHOR REVIEW — FIRST DRAFT

## Time / Location
- 출발: F0 건국력 664년 장야월 21일.
- 도착: N0 건국력 640년 안개월 4일.
- 공간오차: 약 18km 상한에 가까운 오착, 서부 격리촌 외곽 진흙 수로.
- Subact 1A 종료 / 1B 진입.

## Mission / Return
- 역사주소 앵커 성립, 살아 있는 현지 앵커 없음.
- 강제복귀 1회는 오착 수정에 사용하지 않고 보존.
- 귀환석 중심층 3갈래 균열 상태 유지.
- 도착과 동시에 잔여 체류시간 계산 시작.

## Equipment / Identity
- 기록계열 장비 일부와 의료주머니 보존표식이 시간 오차로 잠김.
- 소형 공구와 임무자료는 사용 가능.
- 현지 신분문서는 현재 지역 표식·세금구획과 맞지 않아 신분 실패 상태.
- 임무에 등록되지 않은 개인 물품은 F0에 두고 옴.
- 리아 세른의 개인 경고문은 장갑 안쪽에 미신고 상태로 반입됨.

## Mystery
- 먼 거리의 회색 종과 귀환석이 같은 박자로 진동하는 현상을 최초 관측.
- 종이 무엇을 감지하는지, 공명의 원리와 주체는 확정하지 않음.

## Character
- 에이든 로엔은 오착을 바로잡기 위해 강제복귀를 소비하지 않고 현지 생존을 선택.
- 다음 과제는 장비 은폐, 신분 확보, 격리촌 접근.

## Canon Guard
- 아이리스 네르는 E006에 등장하지 않음.
- 오착을 장치 고장으로 처리하지 않음. E004에서 수용한 위험의 직접 결과로 유지.
- `HUMAN PROSE PASS` 부여하지 않음.
