## TIMELINE_STATE

- Era F1 / 칼레온 대기록소 보존실 대기선. E036 직후 회수조 확인이 pending인 상태에서 보존실 대기선 절차가 이어짐
- 귀환패 파편 보존통과 장부 압흔 복원 결과 원본 묶음은 대기록소 보존실에 남아 있으며, 원본 물증은 이동·분할·재활성되지 않음
- 리아 세른은 증거를 개인 소유하거나 원본을 나누지 않고, 존재 확인과 접수 시각을 서로 다른 공공 보관처에 남기는 분산 접수 계획을 제시함
- 회수조 선임자는 분산 접수가 회수 회피나 물증 오염으로 읽힐 수 있음을 지적하지만, 원본 훼손이 없고 수정권·원문 접근이 닫힌 조건에서는 반대권 보유 상태로 보류함
- 에이든은 사용 제한자로서 개인 철회 불가 조건에 동의함. 이 동의는 추가 영웅 접근권 소진이 아니라 분산된 존재 확인을 에이든 혼자 나중에 철회할 수 없게 하는 상태 변화임
- 장례기록소는 사망 확정이 아니라 `부존재 대조 요청`으로 보류 접수함. 사망자명·사망 원인·유족 청구권은 열리지 않음
- 민간 길드는 원문·수정권 없이 봉인표 사본의 해시와 접수 시각만 공공 보관 증인으로 접수함. 길드는 장부 의미를 주장하지 않고, 허위·불완전 의심 시 공개 질의권만 보유함
- 대기록소 보존실 원본 묶음, 장례기록소 보류 접수, 민간 길드 공공 보관 완료가 서로 다른 표식으로 남아 증거 존재 확인이 한 곳에만 있지 않은 상태가 됨
- 본부 감사망이 공동 보존자 접근 위임, 세무층 제한 대조, 장부 압흔 복원, 장례기록소 보류 접수, 민간 길드 보관 완료를 비정상 열람으로 자동 감지함
- 방위지휘부 쪽에서 두 번째 임무 소집서가 에이든 손목판에 도착함. 대상 칸은 봉인 상태이며, 수락·보류 응답 칸이 먼저 열림

## RELATIONSHIP_MUTATIONS

- 에이든 ↔ 리아: 둘의 협력은 기억 공유나 사적 신뢰가 아니라, 에이든의 사용 제한자 동의와 리아의 보존 책임 확장으로 이어짐. 에이든은 리아가 정지될 위험을 의식하지만 접수 시각을 나누는 선택을 받아들임
- 에이든 ↔ 회수조 선임자: 회수조 선임자는 적대자로 전환되지 않음. 에이든은 회수조의 반대권 보유와 원본 훼손 확인이라는 조건부 절차를 이해하고, 회수조는 즉시 반대 대신 상태 확인으로 보류함
- 리아 ↔ 장례기록소/민간 길드: 리아는 두 기관에 최종 의미나 사망 확정을 요구하지 않고, 각 기관이 감당할 수 있는 보류 접수·증인 접수만 요청함. 두 기관은 자기 피해와 권한 한계를 이유로 조건을 붙임
- 에이든 ↔ 미래 본부/방위지휘부: 본부 감사망 자동 감지와 두 번째 임무 소집서가 에이든 손목판에 도착함. 에이든은 아직 대상 정보를 받지 못했고 수락·보류 응답 압력을 받는 상태로 끝남
