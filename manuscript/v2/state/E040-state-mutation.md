## TIMELINE_STATE

- 통신기록 추가 검토가 임무실 탁자에서 열림. 주소심사 표면과 별도인 청색 통신표면으로 발신·수신 분류, 시간창, 전달 실패, 요약 표지만 부분 공개됨
- 두 번째 표적의 왕실 접촉 외형은 실제 기록으로 유지되지만, 배신 동기 분류는 본문 잠금 상태의 C등급 요약 표지로 분리됨
- 에이든은 통신기록의 사실 줄과 분류 줄을 분리해 다음 검토에 올리라고 요구함
- 빈 장부 경로 대조가 열리고, 에이든은 두 번째 표적 주소보다 빈 장부 경로 표식을 먼저 대조하기로 선택함
- 빈 장부 원본 이동, 실물 위치, 소유권, 수취 기관 원명, 내용은 계속 열리지 않음
- 첫 표적 조사망 대조가 열리고, 열린 표면 기준으로 조사망은 배신 분류가 아니라 왕실 접촉 외형과 장부 경로 표식 쪽을 따라감
- 빈 장부 경로 끝점에 의료국 확인 필요와 보호 시설 분류 가능성이 붙고, 최종 분류명으로 마나열병 아동 보호소가 드러남
- 에이든은 대체 목적 문서 초안에 빈 장부 출처 추적, 장부 운반자 또는 보호 시설 접수 경로 확인, 표적 제거 근거 사용 금지를 올리려 함. 아직 목표변경안 확정은 아님

## RELATIONSHIP_MUTATIONS

- 에이든 ↔ 리아: 둘은 두 번째 표적 기록 전체를 부정하지 않고, 접촉 외형과 동기 분류를 나누는 방식으로 검토를 맞춤. 리아는 에이든의 선택을 확장하지 않고 문구 폭을 줄여 기록함
- 에이든 ↔ 마르칸: 마르칸은 실제 접촉 기록과 구조 지연 비용을 근거로 계속 압박하고, 에이든은 장부 경로 추적을 먼저 열되 암살 주소로 합치지 못하게 막음
- 리아 ↔ 마르칸: 리아는 출처·등급·잠금 유지로 제한하고, 마르칸은 현장 출발문과 병력 조건을 요구함. 갈등은 악역화 없이 절차와 비용 차이로 유지됨
- 에이든 ↔ 첫 표적: 에이든은 첫 표적 조사망 연결을 보지만, 첫 표적의 의도·실제 역할·창시자 기록 이유를 확정하지 않음. 이름 직접 지칭도 하지 않음
- 에이든 ↔ 두 번째 표적: 에이든은 왕실 접촉 외형을 실제 기록으로 받아들이며 자동 신뢰를 피함. 동시에 배신 분류를 암살 근거로 승격하지 않음

## PERMANENT_LOSS_OR_IRREVERSIBLE_CHOICE

- 에이든은 두 번째 표적의 암살 주소 추적보다 빈 장부 경로 표식 우선 대조를 선택함

- 배신 동기 분류는 본문 잠금 상태의 C등급 요약 표지로 분리되어 암살 주소 보완 근거로 승격되지 않음
- 첫 표적 조사망과 빈 장부 경로 표식의 부분 연결이 열림. 의도·목적·실제 역할은 확정되지 않음
- 장부 경로 마지막 분류명으로 마나열병 아동 보호소가 열림. 접수문 번호·명단·병명 판정·세부 주소는 미공개 유지

## CLOCK_MOVEMENT

- 통신기록 검토로 두 번째 표적의 왕실 접촉 외형은 실제로 유지되지만, 배신 동기 분류가 분리되어 즉시 암살 근거가 약화됨
- 빈 장부 경로 표식 우선 대조가 열리면서 다음 절차가 암살 주소 획득에서 증거 경로 추적 쪽으로 기울기 시작함
- 방위지휘부는 구조 지연 비용과 병력 구성 재계산을 유지해 시간 압박이 줄지 않음
- 의료국·유지부·등록부·지휘부 공동 확인 필요성이 열림
- 훅: 빈 장부 경로 마지막 분류명이 마나열병 아동 보호소로 열리고, 이 경로가 첫 표적 조사망 표식과 부분 연결됨
