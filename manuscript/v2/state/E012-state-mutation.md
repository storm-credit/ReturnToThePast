## TIMELINE_STATE

- Era N / CY 640 / 안개월 4일 연속. E011 종료 뒤 강가길 위로 올라온 환자 수레가 도시 관문 검사대에 도착함
- 에이든은 성당 구휼기사단 치료보조자 명부 등재자 상태에서, 환자 수레와 기록상자 구조 실적을 근거로 조건부 도시 통행권을 발급받음
- 환자 수레는 도시 관문 검사대 → 성당 사무소 → 사무소 밖 대기자리 → 관문 안쪽 종루 아래 대기자리로 이동함. 이 구간에서 도시 안쪽이 처음 열림
- 통행권은 승리나 자유 통행권이 아니라 성당 사무소와 관문 안쪽 종루 아래 대기자리 사이 이동, 환자 호송 보조, 기록상자 개봉 금지, 재검문대 기록 접근 불가, 보증인 철회 시 대기자리 복귀 조건이 붙은 제한권임
- 아이리스는 네르 대표 보증을 조건부로 남기고, 에이든이 환자·보호자·기록상자를 표적 접근 수단으로 쓰면 보증과 귀환표식 협조를 걷겠다고 조건을 걸었음
- 에이든은 은폐 가능한 구석에서 귀환석·출발 인장 반응을 확인하고 본부가 표적 접근 시한을 앞당겼음을 알았지만, 아이리스·메이라·검사관에게 말하지 않음
- 관문 안쪽 종루 아래에서 회색 종은 울리지 않았는데 대기 중 환자들이 동시에 귀를 막는 반응이 발생함. 원인·기전·진단은 공개되지 않음

## RELATIONSHIP_MUTATIONS

- 에이든 ↔ 아이리스: 구조 선택을 목격한 감시 관계 → **조건부 보증과 상호 거부권 관계**. 아이리스는 에이든의 통행을 돕지만 신뢰하지 않으며, 환자·기록상자·보호자를 표적 접근 수단으로 쓰면 보증과 귀환표식 협조를 걷겠다고 조건을 붙임
- 에이든 ↔ 메이라: 응급 구조 현장 협력 접점 → **통행권 발급 근거를 공유한 실무 접점**. 메이라는 에이든의 치료보조자 실적을 제도 언어로 정리하지만, 환자 진료와 기록상자 개봉 제한은 계속 분리함
- 에이든 ↔ 관문 검사관 / 성당 사무소: 처리 불가 외지인 → **조건부 통행자로 등재**. 에이든의 도시 체류는 자유가 아니라 기록과 철회 조건 아래 시작됨
- 아이리스 ↔ 메이라: 환자해방 요구와 감염·수용 조건의 충돌 관계 유지. 이번 화에서는 메이라가 진료 책임, 아이리스가 통행 보증을 분리해 맡음
- 아이리스 ↔ 환자 가족들: 뒤쪽 물통·보호자·이름 확인을 조정하는 지역 대표 기능 강화. 결정권을 환자에게서 양도받지는 않음
