## TIMELINE_STATE

- Era N / CY 640 / 안개월 4일 연속. 라베른 은신처 임시 은신실 이후, 에이든은 표적을 기록 비교대로 옮겨 왕실 기록·현장 기록·지방 확인문을 비교함
- 표적은 생존 상태로 유지되며 기록 비교대 아래 쇠고리에 다시 묶임. 즉시 처형 없음
- 왕실 기록상 금지의식 혐의, 기억채취, 동의 공란, 중지 조건 미확보, 명령불복종은 공식 혐의로 성립한다고 에이든이 판정함
- 같은 검증에서 환자 발생일, 피해보고서 접수, 마을 폐허 표시, 내일 날짜 세금 납부가 서로 맞물리지 않음을 확인함
- 에이든은 환자 구역에서 아벨의 증언을 들음. 아벨은 첫 열과 몸에 남은 흔적, 들은 기억, 현재 증명되지 않는 빈자리 관련 말을 서로 다른 등급으로 말하려 하지만 병 때문에 등급이 흔들림
- 에이든은 환자 증언을 자동 진실로 확정하지 않지만, 문서 날짜와 환자 몸의 증언이 인과를 흔든다고 판단함
- 에이든은 통신 지점에서 본부에 검증 요청과 제거 명령 원문 열람 요청, 표적 제거 보류 상태를 송신함
- 본부는 검증 요청을 거절하지 않고 시간오염 신호로 재분류함. 원문 열람 권한 없음, 제거 명령 유지, 현장 체류 위험 상승, 귀환창 안전폭 1일 회수가 통보됨
- 귀환석의 둥근 표시 하나가 검게 죽어 귀환창 1일 단축이 물리적으로 확인됨. 귀환석 귀환 사용 없음
- 왕실 추적대가 환자 수레와 기록 상자를 분리하려는 현장 대응 중 불붙은 갈고리로 환자 수레의 짚 덮개에 불을 붙임. 환자 수레 방화가 회차 종료 훅으로 발생함
- 귀환용 응급약갑 잔량 3개 유지. 강제복귀 1회 미사용. 암호 조각 해독 없음

## RELATIONSHIP_MUTATIONS

- 에이든 ↔ 표적: 처형자/표적 관계는 유지되지만, 에이든은 표적의 자백과 기록 계보 요구를 분리해 검증함. 표적은 자기 유죄 요소를 인정하면서도 인과 판정을 요구하고, 에이든은 그 요구를 본부 검증 요청에 포함함
- 에이든 ↔ 본부: 직접 통신 발생. 본부는 원문 열람을 허락하지 않고 검증 요청을 시간오염 신호로 재분류함. 에이든은 본부 회신을 최종 근거로 수용하지 않음
- 에이든 ↔ 아이리스: 아이리스는 환자 구역의 물자·호흡·결론 비용을 기준으로 에이든을 제한함. 제한 협력은 유지되며 신뢰 전환 없음
- 에이든 ↔ 아벨: 에이든은 아벨을 심문 대상이 아니라 날짜와 몸의 증언을 가진 환자로 대함. 아벨은 본부가 무엇인지 모르며, 자기 말이 어디에 적히는지 먼저 확인함
- 에이든 ↔ 왕실 추적대: 에이든은 왕실 기록의 혐의를 인정하지만, 종료 시 왕실 추적대의 환자 수레 방화로 현장 위험을 직접 마주함. 왕실 전체 적대화 없음
- 아이리스 ↔ 아벨: 아이리스는 아벨을 보호하되 결정권을 대신 행사하지 않음. 대답 거부를 열어 주고 물을 배분함
