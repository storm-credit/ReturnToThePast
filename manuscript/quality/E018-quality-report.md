# E018 품질 보고서 — 하루가 줄어든 증거

Status: AUTHOR REVIEW — FIRST DRAFT / NOT HUMAN-PROSE APPROVED

## 설계 대조
- S형 3장면: 기록 비교대 / 환자 구역 / 본부 통신.
- 행위축 3항목을 각각 사실로 확정: 금지된 시간·주소 의식, 동의 없는 기억채취, 왕실 중단명령 불복종.
- 결과축은 별도 판정: 환자 발생일·왕실 보고서 작성일·마을 소거/납부 시간이 서로 다른 방향으로 어긋나 하나의 공식 인과로 묶이지 않음.
- 환자의 직접 기억과 몸 상태를 문서보다 먼저 확인하고, 직접 본 것과 전해 들은 것을 분리 기록.
- 본부 검증 요청은 거절이 아니라 `현지 시간오염 가능 신호`로 자동 분류.
- 그 결과 귀환창이 하루 단축되며 취소해도 복구되지 않음.
- 마지막에 왕실군이 은신처 외곽 환자 수레 쪽에 불을 놓은 물리 위협으로 1D 진입.
