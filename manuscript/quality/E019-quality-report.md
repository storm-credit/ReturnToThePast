# E019 품질 보고서 — 죽으면 열리는 봉쇄

Status: AUTHOR REVIEW — FIRST DRAFT / NOT HUMAN-PROSE APPROVED

## 설계 대조
- Q형 2장면: 포위된 은신처 안쪽 방 / 장치실 전실.
- 에이든 로엔이 미래 멸망·42만 생존자·세렌 제거 시 19만 증가 예측과 자기 제거 임무를 제한 공개.
- 세렌 바일은 생체인장이 서부 기록망 봉쇄의 강제키이며, 자신이 죽으면 봉쇄가 꺼진다고 밝힘.
- 아이리스 네르가 현지 확인판으로 `세렌 생체신호 단절 → 봉쇄 유지선 단절`을 독립 확인.
- 왕실이 실제 다음 접근권자라는 부분은 아이리스가 이 판으로는 확인 불가라고 선을 그음.
- 같은 검증에서 세렌이 봉쇄권을 혼자 쥐고 후임·분산 구조를 완성하지 않았음도 확인.
- 봉쇄 이전·복제·대체키의 간편 해법을 제시하지 않음.
- 종료 훅: 본부가 `표적 생존 시 F0 잔여일 예측 11일`을 갱신. 객관적 확정값이 아니라 예측으로 처리.

## Legacy 대조

- 옛 19화는 검은 시장에서 추격자가 접근하는 전투·도주 압박이 핵심이다.
- 새 E019는 세렌 생체인장과 서부 기록망 봉쇄의 연동, 권한 독점의 비용, 본부 11일 예측이 핵심이므로 옛 추격자·검은 시장 사건을 이식하지 않는다.
- 참고 가능한 범용 원리는 외부 압박이 판단 시간을 좁히는 방식뿐이며, 현행 원고에서는 왕실 포위와 환자 수레 연기로 이미 구현한다.
