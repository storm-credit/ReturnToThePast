# E015 품질 보고서 — 병원처럼 보이는 실험실

Status: AUTHOR REVIEW — FIRST DRAFT / NOT HUMAN-PROSE APPROVED

## 설계 대조
- S형 3장면: 은신처 외곽 / 두 갈래 통로 / 명단실.
- 병원·대피소와 실험실로 동시에 읽히는 관측 사실을 같은 순서로 제시.
- 에이든은 합리적으로 실험시설 해석을 택하고 증거실, 아이리스 네르는 환자 탈출로를 택해 우선순위로 분리.
- 명단은 감염자 목록이 아니라 삭제예정지 주민·족보·이동 예정표로 재판독.
- 같은 시설에 동의 없는 기억채취가 실제 존재해 세렌 바일 측 위법을 유지.
- 세렌 무죄·임무 취소로 넘어가지 않음.
- 실험기록에서 본부 출발 인장과 같은 핵심 결속 구조의 도면 관측. 원리·작성자 미확정.

## Anti-Padding 재감사
기준: `docs/13_writing_harness/anti-padding-policy-v1.md`.

재감사에서 다음을 실제 수정했다.

- `E010`, `E013`, `E014`처럼 독자용 서술에 노출된 내부 회차번호 제거.
- `그게 첫 번째 문제였다`, `그게 오히려 정확했다`처럼 장면 의미를 따로 정리하는 문장 제거.
- 병원/실험실 관측을 서술자가 다시 해설하던 반복 축소.
- 아이리스와의 조건을 설계문구 `환자 안전을 자기 목적보다 뒤로 밀지 않는다`로 직접 노출하던 문장을 실제 합의 내용으로 교체.
- 마을의 폐허/납부/방향 불일치를 여러 단문으로 재요약하던 부분을 1문장으로 압축.
- `삭제예정지 주민 대피 / 동의 없는 기억채취 / 같은 방` 및 `하나는... 하나는... 둘 다 사실` 대구형 재해설 제거.
- F0 내부 표기 대신 독자가 이미 아는 `본부에서 출발할 때`로 표현.
- 출발 인장 발견 뒤 같은 결론을 3회 반복하던 문장 축소.

3장면의 사건 기능은 유지했으며 분량 보충을 위한 새 전투·실험체·구출·복선은 추가하지 않았다.
