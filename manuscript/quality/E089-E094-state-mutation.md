# E089–E094 State Mutation

Status: AUTHOR REVIEW — FIRST DRAFT

- E089: 전면복원 단일 다수결 기각. 존재·가족 소거 고위험 당사자 거부권과 옛 도시 부분권리 보호 거부권을 분리.
- E090: 시간개입 없이 복구 가능한 역사명·증언시민권·문화·조합·계약·장례·일부 자산권을 실제 집행. 완전 영토·시정권·연속 공동생활은 남는 손실로 확인.
- E091: 전면복원 시간임무를 현재 영향당사자 거부와 고정족수 미충족으로 기각. 통째 원상복구 재시도 금지 방향 확정.
- E092: L004 실행. 옛 도시의 완전한 영토·지배권 복원 포기, 과거 도시 통째 복원 재도약 금지. 반대의견 보존.
- E093: 개별 토지권을 보상·공동관리·향후 재협상으로 처리. 현재 주민 강제퇴거 없음. 시간개입 후속피해 책임기금 논리 도입.
- E094: 비영토 법적 공동체 `증언도시` 성립. 영토·군사·강제시민등록·일반세금·독자 시간임무권 없음. 역사·시민·문화·계약·장례·일부 공공자산·기록이의 권리 보장.

## Exit
증언도시가 법적 존재가 되었으며 완전 영토복원은 영구손실로 잠겼다. 다음 E095–E100은 이 권리가 국제·식량·항만·시민·법정에서 실제로 작동하는지 검증하고 V4를 종료한다.
