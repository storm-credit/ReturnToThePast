# E057–E062 State Mutation

Status: AUTHOR REVIEW — FIRST DRAFT

- E057: 에르나·카르둔·네바르 기록을 사건 기준으로 대조. 세렌 조사망 개입 뒤 중앙 회수 및 관련 피해 증가폭이 낮아지는 방향 확인. 네바르 판결에서 세렌 이의로 생존자 6명 사망처리 정정.
- E058: 기록단위 중복 제거. 73개 관측을 42개 사건묶음으로 정리하되 실제 피해 총수로 쓰지 않음. 공통 인장 원명칭 `부담 경감 개정안` 발견.
- E059: 개정안에 주소미확정·중앙회수 중지와 실제 부담 재배분 조항이 함께 존재. 세렌 단독 설계 기록 약화. 후대본 조항순서 변경 확인.
- E060: 왕실 원본 압수/소각 압박 속 주민·분산사본을 우선. 유일 원판 열손상 가능, 에르나·카르둔·네바르 독립 사본 생존.
- E061: 에이든이 `세렌=재앙 창시 원인` 판단 오류를 공식 서명. 세렌 조사망의 일부 지역 부담완화·확산지연 방향 기능을 한정 확정. 불법행위 사실 유지.
- E062: 세렌 사망 복구 금지 재확인. 절검 에이든 소유권 주장 종료, 조사망·네바르·카르둔 공동보관권 잠금.

## Exit
오류판정과 근거가 공개 가능한 복수 경로로 보존된다. 다음 단계는 진실 공개가 F1의 영웅서사·배급체계·복원정치에 만드는 후폭풍이다.
