# E076–E081 State Mutation

Status: AUTHOR REVIEW — FIRST DRAFT SUPPORT

- E076: 백지도·빈 세금장부·생존자 기억을 겹쳐 사라진 도시의 장소를 좁힌다. 현장에는 군사도로와 소규모 마을이 있으며 옛 증인과 현재 주민을 분리 조사한다. 군사도로 아래 도시 종소리가 들린다.
- E077: 같은 길에서 탐사자별 도착시간·피로 차이가 발생한다. 공동 증언과 카르둔 표식으로 길 일부를 안정시키지만 일부 탐사자는 몇 시간의 기억을 잃고, 한 사람만 옛 성문 앞에 도착한다.
- E078: 지하 폐허·시장 표식·우물을 확인한다. 오래된 폐허가 자동으로 더 정당한 원본이라는 해석을 거부하고, 폐허 우물과 현재 마을 우물의 수맥·사용기억 연결을 확인한다. 현재 우물에 옛 도시 사람 이름이 떠오른다.
- E079: 현재 토지소유자와 옛 도시 후손이 같은 땅의 문서를 맞대고 소유·거주·문화·보상권을 분리한다. 측량국이 인근 거리 붕괴 방지를 명분으로 복원 금지령을 선포하며, 서명자가 현재에 존재하지 않는 관리라는 모순이 드러난다.
- E080: 완전복원 시 현재 군사도로·마을·가족 손실 가능성을 확인한다. 도시 전체가 아니라 증언 가능한 구역의 이름·범위만 시험 고정한다. 백지도에 도시명이 절반만 나타나고 군부의 책임 추궁과 옛 귀족 인장 활성화가 발생한다.
- E081: 세 종족 기록과 현지 생활 흔적으로 도시 위치를 재검증하고 법적 도시가 아닌 `시간주소 조사구역`으로 임시 등록한다. 장소 존재는 입증되지만 소유·지배권은 미결이다. 옛 귀족 가문의 지배권·세금권 소장이 도착하고 증언자 한 명의 이름이 흐려진다.

## Exit
- 사라진 도시의 장소 존재는 검증된다.
- 현재 군사도로와 마을의 생활권은 자동 소거하지 않는다.
- 도시 전면복원은 실행하지 않는다.
- 시간주소 조사구역이 성립한다.
- 장소 존재와 소유·지배권을 분리한다.
- 다음 문제는 기록 없는 주민이 소송과 청문에서 법적 주체로 설 수 있는가이다.
