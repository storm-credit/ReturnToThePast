# E038–E043 State Mutation

Status: AUTHOR REVIEW — FIRST DRAFT

- E038: 두 번째 표적이 에이든의 F0 동료 얼굴임을 확인. F1에서는 에이든에게 패배한 배신자로 기록. 최근 위치는 빈 장부 출처와 겹침.
- E039: 리아가 증거 부족으로 암살 역사주소 서명을 공식 거부. 거부 주소 중 하나는 세렌 사망 뒤 새로 생긴 행정주소.
- E040: 왕실 접촉 자체는 실제로 확인. 동기 미확정. 운반자 탈출 흔적과 다른 환자 이동로 급습이 동시에 존재. 장부 경로 끝에 아동 보호소.
- E041: 마르칸의 지연 피해예측을 유효한 비용으로 인정. 암살이 원인을 해결하는지는 별도 문제로 남김. 구조 후보에 아벨 네르 포함.
- E042: 귀환용량 한계로 환자·운반자·기록 우선순위 결정. 두 번째 표적은 현지 잔류 가능. 아이리스의 3개 현지 조건 수용. 감시요원 동행 조건 발생.
- E043: `표적 제거`를 `증인 확보·기록 회수·현지 주민 대피권 보장`으로 재작성. 좌표·귀환·부담·역사주소·현지동의 새 정족수 성립. 본부 감시요원 합류. 감시요원 이름이 Era N 운반자 기록에 이미 존재.

## Canon Gap
두 번째 표적 정식 이름/ID는 현 정본 인물표에서 미확정. 본 초고는 임의 고유명 추가 없이 유지.

## Exit
구조 임무로 Era N 재진입 준비 완료. 시간 오차 수개월 가능성이 명시적으로 남음.
