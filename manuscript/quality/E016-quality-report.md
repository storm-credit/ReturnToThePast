# E016 품질 보고서 — 세 편이 노리는 기록

Status: AUTHOR REVIEW — FIRST DRAFT / NOT HUMAN-PROSE APPROVED

## 설계 대조
- E형 4장면: 지붕길 / 지하통로 / 기록 분산 / 세렌 바일 첫 짧은 조우.
- 왕실 추적대는 사람보다 기록 회수, 지방연맹은 공개하되 귀족 피해는 제외, 개혁가 조직은 주민 주소·족보 보존을 우선.
- 에이든은 어느 편에도 정체를 밝히지 않아 3세력의 보증을 모두 잃고 읽지 못하는 암호 조각만 확보.
- 아이리스 네르는 에이든의 반복된 무응답을 독립적으로 기억.
- 세렌 바일은 에이든의 출발 인장 구조를 알아보고 `당신들의 명령문은 누가 살아남긴 기록인가`라고 묻지만 시간여행 원리를 설명하지 않음.

## Anti-Padding 재감사
기준: `docs/13_writing_harness/anti-padding-policy-v1.md`.

재감사에서 다음을 실제 수정했다.

- `E013/E014/E015`처럼 독자용 본문에 노출된 내부 회차번호 제거.
- 실제로 말하지 않은 대사를 인용한 뒤 `혼잣말하지 않았다`고 설명하던 모순 제거.
- `문제는 그다음이었다`, `문제는 공개라는 원칙...` 같은 의미정리 문장 제거.
- 지방연맹 대화 뒤 이미 드러난 이해관계를 서술로 다시 요약하던 반복 삭제.
- `첫 번째 문/두 번째 문/세 번째 문이 닫혔다`의 인위적 3단 대칭 축소.
- 기록 분산 뒤 같은 결과를 `문서가 찢겼다 → 각 세력이 가져갔다 → 어느 세력도 전체를 못 가졌다 → 자신도 마찬가지`로 반복하던 부분 축소.
- 세렌 조우 뒤 `도망치지 않았다/붙잡지 않았다/인장을 읽었다/위치가 뒤집혔다`로 의미를 재해설하던 결말 삭제하고 세렌의 마지막 대사에서 장면 종료.

4장면의 실제 기능과 세 세력의 독립 목적은 유지했다. 분량을 위해 옛 전투·추격·괴물 장면을 추가하지 않았다.
