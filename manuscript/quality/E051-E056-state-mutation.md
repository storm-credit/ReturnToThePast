# E051–E056 State Mutation

Status: AUTHOR REVIEW — FIRST DRAFT

- E051: 공식 지도에서 지워진 서부 도로를 라하크 신수의 이동기억과 현지 물질흔적으로 추적. 이동형 환자·기록 호송대 발견.
- E052: 환자 호송 뒤 실제 발병 경험 때문에 지역 민병 차단 발생. 비살상 돌파. 민병 명령서가 F1식 목표·피해·허용손실·책임서명 배열과 유사.
- E053: 아동 증인이 절검을 보기 전 카르둔 공방 핵심 인장을 독립 재현. 공방 화재날 에이든을 봤다는 기억은 미검증으로 분리.
- E054: F1 추적자와 왕실 추격 동시 발생. 운반자가 추적요원의 미래 이름을 세렌의 Era N 축약명부에서 이미 봤다고 증언.
- E055: 붕괴에서 아이를 먼저 구조해 종이 원본 상당 부분 상실. 상자 이중판의 다종족 축약장부 확보. 중앙 단독 판독 불가.
- E056: 에이든 감염책임설이 실제 피해가족의 경험자료로 확산됨. 에르나 기록층 판독 시작. 에르나·카르둔·네바르 기록이 같은 날을 가리킨다는 다음 검증 예고.
