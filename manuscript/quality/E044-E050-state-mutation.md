# E044–E050 State Mutation

Status: AUTHOR REVIEW — FIRST DRAFT

- E044: Era N 목표보다 4개월 6일 늦게 도착. 세렌 사망 뒤 봉쇄 해제와 왕실 기록망 확대 확인. 환자 위치미확인 증가.
- E045: 과거 임시신분은 추정사망 처리. 아이리스가 현지 보증 위험 부담. 에이든 과거 구조행위는 왕실 기록상 `외국 간첩 사건` 발단.
- E046: 두 번째 표적의 왕실 거래 사실·타 이동로 피해 인정. 영웅담 최초 보고서 계열 오래된 사본 확보. 에이든 미기억 숙청명령 서명 존재, 진위 미확정.
- E047: 왕실·지방연맹·감시자 충돌. 지휘 분산. 아이리스가 앵커 동기화를 40분 늦춰 현지 대피를 우선. 왕실이 귀환점 위치 파악.
- E048: 에이든이 암살 폐기·구조 우선을 공개 선언, 공식 임무 실패자. F1 정규 귀환수용 취소. 감시요원 체포권 부여.
- E049: 카르둔 잔류시설로 불안정 대체귀환. 환자·운반자 우선. 다렌이 신병회수팀 지휘로 추적. 먼저 보낸 운반자는 생존 도착했으나 F1 법적 존재 불인정.
- E050: 다렌이 F1 가족·시민 보호를 이유로 추적함을 명시. 영웅담 사본·빈 장부 단서를 제한 공유. 두 번째 표적 증언으로 세렌 마지막 조사 장소가 `지도에서 길이 지워진 서부 도로`임을 확보.

## V2 Exit
- 에이든: 영웅→본부 통제/회수 대상 전환.
- 리아: 직위 안정성 악화.
- 아이리스: 현지 독립 지휘 유지.
- 다렌: 현재 시민 보호를 위한 추적자.
- 증거: 영웅담 사본 일부, 빈 장부 분산사본, 절검 제작흔적, 삭제주소 귀환패 반응.
