# E082–E088 State Mutation

Status: AUTHOR REVIEW — FIRST DRAFT

- E082: 동부 곡창 미라 라디아가 옛 식량채무 상환의 현재 생존필수 상한 제안. 자유해안과 10년 내 재협상 목표.
- E083: 남부 항만노조 토마르 마레이가 항만사용권 상환의 노동·하역·검사비용을 현재 권리로 올림. 도시 후계 법적 주체 부재 확인.
- E084: 영토·군사·강제시민등록 없는 옛 도시 권리 공동기구 설계. 기능별 대표·정족수로 계약책임 시작.
- E085: 도시 역사명·문화·조합·묘지 권리 일부 법적 복원. 현재 마을 행정명·사용권 유지.
- E086: 자발적 증언시민권 첫 발급. 자동혈통 승계 금지, 거부·철회권 유지.
- E087: 자유해안 상호감사 임시협약. 양쪽 원본·공증 오류를 서로 검증. 복원파가 전면 도시복원 시간임무 공식 제안.
- E088: 전면복원 영향표에 현재 마을·가족·식량·항만·외국계약·백지권 공동체 소실 가능성 포함. 도시기억자 내부 입장도 분열.

## Exit
도시 피해는 법적·문화적으로 복구되기 시작했지만 전면 영토복원은 현재 권리를 지우는 비가역 선택으로 좁혀진다.
