# E082–E088 State Mutation

Status: AUTHOR REVIEW — FIRST DRAFT SUPPORT

- E082: 주민 명부를 세금·출생기록 대신 생활·노동·관계 증언으로 작성한다. 핵심 증언자의 얼굴·이름이 사람마다 다르게 보이는 무명화가 시작되고, 가족 물건·신수 감지·반복 생활동선 등록으로 현재 존재를 고정한다. 보증인도 주소 불안정 비용을 나눠 진다. 무명화된 증언자가 옛 귀족의 직계후손으로 나타난다.
- E083: 인간 장부의 서로 다른 3명이 실은 한 사람의 생애 단계·시간선별 호칭임을 에르나 기억문·네바르 장례기록 대조로 확인한다. 하나의 현재 인격에 옛 이름들을 별칭·권리근거로 연결한 통합명부가 성립하며, 옛 이름은 현재 인격을 덮어쓰지 못한다. 같은 방식으로 현재 주민 수십 명의 옛 신분이 드러난다.
- E084: 옛 도시의 토지 수탈·종족 이동 통제 기록이 공개 자료가 된다. 후손의 피해 복권 주장과 가해 역사가 상쇄되지 않은 채 병존하고, 현재 주민 조상 일부가 붕괴 당시 난민을 구조한 사실이 확인된다. 귀족 측이 그 구조행위를 반역으로 처벌한 왕실문서를 제출한다.
- E085: 귀족·군부·난민 삼자 청문이 열리고 에이든은 임시명부 작성권을 지역 법정에 위임한다. 중앙이 전국 소유권 판결 연쇄 동요를 이유로 법정의 시간주소 취소를 시도하며, 법정 건물의 문이 지도에서 사라진다.
- E086: 사람과 땅 중 사람의 현재 신분을 먼저 고정하는 비가역 선택을 한다. 복수 증인·현재 관계·생활 흔적으로 임시 시민권을 부여하고 토지 소유권 판결은 유예한다. 도시 경계가 안정되고 옛 성벽 일부가 재출현하며, 옛 후손은 재산 회복 지연을 배신으로 느낀다. 성벽 안쪽 왕실 승인문 보관소가 열린다.
- E087: 에이든이 영웅·요원 권한 대신 개인 보증 책임을 선택해 임시 시민권에 서명한다. 주민 투표는 완전복원 여부를 후속 결정으로 남긴다. 옛 귀족이 왕실 정본 인장을 제시해 지배권 주장을 강화하고, 주민이 무명화되면 에이든의 법적 주소도 함께 흔들린다. 승인문이 완전복원 의식의 열쇠로 작동한다.
- E088: 완전복원 의식이 시작돼 옛 거리·시장이 현재 마을 위에 겹치고 배우자·부모·자녀 관계가 다른 시간선 기록으로 치환되기 시작한다. 주민을 경계 밖으로 대피시키고 현재 명부를 여러 기관에 복제한다. 의식 직접 파괴는 장소 전체 붕괴 위험이라 해법에서 제외된다. 아이 1명이 자기 어머니를 알아보지 못한다.

## Exit
- 임시 시민권과 증언 공동체가 성립한다. 주민은 기록이 아니라 증언·관계·생활 흔적으로 법적 주체가 된다.
- 현재 인격이 과거 토지보다 우선한다는 비가역 선택이 확정된다. 토지 소유권 판결은 유예 상태다.
- 에이든은 권한이 아니라 개인 보증 책임을 지며, 주민 무명화가 그의 법적 주소와 연동된다.
- 옛 도시의 가해 기록과 구조행위 반역 처벌 왕실문서가 공개 자료가 된다. 단일 피해자 구도가 해체된다.
- 옛 성벽 일부와 왕실 승인문이 재출현하고, 승인문을 열쇠로 완전복원 의식이 시작된다.
- 가족기록 치환이 진행 중이며 주민 대피와 현재 명부의 기관별 복제까지가 이 구간의 대응이다.
- 다음 문제는 주소 기반이 약한 주민부터 흐려지는 소거를 어떻게 막는가이다.
