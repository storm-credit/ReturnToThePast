# E027–E031 State Mutation

Status: AUTHOR REVIEW — FIRST DRAFT

## E027
- 에이든: F0 동료 부재를 사망으로 확정하지 않음.
- F1 제도: 귀환 후 동선기록과 기억오염 관찰·권한정지 절차 확인.
- 증거: 이름 없는 추모벽 문장에 F0 동료 필체와 동일한 특징 발견. 문장에는 `이전 원본에서 전사` 표식이 붙고 상세 경로는 기록소 승인 필요.
- 관계: 다렌이 에이든의 기억 불일치를 명시적으로 인지하기 시작.

## E028
- 에이든/리아: 문서배열 암호의 뜻을 공유하지만 세부 배열·근무기억은 불일치.
- 리아: 에이든 기억을 정답으로 주장하지 않고 자기 기억과 자료도 검증대상으로 유지.
- 기록: 리아 개인일지에 `에이든이 다시 왔다. 바일은 이번에도 서명하지 않았다.` 문구 존재.
- 시간 충돌: 해당 일지 문구는 에이든이 기억하는 출발 18시간 전이며, 같은 시각 현재 출입기록상 에이든은 출발대기실 안에 있음.
- 미확정: `다시 왔다`가 직접 대면인지, 전달·통신인지, 정확히 몇 번째 접촉인지 확정하지 않음.

## E029
- 마르칸 베르(C04) 직접 등장.
- F1: 병원·곡창·주거구의 실제 생존성과 운영효율 확인.
- 자료검증: 인구·병상·곡물·기록누락 추정치를 분리해 대조하고, 불리한 오차를 적용해도 장기 생존 증가 방향은 유지.
- 비용: 회색 재앙의 대규모 시작이 에이든·리아 기억보다 약 20년 앞당겨짐.
- 인과: 첫 대규모 발병지는 세렌 사망지가 아님. 두 사실의 인과는 미확정.

## E030
- 다렌 가족: 배우자·아이 2명·이웃과 일상생활을 이어 가는 F1 현재 시민으로 확인.
- 공동기억: 다렌은 에이든이 기억하지 못하는 구조대 전초기지 전투와 구조 행동을 기억함.
- 단서: F0 적대 세력 문장이 F1 국가 구조대 문장으로 사용되고, 서로 다른 시기의 사진에도 같은 표식이 남아 있음.
- 도덕비용: 과거 복원을 시도할 경우 현재 가족의 출생·관계가 달라질 가능성을 부정할 수 없음. 소거를 확정하지는 않음.
- 에이든: 복원도 비복원도 약속하지 않고 사실 검증을 우선함.
- 훅: 다렌은 에이든이 과거에도 미래를 되돌리려 했다고 진술.

## E031
- 에이든: 영웅 증언에서 세렌 제거·봉쇄 해제를 분기점으로 인정하지만 기억하지 못하는 후속 숙청을 새로 직접 지휘했다고 확인하지 않음.
- 접근권: 현재 공적과 연결된 강제이전·분류재심·사망실종·주소분쟁 피해기록을 고등기록 열람 사유로 제출해 제한열람권 확보.
- 도덕부채: 하지 않은 숙청 공적과 피해자 기록을 접근권 획득에 이용.
- 의료국: 고등기록 접근 승인 직후 시간임무 귀환자 정밀검사 소집. 두 통보의 인과는 미확정.
- 기록소: `F0`라는 격리분류명과 복수 파일이 현재 존재함을 확인.
- 미확정: `F0`의 최초 등록일·명명자·뜻·현재 귀환 이전 존재 여부는 아직 확인하지 못함.

- `F0` 분류명과 복수 파일 존재 확인, 기원은 미해결.
