# E027–E031 State Mutation

Status: AUTHOR REVIEW — FIRST DRAFT

## E027
- 에이든: F0 동료 부재를 사망으로 확정하지 않음.
- F1 제도: 귀환 후 동선기록과 기억오염 관찰·권한정지 절차 확인.
- 증거: 이름 없는 추모벽 문장에 F0 동료 필체와 동일한 특징 발견.
- 관계: 다렌이 에이든의 기억 불일치를 명시적으로 인지하기 시작.

## E028
- 에이든/리아: 문서배열 암호를 공유하지만 세부 기억은 불일치.
- 리아: F0 기억을 정답으로 주장하지 않고 검증대상으로 유지.
- 기록: 리아 개인일지에 에이든과 세렌의 추가 만남을 암시하는 `다시 왔다` 문구 존재.
- 시간 충돌: 해당 기록은 에이든이 기억하는 출발 전날에 놓임.

## E029
- 마르칸 베르(C04) 직접 등장.
- F1: 병원·곡창·주거구의 실제 생존성과 운영효율 확인.
- 비용: 회색 재앙의 대규모 시작이 에이든·리아 기억보다 약 20년 앞당겨짐.
- 인과: 첫 대규모 발병지는 세렌 사망지가 아님.

## E030
- 다렌 가족: F1 현재 현실의 실재 시민으로 확인.
- 도덕비용: F0 복원은 현재 가족의 출생·관계를 소거할 수 있음.
- 에이든: `현재 사람을 지우는 복원은 하지 않는다`를 현시점 원칙으로 세우되 미래를 보증하는 약속으로 만들지 않음.
- 단서: F0 적대 세력 문장이 F1 국가 구조대 문장으로 사용됨.
- 훅: 다렌은 에이든이 과거에도 미래를 되돌리려 했다고 진술.

## E031
- 에이든: 자신의 공식 영웅서사를 완전히 부정하지 않고 고등기록 제한열람권 확보.
- 도덕부채: 하지 않은 숙청 공적과 피해자 기억을 접근권 획득에 이용.
- 의료국: 시간오염 정밀검사 소집.
- 기록소: `F0`라는 복수파일 격리분류가 에이든의 현재 귀환 이전부터 존재함을 확인.

## Subact 2A Exit
- F1 현재시민의 실재성 유지.
- F0 기억도 검증대상으로 하향.
- 영웅 접근권 획득 / 감시 강화.
