# E022 품질 보고서 — 명단을 받은 살인자

Status: AUTHOR REVIEW — FIRST DRAFT / NOT HUMAN-PROSE APPROVED

## 설계 대조
- Q형 2장면: 은신처 외곽 탈출로 / 마지막 방.
- 에이든이 왕실군과 전면 교전하지 않고 `수레는 금지 / 환자·물자 도보 이동은 방해하지 않음`이라는 한 방향 최소 탈출로만 열어 줌.
- 길을 여는 동안 귀환·협상 여유가 실제로 줄어드는 대가를 먼저 지불.
- 마지막 방에서 봉쇄권 이전을 재요구하지만, 에이든 개인 약속은 미래 기관에 강제력이 없어 세렌이 검증불가를 이유로 거부.
- 세렌은 자기 죽음 뒤 소거될 가능성이 높은 마을·가족·환자 명단을 `증거`가 아니라 `인계물`로 넘김.
- 에이든은 명단을 가슴 방호구 안쪽에 보관.
- 세렌은 순교자처럼 죽음을 수용하지 않고, 살고 싶고 권한도 넘기지 않는 상태 유지.
- 회색 종 1회 + 귀환창 최종 단계 + 무기 인출로 종료.

## Anti-Padding 재감사
기준: `docs/13_writing_harness/anti-padding-policy-v1.md`.

재감사에서 다음을 실제 수정했다.

- `E011/E020/E021` 같은 내부 회차번호를 독자용 본문에서 제거.
- 왕실군과 아이리스의 책임구조를 서술자가 `둘 다 자기 책임 안에서 움직였다`고 재해설하던 문장 삭제.
- 최소 탈출로가 열린 뒤 `전면 돌파가 아니었다 / 한 방향만... / 대가가 귀환석에...`로 의미를 3회 정리하던 부분 축소.
- 세렌이 순교자가 아님을 `정확했다 / 성인처럼... / 살고 싶어 했다 / 권한도...`로 반복하던 부분을 실제 `내가 죽는다고 정한 적 없습니다` 대사로 남김.
- `세면 숫자가 된다 / 42만·19만과 비교하게 된다`라는 주제 해설 제거.
- 협상 결렬 뒤 `책임지는 사람이 다르다 / 같은 사람을 지키면 쉽다 / 아니었다` 대구형 해설 제거.
- 마지막 `논파돼서 끝난 게 아니다 / 시간이 끝났다 / 합의가 아니라 실행` 정리문을 삭제하고 귀환창 최종단계·회색 종·무기 인출로 종료.
- 분량을 위해 옛 잔향·전투 장면을 추가하지 않음.
