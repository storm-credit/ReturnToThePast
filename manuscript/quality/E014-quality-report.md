# E014 품질 보고서 — 약품으로 산 열람시간

Status: AUTHOR REVIEW — FIRST DRAFT / NOT HUMAN-PROSE APPROVED

## 설계 대조
- E형 4장면: 기록소 협상실 / 격리촌 약품 인계 / 원본 열람실 / 사본대.
- 뇌물이 아니라 엘사 네르의 책임 위험을 사본 분산으로 줄이고, 주민 이익은 환자 약품으로 늘리는 거래.
- 약품을 먼저 실제 환자에게 인계해 되돌릴 수 없는 비용으로 확정.
- 세렌 바일의 금지의식 혐의는 원본에서도 유지.
- 원본 작성일은 사건 발생 전, 피해 수치는 다른 잉크층으로 나중에 덧씌워진 흔적.
- 서명자는 문서 작성일보다 먼저 죽은 기록관. 이름은 정본 미확정이라 신규 생성하지 않음.
- 귀환용 응급자원 잔량 감소는 장면 결과와 상태기록으로만 남기고 영웅적 자기희생 문장으로 확대하지 않음.

- 참고 가능한 것은 사건과 무관한 작법 원리뿐이다: 공간 제약이 이동 선택을 바꾸는 방식, 아이리스가 에이든에게 종속되지 않고 자기 판단을 유지하는 방식, 비용이 다음 행동에 남는 방식.

## Anti-Padding 재감사
기준: `docs/13_writing_harness/anti-padding-policy-v1.md`.

재감사에서 다음 문제를 실제 수정했다.

- 독자용 원고에 내부 회차번호 `E013`을 직접 언급하던 문장 제거.
- 약품 감소를 빈 상자 → 수량 재계산 → 인계 전/후 → 귀환 후 몫으로 여러 번 반복하던 부분 축소.
- `값은 먼저였다`, `원본은 답을 주지 않았다. 더 나쁜 질문을 줬다` 같은 설계 의미를 다시 정리하는 문장 제거.
- 원본 발견 뒤 `혐의가 남음 / 작성일 역전 / 피해수치 후첨`을 여러 단문으로 재요약하던 부분을 1회로 압축.
- `E003의 삭제된 증언자`처럼 내부 회차 표기를 서술에 노출한 부분을 `출발 전 확인했던 삭제된 증언자`로 교정.
- 마지막 장면의 응급약품 비용 재설명은 상태 기록 행동 1회로 축소.

4장면의 기능 자체는 유지했다. 분량 확보를 위해 새 사건·전투·복선·관계변화를 추가하지 않았다.
