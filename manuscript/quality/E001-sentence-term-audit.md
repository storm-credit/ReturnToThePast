Episode: E001

## 1. 검사 방식

원고를 처음부터 끝까지 문장 순서대로 읽으며 다음을 검사했다.

1. 첫 청취만으로 행동과 공간을 이해할 수 있는지
2. 장비명이 실제 측정 대상과 일치하는지
3. 전체 이름·이름·성·직책·현장 호출명이 장면에 맞는지
4. 기관명이 정본명인지 기능명인지 구분되는지
5. 판타지 설정어가 첫 등장 문맥으로 이해되는지
6. 어려운 일반어·고어·내부 조어가 불필요하게 남았는지
7. 숫자·사건·설정·인물 의도가 유지되는지

## 2. 핵심 교정

| 위치 | 기존 | 교정 | 이유 |
|---|---|---|---|
| 관측실 첫 경보 | `압력계.` | `지하 진동계 확인해.` | 실제 장면은 압력이 아니라 지하 진동을 확인함 |
| 관측병 보고 | `외벽 압력이 아닙니다` | `외벽 쪽 진동이 아닙니다` | 장비와 보고 대상 일치 |
| 첫 무전 | `서부 구조대 로엔` | `서부 구조대 에이든` | 정본상 현장 호출명은 `에이든`; 성 단독 호출 금지 |
| 공식 시스템 호명 | `에이든 로엔 요원` | 유지 | 공식 기록·시스템에서는 전체 이름 사용 |
| 기관 첫 등장 | 기관명 3개만 나열 | 직후 기능 설명 추가 | 독자가 이름만 암기하지 않도록 기능 연결 |
| 방위총감 첫 등장 | `방위총감` | `방위지휘부를 총괄하는 방위총감` | 직책과 기관 연결 |
| 시설 용어 | `증기관` | `증기 공급관` | 첫 독해에서 기능이 바로 보이게 함 |
| 병원 설정 | `병원 인장이 풀린다` | `병원을 유지하는 인장이 풀린다` | 인장의 기능 보충 |
| 시간 용어 | `시간선 잔향` | `다른 시간선의 흔적, 그러니까 시간선 잔향` | 첫 등장 의미 보충 |
| 계산 부서 | `생존선별실` | `생존 예측을 맡는 선별실` | 내부 조어의 기능 보충 |
| 기록 시설 | `원본 기록층` | `원본이 보관된 기록층` | 공간 기능 명확화 |
| 신체 표식 | `등록흔` | `현장요원 등록 표식` | 낯선 축약어 제거 |

## 3. 기관명 정합성

- `방위지휘부`: E001 Context Pack의 구조·군사·생존배분 실무기관으로 유지
- `방위총감`: E001 기능인물 직책으로 유지, 마르칸 베르와 병합하지 않음
- `연대출귀원`: 정본 명명 패키지의 출발·귀환 관리기관 공식명으로 유지
- `성력국`: 정본의 공식 기관명으로 유지
- `달력국`: 성력국 내부 달력 실무부서명으로 정리
- `중앙관측탑연합`, `대기록소`, `왕좌승인원`: 정본 명칭 유지

교차 기준은 `docs/00_project/terminology-and-addressing-clarification-v1.md`에 기록했다.

## 4. 에이든 호칭 정합성

- 첫 등장: `에이든 로엔`
- 일반 서술: `에이든`
- 현장 무전: `서부 구조대 에이든`
- 공식 시스템: `에이든 로엔 요원`, `현장요원 에이든 로엔`
- `로엔` 단독 사용: 제거

## 5. 보존 확인

- 제7방벽 붕괴와 구조 인원 감소 유지
- 공동 승인으로 인한 지연 유지
- 에이든의 브리핑 수령·임무 동의 보류 유지
- 리아의 비인가 접근과 `세` 글자 유지
- 모든 기존 날짜·인원·생존일수·예측값 유지
- 세렌의 유죄·무죄와 기록 조작 주체를 확정하지 않음
- 방위총감에게 새 이름을 부여하지 않음
