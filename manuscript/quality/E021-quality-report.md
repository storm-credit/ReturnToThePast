# E021 품질 보고서 — 도주처럼 보이는 대피

Status: AUTHOR REVIEW — FIRST DRAFT / NOT HUMAN-PROSE APPROVED

## 설계 대조
- E형 4장면: 지하창고 / 수레열 / 귀환표식 중간 확인지점 / 외곽 발각.
- 실제 무기·실제 위조신분·포위 중 이동을 먼저 도주·반란으로 읽을 근거로 제시.
- 아이리스 네르가 같은 물건을 `삭제 예정 주민의 새 주소`와 `호송 방어용 무기`로 정정.
- 정정 뒤에도 위조·무장·세렌의 정보 은폐 사실은 남김.
- 에이든은 정정을 사실로 받아들이면서도 대피를 돕지 않고 장부 확보를 우선.
- 아이리스의 귀환표식 단절 선언은 이전 합의의 집행으로 처리. 새 협박·배신 아님.
- 마지막에 첫 환자 수레가 왕실군 차단선에 발견됨.

## Legacy 대조
- 비교 원본: `Drafts/Vol_1/Vol_1_Chapter_21.md` (`아득한 기록`).
- 옛 21화는 이레이저와의 전투·반복 생애 기억·부상 누적이 핵심이며 현재 E021의 대피/장부 선택 구조와 사건이 다르다.
- 따라서 추격전·이레이저·반복 생애 기억은 직접 재사용하지 않는다.
- 참고 가능한 범용 원리는 피로·부상·시간 비용이 다음 선택에 실제로 남아야 한다는 점뿐이며, 새 E021에서는 귀환창·대피로·현지 앵커 거부권으로 구현한다.

## Anti-Padding 재감사
기준: `docs/13_writing_harness/anti-padding-policy-v1.md`.

재감사에서 다음을 실제 수정했다.

- `E020`, `E012` 같은 내부 회차번호를 독자용 본문에서 제거.
- 무기/위조신분의 판독이 바뀐 뒤 `사라진 것은 아니었다 / 목적이 달라졌을 뿐` 식 의미 재해설 삭제.
- 수레열에서 같은 사실을 3차례 다시 확인하던 대화와 해설을 축소.
- `정확한 정보를 얻었지만 선택은 바뀌지 않았다`, `오해보다 더 불편했다` 같은 주제 정리문 삭제.
- 아이리스 조건을 설계문구로 다시 풀어 설명하는 문단 축소하고 실제 대사로 남김.
- `귀환경로는 에이든 소유가 아니었다`, `한 사람은... 한 사람은... 길이 갈렸다` 같은 격언·대구형 마감 제거.
- 마지막 `선택의 비용이 눈앞에서...` 해설 제거하고 `첫 수레 발각` 기록과 에이든의 정지 행동으로 종료.
- 분량 확보를 위해 옛 추격전이나 새 전투를 추가하지 않음.
