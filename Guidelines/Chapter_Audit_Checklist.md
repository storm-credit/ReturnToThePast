# 🕵️ 챕터 검수 체크리스트 (Chapter Audit Checklist)

> **적용 대상**: 모든 챕터 초안
> **목표**: 건조한 느와르 톤, 시간여행 패러독스 프레임, 대가의 법칙, 높은 웹소설 가독성을 동시에 유지한다.

---

## 1. 분량 및 구성

| 항목 | 기준 | 확인 |
| :--- | :--- | :---: |
| **글자수** | **공백 제외 순수 한글 3,500자 이상**. 내용상 필요하면 더 길어져도 됨. **미달이면 다른 항목과 무관하게 즉시 재작성.** | □ |
| **사건 밀도** | 한 화에 최소 1개의 위기, 반전, 발견, 선택 중 하나가 있는가? | □ |
| **끝맺음** | 마지막 문장이 다음 화를 읽게 만드는 질문이나 잔여 압력을 남기는가? | □ |

## 2. 문체 및 분위기
*(참고: `lore_bible/style/Tone_Manner_Guide.md`)*

| 항목 | 기준 | 확인 |
| :--- | :--- | :---: |
| **건조한 감정** | 감정을 직접 이름 붙이기보다 행동과 감각으로 드러내는가? | □ |
| **잔혹성 절제** | 과장된 혈색 수사(`핏빛`, `선혈`, `피비린내`)를 장식처럼 남발하지 않는가? | □ |
| **웹소설 직진성** | 한 번에 읽히는 문장과 동선이 유지되는가? | □ |
| **서사 절제** | 분위기 서술과 비유가 흐름을 끊지 않고 장면 선명도에 기여하는가? | □ |
| **중2병 대사 금지** | 운명론 웅변, 허세 선언, 멋 부린 악역 대사가 없는가? | □ |
| **중2병 서사 금지** | 인물과 사건을 선택받은 자 감성, 과장된 파멸 미학, 자기 신화화로 포장하지 않는가? | □ |
| **폭력의 체감** | 피의 시각적 과시보다 통증, 이명, 숨 막힘, 후유증, 몸의 무게가 중심인가? | □ |
| **가독성** | 짧은 문장, 짧은 문단, 잦은 줄바꿈으로 모바일 가독성이 확보되는가? | □ |
| **아이리스 말투** | 아이리스가 나른한 소녀 톤을 유지하는가? | □ |
| **세계관 용어 절제** | `인과율`, `패러독스` 같은 핵심어를 설명서처럼 남발하지 않는가? | □ |
| **고유명사 어감** | 지명, 세력명, 금기명, 물건명이 고풍하고 오래된 다크 판타지 어감을 유지하는가? | □ |

## 4. 금지 요소

| 항목 | 기준 | 확인 |
| :--- | :--- | :---: |
| **시스템/게임 용어** | 시스템, 상태창, 퀘스트, 스킬, S급 등 가벼운 현대 장르 용어가 없는가? | □ |
| **현대 SF 용어** | 데이터, 코드, 시뮬레이션, 로봇, 백도어, 팩트 같은 용어가 없는가? | □ |

| **중2병 독백/서사** | 자기 신화화, 장엄한 파멸 미학, 세계를 상대로 한 과장 독백이 없는가? | □ |
| **과장된 엔딩 문장** | 챕터 끝을 거창한 선언문으로 밀어붙이지 않는가? | □ |

## 핵심 질문

> **이 챕터에서 에이든은 무엇을 얻었고, 그 대가로 무엇을 잃었는가?**

잃은 것이 없다면, 그 화는 구조상 다시 점검해야 한다.

## 분량 실패 처리

- 공백 제외 `3,500자 미만`이면 그 화는 **자동 FAIL**이다.
- 자동 FAIL 화는 `Chapter Audit 통과`로 취급하지 않는다.
- 자동 FAIL 화는 `3화 배치 검증`, `5화 체크포인트`, `권 단위 검수`의 유효 입력으로 넣지 않는다.
- 자동 FAIL 화는 **무조건 재작성 후 재검사**한다.
