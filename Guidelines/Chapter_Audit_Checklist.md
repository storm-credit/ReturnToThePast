## 1. 📏 분량 및 구성 (Volume & Structure)

| 항목 | 기준 (Criteria) | 확인 |
| :--- | :--- | :---: |
| **글자수** | **공백 제외 순수 한글 4,000~4,500자 내외** (빠른 전개/글근육 톤 최적화). | □ |

## 2. 🩸 문체 및 분위기 (Tone & Manner)
*(참고: `lore_bible/style/Tone_Manner_Guide.md`)*

| 항목 | 기준 (Criteria) | 확인 |
| :--- | :--- | :---: |
| **건조한 감정** | "슬프다/기쁘다" 금지. 행동/상황으로 묘사(Show Don't Tell). | □ |
| **적정 수준의 잔혹성** | 억지로 잔인한 비유(안구에 피를 붓는다 등)를 지양하고, 무겁고 서늘한 생존주의적 비유를 사용할 것. | □ |
| **문학적 비유** | 단조로운 서술을 피하고, 밀도 있고 상징성이 강한 문학적 은유가 묘사에 적극 활용되었는가? | □ |
| **피비린내** | 묘사는 시각보다 **후각(약품, 곰팡이), 청각(이명, 쇳소리), 촉각** 위주 서술. | □ |
| **짧은 호흡과 가독성 (매우 중요)** | 문장을 반드시 짧게 끊어라(단문 위주). **특히 문단을 길게 쓰지 말고 1~2문장 단위로 잦은 줄바꿈을 사용하여** 스마트폰에서 시원시원하게 읽어내릴 수 있는 **압도적인 가독성**을 확보할 것. 지루한 만연체, 불필요한 접속사 지양. | □ |
| **색채** | 세계가 **회색빛, 비, 안개** 등으로 묘사되는가? | □ |
| **아이리스 말투** | **나른한 소녀 톤**(`~어?`, `~지`, `...`)인가? (군인 말투 `~다/까` 금지) | □ |
| **세계관 용어 남용 금지** | **인과율**, **패러독스** 등의 고유 세계관 용어를 일반 명사처럼 남발하지 마라. (챕터당 1~2회로 제한) | □ |
| **시스템 용어 금지** | **세계 붕괴**/**시스템** 금지. | □ |
| **장면 전환** | `***`는 시공간의 큰 도약 시점에만 최소화(화당 1회 권장)하여 사용하였는가? | □ |

## 4. 🚫 금지 요소 (Red Flags)

| 항목 | 기준 (Criteria) | 확인 |
| :--- | :--- | :---: |
| **설명충** | 대화로 설정을 길게 설명하지 마라. 사건 속에 녹여라. | □ |
| **쉬운 성공** | "미래를 아니까 쉽네" 태도 금지. → **"알아도 개같이 구르네"**. | □ |
| **현대어** | "AI", "다운로드", "해킹", "데이터", "타임라인", "팩트", "가설", **"싱크홀"** 등 현대/SF/지질학 용어 절대 금지. 시간/거리 측정 단위 및 연상어(**"초침", "미터", "센티"**) 100% 검열. | □ |
| **등급 용어** | "중급 검사", "S급" 대신 **"실버 태그", "초월자급"** 등 고유 명사 사용. | □ |
