# 🔍 아웃라인 3축 감사 프롬프트 (Outline 3-Axis Audit Prompt)

> **적용 대상**: `outline/Vol_N_Outline.md` + `outline/Vol_N_Timeline.md`
> **목적**: 완성된 아웃라인을 **개연성 / 정합성 / 흥미** 3개 축으로 정밀 검사.
> **사용법**: 아래 프롬프트를 복사 → AI에 붙여넣기 → 대상 Outline + Timeline 첨부.

---

## 📋 프롬프트 (복사용)

```text
# 역할 부여
당신은 23년 경력의 장르소설 편집장 겸 구조 분석가입니다.
첨부된 '아웃라인(Outline)' + '타임라인(Timeline)'을 읽고,
아래 3개 축에 대해 **냉정하고 구체적으로** 감사 보고서를 작성하세요.

감사 보고서에서 문제를 지적할 때는 반드시
**어떤 챕터(Ch.N)**에서 문제가 발생하는지 명시하세요.

---

# 축 1: 개연성 (Plausibility) — "이게 말이 돼?"

다음 항목을 각각 ✅ PASS / ⚠️ WARNING / ❌ FAIL로 평가하세요.

| # | 점검 항목 | 기준 |
|---|---------|------|
| P-1 | **시간 물리학** | 타임라인의 일수(Day) 안에 해당 사건들이 물리적으로 가능한가? (이동 거리, 준비 시간, 회복 기간) |
| P-2 | **능력 상한** | 에이든이 자신의 현재 능력 범위(172회차 기억 + 등가교환)를 넘어서는 행동을 하지 않는가? |
| P-3 | **등가교환의 무게** | 얻는 것 대비 잃는 것이 **납득 가능한 무게**인가? 공짜 점심는 없는가? |
| P-4 | **적의 지능** | 적(안타고니스트)이 에이든만큼 합리적으로 행동하는가? 바보짓을 하는가? |
| P-5 | **동맹의 동기** | 동맹들이 에이든을 돕는 이유가 자연스러운가? 어색한 합류는 없는가? |
| P-6 | **감정 곡선** | 에이든의 감정 변화가 점진적이고 자연스러운가? 급격한 성격 변화는 없는가? |

---

# 축 2: 정합성 (Consistency) — "설정과 안 맞는 데 없어?"

다음 항목을 각각 ✅ PASS / ⚠️ WARNING / ❌ FAIL로 평가하세요.

| # | 점검 항목 | 기준 |
|---|---------|------|
| C-1 | **로드맵 준수** | `Series_Roadmap.md`에 명시된 해당 Arc의 타임 이벤트, 반전, 등가교환이 **정확히** 반영되어 있는가? |
| C-2 | **전권 연결** | 이전 권의 마지막 장면(Ch.25)과 이 권의 시작(Ch.1)이 자연스럽게 이어지는가? |
| C-3 | **후권 복선** | 다음 권으로 넘어가는 복선이 깔려 있는가? 떡밥이 회수 없이 방치되지 않는가? |
| C-4 | **캐릭터 상태** | 이전 권에서 부상/기억 상실/사망한 캐릭터의 상태가 정확히 반영되어 있는가? |
| C-5 | **금지어** | 금지 용어(시스템, 세계 붕괴, 데이터, 스킬, AI, S급 등)가 사용되지 않았는가? |
| C-6 | **회귀 카운트** | 172번이라는 회귀 횟수가 정확하게 사용되고 있는가? |
| C-7 | **에이든의 위치** | 에이든이 **그림자/뒷골목 인물**로 유지되는가? 공적 영웅/통치자로 묘사되지 않는가? |

---

# 축 3: 흥미 (Engagement) — "이걸 읽고 싶어?"

다음 항목을 각각 ⭐⭐⭐ (탁월) / ⭐⭐ (양호) / ⭐ (미흡) / 💀 (치명적)로 평가하세요.

| # | 점검 항목 | 기준 |
|---|---------|------|
| E-1 | **훅(Hook)** | Ch.1의 시작이 **즉시 독자를 잡는가?** "이게 뭐야?"라는 궁금증을 유발하는가? |
| E-2 | **절단신(Cliffhanger)** | 각 챕터 끝이 **"다음 화 안 읽고는 못 배기게"** 되어 있는가? (최소 60% 이상) |
| E-3 | **사건 밀도** | 쉬어가는 화(아무 사건 없는 화)가 **2연속** 이상 나오지 않는가? |
| E-4 | **반전 배치** | 권의 중간(Act 2~3 전환)과 클라이맥스(Act 3~4)에 **핵심 반전**이 있는가? |
| E-5 | **감정 피크** | 독자가 **울거나 소름끼칠** 장면이 최소 1개 이상 있는가? |
| E-6 | **템포 변화** | 긴장-이완-긴장의 리듬이 있는가? 전부 같은 템포로 밋밋하지 않은가? |
| E-7 | **이 권만의 무기** | 다른 권에 없는 **이 권만의 고유한 매력 포인트**가 명확한가? |

# 필수 참조 파일 (반드시 읽고 비교할 것)
1. `outline/Series_Roadmap.md` — 전체 로드맵 (Arc별 이벤트, 반전, 등가교환)
2. `outline/Vol_[N-1]_Outline.md` — 이전 권 (연결 확인)
3. `outline/Vol_[N+1]_Outline.md` — 다음 권 (복선 확인)
4. `outline/Vol_N_Timeline.md` — 해당 권 타임라인 (시간 개연성)
5. `Guidelines/Chapter_Audit_Checklist.md` — 금지어/톤 규정

# 대상 텍스트
(여기에 감사할 Vol_N_Outline.md + Vol_N_Timeline.md 내용을 붙여넣으세요)
```

## 💡 사용 팁

1. **한 번에 1권씩** 감사하세요. 뭉뚱그려 돌리면 정밀도가 떨어집니다.
2. **전권/후권 연결** 체크 시, 해당 권 앞뒤 아웃라인도 함께 첨부하면 정합성 ↑.
3. ❌ 또는 💀이 **1개라도** 나오면 수정 후 재감사하세요.
4. 🟢 PASS가 나올 때까지 반복합니다.
