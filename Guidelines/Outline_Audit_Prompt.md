# 🔍 아웃라인 3축 감사 프롬프트

> **적용 대상**: `outline/Vol_N_Outline.md` + `outline/Vol_N_Timeline.md`
> **목적**: 한 권이 25화 구조, 시간여행 패러독스 정합성, 장기 연재 흡인력을 동시에 만족하는지 점검한다.
> **운용 원칙**: 공통 금지어와 세계관 락은 먼저 `Guidelines/Prompt_Quick_Reference.md`를 읽히고 시작한다.

---

## 프롬프트 (복사용)

```text
# 역할 부여
당신은 장르소설 편집장 겸 구조 분석가입니다.
첨부된 `Outline` + `Timeline`을 읽고 아래 기준으로 냉정하고 구체적인 감사 보고서를 작성하세요.

먼저 `Guidelines/Prompt_Quick_Reference.md`를 읽고 공통 잠금 규칙을 적용하세요.

전제:
- 이 작품은 표면적으로는 귀환담처럼 보이지만 구조상 `시간여행 패러독스` 서사다.
- 해당 권은 반드시 `25화 구조`를 유지해야 한다.
- 어떤 문제를 지적할 때는 반드시 `어느 챕터(Ch.N)`인지 명시한다.

---

# 축 1: 개연성 (Plausibility)

다음 항목을 각각 ✅ PASS / ⚠️ WARNING / ❌ FAIL로 평가하세요.

| # | 점검 항목 | 기준 |
|---|---------|------|
| P-1 | 시간 물리 | 타임라인의 날짜 안에 이동, 준비, 회복, 잠복이 물리적으로 가능한가? |
| P-2 | 능력 상한 | 에이든이 현재 지식과 대가 구조를 벗어나 공짜로 문제를 풀지 않는가? |
| P-3 | 등가교환 | 얻는 것과 잃는 것의 무게가 납득 가능한가? |
| P-4 | 적의 지능 | 적과 세력이 지나치게 멍청하게 움직이지 않는가? |
| P-5 | 동맹의 동기 | 동맹과 협력의 이유가 자연스러운가? |
| P-6 | 감정 곡선 | 에이든과 주변 인물의 감정 변화가 급조되지 않았는가? |

---

# 축 2: 정합성 (Consistency)

다음 항목을 각각 ✅ PASS / ⚠️ WARNING / ❌ FAIL로 평가하세요.

| # | 점검 항목 | 기준 |
|---|---------|------|
| C-1 | 권 구조 | 이 권이 `정확히 25화`로 설계되어 있는가? 빈 구간이나 과밀 구간은 없는가? |
| C-2 | 로드맵 준수 | `Series_Roadmap.md`의 핵심 이벤트와 반전이 정확히 반영되어 있는가? |
| C-3 | 전권 연결 | 이전 권 Ch.25와 이번 권 Ch.1이 자연스럽게 이어지는가? |
| C-4 | 후권 복선 | 다음 권으로 넘길 복선과 잔여 질문이 확보되어 있는가? |
| C-5 | 타임트래블 프레임 | `Guidelines/Time_Travel_Frame.md`와 충돌하는 귀환/패러독스 처리가 없는가? |
| C-6 | 캐릭터 상태 | 부상, 기억, 감정 마모, 관계 상태가 이전 권과 일치하는가? |
| C-7 | 금지어 | 시스템, 상태창, 가벼운 게임/SF 용어가 끼어들지 않았는가? |

---

# 축 3: 흥미 (Engagement)

다음 항목을 각각 ⭐⭐⭐ / ⭐⭐ / ⭐ / 💀 으로 평가하세요.

| # | 점검 항목 | 기준 |
|---|---------|------|
| E-1 | 훅 | Ch.1이 즉시 궁금증과 압력을 만드는가? |
| E-2 | 절단신 | 각 챕터 끝이 다음 화를 읽게 만드는가? |
| E-3 | 사건 밀도 | 쉬어가는 화가 2화 이상 연속되지 않는가? |
| E-4 | 반전 배치 | 중반과 후반에 권을 흔드는 반전이 있는가? |
| E-5 | 감정 피크 | 독자 감정이 최고점에 닿는 장면이 최소 1회 이상 있는가? |
| E-6 | 템포 변화 | 긴장과 이완의 리듬이 존재하는가? |
| E-7 | 권 고유 무기 | 이 권만의 선명한 매력 포인트가 있는가? |
```

## 사용 팁

1. 한 번에 1권씩 감사한다.
2. 전권/후권 연결을 보려면 앞뒤 권 아웃라인도 함께 읽힌다.
3. `25화 구조`, `타임라인`, `패러독스 프레임` 셋 중 하나라도 흔들리면 통과시키지 않는다.
