# Landmark & Faction Visual Collection Bible v1

Status: **D16 IP COLLECTIBILITY DEEP DESIGN**  
Depends On: `visual-design-bible-v1.md`, `faction-atlas-v1.md`, geography/culture bibles  
Rule: 색상만으로 세력·지역을 구분하지 않는다. **형태 + 재질 + 사용행동** 3축을 사용한다.

# 1. 핵심 지역 8종 — One-Shot Landmark Rule

## L01 아르켄 왕관수도 — LAYERS OF AUTHORITY

- **One Shot:** 낮은 하항의 옛 주소표 뒤로 서로 다른 시대 기초 위에 올라간 왕궁 승인회랑이 겹쳐 보이는 구도.
- **Silhouette:** 수직 왕궁 / 수평 성당 / 다리로 연결된 관측탑 군집의 3층 스카이라인.
- **Material:** 백색 석회, 황동, 붉은 밀랍, 오래된 목재 하항.
- **Life Detail:** 짐꾼이 왕실 문양 아래 옛 지명판을 아직 길찾기에 사용.
- **Variant:** Era N에는 중앙표식이 선명, P1에는 중앙표식 일부가 제거되고 지역표식이 같은 벽에 병렬 등장.
- **Collectible Hook:** 같은 시점의 `왕궁층 / 기록소층 / 하항층` 3단 배경세트.

## L02 서부 잿빛 변경 / 벨하임 — THE REPAIRED EDGE

- **One Shot:** 한쪽만 남은 성벽 아래 학교와 시장이 열리고, 문마다 서로 다른 시대 이름판이 겹친 거리.
- **Silhouette:** 완성된 성벽보다 끊긴 벽선과 보강재.
- **Material:** 회색석, 바랜 적갈천, 목재 덧댐, 노란 경보천.
- **Life Detail:** 주민이 매일 문패를 고쳐 쓰고 아이는 낡은 벽을 칠판처럼 사용.
- **Variant:** 증언구역 이후 중앙 주소판 옆에 주민 증언표가 공식적으로 걸림.
- **Collectible Hook:** 문패만 모아도 시간변화가 읽히는 ‘주소판 시리즈’.

## L03 셀카르 유리산맥 — THE LIVING WORKSHOP

- **One Shot:** 산을 파낸 층형도시의 단면에서 용광로 불빛과 무덤통로, 균열광맥이 동시에 보임.
- **Silhouette:** 위로 솟은 성보다 옆으로 파인 층.
- **Material:** 검은 철, 불순 유리광맥, 주황 용광로, 광분진 천.
- **Life Detail:** 작업자가 무덤 벽을 장식이 아니라 구조재 계보처럼 관리.
- **Variant:** V15에는 일부 유산 재료가 생활망으로 옮겨가 작업면이 비어 있음.
- **Collectible Hook:** 단면 디오라마와 교체 가능한 균열판.

## L04 라디아 곡창초승달 — THE CALENDAR YOU CAN EAT

- **One Shot:** 거대한 수문 눈금, 배급광장, 밀밭의 경계가 한 프레임에 들어옴.
- **Silhouette:** 종탑보다 낮고 긴 제방과 수평선.
- **Material:** 곡물황색, 청록 수로, 갈색 목제계량기, 흰 달력표식.
- **Life Detail:** 농민이 종소리보다 수문 높이와 흙을 보고 날짜를 판단.
- **Variant:** 중앙정지 후 서로 다른 지역표식이 수문판에 덧대어짐.
- **Collectible Hook:** 계절별 수문눈금 4종이 자연스러운 배경 변형.

## L05 조류도시연맹 — THE CITY THAT OPENS WITH TIDE

- **One Shot:** 물이 빠지며 하층 시장과 행정통로가 동시에 드러나는 순간.
- **Silhouette:** 고정된 성문보다 다리·부교·선착장의 움직이는 선.
- **Material:** 소금백, 남청, 녹청동, 방수천, 염판.
- **Life Detail:** 상점 간판이 수면 높이에 따라 뒤집혀 읽히도록 제작.
- **Variant:** 봉쇄기에는 부교 일부가 끊기고 난민통로 표식이 별도로 남음.
- **Collectible Hook:** 만조/간조 2상태 디오라마.

## L06 아노르 백지권 — THE PLACE THAT MUST BE REDRAWN

- **One Shot:** 공동명부판 앞에서 누군가는 문이 3개, 누군가는 4개라고 말하지만 아이들이 같은 식탁에 앉아 있는 장면.
- **Silhouette:** 건물 자체보다 이동칸막이·매일 그린 선·공동판.
- **Material:** 여러 출처 천, 지워졌다 다시 쓴 목판, 수선가구.
- **Life Detail:** 집 위치보다 ‘오늘 누가 여기서 잤는가’ 표식이 중요.
- **Variant:** P1에는 임시표식이 법적 이의제기 양식과 나란히 붙음.
- **Collectible Hook:** 동일 장소의 관찰판 3종을 병렬 제작해도 정본 모순이 아님.

## L07 Era F 생존구 — THE HERO POSTER AND THE REAL WALL

- **One Shot:** 에이든 영웅선전물이 붙은 벽 아래에서 재사용 부품으로 난방관을 고치는 시민.
- **Silhouette:** 지상 탑보다 지하 통로와 패치벽.
- **Material:** 녹슨 금속, 재사용천, 희미한 표시광, 따뜻한 생활등.
- **Life Detail:** 군용 표식이 냄비·침대·배급선으로 재사용됨.
- **Variant:** F0/F1/F3마다 같은 통로 구조가 다른 선전문구와 배급체계로 바뀜.
- **Collectible Hook:** ‘같은 복도 다른 미래’ 3~4종 배경세트.

## L08 P1 증언자의 길 / 지역망 — THE WORLD AFTER THE HERO

- **One Shot:** 중앙 상징이 제거된 빈 벽에 여러 지역표식과 이의제기문이 함께 붙어 있고, 아이·상인·정비사가 그 앞을 평범하게 지나는 장면.
- **Silhouette:** 기념비보다 낮은 게시판·수문·학교·병원이 이어진 생활축.
- **Material:** 통일재료 없음. 지역별 수선재가 병존.
- **Life Detail:** 오류를 지우지 않고 수정이력 자체를 남김.
- **Collectible Hook:** 에필로그 배경의 ‘완벽하지 않은 정상성’.

# 2. 세력 시각 문법 14종

## F01 왕실 중앙유지파
- **Shape:** 닫힌 고리 + 연결부 1개
- **Material:** 황동 / 붉은 밀랍 / 표준직물
- **Behavioral Mark:** 모든 공문·통로가 중앙을 향해 정렬
- **Corruption Variant:** 고리가 완전히 닫히며 다른 인장 슬롯을 덮음

## F02 성당 정통력파
- **Shape:** 3개의 삼중 상처선
- **Material:** 석회 / 진료천 / 종합금
- **Behavioral Mark:** 의례와 생활시설이 같은 건물에 존재
- **Faction Variants:** 구휼파는 진료표, 달력파는 눈금, 종말파는 선을 닫는 형태

## F03 마탑 계산연합
- **Shape:** 교차축 + 오차범위
- **Material:** 관측유리 / 황동 / 얇은 기록판
- **Behavioral Mark:** 정답값보다 범위를 표시
- **Corruption:** 왕실계약파는 오차범위를 지우고 단일 숫자만 남김

## F04 대기록소·주소관료단
- **Shape:** 겹문장 + 수정표식
- **Material:** 종이 / 실 / 밀랍 / 목재함
- **Behavioral Mark:** 원본·수정본·증언본의 물리 보관방식 차이
- **Corruption:** 비등록자를 위한 빈칸이 아니라 칸 자체를 지움

## F05 국경 고정환 수비연합
- **Shape:** 열린 고리 안에 요새·마을표식 병렬
- **Material:** 철 / 목재 / 결정판 / 경보천
- **Behavior:** 명령패와 철회패가 한 쌍

## F06 서부 변경개혁연합
- **Shape:** 겹친 문패 / 열린 원 / 주민 증언점
- **Material:** 수선석 / 지역천 / 복제장부
- **Behavior:** 하나의 깃발보다 여러 마을표식을 함께 듦

## F07 복원파
- **Shape:** 완전한 원을 되찾으려는 봉합선
- **Material:** 가족기록 / 옛 제복조각 / 보존사진
- **Behavior:** 사라진 이름을 반복 기록
- **Extreme Variant:** 봉합선이 현재 표식을 덮어씌움

## F08 F1 군정
- **Shape:** 직사각 구역망 / 숫자칸
- **Material:** 무광 군용판 / 배급토큰 / 영웅포스터
- **Behavior:** 사람을 구역으로 먼저 분류

## F09 자유해안 계약동맹
- **Shape:** 열린 파도선 + 계약매듭
- **Material:** 방수천 / 염판 / 녹청동
- **Behavior:** 국경보다 항로를 따라 표식이 반복

## F10 북부 공방동맹
- **Shape:** 접합부가 드러난 다중판
- **Material:** 철 / 가죽 / 불순결정 / 공방도장
- **Behavior:** 완제품보다 수리·교체 흔적을 자랑

## F11 라하크 이동단 협의회
- **Shape:** 닫히지 않는 경로선 / 매듭
- **Material:** 층겹천 / 이동표식 / 천연섬유
- **Behavior:** 고정 깃발보다 이동경로 자체가 표식

## F12 네바르 장례법정
- **Shape:** 빈 중심 + 판결끈
- **Material:** 무광천 / 불완전 결정 / 얇은 금속틀
- **Behavior:** 죽음·부재·소거를 서로 다른 표식으로 구분

## F13 백지권 권리연합
- **Shape:** 한쪽이 비어도 계속 이어지는 선 + 복수 증언점
- **Material:** 수선천 / 목판 / 현재생활물
- **Behavior:** 과거문서보다 현재 생활증거를 전면 배치

## F14 F3 연대개입산업연합
- **Shape:** 기능별 모듈 인장열
- **Material:** 방진천 / 표준금속 / 교체형 계약판
- **Behavior:** 성과별 색·형태가 다른 계약인장
- **Corruption:** 유익/군사 계약이 같은 연결소켓을 공유하는 것이 핵심 시각 단서

# 3. Faction Collectible Sets

- `CENTRAL SYSTEM SET`: F01/F02/F03/F04 — 같은 중앙도시 안에서도 형태·재질을 명확히 분리.
- `EDGE RIGHTS SET`: F05/F06/F13 — 같은 ‘지역’ 진영처럼 보이지 않도록 군사/개혁/현재권리의 물성을 다르게.
- `MOBILE & EXTERNAL SET`: F09/F11 — 바다와 육상 이동의 차이.
- `MATERIAL & DEATH SET`: F10/F12 — 물질고정과 죽음증언의 대비.
- `FUTURE POWER SET`: F08/F14 — 군정의 구역표와 산업의 모듈인장 대비.

# 4. Anti-Theme-Park Rule

지역마다 모든 인물이 같은 색 옷을 입거나 같은 문양을 크게 달지 않는다. 세력 표식은 **행정서류·장비·통로·작업도구·건축 접합**에서 반복되어야 한다.

독자는 ‘파란 옷이라 마탑’이 아니라 ‘오차범위가 남은 투명판과 교차축이 있어서 마탑’이라고 알아봐야 한다.
