## 0. 목적

`naming-pack §9 명명 음운 가이드`는 문화권별 인상만 서술한다. 이 문서는 거기에 **실제 생성·검수에 쓸 수 있는 음운 제약과 충돌 지도**를 추가한다.

명명규칙 §5.1 원칙을 그대로 따른다.

- 문화권 하나에 주된 어원 계열 하나
- 같은 지역에서 라틴·그리스·북유럽·현대영어식을 무작위로 섞지 않음
- 실제 신·영웅·유물의 유명한 이름을 그대로 쓰지 않음
- 어근을 참고해도 한국어로 읽기 쉬운 2–4음절로 다시 다듬음

## 2. 문화권별 명명표 (규칙 §5.5 양식)

### 2.1 칼레온 중앙 왕국 (인간권)

| 항목 | 기록 내용 |
|---|---|
| 참고 어감 | 라틴·로망스 (느슨한 참고. 실제 라틴 문법 재현 금지) |
| 허용 음절 | 초성 ㄱ·ㅋ·ㄹ·ㅁ·ㅂ·ㅅ·ㅇ·ㅌ·ㅍ / 중성 ㅏ·ㅔ·ㅗ·ㅣ 중심 / 받침 ㄴ·ㄹ·ㅁ 중심 |
| 이름 길이 | 개인명 2–3음절, 가문·서임명 1–2음절, 도시명 2–3음절 |
| 직함 방식 | 이름 뒤 (`세른 기록관`, `베르 사령관`). 서임명·출신지명이 가문명 자리를 대신할 수 있음 |
| 지명 접미 | 없음(고유명 단독) 또는 `왕관수도`·`분지`·`언덕`·`협곡` 등 한국어 일반명 |
| 금지 혼합 | 북유럽풍 거친 자음군, 그리스풍 `-오스/-아스`, 현대영어식 |
| 대표 예시 (정본) | 칼레온 · 아르켄 · 세르바 · 에이든 로엔 · 리아 세른 · 마르칸 베르 · 메이라 솔 · 테온 리브 |

**기관 명명 구조**: `외래어풍 고유명 + 익숙한 한국어 조직어 1개`
예: `아르켄 마탑`, `칼레온 대기록소`, `아르켄 귀환청`
금지: 기능어 3개 이상 압축(`앙카 귀환다리`), `국·원·실` 연속 나열(규칙 §4.4)

### 2.2 북부 셀카르 / 카르둔

| 항목 | 기록 내용 |
|---|---|
| 참고 어감 | 제한적 북유럽풍 |
| 허용 음절 | 초성 ㄷ·ㄱ·ㅋ·ㅂ 중심 파열음 / 받침 ㄴ·ㄹ·ㄱ |
| 이름 길이 | 개인명 2–3음절 + 공방계보명 2음절 |
| 직함 방식 | `공방대표`, `고정관` 등 기능어 후치 |
| 지명 접미 | `산맥`·`협곡`·`공방`·`원점` |
| 금지 혼합 | 오딘·토르·로키·발할라·라그나로크 직접 차용 금지(규칙 §5.4). 전원 `-손` 어미 통일 금지. 남부 성당·중앙 왕실에 북부풍 혼입 금지 |
| 대표 예시 (정본) | 셀카르 · 도르칸 카르바 · 카르둔 |

**주의**: `카르둔`(종족)·`카르바`(공방)·`카르센`(중앙 인물)이 이미 `카르-`를 공유한다. 북부 신규 이름에서 `카르-` 시작은 **동결**한다.

### 2.3 고대 종교·유적층

| 항목 | 기록 내용 |
|---|---|
| 참고 어감 | 제한적 그리스·고대 지중해풍 |
| 사용 범위 | Era O 이전 유적, 신전, 예언, 별, 의술. **현재 왕실·마탑·북부 문화와 분리된 층**일 때만 |
| 선행 조건 | 교리 이름보다 **의례와 신화가 원고에 먼저 등장**해야 함 (규칙 §4.5, initial-audit §3.3) |
| 금지 혼합 | 제우스·아테나·아폴론·크로노스·타르타로스 직접 차용 금지. `아카식 레코드` 자동 사용 금지 (규칙 §5.3) |
| 대표 예시 | 현재 정본 없음 — 신규 생성 시 A15 유사성 감사 선행 |

### 2.4 남부 마레이 / 자유해안

| 항목 | 기록 내용 |
|---|---|
| 참고 어감 | 해양·계약 문화. 모음이 길고 항구·섬 출신명 결합 (naming-pack §9) |
| 허용 음절 | 개음절 우선, 받침 최소 |
| 이름 길이 | 개인명 2–3음절 + 항구·섬명 2음절 |
| 지명 접미 | `항`·`섬`·`연맹`·`동맹` |
| 대표 예시 (정본) | 마레이 · 마레사 · 레바 · 마리엔 레바 · 에스라 마레사 |

**경보**: `마레이`(조류도시연맹)와 `마레사`(자유해안동맹)는 **인접한 남부 해양 세력 2개가 같은 어두를 공유**한다. §4 충돌 지도 참조.

### 2.5 서부 잿빛 변경

| 항목 | 기록 내용 |
|---|---|
| 참고 어감 | 중앙 방언층. 별도 외래 계열 없음 |
| 문화 특성 | 증언어 — 확실함·기억함·전해들음·몸에 남음을 문법으로 구분 (calendar-language §2) |
| 이름 관습 | **아이에게 공적 이름 1개와 사적 기억이름 2개를 준다** (atlas R05). 명명 시 이 3중 구조를 보존 |
| 지명 성격 | 사건·상실을 가리키는 서술형이 자연스러움 (`빈 세금소`, `절검의 언덕`, `회색종 마을`) |
| 대표 예시 (정본) | 네르바 · 벨하임 · 라베른 · 아이리스 네르 · 엘사 네르 |

### 2.6 백지권

| 항목 | 기록 내용 |
|---|---|
| 참고 어감 | 고정 계열 없음 |
| 명명 원칙 | **여러 실패한 역사주소가 겹쳐 확정되지 않은 지역**(atlas R08)이므로, 이름이 하나로 확정되지 않는 것 자체가 설정이다 |
| 권장 방식 | 서술형 장소명 우선 (`얼굴 없는 시장`, `세 번 난 마을`, `끊긴 학교`, `마지막 길`) |
| 대표 예시 (정본) | 아노르 · 나하 아노르 · 트리엔 마을 |

### 2.7 에르나 / 라하크 / 네바르

| 종족 | 이름 구성 | 근거 |
|---|---|---|
| 에르나 | 출생명 + 첫 기억문명 + 공동체명. **옛 이름을 삭제하지 않고 층으로 보존** | calendar-language §4 |
| 라하크 | 개인명 + 현재 이동단 + 선택한 길 또는 계약 신수와의 관계명. **신수 이름을 소유격으로 부르지 않음** | calendar-language §4, peoples §4 |
| 네바르 | 살아 있는 이름과 계승기억의 출처명을 분리. **죽은 자 이름을 자녀에게 그대로 주는 것은 금기** | calendar-language §4 |

대표 예시: 사하드 렌(라하크) · 베사르 움(네바르)

## 3. 공통 검수 규칙

명명규칙 §7 7단계 검사에 더해, 신규 이름은 다음 문장 5개에 넣어 낭독한다(규칙 §2.3).

- `___에서 사람이 왔다.`
- `___의 승인이 필요하다.`
- `___ 소속이다.`
- `___로 가자.`
- `___가 무너졌다.`

**추가 필수 검사 — 동일 장면 동시 등장 검사**
새 이름을 만들 때, 그 이름이 **같은 장면에 등장할 수 있는 기존 이름**과 첫 2음절을 공유하면 탈락시킨다. 설정집에서만 비교하고 장면 배치를 확인하지 않으면 E001의 `리아 세른 / 세렌 바일` 같은 사례가 재발한다.

## 4. 음운 충돌 지도 (신규 생성 시 회피 대상)

[`naming-full-audit-v1.md`](../99_quality_control/naming-full-audit-v1.md) §2에서 확인된 과포화 구간이다. **신규 이름은 아래 어두를 사용하지 않는다.**

| 어두 | 이미 점유한 이름 | 상태 |
|---|---|---|
| `세르-` / `세-` | 세르바(왕조) · 세르나(도시) · 세른(리아) · 세렌(표적) · 세라트(구휼원) | **동결** |
| `셀-` | 셀카르(산맥) · 셀린(협곡) | **동결** |
| `카르-` | 카르둔(종족) · 카르바(공방) · 카르센(인물) · 카센(언덕) | **동결** |
| `-르켄/-르칸` | 아르켄(수도) · 마르칸(인물) · 도르칸(인물) | **동결** |
| `네르-` / `네바-` | 네르바(권역) · 네르(인물 2) · 네바르(종족) | **동결 + 기존 충돌 해소 필요** |
| `마레-` | 마레이(연맹) · 마레사(동맹) | **동결 + 기존 충돌 해소 필요** |
| `레-` | 레바(섬·인물) · 레오르(인물) | 주의 |
| `-렌/-란` | 세렌 · 다렌 · 하렌 · 트리엔 | 주의 |

### 미사용 음운대 (신규 이름 권장 구간)

중앙 왕국권 기준으로 아직 비어 있는 초성: **ㅍ · ㅌ · ㅎ · ㅈ**
비어 있는 받침 조합: **-ㅁ(벨하임 외) · -ㅇ · -ㅂ**

예시 방향: `포르텐` · `톨민` · `하벨` · `테반`
(정본 후보가 아니라 음운대 예시다. 실제 채택은 대상별 증거표 작성 후)

## 5. 금지사항 (calendar-language §10 승계)

- 실제 국가 `바레인`과 혼동되는 작업명을 최종명으로 고정하지 않는다
- 특정 현실문화의 이름·복식·종교를 한 종족에 통째로 대응시키지 않는다
- 모든 판타지 이름을 동일한 서구식 음절로 만들지 않는다
- 시대가 수백 년 차이인데 발음·어휘가 완전히 동일하지 않게 한다
- 이름을 바꾸더라도 E001–E375의 역할·인과·관계식별자가 깨지지 않도록 ID를 유지한다
