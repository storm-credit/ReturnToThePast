## 1. 핵심 원리

칼레온의 지배적 종교는 하나의 신앙체계이면서 달력·출생·장례·치료·토지·세금·시간 안정에 관여하는 공공제도다.

아홉 상처는 아홉 성인이나 사도 명단이 아니다.

- 이름
- 기억
- 몸
- 장소
- 경계
- 계절
- 출발
- 귀환
- 대가

사람들은 이를 신화적 상처로 믿고, 성당은 봉합 의무로 해석하며, 기술자들은 주소 변수로 읽고, 실제 건국사에서는 다종족 생존협약이었다.

종교 장면은 이 네 층 가운데 어떤 인물이 어느 층을 믿는지 분명히 해야 한다.

## 2. 공인 명칭

- 중앙 성당: 아홉 상처 대성당
- 공인 교단: 봉합성회
- 일반 예배소: 봉합당, 상처당, 길당
- 지역 구휼시설: 회복소, 회색병동, 이름보관소
- 성직자 총칭: 봉합자
- 의례 실무자: 결속사
- 기록·장례 담당: 기억사
- 달력·농업 담당: 계절사
- 의료·구휼 담당: 구휼사
- 경계·여행 담당: 문지기 사제

지역과 종족에 따라 다른 명칭을 사용할 수 있으나 CP에서 공인명과 현지명을 함께 기록한다.

## 3. 성직 계급과 실제 권한

### 3.1 대봉합관

- 대성당의 최고 의례 책임자
- 왕관과 달력 개시를 공동 승인
- 시간 파견을 단독 승인할 수 없음
- 전국 교리를 통제하지만 지방 구휼·장례 판정을 직접 뒤집으려면 기록소와 법원의 동의가 필요

### 3.2 상처감독관

아홉 원리를 지역별로 감사하는 고위직이다. 한 사람에게 하나의 상처가 영구 배정되는 ‘아홉 좌’가 아니다.

- 여러 원리를 순환 담당
- 감사 임기 제한
- 현지 성당·관청·마탑 간 충돌 조정
- 비용 전가와 기록 누락을 조사

### 3.3 지방 봉합장

- 도시 또는 권역 성당 운영
- 구휼·장례·달력·출생 등록의 예산 배분
- 지방 영주와 갈등하거나 결탁 가능

### 3.4 기능 성직자

- 구휼사: 질병·난민·배급
- 기억사: 장례·증언·기록 봉인
- 계절사: 파종·수문·축일·기상 관측
- 문지기 사제: 국경·순례·귀환자 임시신분
- 결속사: 혼인·양자·공동체 서약·계약 의례

### 3.5 평신도 실무자

- 종지기
- 장부필사원
- 시신세정인
- 촛농관리인
- 배급조리사
- 순례길 정비인
- 공동묘지 경계원

성당은 성직자만으로 작동하지 않는다. 평신도 노동·세금·증언이 세계 안정 비용의 일부다.

## 4. 주요 분파

### 봉합정통파

- 중앙 달력·왕관·성당 질서를 지지
- 실제 장점: 농업·의료·장례·통신의 표준화
- 구조적 피해: 지방 예외와 무등록자를 오류로 처리

### 구휼파

- 환자·난민·주소불안정자의 현장 보호 우선
- 실제 장점: 사망률 감소, 격리 오판 재심
- 위험: 지역 수용력을 넘는 보호 약속

### 증언파

- 지워진 이름과 상충기록을 예배에 포함
- 실제 장점: 움브라·소거지역 권리 보존
- 위험: 검증되지 않은 증언권력이 새로운 독점이 될 수 있음

### 종말파

- 회색 재앙을 잘못 봉합된 역사의 심판으로 해석
- 일부는 폭력적 폐쇄론자지만 전부 광신도가 아님
- 실제 지지 이유: 중앙제도가 자기 마을을 희생시킨 경험

### 달력관료파

- 신학보다 정확한 농업·치료·수문 운영을 중시
- 실제 성과가 크며 중앙 통제를 합리화
- 사람의 권리보다 수치 안정성을 우선할 위험

## 5. 일상 신앙

### 아침의 이름 확인

가족이나 공동체가 서로의 이름을 한 번씩 부르고 오늘의 날짜를 확인한다. 단순 기도가 아니라 시간선 불일치의 초기 증상을 알아채는 생활습관이다.

### 문턱 매듭

집의 문턱에 실이나 금속 고리를 묶는다. 장소와 경계의 상처를 봉합한다는 의미이며, 실제로는 피난·화재·질병 표시 기능도 한다.

### 저녁의 빈자리

죽거나 사라진 사람의 자리를 완전히 치우지 않고 한 끼 동안 빈 그릇을 둔다. 장례 후에는 기억사가 그릇을 깨거나 공동식기로 전환한다.

### 여행 전 세 문답

문지기 사제가 묻는다.

1. 어디에서 왔는가
2. 누구에게 돌아가는가
3. 돌아오지 못하면 누가 책임지는가

정답보다 주소·관계·책임의 존재를 확인하는 절차다.

## 6. 출생·이름 의례

### 첫 호흡 기록

- 산파·가족·기억사 중 둘 이상의 증언
- 몸의 특징, 장소, 시간, 보호자 기록
- 이름은 즉시 확정하지 않아도 됨

### 이름 얹기

출생 7~30일 사이 공동체가 이름을 공적으로 사용한다.

- 이름은 소유권이 아니라 관계망의 약속
- 입양·난민·움브라에게 재이름을 강요하지 않음
- 시간선 충돌 시 복수 이름을 병기할 수 있음

### 장면 갈등

- 기록과 가족 증언이 다름
- 같은 아이의 두 출생일
- 이름 변경이 상속권·귀환권을 바꿈
- 움브라 아이의 현재 생활이 과거 혈통보다 우선하는가

## 7. 혼인·가족·공동체 서약

### 결속 의례

혼인은 두 사람만의 계약이 아니라 돌봄·재산·장례·이동권·아이의 이름을 누가 책임질지 기록한다.

필수:
- 당사자 동의
- 재산·부채 공개
- 철회 조건
- 다른 시대·지역 귀환 시 권리

### 공동체 결속

혈연이 없는 난민·군인·시간 잔류자도 보호공동체를 만들 수 있다.

### 금지

- 과거 시간선의 연인이 현재 인물의 동의를 대신함
- 기억만으로 혼인관계 자동복원

## 8. 질병·치료 의례

### 회색열 진단

성당은 생물학적 감염병과 연속성 불일치를 구분해야 한다.

절차:
1. 체온·피부·호흡 검사
2. 이름·날짜·장소 문답
3. 가족·토지·세금 기록 비교
4. 회색 종 또는 주소 반응 검사
5. 격리 또는 기록재심 결정

### 봉합 치료

- 수분·영양·수면·감염치료
- 상충기록을 한 번에 강제 통합하지 않음
- 환자가 유지할 현재 관계를 선택
- 몸·기억·기록 중 하나를 희생시키는 응급치료는 당사자 동의와 사후감사 필요

### 구조적 갈등

- 의료망 유지에는 중앙 달력이 필요
- 중앙 기록이 환자의 존재를 지우는 원인이 될 수 있음
- 격리 해제는 지역 주민의 실제 감염 위험과 충돌

## 9. 장례 의례

### 세 번의 확인

1. 몸의 죽음
2. 법적·사회적 관계의 종료 또는 승계
3. 기억·증언의 보존 범위

주소상실자는 몸이 살아 있어도 장례 판정 대상이 아니다.

### 장례보석

- 완전한 인격 저장 금지
- 마지막 증언·서약·감각 일부만 보존
- 산 자의 결정을 지배하는 예언장치로 사용 금지

### 종족별 차이

- 인간: 이름·토지·가족 중심
- 에르나: 기억문과 피부·직물 기록
- 카르둔: 공방·도구·무덤 재료
- 라하크: 이동경로와 마지막 발자국
- 네바르: 장례보석과 법적 증언

## 10. 계절·농업 의례

### 파종종

계절사가 성당 종과 수문 기록을 맞춘다. 신앙행위이면서 실제 농업 동기화다.

### 봉합일

달력 오차를 보정하는 공휴·노동일이다.

- 세금·채무 만기 조정
- 출생·장례 기록 재검증
- 시간 이상 신고

### 흉년 의례

희생 제물이 아니라 부담 배분 공개가 원래 기능이다. 후대 일부 지역에서는 책임을 특정 마을·종족에 떠넘기는 의식으로 변질된다.

## 11. 출발·귀환 의례

### 출발 서약

시간 파견자는 다음을 공개한다.

- 임무 목적
- 예상 수혜자
- 예상 피해자
- 귀환 실패 책임
- 변경 금지선

성당은 주소와 날짜를 동기화하지만 단독 승인기관이 아니다.

### 귀환 심사

- 몸 확인
- 출발 인장 확인
- 기억·관계·신분 불일치 기록
- 현재 세계의 수용 여부
- 이전 시간선 권리를 현재인에게 강요하지 않는 서약

## 12. 성물과 물질문화

### 회색 종

질병·악의를 감지하는 성물이 아니라 몸·기억·기록·장소의 주소 불일치를 감지한다.

### 봉합실

출생·혼인·장례·여행 문서에 사용하는 실. 색은 원리와 지역에 따라 다르며 마법 만능재료가 아니다.

### 날짜판

성당 입구에 오늘 날짜와 지역계절 상태를 표시한다. 시간변형을 가장 먼저 체감시키는 생활물건이다.

### 빈 촛대

기록에서 사라진 사람을 위해 이름 없이 켜는 자리. 증언파와 정통파의 정치 갈등 대상이다.

### 문턱쇠

경계 의례와 실제 재난 표식을 겸한다.

## 13. 성당 공간

- 공개예배실: 설교·달력 발표
- 이름회랑: 출생·사망·실종 명판
- 회색병동: 구휼·진단
- 기억고: 장례·증언 보관
- 봉합종탑: 계절·경보
- 문지기실: 여행·귀환 심사
- 지하 주소실: 제한된 기술·기록 기능
- 배급주방: 재난구휼

동일 성당 안에서도 공개신앙·의료·행정·기술 영역의 출입권이 다르다.

## 14. 종교 재판과 이의제기

### 대상

- 의례 위조
- 출생·장례 기록 변조
- 환자 비용 전가
- 시간주소 불법거래
- 성물 오용

### 절차

1. 지역 조사
2. 피해자·공동체 증언
3. 기록소·마탑 자료 대조
4. 공개 또는 제한 심리
5. 치료·배상·직위박탈·형사이관

이단이라는 이유만으로 처벌하지 않는다. 위험한 행위와 권리침해를 입증해야 한다. 종말파 탄압은 실제 정치적 남용으로 등장할 수 있다.

## 15. 시대별 변화

### Era O

- 다종족 생존협약과 현장 의례
- 교리보다 기능·동의·분담 중심

### Era N

- 왕조·성당 중앙화
- 지방 구휼과 중앙 달력의 갈등
- 아홉 상처가 성인전으로 왜곡

### F0/F1/F2

- 성당이 의료·배급·신분 생존망으로 군사화
- 기록되지 않은 시민이 구휼에서 탈락
- 분파별로 에이든을 구원자·범죄자·오염자로 다르게 해석

### F3

- 의례가 시간산업의 인증 절차로 상품화
- 빠른 재난예방 성과와 동의 침해가 공존

### P1

- 중앙 교리독점 약화
- 지역·종족·시민 감사 참여
- 이름 없는 증언을 공식 의례에 포함

## 16. 인물별 신앙 차이

- 에이든: 의례를 임무절차로 보지만 후반에는 책임 공개의 의미를 배움
- 리아: 기록·증언의 윤리를 중시하나 완전기록 신앙을 버림
- 아이리스: 구휼과 현재 주민권을 우선, 중앙 봉합을 불신
- 마르칸: 달력·배급·의료의 실제 효율 때문에 중앙 질서를 지지
- 오르바드: 신화 이전의 기술·사회협약을 앎
- 세렌: 증언파적 공개감사를 사용하지만 대피보다 폭로를 앞세우는 결함

## 17. 장면 작성 규칙

종교 장면에는 최소 두 가지가 동시에 작동해야 한다.

- 개인 신앙
- 실제 생활기능
- 기관 권한
- 정치적 이해
- 마법·주소 기능
- 종족·지역 관습

설교만으로 세계관을 설명하지 않는다. 의례 중 누가 입장할 수 있는지, 누가 비용을 내는지, 어떤 기록이 빠졌는지가 갈등을 만든다.

## 18. 금지

- 아홉 사도·9인 보스 조직
- 성직자 전부 위선자 또는 광신도
- 신앙과 기술 중 하나만 진실이라고 단순화
- 기도 한 번으로 시간병 치료
