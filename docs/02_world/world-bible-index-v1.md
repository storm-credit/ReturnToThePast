## World Proposition

이 세계에서 역사는 과거에 대한 설명이 아니라 사람·땅·계절·소유권을 현재에 고정하는 공공 기반시설이다. 마법은 개인의 재능만으로 작동하지 않고 물질, 기억, 공적 기록, 반복된 관습이 서로 일치할 때 안정된다. 왕국 시간장치는 이 원리를 문명 전체 규모로 확장한 시스템이다.

## Canon Rules

- 시간장치와 일반 마법은 동일하지 않다.
- 왕국 밖 세계가 존재하며, 중심 왕국의 변경은 외부에 다른 강도로 파급된다.
- 종족은 단일 기능의 의인화가 아니다. 각 종족 내부에 협력·거부·개혁 파벌이 있다.
- 아홉 상처는 아홉 명의 사도나 보스 조직이 아니다.
- 신수는 지성·거부권을 가진 독립 주체이며 포획 도감이 아니다.
- 유물 수량은 15권 플롯에서 역산하고, World Bible은 생성·소유·상실 규칙만 잠근다.
- 마나열병의 완치가 시간선 피해를 무효화하지 않는다.
- 행정 기록은 현실을 창조하지 않지만, 장기간 사회적 인정과 결합하면 현실의 안정도를 높이거나 약화한다.

## Reader Value

- 서로 다른 시대의 같은 도시·법·종족을 비교하는 발견감
- 마나열병 환자의 모순된 기억을 통한 미스터리
- 국가 운영과 개인 존재가 연결된 정치적 긴장
- 유물·신수·기록이 힘이자 증거이자 윤리적 부채가 되는 수집 만족
- 과거 개입 후 생활 세계가 실제로 달라지는 체감
