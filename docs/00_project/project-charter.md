## Project Identity

- Working Title: 《나는 과거로 간다》
- Genre: 다크 판타지 시간여행 음모 스릴러 + 정치 판타지
- Selected Direction: A+C hybrid
- Reference Intent: 드라마 《12 몽키즈》가 제공한 시간 임무, 변하는 미래, 인과 역전, 시대별 음모와 관계극의 효과
- Reference Prohibition: 문장, 고유명사, 숫자 조직, 동일 사건, 동일 반전, 동일 인물관계 복제 금지
- Pre-Writing Gate: CLOSED
- Manuscript Production: BLOCKED

## Core Promise

멸망한 미래의 현장 요원 에이든은 왕국 전체를 구성하는 시간 장치를 통해 여러 연대로 직접 파견된다. 임무의 성공은 귀환할 미래를 바꾸고, 바뀐 미래는 다음 임무의 명령과 적·동료·진실까지 다시 쓴다.

## Core Fantasy

- 서로 다른 판타지 시대에 잠입한다.
- 미래의 정보가 틀렸음을 현장에서 밝혀낸다.
- 과거의 선택으로 변화한 미래를 직접 확인한다.
- 왕조, 성당, 마탑, 연대기가 사실 하나의 거대한 시간 장치임을 해체한다.
- 단순히 적을 죽이는 것이 아니라 어느 미래를 남길지 선택한다.

## Non-Goals

- 죽으면 시작점으로 돌아가는 회귀 구조
- 수백 회차 경험으로 모든 전투와 사건을 공략하는 만능 주인공
- 시간여행을 후반 반전용 장식으로만 사용하는 구성
- 참고작의 12명 조직, 0번 환자, 동일한 바이러스 추적 플롯 복제
- 설계 이전의 원고 생산
