## Title Candidates

1. **《왕국은 과거를 먹고 산다》 — Recommended Working Title**
   - 차별점과 세계 구조를 즉시 전달.
   - 정치·다크 판타지 인상이 강함.

2. 《돌아갈 미래가 없다》
   - 감정과 시간여행을 강하게 전달.
   - 세계관 수집·정치 요소는 약하게 보임.

3. 《내가 구한 미래가 나를 죽이려 한다》
   - 웹소설 훅은 강함.
   - 장기 서사의 품격과 다종족 건국부를 좁힐 수 있음.

4. 《회색 연대기》
   - 분위기와 미스터리가 좋음.
   - 장르 약속이 덜 직접적.

기존 《나는 과거로 간다》는 저장소명·프로젝트 코드 또는 부제 후보로 유지한다.

## Aiden Name Audit

- `에이든`은 익숙하고 읽기 쉽지만 판타지에서 흔하다.
- 권장 처리: 에이든을 미래 파견기관의 **호출명**으로 유지하고 출생명은 명명 문화 확정 후 별도 설정.
- 호출명이라는 사실을 거대한 반전으로 소비하지 않는다. 신분·주소 붕괴와 자연스럽게 연결한다.

## Other Names

- Ria, Iris, Balthazar는 역할 이해용 SOFT LOCK.
- 에르나/카르둔/라하크/네바르도 언어·음운 감사 후 변경 가능.
- 이름 확정 전에 15권 플롯 기능을 바꾸지 않는다.

## Naming Gate

최종명은 다음을 통과해야 한다.

- 종족·지역별 음운 차이
- 시대 O/N/F의 이름 변화
- 한글 가독성
- 주요 인물 간 첫음절 중복
- 참고작·유명 판타지 고유명사 과유사
- 제목 검색성과 장르 약속
