## 1. 목적

기존 Deep Design의 서사·세계관·제도·유산 기능 위에 **IP 수집욕 전용 층**을 추가한다.

독자가 느껴야 하는 감정은 다음이다.

- `저 캐릭터는 실루엣만 봐도 안다.`
- `나는 이 인물이 최애다.`
- `저 유산은 갖고 싶다.`
- `저 신수는 다시 나오면 반갑다.`
- `저 장소를 한 컷만 봐도 어디인지 안다.`
- `같은 대상의 시대별 변형을 나란히 보고 싶다.`

이 작품의 수집욕은 게임식 희귀도·가챠·상위호환이 아니라 **역사·소유권·손상·변형·관계가 누적된 개체성**에서 나온다.

## 2. 10/10 설계 규칙

### 2.1 3초 인지
주요 캐릭터·유산·신수·랜드마크는 흑백 실루엣 또는 3개의 단서만으로 구별 가능해야 한다.

### 2.2 3중 서명
각 대상은 최소 3개를 가진다.
1. 형태 서명: 실루엣 / 비례 / 빈 공간
2. 재질 서명: 천 / 금속 / 돌 / 유리 / 종이 / 생체표면
3. 서사 서명: 상처 / 사용흔적 / 소유권 / 누락 / 변형

### 2.3 변화는 스킨이 아니라 역사
시대별 변형은 단순 색놀이가 아니다. 다음 중 2개 이상이 바뀐다.
- 소유자
- 용도
- 파손
- 덧댐
- 지워진 문장
- 봉인 기능
- 기억 주체

### 2.4 소유와 애착 분리
독자가 좋아하는 대상과 에이든이 소유하는 대상은 같을 필요가 없다. R01–R12의 공동소유·반환·봉인·파괴와 B01–B05의 비소유 원칙을 유지한다.

### 2.5 한 대상 = 한 Primary Icon
대표 이미지에서 모든 설정을 보여주지 않는다. 각 대상은 대표 아이콘 1개만 둔다.

## 6. 유산 잠금 필드

R01–R12는 기존 기능·소유권·최종상태를 유지하면서 다음을 추가한다.

- 휴대/설치 스케일
- 1차 실루엣
- 손에 잡는 위치 또는 전시 방향
- 주재료 / 수리재료 / 금지재료
- 손상 단계 0–3
- 소유자 교체 시 변형
- 가장 갖고 싶은 순간
- 놓아줘야 하는 순간

## 7. 신수 잠금 필드

B01–B05는 포획물처럼 설계하지 않는다.

- 크기비
- 이동 리듬
- 멀리서 먼저 보이는 기관
- 발자국·소리·냄새의 Presence Trace
- 계약 성립/파기의 시각 차이
- 새끼/군집/노령 개체 차이
- 인간 장비 장착 금지선

## 8. 배경 규칙

각 핵심 지역은 사건과 제도가 보이는 한 장면을 가진다.

- 아르켄: 겹친 시대기초 + 승인회랑 + 하항 옛 주소표
- 서부 잿빛 변경: 수선벽 + 겹문패 + 살아 있는 학교/시장
- 셀카르 유리산맥: 층형도시 + 공방열 + 균열광맥
- 라디아 곡창: 수문 + 배급광장 + 달력표식
- 조류도시연맹: 잠기는 하층 + 부교시장 + 염판기록
- 백지권: 매일 다시 그리는 표식 + 공동명부판 + 생활
- Era F 생존구: 재사용 장비 + 지하생활빛 + 영웅 선전물과 실제 결핍
- P1: 중앙 상징의 빈자리 + 여러 지역표식 + 이의제기판
