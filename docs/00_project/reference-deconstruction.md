# Reference Deconstruction — 원하는 시간여행 효과

Status: REVIEW  
Owner: Story Architecture  
Last Reviewed: 2026-08-07  
Canon Level: SOFT LOCK

## 가져올 효과

1. **임무형 시간여행**  
   미래에서 특정 인물·장소·사건을 조사하거나 개입하기 위해 과거로 파견된다.

2. **불완전한 미래 정보**  
   미래 조직이 제공한 정보는 기록 손실, 선전, 조작, 시간선 변경 때문에 틀릴 수 있다.

3. **변형된 귀환점**  
   임무 후 돌아온 미래는 출발 당시와 달라질 수 있다. 본부의 지도자, 조직 목적, 동료의 생사와 관계가 변한다.

4. **원인과 결과의 역전**  
   재앙을 막기 위한 행동이 재앙 조직·기술·예언·왕조의 탄생 원인이 될 수 있다.

5. **여러 시대의 능동적 인물**  
   과거 사람은 단순한 보호 대상이 아니라 자기 시대의 목표를 가진 주체이며, 미래의 명령을 거부하거나 역이용한다.

6. **관계가 시간선보다 강한가라는 질문**  
   사람들은 서로 다른 시간선에서 다른 관계를 맺지만, 선택과 기억의 흔적이 반복해서 연결된다.

## 복제하지 않을 요소

- 숫자 12를 전면에 둔 종말 조직
- ‘0번 환자’를 찾는 동일 추적 목표
- 동일한 바이러스 발생 과정
- 동일한 주인공·연인·과학자 관계 배치
- 동일한 최종 정체와 결말
- 참고작의 고유 장면·대사·상징

## 판타지 고유 치환

- 시간 기계 → 왕국의 수도·성당·왕좌·연대기·지맥이 결합한 문명 장치
- 시간 좌표 → 왕조력, 성력 주기, 왕의 혈통, 기록의 진명
- 미래 본부 → 멸망 이후 지하에 남은 ‘최후 연대국’
- 시간 이상 → 사라진 영지, 존재하지 않았던 왕, 바뀐 별자리와 성인의 계보
- 시간여행 비용 → 신체·기억만이 아니라 권리, 혈통, 역사적 존재감, 미래의 자원 소모
