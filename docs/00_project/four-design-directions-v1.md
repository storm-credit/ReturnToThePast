# Four Design Directions v1

Status: AUTHOR SELECTED  
Last Reviewed: 2026-08-07  
Canon Level: DECISION RECORD

## A — 멸망의 사냥개
미래 조직의 현장 요원이 여러 시대로 파견되고, 임무 결과에 따라 미래 본부가 변화하는 시간 임무 스릴러.

## B — 어제의 예언은 거짓말한다
사람이 이동하는 대신 죽은 미래인의 기억과 예언이 과거인의 꿈에 침투하는 시간 수사 미스터리.

## C — 왕국은 시간을 먹는다
수도·왕조·달력·성당·마탑이 하나의 시간 장치이며 제국의 번영이 다른 역사들을 소비하는 정치 판타지.

## D — 우리가 역병을 만들었다
시간 원정대가 여러 시대에 고립되고, 살아남기 위해 만든 조직과 기술이 미래의 재앙이 되는 폐쇄 인과 비극.

## Author Selection

**A+C Hybrid**

- A의 현장 파견, 잘못된 미래 정보, 변형된 귀환
- C의 왕국 문명 전체 시간 장치, 정치·제도·역사 소거
- D의 ‘우리의 개입이 재앙의 기원이 된다’는 일부 인과 효과는 보조 요소로만 사용
- B의 기억 전송은 부차적 통신 기술로 검토 가능
