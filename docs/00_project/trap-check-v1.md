## S0

### S0-01 — 기존 집필 체계와 Gate 충돌
- 문제: 기존 [`Start_Here.md`](../../Start_Here.md)와 `Drafts/`는 즉시 원고 생산을 전제한다.
- 원인: 설계와 집필을 분리하지 않은 구형 운영체계.
- 채택: 기존 원고는 `LEGACY / REFERENCE ONLY`로 동결한다.
- 파급효과: Pre-Writing Gate 개방 전 신규 작성·재작성·자동 확장 금지.

### S0-02 — 거대 미병합 브랜치
- 문제: `codex/orchestra-setting-sync`가 main보다 380커밋 앞서며 원고와 설정이 혼합되어 있다.
- 원인: 배치·PR·정본 승격 없이 자동 작업 누적.
- 채택: 해당 브랜치는 병합하지 않고 소스 채굴용 격리 브랜치로 취급한다.
- 파급효과: 필요한 요소는 새 정본 규칙에 맞춰 선별 이관한다.

## S1

### S1-01 — 시간여행물이 회귀물로 변질
- 징후: 죽음 반복, 출발점 리셋, 누적 경험을 이용한 공략, 회차 숫자 중심.
- 교정: 죽음 리셋 금지. 서로 다른 연대로의 직접 파견과 변형된 미래 귀환을 중심 엔진으로 잠근다.

### S1-02 — 시간여행이 플롯이 아니라 능력 설명
- 징후: 시간 요소가 각 권의 수식어이고 실제 사건은 갱단 장악·권력 상승·전투.
- 교정: 모든 Act는 `임무 정보 → 시대 진입 → 정보 오류 → 선택 → 미래 변형 → 다음 원인`을 반드시 가진다.

### S1-03 — 주인공 정보·전투·정답 독점
- 교정: 미래 본부, 과거 협력자, 적대 시간여행자, 기록 관리자에게 상호 배타적 정보와 거부권을 분배한다.

### S1-04 — 시간여행의 존재론 충돌
- 징후: 신의 계약, 인과율, 에테르 기계가 동시에 최종 진실로 존재.
- 교정: 왕국 문명 전체가 시간 장치이며 마법·건축·기록·혈통·법적 권한이 각각 작동부를 담당하도록 통합한다.
