# Full-Series Deep Context Routing Errata — 2026-08-20

Status: **ACTIVE ROUTING ERRATA / NO CANON MUTATION**
Scope: E001–E375 Static Deep Context routing

## 1. Purpose

기존 Subact Hub와 과거 Context Pack 문서에는 작성 당시의 생산상태를 반영한 문구가 남아 있다. 대표적으로 일부 Hub는 `Context Pack 없음`, `CP는 E001–E025에만 존재`라고 적고 있다.

Full-Series Deep Context 작업 이후 이 문구는 **사건·설계 부재를 뜻하지 않는 stale routing/index statement**가 되었다.

이 Errata는 해당 문구를 정본 사실로 오독하지 않도록 생산 라우팅만 교정한다. 사건·설정·결말·인물의도·POV 정본·손실 정본을 새로 만들거나 바꾸지 않는다.

## 4. Historical Context Pack preservation

기존 Context Pack은 삭제하지 않는다.

특히 충분히 깊게 컴파일된 기존 Pack은 Deep Master의 support source로 계속 사용한다.

예:
- `.agent/context-packs/episodes/E089-E093-context-pack-d12.md`

이 파일은 Authority Stack, E088 Exit, Subact 4C contract, clocks, location/spatial rules, character Want/Boundary/Knowledge Ceiling 등을 이미 깊게 컴파일했다.

새 Deep Master는 이런 검증된 내용을 억지로 다시 복사하지 않고:

`Deep Master → active/current CP if present → source bibles`

로 읽어 drift를 줄인다.

## 5. Full-series static vs runtime

Full-Series Deep Context가 E001–E375에 존재한다는 뜻은 미래 사건의 실제 결과가 확정됐다는 뜻이 아니다.

Static Deep Context:
- architecture ownership
- episode planned causality
- POV / knowledge ceiling
- character/faction agenda
- system/mystery ceiling
- asset/loss/visual locks
- next-cause boundary

Runtime Overlay:
- actual previous Exit
- wounds / missing persons
- current custody / possession
- exact relationship delta
- exact permissions / clocks
- surviving/destroyed evidence

Runtime 값은 실제 이전 원고가 존재한 뒤에만 확정한다.
