## Rules

1. 기존 원고는 삭제하지 않는다.
2. Pre-Writing Gate 개방 전 기존 원고를 재작성하거나 확장하지 않는다.
3. 기존 원고와 설정은 새 정본의 증거가 아니라 아이디어 후보 자료다.
4. 회귀 횟수, 죽음 리셋, 0회차 자기 자신 최종보스, 12인의 사도, 0번 환자는 자동 승계하지 않는다.
5. 유지할 이름·장소·관계·장면은 `docs/00_project/legacy-salvage-ledger-v1.md`를 통해 개별 심사한다.
6. 거대 작업 브랜치는 직접 병합하지 않는다.
7. 이관 항목마다 원본, 채택 사유, 변경점, 영향 파일, 작가 승인 상태를 기록한다.
