## 2. 중심 국가와 수도

### 국가
**칼레온 왕관령**

- 발음: 칼-레-온
- 뜻: 건국연합어에서 ‘고정된 둘레/서로 묶인 경계’에서 유래했다는 설정
- 이전 작업명 `바레인 왕관령`은 실제 국가명과 혼동되므로 폐기

### 수도
**아르켄**

- 정식: 아르켄 왕관수도
- 옛 이름: 강하구 피난장, 네 길의 캠프
- 의미: ‘네 주소가 겹치는 곳’이라는 후대 어원설

### 왕조
**세르바 왕조**

- 왕국 전체와 동일시하지 않는다.
- 장치를 만든 주체가 아니라 후대에 공동협약을 왕권서사로 편집한 혈통.

## 5. 핵심인물 정식명

### C01 에이든 로엔
- 현장 호출명: 에이든
- 출생명: 에이든 로엔
- F1 공식 칭호: 회색 재앙을 늦춘 귀환자 / 공식 영웅칭호는 정권별로 달라짐
- 결말 후: 공적 이름이 소실되므로 ‘로엔’은 독자와 설계도 식별용 정본에만 남는다.

### C02 리아 세른
- 직함: 팔림프세스트 기록관
- ‘세른’은 가문이 아니라 기록소 서임명.

### C03 아이리스 네르
- 서부 이름: 아이리스 네르
- ‘네르’는 네르바 변경 출신지명이며 귀족가문이 아니다.

### C04 마르칸 베르
- 기존 `F1 지휘관`의 정식명
- 직함: 최후 연대국 방위사령관
- 다른 시간대 버전으로 대체하지 않는다.

### C05 오르바드 카르센
- 기존 `[WORKING: 발타자르]` 폐기
- 직함: 건국연합 조정설계자
- 카르센은 공방·행정 공동서명명이며 단일 종족 가문으로 고정하지 않는다.

### C06 세렌 바일
- 첫 개혁가 정식명
- 서부 비용장부 감사관 출신
