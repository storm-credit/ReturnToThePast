# 기관 조직도·의사결정 절차 설정집 v1

Status: D8 ENCYCLOPEDIA REVIEW  
Canon: 권한분리·절차 HARD LOCK / 직함·인원수 SOFT LOCK  
Purpose: 명령 하나로 세계가 움직이는 편의 전개 방지

## 1. 공통 원칙

- 국가 규모 시간개입은 최소 7개 권한영역의 결합을 요구한다.
- 각 기관은 독립적 생활기능과 자기 예산·인력·법적 책임을 가진다.
- 비상권은 범위·기간·목적·사후감사를 명시해야 한다.
- 서명은 마법적 버튼이 아니라 정보와 책임을 승인하는 법적·기술적 행위다.
- 기관장은 실무를 단독 수행하지 못하며, 실무자는 전체 진실을 모를 수 있다.

## 2. 왕실·왕좌 승인체계

### 조직
- 군주 또는 섭정
- 왕실평의회
- 혈통·승계원
- 재정·징발원
- 외교·조약원
- 왕궁경비대
- 긴급권 기록관

### 평시 권한
- 법 공포, 조약, 세금안, 군 지휘, 고위직 임명
- 시간장치에는 ‘목적·책임주체·국가비상 필요’를 승인할 뿐 좌표와 출발을 직접 계산하지 않는다.

### 시간임무 승인 절차
1. 임무 제안 접수
2. 피해·대안·현지권리 검토
3. 왕실평의회 목적 승인
4. 성당·마탑·기록소·귀환·부담기관 의견
5. 제한조건과 종료시점 기록
6. 군주·증인단 공동인장
7. 임무 후 사후재판·기록감사

### 비상권
- 최대 기간 `[ASSUMPTION]` 30일 또는 특정 사건 종료까지
- 연장 시 최초 승인과 다른 증인 필요
- 비상권으로 출생·사망·토지 원본을 영구 삭제할 수 없음

### 취약점
- 증인 매수
- 혈통인장 위조
- 임시권 반복 연장
- 군사기밀을 이유로 피해지역 비공개

## 3. 중앙 성당

### 조직
- 대성좌 회의
- 달력국
- 의료·구휼국
- 장례·사망등록국
- 지역 성당망
- 교리·교육원
- 성당수호대

### 핵심 직무 분리
- 달력국은 날짜와 동기화를 관리하지만 교리판정을 하지 않는다.
- 의료국은 환자 격리·치료를 맡지만 기록삭제를 승인하지 않는다.
- 장례국은 사망을 확정하지만 죽은 기억의 법적 유죄를 단독 판정하지 않는다.

### 달력 조정 절차
1. 마탑 천문자료
2. 동부 수문·농사 보고
3. 국경 고정석 오차
4. 지역 성당 이의제기
5. 조정일·축일·파종일 공고

### 마나열병 격리 절차
- 일반 감염병 검사 선행
- 환자 동의와 위험도 평가
- 가족·주소기록 보호
- 격리기간·재심일 명시
- 기억증언을 질병증상과 증거로 분리 보존

### 취약점
- 교리와 행정의 혼합
- 구휼을 복종 조건으로 사용
- 종말파의 환자 낙인

## 5. 대기록소

### 조직
- 총기록관
- 출생·가족부
- 토지·세금부
- 계약·공증부
- 사망·주소상실부
- 원본보존부
- 팔림프세스트 감사실
- 기록감찰대

### 기록 상태
- 정본: 현재 법적 효력
- 원본: 최초 매체 또는 가장 이른 확인본
- 수정본: 변경이력 포함
- 상충본: 서로 양립 불가하지만 폐기하지 않음
- 봉인본: 공개 제한, 재심 가능
- 주소상실본: 사람·장소의 현재 존재는 있으나 과거 연결이 불완전

### 시민권 판정
1. 공적 기록 검색
2. 생활 흔적
3. 복수 독립증언
4. 물질·신체 흔적
5. 신수·기억매체 보조증거
6. 임시권리 부여
7. 공개 이의제기와 재심

### 기록 삭제
- 행정 오류 수정과 역사주소 삭제를 구분
- 영구 삭제는 원칙적으로 금지
- 위험정보는 출처표시·부분봉인·접근기록으로 관리

- 검역·심문부
- 유실요원 대응반
- 현지잔류 심사위원회

### 출발 전
- 임무 범위, 금지행위, 신분준비, 언어교육, 장비등록, 귀환조건, 현지 책임, 가족통보.

### 귀환 후
- 신체검사
- 마나열·중첩기억 검사
- 소지품·증거 분리
- 출발 미래와 현재 미래 비교
- 요원 법적 신분 재등록
- 독립 심문과 심리치료

### 잔류
요원은 현지에 남을 수 있으나 미래 군사정보 제한, 현지법 수용, 가족관계와 책임 확인을 요구한다. 강제귀환이 항상 정의롭지 않다.

## 10. 의사결정 정족수

### 평시 국가 시간개입
- 왕좌 목적
- 성당 동기화
- 마탑 좌표
- 기록주소
- 귀환관리
- 지역 부담동의
- 독립감사

7개 권한 모두 필요.

### 긴급 구조귀환
- 귀환관리 + 좌표 + 검역 + 현지/가족 책임
- 군사목적 추가 시 왕좌와 지역감사 필요

### 중앙 기능 정지
- 7개 운영권 + 민간 대피계획 + 지역망 준비

### 재가동
- 재난 사유만으로 자동 허용되지 않으며, 이전 피해·대안·기간·소거위험을 공개해야 한다.

## 11. 기관 상태 변화

- V1–V3: 중앙기관 정보독점과 첫 실패
- V4–V6: 기록·귀환·지역 권한 분열
- V7–V9: 원래 공동협약과 권한만료 조항 발견
- V10–V12: 시간산업·세 시대 감사·중앙 정지
- V13–V15: 증언 시민권·지역 감사·기능 분리

## 금지 모순

- 기관장 한 명이 전체 실무자의 생각을 대표하지 않는다.
- 서명 한 번으로 복잡한 절차와 후속책임을 생략하지 않는다.
- 관료 절차를 무조건 악으로, 즉흥 영웅판단을 무조건 선으로 만들지 않는다.
- 비상상황에서도 민간 인프라와 사후감사를 삭제하지 않는다.
- 분산기관도 부패·지연·지역이기주의에서 자유롭지 않다.
