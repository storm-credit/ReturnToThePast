# Temporal Authority Split v1

Status: REVIEW  
Owner: Institution / Faction  
Last Reviewed: 2026-08-07  
Depends On: Time-Travel Ontology  
Canon Level: HARD LOCK for separation of powers

## Purpose

시간여행을 주인공의 개인 능력으로 만들지 않고, 서로 다른 기관·인물의 승인·기술·현장 협력이 필요한 정치적 행위로 유지한다.

## Roles

### 1. Mission Council — 목표 승인
- 재앙과 자원 상태를 근거로 개입 목표를 정한다.
- 거부권: 임무 자체를 승인하지 않을 수 있다.
- 제한: 정확한 좌표와 현장 진실을 독점하지 못한다.
- Abuse Case: 체제에 유리한 역사만 ‘구해야 할 미래’로 지정.

### 2. Throne Custodian — 법적 접근
- 왕좌 인장과 혈통·승계 권한을 관리한다.
- 거부권: 특정 인물의 시간장치 접근을 차단.
- 제한: 성당력과 좌표 없이는 출발 불가.
- Abuse Case: 왕가의 존속을 역사 보존과 동일시.

### 3. Cathedral Synchronist — 시간 동기화
- 시대의 성력 주기와 의례 창을 맞춘다.
- 거부권: 종교적 금기 시점으로의 파견 거부.
- 제한: 역사 주소와 장소 좌표를 모름.
- Actual Benefit: 계절·농업·치료 의례의 동기화도 유지.

### 4. Tower Navigator — 장소·오차 계산
- 도착지와 안전 범위를 계산한다.
- 거부권: 사망 확률이 높은 좌표를 폐기.
- 제한: 어떤 사건이 진짜 목표인지 판단 권한 없음.
- Abuse Case: 경쟁 지역을 높은 오차 구역으로 지정.

### 5. Palimpsest Archivist — 역사 주소·기억 검증
- 진명, 사건 기록과 지워진 미래의 잔흔을 관리한다.
- 거부권: 증거가 부족한 인물 암살 임무에 주소 제공 거부.
- 제한: 현지 행동과 군사 자원 없음.
- Actual Benefit: 소거된 사람·영지의 증거를 보존.

### 6. Border Anchor Keeper — 귀환
- 국경 고정석과 귀환 창을 유지한다.
- 거부권: 귀환 수용을 차단하거나 다른 고정석으로 전환.
- 제한: 출발과 임무 목표 권한 없음.
- Abuse Case: 정치적 망명자나 실패한 요원을 시대에 버림.

### 7. Field Traveler — 현장 선택
- 승인된 범위에서 조사·협상·전투·선택 수행.
- 거부권: 현장 정보가 다르면 명령을 중단할 수 있다.
- 제한: 임의 출발, 임의 귀환, 기록 수정 불가.
- Cost: 모든 선택의 인간적·법적 책임이 몸에 누적.

### 8. Local Anchor — 현지 현실과 동의
- 은신처, 신분, 언어, 증인, 귀환 표식을 제공.
- 거부권: 미래 조직의 임무에 협력하지 않을 수 있다.
- 제한: 미래 정보와 장치 전체 접근 없음.
- Actual Benefit: 미래 개입이 현지 주민을 단순 희생시키지 못하게 함.

## Required Mission Quorum

정상 임무에는 최소 다음이 필요하다.

- 목표 승인
- 역사 주소
- 시간 동기화
- 장소 좌표
- 귀환 고정
- 현지 앵커 또는 대체 현장 계획
- 현장 요원의 동의

긴급 임무가 일부 절차를 생략하면 해당 결손이 구체적 비용과 실패 원인이 되어야 한다.

## Political Engine

각 기관은 시간여행 외에도 현재 사회에 실제 효용을 제공한다. 따라서 부패했다고 해서 즉시 폐기할 수 없다.

- 왕좌: 법과 승계
- 성당: 달력, 치료, 구휼
- 마탑: 기상·측량·통신
- 기록소: 소유권·신분·역사 증거
- 국경 고정망: 계절·공간 안정과 국방

개혁은 효율 저하와 공백 비용을 수반하며, 적대 세력의 지지가 합리적일 수 있다.
