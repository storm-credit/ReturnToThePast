## C21 레오르 세르바 — ROYAL SPEED / CENTRAL AUTHORITY

- **Silhouette:** 의례복의 수직선 위에 실무 장부끈이 가로로 끼어 `왕족인데 현장 결재를 직접 하는 사람`으로 보인다. 망토보다 목·가슴의 승인층과 오른손이 중요하다.
- **Face/Hand:** 오른손 검지 왕관 인장흉터를 반복 노출. 손가락 하나가 왕권의 상징과 상처를 동시에 가진다.
- **Material:** 매끈한 왕실직물 + 거친 장부끈 + 황동 승인판.
- **Signature Prop:** 왕관보다 **비상 승인판**. 왕권을 머리가 아니라 손에서 읽게 한다.
- **Gesture:** 불리한 질문에도 눈을 피하지 않고 검지로 범위를 세 구간으로 나눈다.
- **Movement:** 군중을 가르며 걷지 않고 사람들이 비켜줄 것을 전제로 일정한 직선 보폭.
- **Variant:** `ERA O HEIR → CENTRALIZING RULER → DISTRIBUTED-SYSTEM OPPOSITION`. 후반에는 왕실표식 수가 줄기보다 **표식의 법적 효력이 줄어드는 것**이 핵심.
- **Thumbnail:** 검지 인장흉터 + 실무장부끈 + 세로 의례복.
- **Merch:** 왕좌포즈보다 승인판을 들고 세 조항을 선언하는 자세.
- **No-Overlap:** 오렐의 수선 행정복과 달리 구조적으로 완성된 권력 실루엣.

## C22 하렌 세른 — ORIGINALISM / HARD EVIDENCE

- **Silhouette:** 등 뒤로 책이 쌓인 학자보다 **정사각 원본상자 + 짧은 실끈 묶음 + 손 가까운 감정도구**로 단단한 블록형.
- **Face/Hand:** 잉크에 변색된 왼손 손톱 유지. 얼굴 표정보다 손의 절제.
- **Material:** 두꺼운 기록지, 단단한 목재, 검은 실, 봉인납, 긁힘 적은 보존금속.
- **Signature Prop:** 접지 않는 문서와 별도 실끈. 리아의 겹판과 대비.
- **Gesture:** 상대 발언을 적지 않고 출처만 먼저 기록.
- **Variant:** `ORIGINAL-KEEPER → CONTESTED-ARCHIVE → OPEN-VERIFICATION`. 상자가 가벼워지기보다 **여러 사람이 봉인을 공유**하게 된다.
- **Thumbnail:** 정사각 원본상자 + 왼손 잉크손톱 + 곧은 실끈.
- **No-Overlap:** 리아의 유동적 겹기록, 엘사의 분산 생활기록과 구분.

## C23 미라 라디아 — FOOD / WATER / NEXT SEASON

- **Silhouette:** 상체 장식보다 허리의 곡물표본주머니와 손의 움직임이 중심. 농민복 코스프레가 아니라 **수문조합 대표의 실무층**.
- **Face/Hand:** 햇빛과 수문염에 갈라진 손등이 핵심.
- **Material:** 볏짚섬유, 방수천, 수문철, 곡물자루, 나무계량통.
- **Signature Prop:** 여러 곡물표본이 든 작은 주머니 3개. 각기 습도·종자·배급 의미.
- **Gesture:** 숫자를 들으면 주머니를 만져 며칠치 식량으로 환산.
- **Variant:** `REGIONAL-DELEGATE → CENTRAL-STOP SHORTAGE → P1 BURDEN-CAP`.
- **Thumbnail:** 갈라진 손 + 삼중 곡물주머니 + 낮은 실무외투.
- **No-Overlap:** 상인·풍요여신 이미지 금지.

## C24 브란 케르 — FORTRESS / CONDITIONAL COMMAND

- **Silhouette:** 두꺼운 중갑보다 **요새용 짧은 방풍갑 + 허리 철회조건패 + 우물/마구간 지도판**.
- **Face:** 왼귀 동상 흔적 유지. 얼굴의 한쪽 선이 겨울과 국경을 말한다.
- **Material:** 보온천, 무광 철, 밧줄, 나무패, 얼음 긁힌 가죽.
- **Signature Prop:** 명령패와 같은 크기의 **철회조건패**가 한 쌍.
- **Gesture:** 명령 후 반드시 두 번째 패를 뒤집어 종료조건 확인.
- **Variant:** `FORTRESS-COMMAND → RETURN-NET CONFLICT → RIGHTS-SEPARATION`.
- **Thumbnail:** 동상귀 + 쌍패 + 짧은 방풍갑.
- **No-Overlap:** 마르칸은 국가 군정, 브란은 절점·마을 실무.

## C25 케론 셀카르 — REPAIR TIME / MATERIAL REALITY

- **Silhouette:** 장갑·갑옷보다 목의 균열음 측정추와 무릎 보호대, 도구가방이 먼저 보이는 정비사.
- **Material:** 진동금속, 광분진 천, 교체 볼트, 가죽 손잡이, 석분.
- **Signature Prop:** 목에 걸린 균열음 측정추. 흔들림 자체가 연출.
- **Gesture:** 대화 중 발끝으로 바닥 진동 확인.
- **Movement:** 급박한 장면에서도 뛰기 전 구조물을 두 번 두드리는 습관.
- **Variant:** `BORDER-MAINTAINER → MULTI-ERA REPAIR → P1 NETWORK COMMISSIONER`.
- **Thumbnail:** 목 추 + 무릎보호 + 두꺼운 도구가방.
- **No-Overlap:** 도르칸은 소유·제작, 케론은 수리·가동시간.

## C26 아벨 네르 — MANA-FEVER WITNESS / PERSON BEFORE SYMPTOM

- **Silhouette:** 환자복으로 통일하지 않는다. **평범한 생활복 위에 의료표식과 서로 다른 시대의 흉터 위치가 어긋나 보이는 것**이 핵심.
- **Face/Body:** 얼굴 변형보다 이름을 잊는 주변 반응, 손에 없는 상처를 감싸는 행동 같은 불일치가 인지점.
- **Material:** 생활천, 임시 진료띠, 개인 물건, 수정된 이름표.
- **Signature Prop:** 치료표가 아니라 **여러 번 고쳐 쓴 현재 이름표**.
- **Gesture:** 기억 속 가족을 부르다 멈춘 뒤 현재 주변 사람을 확인한다.
- **Variant:** `PATIENT-STIGMA → PUBLIC-WITNESS → RIGHTS-RECOGNIZED`.
- **Thumbnail:** 평범한 몸 + 수정 이름표 + 비대칭 흉터/보호동작.
- **No-Overlap:** 괴물화, 발광혈관, 광기환자 이미지 금지.

## C27 시아 아노르 — SCHOOL / ORDINARY RIGHTS

- **Silhouette:** 교사복보다 **큰 공동명부판과 아이 높이에 맞춰 낮게 묶은 도구가방**. 몸의 중심이 성인 권위가 아니라 아이들과 같은 높이로 내려간다.
- **Material:** 분필석, 천 명찰, 나무명부판, 수선책, 생활앞치마.
- **Signature Prop:** 지워졌다 다시 써진 학적명부판.
- **Gesture:** 아이 이름을 부를 때 얼굴을 보고 출석표를 나중에 확인한다.
- **Movement:** 문턱과 줄 사이에서 계속 아이 높이로 몸을 낮춘다.
- **Variant:** `BLANK-ZONE TEACHER → TEMPORARY REGISTER → P1 APPEAL SCHOOL`.
- **Thumbnail:** 낮은 도구가방 + 큰 명부판 + 분필손.
- **No-Overlap:** 성녀·마법학교 교장 이미지 금지.

## C28 토마르 마레이 — PORT LABOR / DISTRIBUTION POWER

- **Silhouette:** 선장·해적보다 **한쪽 어깨의 화물끈, 넓은 손바닥 보호대, 젖은 작업바지**가 중심.
- **Material:** 밧줄, 방수천, 목재표, 녹청금속, 소금.
- **Signature Prop:** 배 이름이 아니라 하역순서를 표시하는 노동조합 화물패.
- **Gesture:** 회의에서도 무의식적으로 무거운 물건을 들 준비하듯 손바닥 보호대를 조인다.
- **Variant:** `PORT-WORKER LEADER → BLOCKADE/SMUGGLE → P1 DISTRIBUTION COUNCIL`.
- **Thumbnail:** 어깨 화물끈 + 손보호대 + 화물패.
- **No-Overlap:** 에스라의 외교적 항구매듭과 구분.

## C29 렌 바르 — STAYED TRAVELER / CHOSEN LOCAL LIFE

- **Silhouette:** 에이든과 같은 시간요원 계열의 옛 구조를 일부 공유하지만 **귀환장비가 제거된 자리 + 현지 가족·직업용 도구가 그 빈자리를 채움**.
- **Material:** 오래된 F계열 장비조각 + Era N 생활수선재 + 현지 도구.
- **Signature Prop:** 작동하지 않는 귀환장비 케이스를 도구함으로 개조한 물건.
- **Gesture:** 시간요원 습관으로 출구를 확인한 뒤, 실제로는 집 안 사람에게 시선을 돌린다.
- **Variant:** `STRANDED-AGENT → LOCAL-RESPONSIBILITY → LAST RETURN REFUSAL`.
- **Thumbnail:** 빈 귀환슬롯 + 개조 도구함 + 현지생활 패치.
- **No-Overlap:** C01은 돌아가려는 흔적, C29는 남기로 한 흔적.

## C30 이름 없는 여행자 — UNCLAIMED ENDING / ICONIC EPILOGUE

- **Silhouette:** 특별한 영웅장비가 없는 여행생활복. **한쪽 끈이 약간 짧은 가방 + 낡은 신발 + 접힌 길안내표** 정도만 반복.
- **Face/Hair:** 에이든과 닮았다고 단정할 수 있는 흉터·머리·눈색을 금지. 독자가 ‘가능성’을 느끼는 것은 몸짓과 장면구조이지 생체표식이 아니다.
- **Material:** P1 생활천, 지역별 수선재가 섞인 일반 여행장비.
- **Signature Prop:** 이름 없는 항소용 임시표 또는 길안내표. 귀환패·절검·에이든 전용장비 금지.
- **Gesture:** 길을 물을 때 자기 과거를 설명하지 않고 현재 머물 곳을 묻는다.
- **Movement:** 에이든 특유의 출구확인과 비슷해 보일 수 있는 한 번의 모호한 동작까지는 허용하되 반복 증거 금지.
- **Variant:** 없음. 변형을 만들수록 정체확정 압력이 커지므로 단일 에필로그 상태 유지.
- **Thumbnail:** 일반 여행자 + 비대칭 가방끈 + 임시표. 얼굴 삭제가 아니라 평범함이 핵심.
- **Merch:** ‘에이든 최종폼’으로 상품명 확정 금지. `이름 없는 여행자` 그대로.
- **No-Overlap:** C01의 모든 고유 장비와 직접 연결 금지.
