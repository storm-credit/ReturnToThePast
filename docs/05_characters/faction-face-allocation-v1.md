## 1. 상태표기

- **LOCKED**: 기존 정본에서 역할·권·사건 연결이 이미 명시됨.
- **COMPATIBLE**: 기존 욕망·핵심권 안에서 배정 가능. 사건을 바꾸지 않음.
- **OPEN**: 기존 인물로 무리 없이 해결되지 않음. 자동 신규인물 금지.

**C09 나하 아노르 — E089부터 주소상실 주민 대표로 배정 가능.**

근거:

- 최종기능이 백지권/증언시민권 대표

제약:

**C22 하렌 세른 — 4C의 원본주의 논리에 연결 가능.**

- 첫 핵심권 V4
- 대기록소 원본주의자
- 최종상태가 `원본 특권 포기`이므로 장기 변화축 가능

제약:

- `가장 오래된 검증 기록을 우선해야 한다`는 행정·증거 논리를 담당한다.

**군부 사령관 — OPEN 유지.**

C24 브란 케르는 첫 핵심권 V5라 V4에 소급하지 않는다. E091의 군부 사령관은 1회성 기능인물로 유지할 수 있으며, V5 이후 반복될 경우에만 정식 얼굴 필요성을 다시 판정한다.

## 4. 여성 인물 독립성 Gate

기존 금지규칙을 구체화한다.

- 리아: 기록/증거의 독립 결정이 에이든 감정선보다 우선하는 회차 유지
- 아이리스: 지역 주민의 선택이 에이든 전략과 다를 수 있어야 함
- 유나: 복원 욕망을 에이든에게 설득당해 즉시 포기하지 않음
- 마리엔/에스라: 외부국 이해를 왕국 주인공 편의에 종속하지 않음
- 시아: 백지권 아동/교육의 생활문제를 최종 철학의 장식으로 쓰지 않음

## 5. 주인공성 균형

반복 얼굴을 늘려도 에이든은:
- 시간개입의 누적 책임
- F0 상실의 감정선
- 자신의 역사주소 부식
- 젊은 자신과의 책임
- 마지막 중앙 연결비용

을 독점적으로 가진다.

다른 인물이 독립적으로 움직이는 것과 주인공의 중심성이 충돌하지 않는다.
