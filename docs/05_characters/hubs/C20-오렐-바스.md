## 3. 목소리

원본: [supporting-cast-dossiers-c11-c20-v2.md](../supporting-cast-dossiers-c11-c20-v2.md) C20 목소리 · [calendar-language-naming-bible-v1.md](../../02_world/calendar-language-naming-bible-v1.md) §6

직업 말투 층: **왕실 관료** — 책임 주체를 수동형·기관명으로 숨기는 경향 / 날짜·문서번호·선례를 자주 언급 (§6).

| 습관 | 내용 |
|---|---|
| 기본형 | 극단적 주장 사이에서 **실행 가능한 기간·인력·법적 책임**을 제시한다 |
| 어휘 | 날짜·문서번호·선례. Era O에는 없는 표준 문서번호 체계가 그의 시대에는 있다 |
| 회피 방식 | **수동태로 책임을 기관 뒤에 숨긴다.** 이 어법은 정본이 명시적으로 C20의 것이라고 지정했다 |
| 지연 어법 | 거절 대신 절차를 건다. 늦추는 것과 살리는 것이 같은 문장에서 나온다 |
| 피로 표식 | 잠이 부족할수록 **존칭이 더 정확해진다.** 흐트러지는 방향이 아니라 굳어지는 방향이다 |

**다른 인물과 무엇이 다른가**

| 대비 | 차이 |
|---|---|
| vs [에이든](C01-에이든-로엔.md) | 에이든은 `목표 → 출구 → 비용`의 임무 문법. 오렐은 `기간 → 인력 → 법적 책임`의 행정 문법이다. 에이든의 회피는 결론을 미루는 것, 오렐의 회피는 **주어를 지우는 것**이다 |
| vs C21 레오르 세르바 | 레오르는 짧은 선언 뒤 근거를 세 조항으로 끊는 왕실 **교육체**. 오렐은 선언하지 않고 절차부터 깐다. dossier가 두 어법을 명시적으로 분리했다 — 수동태·기관명 은폐는 **오렐의 것** ([c21-c30 dossier](../supporting-cast-dossiers-c21-c30-v2.md) C21 금지) |
| vs C24 브란 케르 | 브란은 국경병 보고체. 명령 한 문장 + 철회조건 한 문장. **왕실 관료 층의 수동태·기관명 은폐를 쓰지 않는다**는 것이 브란 항목에 오렐과의 대조로 적혀 있다 ([c21-c30 dossier](../supporting-cast-dossiers-c21-c30-v2.md) C24) |
| vs C23 미라 라디아 | 미라는 오렐 앞에서 **부담 상한을 숫자로 먼저 못 박은 뒤** 말을 시작한다. 그녀 쪽 관계 표식이 곧 오렐 어법의 거울이다 ([c21-c30 dossier](../supporting-cast-dossiers-c21-c30-v2.md) C23) |

**한계**: 이 인물은 [voice-relationship-state-bible-v1.md](../voice-relationship-state-bible-v1.md) §2·§2-A의 말투 항목에 **없다**. 위 표는 dossier와 직업 말투 층에서 온 것이며, 감정고조형·첫 접촉 절차 같은 세부는 `[설계 미정]`이다.

## 9. 갱신 조건

- 위 원본 중 하나라도 바뀌면 이 문서는 **STALE**이다. 원본을 먼저 고치고 여기를 맞춘다. 반대 방향은 금지한다.
- `[설계 미정]` 칸은 다음이 생기면 채운다.
  - `character-state-checkpoints-v1.md` §미해결의 **C20 첫 핵심권(V3) 구체 변곡 사건**
  - `voice-relationship-state-bible-v1.md` §2-A에 C20 말투 항목 / §5에 C20 정보상한 항목
  - `core-character-arc-map-v1.md`에 C20 아크
  - `knowledge-holder-ledger-v1.md`에 C20 KH 항목
  - `pronunciation-lexicon.md` 인물표에 `오렐 바스` 행 (발음·기본 호칭·직함 결합형)
  - V04·V12·V15 Subact 문서 (현재 V01–V03만 존재)
- `[허브 미생성]` 표시된 C21·C23 허브가 생성되면 링크로 교체한다.
- `[A]`·`[ASSUMPTION]` 표기는 원본이 붙인 것이다. 이 허브에서 임의로 떼지 않는다.
