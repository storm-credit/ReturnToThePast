## 3. 목소리

원본: [supporting-cast-dossiers-c11-c20-v2.md](../supporting-cast-dossiers-c11-c20-v2.md) C15 「목소리」

> 사망·소거·부재를 엄격히 구분하고, 감정적 순간에도 법적 용어를 줄이지 않음

| 습관 | 내용 |
|---|---|
| 핵심 어휘 | **`사망` / `소거` / `부재`를 절대 섞지 않는다.** 세 낱말이 이 인물의 문법 전체다 |
| 호흡 | 감정이 고조되어도 **법적 용어를 줄이지 않는다** — 위로하려고 쉬운 말로 바꾸지 않는다 |
| 회피 방식 | 슬픔을 다루는 대신 **판정 범주로 되돌린다.** 유족이 울면 답이 아니라 구분을 준다 |
| 판정 한계 | 마지막 감각의 법적 한계를 먼저 말한다. 재생된 것은 **인격이 아니라 감각**이다 |
| 공개 방식 | 전부 공개하지 않고 **사실 단위로 제한 공개한다** (V12 대피 완료 사실만 공개) |
| 전용 voice bible 항목 | **[설계 미정]** — [voice-relationship-state-bible-v1.md](../voice-relationship-state-bible-v1.md)에 C15 행이 없다 |

**다른 인물과 무엇이 다른가**

| 대비 | 차이 |
|---|---|
| vs [에이든 C01](C01-에이든-로엔.md) | 에이든은 죄책감에서 이름을 버리고 역할명(`표적·환자`)으로 후퇴한다. 베사르는 반대로 **처음부터 끝까지 범주어를 쓰되 그것이 후퇴가 아니라 직무**다. 에이든의 범주어는 회피, 베사르의 범주어는 판결 |
| vs [메이라 솔 C10](C10-메이라-솔.md) | 메이라는 **판정을 미루기 위해** 판정 전 표현을 쓴다(`아직 구분되지 않은 사람`). 베사르는 **판정을 확정하기 위해** 구분어를 쓴다. 같은 범주어, 반대 방향 |
| vs [리아 세른 C02](C02-리아-세른.md) | 리아는 `기억한다`와 `증명할 수 있다`를 구분한다. 베사르는 `죽었다`와 `지워졌다`와 `없다`를 구분한다. 둘 다 구분의 인물이나 **축이 다르다** — 리아는 증거의 등급, 베사르는 상실의 종류 |
| vs C11 테온 리브 | 테온은 감정 질문을 **조건문으로 돌린다**. 베사르는 돌리지 않고 **법적 용어 그대로 답한다**. 회피가 아니라 정면의 냉정함이다 |

**금지 말투**: 죽은 자와 자유롭게 대화하는 화법, 무감정 사신 이미지 (원본: 같은 dossier 「금지」).

| 제한 관찰자 배정 | **[설계 미정]** — [secondary-pov-and-offscreen-action-allocation-v1.md](../../10_story_architecture/secondary-pov-and-offscreen-action-allocation-v1.md)에 C15 회차 배정 없음 |

- **현장 전투 없음** — 전투 국면의 정보에 접근하지 못한다
- **증언이 물질증거를 대신하지 못한다** — 장례보석만으로 사실을 확정할 수 없다
- **네바르 내부 교리갈등** — 자기 법정 내부에서도 단일 견해를 대표하지 못한다
- 장례보석은 **마지막 감각만 재생하며 인격이 아니다** ([asset-state-checkpoints-v1.md](../../09_collection/asset-state-checkpoints-v1.md) R09 V8) — 죽은 자에게 물어서 답을 얻는 통로가 아니다
