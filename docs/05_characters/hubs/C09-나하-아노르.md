## 2. 호칭

원본: [terminology-and-addressing-clarification-v1.md](../../00_project/terminology-and-addressing-clarification-v1.md) §1 · [pronunciation-lexicon.md](../../../.agent/skills/sentence-narrator/pronunciation-lexicon.md) · [canon-naming-pack-v1.md](../../00_project/canon-naming-pack-v1.md) §C09

| 상황 | 표기 |
|---|---|
| 정식 표기 | 나하 아노르 |
| 기본 호칭 | 나하 |
| 직함 결합 | **아노르 대표** |
| 자기 소개 (본인 어법) | `트리엔의 나하, 증인 넷` — 공동체명 + 이름 + 보증 증인 수 |
| 발음 | 나-하 아-노르 |

**`아노르` 단독 호출 금지.** `아노르`는 가문명이 아니라 **백지권 공동체가 부여한 현재 주소명**이고, 두 번째 요소는 직함과 붙을 때만 쓴다(`네르 대표`·`로엔 요원`과 동일 규칙, DEC-018). 같은 요소를 [C27 시아 아노르](../supporting-cast-dossiers-c21-c30-v2.md)도 공유하므로 혈연으로 읽히지 않게 첫 동석 장면에서 **대사로** 한 번 드러낸다. 또한 `아노르`는 [아노르 백지권](../../02_world/atlas-region-dossiers-v1.md)의 단축 지명이기도 하다.

**집단 총칭 금지.** `움브라`는 설계 문서 전용이며 원고 표층 금지, `무등록 위험군`·`빈칸`·`오류`·`저주받은 자`는 부르는 쪽의 편견 표현이다. 근거: [peoples-and-cultures-v1.md](../../02_world/peoples-and-cultures-v1.md) §「누가 뭐라고 부르는가」

## 3. 목소리

원본: [voice-relationship-state-bible-v1.md](../voice-relationship-state-bible-v1.md) §2-A C09

직업 말투 층: `[ASSUMPTION]` 서부 주민 — 「지금 여기에서 기억한다」. 문법은 서부 증언어(확실함·기억함·전해들음·몸에 남음의 증거 수준 구분).

| 국면 | 어법 |
|---|---|
| 자기·타인 호명 | 이름 하나로 끝내지 않고 **공동체 + 증인 수**를 붙인다 |
| 총칭을 들었을 때 | 그 말을 되받아 쓰지 않고, 대답 대신 **그 자리 사람들의 이름을 하나씩 센다** |
| 날짜 | 왕조 연호를 쓰지 않고 명부 일수 — `세 번 난 마을의 현 명부 41일`. 공식 날짜는 부정하지 않고 자기 셈으로 환산해 되돌린다 |
| 증거 | 봤다·들었다·전해들었다·몸에 남았다를 **한 문장에 섞지 않는다.** 전해들은 것은 전한 사람 이름과 함께 |
| 서류 요구 | 문서에 문서로 답하지 않고 **오늘의 생활 흔적**을 센다 — 아침에 밥 먹은 사람 수, 물 길어 온 사람, 아이 맡은 집. 명단은 **적힌 이름이 아니라 빠진 이름**부터 |
| 감정고조 | 목소리를 높이지 않고 **이름 나열이 길어진다.** 거부는 조건 없이 한 문장 — `그건 안 됩니다.` |
| 결함의 표식 `[ASSUMPTION]` | `우리는`으로 전하다가 마지막 결정 문장만 `제가 답하겠습니다`로 인칭이 바뀐다 |
| 숫자 세계관 | 아홉을 부를 때 민간 신화형 `아홉 매듭` `[ASSUMPTION]` (성당 교리형 `아홉 상처` 아님) |

**다른 인물과의 구별점**

| 대비 | 차이 |
|---|---|
| [C01 에이든](C01-에이든-로엔.md) | 에이든은 역할명↔이름 교체가 감정 계기판. 나하는 **총칭을 아예 발화하지 않고 이름을 나열**하는 쪽 |
| C07 다렌 모트 | 둘 다 추상어 대신 이름·숫자를 세지만, 다렌은 **자기 가족 단위**, 나하는 **공동체 명부와 증인 수** |
| C10 메이라 솔 | 메이라는 거절 대신 조건을 붙여 문장을 잇는다. 나하는 **조건 없이 한 문장으로 끊는다** |
| C27 시아 아노르 | 같은 증언 어법을 쓰되 시아는 아이 어휘로 번역하고 **`우리 전부가 그렇게 말한 건 아니에요`를 먼저 붙인다** — 나하의 대표권 독점에 대한 대구 |

## 8. 금지

원본: [voice-relationship-state-bible-v1.md](../voice-relationship-state-bible-v1.md) §2-A C09 금지 · [cast-canon-index-v2.md](../cast-canon-index-v2.md) §6 · [atlas-region-dossiers-v1.md](../../02_world/atlas-region-dossiers-v1.md) R08

- 자기 집단을 총칭으로 자칭 (`저희 움브라는`·`무등록 위험군`·`빈칸`) — HARD 규칙
- 눈물·동정을 요청하는 **순수 피해자 호소조**
- 과거 혈통·출생 증명을 근거로 삼는 권리 주장 — 욕망과 정면 충돌

- `아노르` 단독 호칭, 원고 표층에 `움브라` 노출
- 백지권 전체를 **에이든 생존비용**으로 사용하는 최종안 채택
- 백지권을 무인 폐허로 단순화 / 대표를 배신자 또는 순수피해자로 단순화
- 한 사람의 전권대표 구조로 처리 (13A는 전권대표를 피하도록 설계됨)
- 조연을 한 장면 설명용 단역으로 소모 / 여성 인물을 에이든의 양심·연애·피해자 역할에만 배치
