## 3. 목소리

원본: [voice-relationship-state-bible-v1.md](../voice-relationship-state-bible-v1.md) §2-A C10

직업 말투 층: **성당 실무자** — 교리어와 의료·배급 실무어의 혼합 ([calendar-language-naming-bible-v1.md](../../02_world/calendar-language-naming-bible-v1.md) §6). 그 두 갈래 중 현장구휼사 쪽.

| 습관 | 내용 |
|---|---|
| 첫 접촉 | **이름 → 오늘 날짜 → 여기가 어디인지.** 회색열 진단 2단계 문답이 인사와 구분되지 않는다 |
| 문장 구조 | 교리어로 열고 **실무어로 닫는다** — 봉합·상처로 시작해 물·소금·침상 수로 끝난다 |
| 회피 방식 | 병명을 확정하지 않는다. `아직 구분되지 않은 사람` 같은 판정 전 표현 |
| 판정 어법 | 격리와 재심을 한 호흡으로 붙인다 — `오늘은 떼어 놓고, 사흘 뒤에 다시 봅니다` |
| 거절 | 교리를 근거로 대지 않는다. **침상 수·물·오늘 밤 들어올 사람 수**로 답한다 |
| 거절의 형태 | 완전한 거절 대신 조건을 붙여 문장을 이어 간다 — `데려가시려면, 대신…` |
| 감정고조 `[ASSUMPTION]` | 목소리가 커지는 대신 **감당할 수 없는 약속이 먼저 튀어나온다** — `제가 받겠습니다`. 직후 스스로 수를 다시 센다 |
| 기관 호칭 | 달력기관은 대사에서 `종탑`으로만 |

**다른 인물과 무엇이 다른가**

| 대비 | 차이 |
|---|---|
| vs [에이든](C01-에이든-로엔.md) | 에이든은 `목표 → 출구 → 비용` 순서. 메이라는 `이름 → 날짜 → 장소` 순서다. 에이든은 죄책감에서 이름을 역할명으로 바꾸지만, 메이라는 **판정을 미루기 위해** 역할명을 쓴다 — 같은 회피처럼 보이지만 동기가 반대다 |
| vs C03 아이리스 | 아이리스도 `오늘 필요한 물자`를 구체적으로 말한다. 차이는 아이리스가 **누가 언제 무엇을 잃는지 묻는** 반면, 메이라는 묻지 않고 **자기 쪽 수용치를 먼저 내놓는다** (`voice bible` §2 아이리스 / §2-A C10) |
| vs C09 나하 아노르 | 둘 다 숫자로 답하지만 나하는 **빠진 이름**을 세고, 메이라는 **남은 침상**을 센다 |
| vs C07 다렌 모트 | 다렌은 화가 날수록 문장에서 사람이 사라지고 좌표만 남는다. 메이라는 반대로 **감당 못 할 약속이 튀어나온다** |

**금지 말투**: 기도·의례만으로 낫는다는 단언, 설교로 장면을 채우는 위선·광신 말투, 마나열병 여부 확정 진단.
