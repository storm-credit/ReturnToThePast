| `세른 기록관` 형 | **[설계 미정]** — 렉시콘은 `세른 기록관`을 **C02 리아**의 기본 호칭란에 배정했고, 하렌 항에는 `원본주의 기록관`만 적는다. 같은 서임명을 쓰는 두 인물이 한 장면에 있을 때 이 결합형을 누구에게 쓰는지 정본 명시가 없다 |

**첫 등장 처리 규칙**: 하렌과 [리아](C02-리아-세른.md)가 처음 한 장면에 들어올 때 혈연 오해를 **서술이 아니라 대사로** 한 번 푼다 ([terminology §1](../../00_project/terminology-and-addressing-clarification-v1.md)).

## 3. 목소리

원본: [supporting-cast-dossiers-c21-c30-v2.md](../supporting-cast-dossiers-c21-c30-v2.md) C22 「말투」 및 후반 「목소리 — C21~C30 `[DEC-019]`」 C22 절

**직업 말투 층**: 기록관. [calendar-language-naming-bible-v1.md](../../02_world/calendar-language-naming-bible-v1.md) §6 기록관층 「봤다, 들었다, 원본이다, 수정본이다, 증언이다를 구분」의 **순정형이자 극단형**.

| 국면 | 습관 |
|---|---|
| 평시 | **`사실`이라는 말을 입에 담지 않는다.** 모든 진술에 `검증됨`·`미확인`·`상충` 중 하나를 등급으로 붙여 되돌려 준다 |
| 평시 | 상대가 말한 **내용을 받아 적지 않고 출처만 먼저 적는다.** 대화의 첫 질문이 늘 출처다. 내용에 대한 반응은 출처가 확정된 뒤에 온다 |
| 평시 | 반대할 때 원칙어 대신 **피해 건수**를 든다. 추상적 위조 위험이 아니라 실제로 집을 잃은 숫자를 센다 |
| 압박 | 결론을 요구받으면 **판정하지 않는 방식으로 버틴다.** 답을 미루는 조건은 언제나 구체적 — 무엇이 더 있어야 등급이 올라가는지 항목으로 말한다 |
| 감정고조 | **목소리를 낮추고 문서번호를 정확히 말한다.** 화가 오를수록 번호가 길어지고 발음이 또렷해지며 문장은 짧아진다. 고성·말 끊기 없음 |
| 리아에게 | 이름을 부르지 않고 **직함으로** 부른다. 상급자 어법과 전문적 적대가 한 문장에 같이 들어간다 |
| 어휘층 | 대사에서는 **`잔문`**을 쓴다 (`팔림프세스트`는 설정 문서 표기). 아홉 개를 부를 때는 기록관층의 **`아홉 주소 변수`** — 교리어 `아홉 상처`·민간어 `아홉 매듭`으로 옮겨 가지 않는다 |
| 에이든 응대 | **[설계 미정]** — 전용 응대 어법 기술 없음. 인접 근거는 부재행동 「에이든의 F0 주장과 **별개로** 위조 가능성을 검사한다」뿐 |
| 회피 방식 | **판정 유보.** 거절하지 않고 등급을 내려 붙인 뒤, 등급을 올릴 조건을 항목으로 되돌려 준다. 감정을 부인하지 않고 **음량을 낮춰** 문서번호로 옮긴다 |

### 이 인물만의 것 — 다른 인물과 무엇이 다른가

| 대비 | 차이 |
|---|---|
| vs [C02 리아 세른](C02-리아-세른.md) | **같은 기록관층, 정반대 방향.** 리아는 확실성 등급을 **자기 진술을 낮추는 데** 쓴다(`기억한다`↔`증명할 수 있다`). 하렌은 같은 도구를 **상대의 자격을 깎는 데** 쓴다 (dossier C22 직업 말투 층) |
| vs [C01 에이든 로엔](C01-에이든-로엔.md) | 에이든은 감정이 격해질수록 이름을 버리고 **역할명**으로 후퇴한다. 하렌은 격해질수록 **음량을 내리고 문서번호를 올린다** — 감정이 정확도로 나온다 ([voice bible §2](../voice-relationship-state-bible-v1.md)) |
| vs [C17 유나 벨](C17-유나-벨.md) | 같은 GA V 연합이지만 유나는 `추상적 원본보다` **사람의 이름과 일상**으로 말한다. 하렌은 그 반대편 — 가장 오래된 원본과 검증기준 ([사다리 §6](../../04_factions/antagonist-face-ladder-v1.md)) |
| vs [C12 엘사 네르](C12-엘사-네르.md) | 둘 다 원본 쪽이다. 엘사는 원본을 **숨겨서** 지킨다고 믿고, 하렌은 **공개봉인·법정 감정**으로 지킨다. 방향이 은닉↔공개로 갈린다 |
| vs [C20 오렐 바스](C20-오렐-바스.md) | 왕실 관료층의 **수동태로 책임을 기관 뒤에 숨기는** 어법은 오렐의 것이다. 하렌의 문서번호는 회피가 아니라 **정확도** 쪽으로 쓰인다 |
| vs C27 시아 아노르 | 시아는 원본 유무를 논박하지 않고 **현재 관찰**로 검증 기준을 갈아 낸다(「그 아이가 지난달에 어디 있었는지는 열두 명이 압니다」). 하렌은 그 관찰을 등급어로 되받는다 — **두 사람의 갈등축이 곧 검증기준** (dossier C27 관계) |

**금지 말투**: 리아의 냉정한 아버지상(훈계조, `너는 아직`, 실망의 한숨) / 증거를 태우겠다는 위협 / `그건 내가 다 안다`류 전지 어법 / 고성·말 끊기·감정 폭발. (원본: dossier C22 금지)

## 4. 이 인물이 모르는 것

원본: [voice-relationship-state-bible-v1.md](../voice-relationship-state-bible-v1.md) §5 · [knowledge-holder-ledger-v1.md](../../11_mystery/knowledge-holder-ledger-v1.md) · [supporting-cast-dossiers-c21-c30-v2.md](../supporting-cast-dossiers-c21-c30-v2.md) C22 「자원·한계」

| 항목 | 상태 |
|---|---|
| 전용 정보상한 항목 | **[설계 미정]** — §5는 에이든·리아·아이리스·지휘관 4인만 규정 |
| 지식 보유 장부 등재 | **[설계 미정]** — KH 항목에 C22 없음 |
| 보조 POV 배정 | **[설계 미정]** — [secondary-pov-and-offscreen-action-allocation-v1.md](../../10_story_architecture/secondary-pov-and-offscreen-action-allocation-v1.md)에 C22 제한 관찰자 회차 없음 |

dossier가 명시한 **인물 자체의 한계**(시점 장면에서 그가 도달할 수 없는 것):

- **기억·생활증언의 진실성을 수치화할 수 없다.** 그의 도구는 원본금고 접근권·법정 감정권·기록관 인맥까지다.
- 그러므로 **복수증언만으로 성립하는 권리**를 그의 문법으로 판정할 수 없다. 그는 그것을 「위조가 먼저 승리한다」로 읽는다 (거짓 믿음).
- **자기가 선 원본 자체가 후대 위조층일 가능성**을 아직 정면으로 인정하지 않는다 — 인정하는 것이 그의 변화다 ([cast-encyclopedia-v1.md](../cast-encyclopedia-v1.md) C22 「변화」).

정보상한 위반은 반전 편의를 위해서도 허용하지 않는다 ([voice bible §5](../voice-relationship-state-bible-v1.md) 말미).
