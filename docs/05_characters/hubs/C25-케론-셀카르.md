## 3. 목소리

원본: [supporting-cast-dossiers-c21-c30-v2.md](../supporting-cast-dossiers-c21-c30-v2.md) §C25 말투 · [calendar-language-naming-bible-v1.md](../../02_world/calendar-language-naming-bible-v1.md) §2·§6

직업 말투 층: **마탑 계산원의 오차 문법 + 북부 공방어의 재료 명사.** 정본이 명시적으로 조합을 지정했다 — 확률·오차·관측조건을 명시하되, 어휘는 계산원의 확률어가 아니라 §2 `북부 공방어`(재료상태·공정·소유관계 용어)를 쓴다.

| 습관 | 내용 |
|---|---|
| 되묻기 | 이론어·기관어를 그대로 받지 않고 **재료·시간·인원 셋**으로 바꿔 되묻는다. 셋 중 하나라도 답이 없으면 그 말을 **계획으로 취급하지 않는다** |
| 숫자 | 확정 숫자 대신 **범위**를 말한다. 좁히라는 요구에는 좁혀 주는 대신 **무엇을 더 재면 좁아지는지**로 답한다 |
| 어휘 분리 | `가능하다`와 `안전하다`를 **한 문장에 섞지 않는다.** 상대가 붙여 쓰면 그 자리에서 떼어 되풀이한다 |
| 모름의 표기 | `불가능`이라 하지 않는다. **아직 재보지 않았다 / 측정값이 없다 / 균열음이 안 잡힌다** |
| 압박 | 일정을 당기라는 요구에 **거절로 답하지 않는다.** 대체 자재 목록과 그때 늘어나는 사망 위험을 순서대로 읊은 뒤 **결정을 상대 쪽에 되돌려 놓는다** |
| 감정고조 ① | 말을 끊고 **발끝·손바닥으로 벽·바닥을 짚은 뒤** 다시 말한다. 문장이 짧아지고 **형용사가 아니라 단위가 늘어난다** |
| 감정고조 ② | 평소 `삼반`·`수리조`처럼 **반 번호**로 부르던 사람을 그때만 **이름**으로 부른다 |

**회피 방식**: 정본이 지정한 그의 회피는 **결정 되돌리기**다 — 거절도 수락도 하지 않고 대체안과 사망 위험을 나열해 판단을 상대에게 밀어 놓는다. 정본은 이것을 그의 **기술중립이자 회피**라고 같은 문장에서 부른다.

**다른 인물과 무엇이 다른가**

| 대비 | 차이 |
|---|---|
| vs [에이든 (C01)](C01-에이든-로엔.md) | **정확히 반대 방향의 계기판이다.** 에이든은 죄책감이 오면 이름을 버리고 역할명으로 후퇴한다. 케론은 격앙되면 반 번호를 버리고 **이름을 부른다**. dossier가 이 대칭을 명시적으로 배치했다고 적어 두었다 |
| vs [테온 리브 (C11)](C11-테온-리브.md) | 테온이 **마탑 계산원 본직**이다 ([인덱스](../cast-canon-index-v2.md) §2). 케론은 계산원의 오차 문법만 빌리고 어휘는 **공방의 재료 명사**를 쓴다 — 확률어를 쓰지 않는다는 것이 dossier의 명시 조항이다 |
| vs [오렐 바스 (C20)](C20-오렐-바스.md) | 오렐의 회피는 **수동태로 주어를 지우는 것**. 케론은 주어를 지우지 않고 **결정권자를 지목해 되돌려 놓는다** |
| vs C24 브란 케르 | 브란은 국경병 보고체(명령 + 철회조건). 케론은 명령하지 않고 **공정표**를 낸다. 두 인물 모두 V5 첫 핵심권이나 어법 층이 다르다 |
| vs [메이라 솔 (C10)](C10-메이라-솔.md) | 메이라는 구휼 실무의 환자 단위. 케론은 **자재·공정·수리시간 단위**다 |

**한계**: 이 인물은 [voice-relationship-state-bible-v1.md](../voice-relationship-state-bible-v1.md) §2·§2-A(C07·C09·C10만 추가)에 **없다**. 위 표는 dossier와 직업 말투 층에서 온 것이다.

**정본이 `[ASSUMPTION]`으로 표시한 항목** — 여기서 임의로 떼지 않는다.

| 항목 | 원본 표기 |
|---|---|
| 요구에 거절 대신 대체 자재 목록·위험을 읊고 결정을 되돌려 놓음 | `[ASSUMPTION]` — 자원 `자재대체` + 필요 `기술중립…묵인`에서 도출 |
| 격앙 시 반 번호 대신 이름을 부름 | `[ASSUMPTION]` — 두려움 `정비반이 희생양`에서 역산 |

## 4. 이 인물이 모르는 것

원본: [voice-relationship-state-bible-v1.md](../voice-relationship-state-bible-v1.md) §5 · [knowledge-holder-ledger-v1.md](../../11_mystery/knowledge-holder-ledger-v1.md)

| 항목 | 상태 |
|---|---|
| 전용 정보상한 항목 | **[설계 미정]** — §5는 에이든·리아·아이리스·지휘관 4인만 규정한다 |
| 지식 보유 장부 등재 | **[설계 미정]** — KH-01~KH-05에 C25 항목이 없다 |
| 시대에서 오는 실질 상한 | 시대는 **N**이다. Era O 구간(V7–V9)은 체크포인트가 `[A] 명시 변곡점 없음`으로 남겼다 |
| 권한에서 오는 실질 상한 | **대규모 마법·법적 승인 권한 없음** (dossier 자원·한계). 승인·입법 층의 정보를 그의 입으로 확정시키지 않는다 |
| 태도에서 오는 상한 | 거짓 믿음이 **`수리만 제대로 하면 운영자의 목적은 중요하지 않다`**이다. 운영자의 정치적 목적을 스스로 꿰뚫어 보는 대사는 이 믿음과 충돌한다 |

- 정보상한 위반은 **반전 편의를 위해서도 허용하지 않는다** (§5 말미).
- dossier 금지에 **`정치적 판단을 자기 언어로 요약해 주는 대사`**가 있다. 실질적으로 이 인물의 정보·발화 상한선이다.
- C25 전용 목록이 채워지기 전에는 **미래·시간선 지식을 이 인물에게 주지 않는다** — 정본이 준 근거가 없다.
