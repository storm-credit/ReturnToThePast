## 2. 호칭

원본: [pronunciation-lexicon.md](../../../.agent/skills/sentence-narrator/pronunciation-lexicon.md) 핵심 인물 · [terminology-and-addressing-clarification-v1.md](../../00_project/terminology-and-addressing-clarification-v1.md) §1

| 상황 | 표기 |
|---|---|
| 기본 호칭 | **젊은 에이든** |
| 발음 | `젊은 / 에이-든 로-엔` |
| 정식 표기 | 젊은 에이든 로엔 |
| 성 단독 | **`로엔` 단독 호출 금지** — 성만 부르는 문화 규칙이 미확정 |

- `로엔`은 가문명이 아니라 **F0 출생등록이 부여한 공적 식별명**이다. 성만 부르면 등록번호로 부르는 셈이다.
- 두 번째 요소는 **직함과 붙을 때만** 쓴다. 다만 C08에게 배정된 직함 호칭(`로엔 ○○`)은 정본에 없다 → `[설계 미정]`.
- `로엔`을 C01과 C08이 공유한다. 둘은 **동일인**이지 가족이 아니다. 같은 요소를 가진 두 인물이 한 장면에 처음 들어올 때는 서술이 아니라 **대사로** 한 번만 드러낸다.
- 이름 소거 뒤 대사에서 본명을 임의 복구하지 않는다.

## 3. 목소리

| 축 | 내용 |

**C01과 무엇이 다른가** (대조 원본: 같은 문서 §2 `에이든`)

|---|---|---|
| 감정 | 직접 말하지 않고 장비·식사로 대신함 | 직접 표현 |

| 죄책감 처리 | 이름 대신 역할명(`표적·환자·요원`)으로 부름 | `[설계 미정]` |
| 대화 방향 | 결론을 미루며 현장조건을 확인 | 상대에게 되묻는다 |

**닮음은 대사 반복이 아니라 같은 상황에서의 다른 선택으로 표현한다** (§3).

## 4. 이 인물이 모르는 것

원본: [secondary-pov-and-offscreen-action-allocation-v1.md](../../10_story_architecture/secondary-pov-and-offscreen-action-allocation-v1.md) §4

| 지점 | 모르는 것 |
|---|---|
| E247 | 현재 에이든의 전체 생애 |
| E253 | 시간인과 규칙 |
| E266 | 자기 선택이 현재 에이든을 얼마나 지울지 |

**아는 쪽**: 자기 가족·마을 정보는 현재 에이든보다 **더 많이 안다** ([voice-relationship-state-bible-v1.md](../voice-relationship-state-bible-v1.md) §3).

**시점 장면 제약**: 보조 POV는 에이든이 알 수 없는 행동이 권말 인과 이해에 필수일 때만 쓰고, **반전의 정답을 독자에게 직접 말하지 못한다** ([episode-card-composition-standard-v1.md](../../10_story_architecture/episode-card-composition-standard-v1.md) POV Rule). E250 교차 지점에서 `젊은 에이든 미래 선택`은 미확정으로 유지한다.

[knowledge-holder-ledger-v1.md](../../11_mystery/knowledge-holder-ledger-v1.md)에 C08 전용 KH 항목은 없다 → `[설계 미정]`.
