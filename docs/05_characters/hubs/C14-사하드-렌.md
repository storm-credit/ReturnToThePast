| voice bible 전용 항목 | **[설계 미정]** — [voice-relationship-state-bible-v1.md](../voice-relationship-state-bible-v1.md)에 C14 행 없음 |

**다른 인물과 무엇이 다른가**

| 대비 | 차이 |
|---|---|
| vs [에이든 C01](C01-에이든-로엔.md) | 에이든은 `목표 → 출구 → 비용`이라는 **임무 문법**으로 센다. 사하드는 세지 않는다 — 냄새·바람·기억으로 **가리킨다**. 에이든은 직함 체계 안에서 자기를 식별(`서부 구조대 에이든`)하는데, 사하드는 그 직함을 **인정하지 않고 `길손`으로 되돌린다** |
| vs [아이리스 C03](C03-아이리스-네르.md) | 둘 다 지역 권리를 말하지만 아이리스는 **오늘 필요한 물자와 사람·장소를 구체적으로 댄다**(voice bible §2). 사하드는 물자 목록을 만들지 않는다. 아이리스는 **지역권**, 사하드는 **이동권** — 공통점과 차이가 관계축 자체다 |
| vs C13 도르칸 카르바 | 도르칸도 소유권을 말하지만 방향이 반대다. 도르칸의 Lie는 `소유권을 단단히 잠그면 착취를 막을 수 있다`이고, 사하드의 Lie는 `길을 열어 두면 갈등은 결국 흩어진다`. **잠그는 말투 vs 여는 말투** ([supporting-cast-dossiers-c11-c20-v2.md](../supporting-cast-dossiers-c11-c20-v2.md) C13·C14) |
| vs [메이라 솔 C10](C10-메이라-솔.md) | 메이라는 **남은 침상 수**로 답한다. 사하드는 수치로 답하지 않는다 — 계약 조건과 신수의 거부 여부로 답한다 |

**인물구조** (원본: 같은 dossier)

| 항목 | 내용 |
|---|---|
| Want | 이동단과 신수가 왕국 인프라의 소유물로 편입되지 않게 함 |
| Need | 이동자유도 정착민의 수문·농경·묘지를 침해할 수 있음을 인정 |
| **Lie** | 길을 열어 두면 갈등은 결국 흩어진다 |
| Fear | 국가가 길과 신수의 이름을 **등록**해 이동 자체를 허가제로 만듦 |
| Boundary | **신수의 거부를 인간의 동의로 대체하지 않음** |
| 자원 | 고대 이동로, 날씨 감각, 신수와의 장기 신뢰 |
| 한계 | 고정거점 부족, 이동단 내부 합의 필요, **성문법 증거 취약** |

## 4. 이 인물이 모르는 것

원본: [voice-relationship-state-bible-v1.md](../voice-relationship-state-bible-v1.md) §5 · [knowledge-holder-ledger-v1.md](../../11_mystery/knowledge-holder-ledger-v1.md)

| 항목 | 상태 |
|---|---|
| 전용 정보상한 항목 | **[설계 미정]** — §5는 에이든·리아·아이리스·지휘관 4인만 규정한다 |
| 지식 보유 장부 등재 | **[설계 미정]** — 장부는 KH-01–KH-05뿐이며 C14 항목이 없다 |

**원본에서 확인되는 구조적 상한** (지어낸 것이 아니라 다른 절의 사실에서 직접 따라오는 것만 적는다)

- **시대 상한**: 시대는 O 중심이다 ([supporting-cast-dossiers-c11-c20-v2.md](../supporting-cast-dossiers-c11-c20-v2.md) C14 「기본」). 에이든의 미래 직함을 인정하지 않는 이유가 거부가 아니라 무지일 수 있는 자리 — **어느 쪽인지는 [설계 미정]**
- **증거 형식 상한**: 성문법 증거가 취약하다 (같은 곳 「한계」). 문서로 증명해야 하는 국면에서 자기 주장을 문서로 뒷받침할 수 없다
- **권한 상한**: 이동단 내부 합의가 필요하다 (같은 곳). 혼자 계약을 확정하지 못한다
- **대리 금지**: 신수의 거부를 인간의 동의로 대체하지 않는다 (같은 곳 「Boundary」). 신수가 아직 답하지 않은 것을 사하드가 대신 답할 수 없다

정보상한 위반은 반전 편의를 위해서도 허용하지 않는다 ([voice-relationship-state-bible-v1.md](../voice-relationship-state-bible-v1.md) §5 말미).
