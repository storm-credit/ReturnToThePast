## 3. 목소리

원본: [supporting-cast-dossiers-c21-c30-v2.md](../supporting-cast-dossiers-c21-c30-v2.md) §목소리 C30 `[DEC-019]`

**직업 말투 층이 없다.** 어떤 계급·직업 층에도 배치하지 않는 것이 정본이며, 이 인물은 **절차 신청자의 말**만 쓴다. 층이 없다는 사실 자체가 결말의 논지(이름·소속 없이도 이의제기권이 성립한다)를 문장 수준에서 실행한다.

| 국면 | 규칙 |
|---|---|
| 평시 | 자기를 주어로 하는 문장을 거의 쓰지 않는다. 답할 차례에 자기 사정 대신 질문을 되돌린다 — `어느 쪽 길이 지금 사람이 부족합니까.` |
| 평시 | 담당자의 직함·이름을 부르지 않고 서류 이름과 순서만 말한다 — `다음은 뭘 냅니까.` `이건 어디로 갑니까.` |
| 평시 | **과거형 문장을 피한다.** 오늘·이번 주·다음 배급 같은 현재·근미래 단위로만 말하고, 회상을 여는 어휘가 목록에 없다 |
| 평시 | 증거를 낼 때 **증인 두 명과 현재 생활 증거를 먼저** 말하고 1인칭 주장은 마지막 한 줄 |
| 압박(정체 질문) | 부인도 인정도 하지 않고 절차 문장으로 바꾼다 — `그게 이 신청에 필요한 항목입니까.` **허용된 단 하나의 익숙한 말버릇**이며 형태를 바꾸지 않는다 |
| 감정고조 | 문장이 길어지지 않는다. 낮추기·뜸 들이기 연출 없음. 절차 문장을 같은 길이로 이어 말한다 |
| 관계 | 리아·에이든 관련 고유명이 대화에 나와도 반응 문장을 만들지 않고 자기 절차 질문을 이어 간다 |

`[ASSUMPTION]` 표시된 두 항목(익숙한 말버릇을 조건 확인형 되물음으로 특정 / 과거형 회피를 문법 규칙으로 승격)은 dossier가 스스로 가정으로 명시한 것이다. 원문 근거를 그대로 확인하고 쓴다.

### 이 인물만의 것 — 다른 인물과 무엇이 다른가

원본: [supporting-cast-dossiers-c21-c30-v2.md](../supporting-cast-dossiers-c21-c30-v2.md) §목소리 C21–C30

| 비교 대상 | 그쪽 | 이름 없는 여행자 |
|---|---|---|
| [C01 에이든 로엔](C01-에이든-로엔.md) | 짧은 확인 질문·조건부 판단이 정본 습관. 죄책감이면 상대를 **역할명**으로 바꿔 부른다 | 같은 계열의 되물음을 **단 한 형태만** 남기고 나머지를 전부 지웠다. 애초에 사람을 호명하지 않으므로 역할명 후퇴가 일어날 자리가 없다 |
| [C02 리아 세른](C02-리아-세른.md) | 출처와 확실성 등급을 밝히고 `기억한다`와 `증명할 수 있다`를 구분 | 기억을 아예 발화하지 않는다. 증거는 **타인의 증언과 현재 생활**로만 낸다 |
| C27 시아 아노르 | 같은 백지권 무대. 자칭을 `어느 공동체의 누구, 증인 몇` 형식으로 **말한다** | 자칭 형식 자체를 쓰지 않는다. 자기를 주어로 세우는 문장을 피한다 |
| C29 렌 바르 | 정체가 알려진 잔류 요원. 위기에서 보고체로 되돌아갔다가 다시 현지어로 정정하는 **왕복**이 말투의 본체 | 왕복이 없다. 감정고조에도 문장 길이와 형태가 변하지 않는다 |
| C21 레오르 세르바 | 1인칭으로 결재를 선언하고 날짜·선례를 댄다 | 1인칭 선언이 없다. 날짜를 대면 출발지가 문장에 생기므로 시제 자체를 제한한다 |

**회피 방식**: 정체를 묻는 질문을 **절차 항목 확인으로 되돌린다.** 부인하지도 인정하지도 않고, 침묵으로 의미를 만들지도 않는다. 이 되물음 하나가 이 인물이 쓸 수 있는 유일한 회피이며, 동시에 유일하게 허용된 단서다.

## 4. 이 인물이 모르는 것

원본: [supporting-cast-dossiers-c21-c30-v2.md](../supporting-cast-dossiers-c21-c30-v2.md) C30 정보상한

이 인물은 **E375 최종 3중 POV의 마지막 시점**을 맡는다 ([character-state-checkpoints-v1.md](../character-state-checkpoints-v1.md) C30). 그 시점 장면에서 서술로도 쓸 수 없는 것이 아래다.

| 상한 | 원본 |
|---|---|
| 자기 정체·기억·출발지 — **독자와 담당자 모두 확정하지 못함** | [dossier C30 정보상한](../supporting-cast-dossiers-c21-c30-v2.md) |
| 에이든만 아는 정보를 말하지 않음 | 같은 곳 |
| **리아와의 사적 약속을 인식하는 장면 금지** | 같은 곳 |
| 시간·귀환·미래·장치 관련 어휘 일체 | [dossier 목소리 C30 금지](../supporting-cast-dossiers-c21-c30-v2.md) |
| 정체 단서는 E374 장면에서 한 개 이하 | [secondary-pov-and-offscreen-action-allocation-v1.md](../../10_story_architecture/secondary-pov-and-offscreen-action-allocation-v1.md) §6 |

**주의**: 다른 인물의 정보상한이 「무엇을 모르는가」인 데 비해, C30의 상한은 「**독자도 확정하지 못한다**」까지 포함한다. 시점을 열되 자기 과거를 아는 내면 서술을 넣으면 그 자체로 위반이다.
