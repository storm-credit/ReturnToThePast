## 3. 목소리

원본: [E017-context-pack.md](../../../.agent/context-packs/episodes/E017-context-pack.md) §4·§5 · [E016-context-pack.md](../../../.agent/context-packs/episodes/E016-context-pack.md) §5 · [E023-context-pack.md](../../../.agent/context-packs/episodes/E023-context-pack.md) §2

> [voice-relationship-state-bible-v1.md](../voice-relationship-state-bible-v1.md) §2에 **C06 항목이 없다.** 이는 [V01-1D.md](../../10_story_architecture/subacts/V01-1D.md)가 기재한 정본 충돌 항목이다. 아래는 CP에 적힌 행동 규정이며 어휘·호흡의 세부 규격은 **[설계 미정]**.

| 항목 | 내용 |
|---|---|
| 기본 태도 | 무릎 꿇지 않고, 위협하지도 않는다 |
| 요구 형태 | **명령의 원문** → **그 명령이 근거한 기록의 계보**. 누가 언제 무엇을 남겨 이 명령이 성립했는가 |
| 요구의 성격 | 목숨 구걸이 아니라 **감사관의 직업적 질문** |
| 회피 방식 | 부인이 아니라 **부분 자백 + 피해 축소**. 기억채취는 인정하되 자기 방식의 피해는 줄여 말한다 |
| 위기 반응 | 도주가 아니라 **확인**(E016), 도주가 아니라 **시간 끌기**(E023) |
| 거부 | 미래 기관의 **검증 불가능한 약속**을 끝까지 거부 |

**다른 인물과 무엇이 다른가**

| 인물 | 말의 축 |
|---|---|
| 에이든 (C01) | `목표 → 출구 → 비용`. 결론을 미루는 **현장조건 확인** — [voice bible](../voice-relationship-state-bible-v1.md) §2 |
| 리아 (C02) | `기억한다`와 `증명할 수 있다`의 구분, 출처·확실성 등급 — 같은 곳 |
| **세렌 (C06)** | **문서의 계보를 되묻는다.** 사실 여부가 아니라 **그 사실이 어디서 왔는가**를 묻는다 |

리아가 기록의 **신뢰도**를 등급으로 말한다면, 세렌은 기록의 **출처 사슬**을 요구한다. 에이든이 조건을 확인할 때 세렌은 권한의 근거를 확인한다.

## 4. 이 인물이 모르는 것

원본: [E016-context-pack.md](../../../.agent/context-packs/episodes/E016-context-pack.md) §5 · [E017-context-pack.md](../../../.agent/context-packs/episodes/E017-context-pack.md) §4 · [E019-context-pack.md](../../../.agent/context-packs/episodes/E019-context-pack.md) §4

| 아는 것 | 시점 |
|---|---|
| 미래 본부의 존재 | E017 진입 시점 |
| 에이든의 출발 인장을 알아볼 만큼의 구조 지식 | E015 실험기록 · E016 |
| 자기 생체인장이 서부 봉쇄의 **강제키**이며, 죽으면 왕실이 기록망을 장악한다 | E019 |
| 자기 조직의 기록이 세 방향으로 쪼개진 뒤 남은 몫 | E017 |

| **모르는 것 — 시점 장면에서 쓸 수 없다** |
|---|
| 미래 개입의 **규모**와 본부 구조 |
| **명령을 만든 주체** |
| **자신이 어떤 이름으로 기록될지** (= 회색 재앙 창시자) |

세렌은 자기 명예가 어떻게 처리됐는지 모른 채 죽는다. M02의 답을 본인이 알지 못한다.

## 8. 금지

원본: [V01-1A.md](../../10_story_architecture/subacts/V01-1A.md) · [V01-1C.md](../../10_story_architecture/subacts/V01-1C.md) · [V01-1D.md](../../10_story_architecture/subacts/V01-1D.md) · [V03-3B.md](../../10_story_architecture/subacts/V03-3B.md) · [cast-encyclopedia-v1.md](../cast-encyclopedia-v1.md) · [permanent-loss-lock-v1.md](../../12_losses/permanent-loss-lock-v1.md) L001 / RF-02

- **모든 진실을 아는 예언자** / 시간여행 원리 강의 / 취조실에서 진실을 알려 주는 정보전달형 대화
- **유언조 진실 폭로·순교자 선언·자기 기능의 자기 설명** (E072 회수를 선취한다)

- 생체인장의 해제·복제·이전 간편 절차 제시 / 봉쇄권을 즉석에서 넘기겠다는 제안
- `사실 개혁가는 완전히 결백했다` / `모든 왕실 문서가 위조였다` 단순 반전
- E019 이전에 봉쇄 강제키 정보 사용, E061 이전에 M02 확정, E072 이전에 전체 기능 공개
- 개인 흑막으로 연결하거나 그 반대편에 개인 흑막을 세우기 (M12)

**공정성 기준선**: 독자는 `행위는 유죄인데 결과의 인과가 서지 않는다`를 조립할 수 있어야 하지만, **위조 주체와 세렌의 실제 기능은 추론으로 확정할 수 없다**.
