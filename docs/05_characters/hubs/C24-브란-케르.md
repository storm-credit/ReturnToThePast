| 금지 | 이유 |
|---|---|
| `케르` 단독 | 두 번째 요소는 가문명이 아니다. **직함과 붙을 때만** 쓴다 (§1 `[DEC-018]`) |

- **[설계 미정]** — `케르`가 §1의 「같은 요소를 여러 인물이 공유한다」 표(네르·세른·아노르·로엔)에 **등재되어 있지 않다.** 브란과 아르덴이 요소를 공유하는 관계인지, 그래서 첫 동석 장면에 **대사로 한 번 드러내는 처리**가 필요한지 정본이 답하지 않았다. 여기서 정하지 않는다.
- 발음 원칙은 사전 공통 규칙을 따른다 — 원문에 전체 이름이 있으면 전체를 읽고, 개인 이름만 있으면 성을 덧붙이지 않는다. 무대명 `칼레온 고정환`의 단축 호칭은 `고정환`·`국경고리`다 (같은 사전 권역표).

## 3. 목소리

원본: [supporting-cast-dossiers-c21-c30-v2.md](../supporting-cast-dossiers-c21-c30-v2.md) 「목소리 — C21~C30 `[DEC-019]`」 C24 · [calendar-language-naming-bible-v1.md](../../02_world/calendar-language-naming-bible-v1.md) §6

직업 말투 층: **국경병** — 거리·날씨·보급·귀환 가능성 중심의 짧은 보고 (§6). 요새장 직위이므로 이 보고체를 **명령 + 철회조건의 2단 구조**로 확장한다.

| 상태 | 습관 |
|---|---|
| 평시 | 지형을 말할 때 **성벽 높이보다 우물 깊이·마구간 사료 일수를 먼저** 센다. 손가락이 물과 사료에 먼저 닿는다 |
| 평시 | 명령은 **반드시 두 문장.** 첫 문장은 지시, 둘째 문장은 철회 조건. "동쪽 문을 봉쇄한다. 구휼 수레가 들어오면 푼다." **조건 없는 명령은 그의 입에서 나오지 않는다** |
| 평시 | 보고는 **거리 → 날씨 → 보급 → 귀환 가능성** 순서. 형용을 붙이지 않는다. 사기(士氣) 이야기는 네 항목이 끝난 뒤 한 문장만 |
| 압박 | 결정을 미루는 상대에게 남은 시간을 **종소리·끼니·교대 횟수로 잘라** 되돌려 준다. "종 세 번까지." **숫자로 자를 수 없는 요구는 그 자리에서 거절한다** |
| 압박 | 상급 명령과 마을 거부가 충돌하면 어느 한쪽을 고르는 대신 **제한시간 이중승인 절충안을 상대보다 먼저 자기 입으로** 낸다. 절충안에도 만료 시각이 붙는다 |
| 감정고조 | 목소리를 키우지 않는다. 대신 **문장에서 철회 조건이 빠진다.** `[ASSUMPTION]` |
| 감정고조 | 나누어 부르던 `민간`과 `내 인원`이 **`안에 있는 사람`으로 뭉쳐진다** — 자기 거짓 믿음 안으로 들어간 신호 `[ASSUMPTION]` |

**이 인물만의 것 — 다른 인물과 무엇이 다른가**

| 대비 | 차이 |
|---|---|
| vs [에이든](C01-에이든-로엔.md) (C01) | 에이든은 `목표 → 출구 → 비용`의 임무 문법이고 **회피는 결론을 미루는 것**이다. 브란은 미루지 않는다 — 미루는 쪽을 **종소리 단위로 잘라 되돌려 준다.** 브란의 회피는 결정 회피가 아니라 **조건 부착**이다 |
| vs C07 다렌 모트 | **같은 국경병 층을 공유한다.** 다렌은 `거리 → 보급 → 돌아올 수 있는가`에 **Era F 미래 축약어**가 겹치고 기관명을 축약형으로 부른다 ([voice bible §2-A](../voice-relationship-state-bible-v1.md)). 브란에게는 미래 축약어가 없고, 대신 **철회조건 2단 명령**이 얹힌다. 같은 층 위에서 갈리는 지점이 이 둘의 구분선이다 |
| vs [오렐 바스](C20-오렐-바스.md) (C20) | 오렐은 왕실 관료 층 — **수동태·기관명으로 주어를 지운다.** 브란은 그 어법을 **쓰지 않는다.** dossier가 브란 항목에 오렐·레오르와의 대조로 명시한 지점이다 |
| vs C21 레오르 세르바 | 레오르는 짧은 선언 + 근거 **세 조항**의 왕실 교육체. 브란은 조항이 아니라 **철회 조건**을 붙인다. 레오르가 시간을 **일수**로 환산한다면 브란은 **종소리·끼니·교대**로 자른다 |
| vs C23 미라 라디아 | 미라는 숫자를 **며칠치 식량**으로 환산해 되묻고 감정이 오르면 단위가 작아진다. 브란은 환산하지 않고 **만료 시각을 붙인다.** 미라의 계기판은 단위, 브란의 계기판은 **조건절의 유무**다 |

**회피 방식**: 정면 거절이 아니라 **조건 부착**이다. 못 한다고 말하는 대신 언제 풀린다고 말한다. 그리고 숫자로 자를 수 없는 요구만 즉시 거절한다.

**한계**: 이 인물은 [voice-relationship-state-bible-v1.md](../voice-relationship-state-bible-v1.md) §2·§2-A의 말투 항목에 **없다.** 위 표는 dossier 「목소리」절과 직업 말투 층에서 왔고, `[ASSUMPTION]` 표시가 붙은 두 줄은 **원본이 스스로 붙인 표시**다. 여기서 떼지 않는다.

## 4. 이 인물이 모르는 것

원본: [supporting-cast-dossiers-c21-c30-v2.md](../supporting-cast-dossiers-c21-c30-v2.md) C24 자원·한계 · [voice-relationship-state-bible-v1.md](../voice-relationship-state-bible-v1.md) §5 · [knowledge-holder-ledger-v1.md](../../11_mystery/knowledge-holder-ledger-v1.md)

| 항목 | 상태 |
|---|---|
| **시간정치 전체** | **모른다.** 정본 명시 — "귀환망 기술은 이해하나 시간정치 전체는 모름" |
| 귀환망 **기술** | 이해한다. 단, **원리를 자기 입으로 강의하는 대사는 금지**다 (dossier 목소리 금지) |
| 전용 정보상한 항목 | **[설계 미정]** — §5는 에이든·리아·아이리스·지휘관 4인만 규정한다 |
| 지식 보유 장부 등재 | **[설계 미정]** — KH 항목에 C24가 없다 |
| 시대에서 오는 실질 상한 | 시대는 **N**. V7–V9(Era O) 구간은 체크포인트가 `[A] 명시 변곡점 없음`으로 남겼다 |

정보상한 위반은 반전 편의를 위해서도 허용하지 않는다 (§5 말미). **미래·시간선 전체 지식을 이 인물에게 주지 않는다** — 정본이 준 것은 `귀환망 기술 이해`까지다.
