# Character Visual Identity Bible — C01–C10 v1

Status: **D16 IP VISUAL DEEP DESIGN**  
Canon: 역할·욕망·관계·최종상태 HARD LOCK / 색조·세부머리형 SOFT LOCK  
Rule: 인물은 의상 코스프레가 아니라 **직업·문화·손실의 누적**으로 식별한다.

## 공통 규격

각 인물은 `실루엣 / 얼굴·머리 / 재질 / 대표소품 / 기본자세 / 움직임 / 손상 / 변형 / 썸네일 테스트 / 금지중복`을 가진다.

## C01 에이든 로엔 — FIELD TRAVELER / ICON

### Primary Silhouette
- 마른 장신보다 **실전형 중간 체격**, 어깨는 넓지 않지만 중심이 낮다.
- 상체를 완전히 감싸는 롱코트 대신 **사선으로 잘린 짧은 방풍외투 + 허리 장비띠 + 한쪽 어깨 수선판**.
- 정면보다 3/4 측면에서 `한쪽 어깨가 무겁고 반대쪽 손이 자유로운 비대칭`이 읽혀야 한다.
- 칼집·가방·망토가 좌우 대칭으로 늘어지지 않는다.

### Face / Hair Read `[SOFT]`
- 얼굴은 미소년형보다 **눈 밑 피로와 각진 광대가 남는 현장형**.
- 머리는 귀와 목선을 가리되 전투 시 시야를 막지 않는 중간 길이. 색조는 회흑~은회 범위 SOFT.
- 완전 백발·빛나는 눈을 시간능력 표식으로 사용하지 않는다.

### Material Grammar
`마모된 방수천 / 재사용 금속판 / 가죽 손잡이 / 오래 닳은 인장재`.
깨끗한 왕실금속과 대비된다.

### Signature Props
- 초중반: R04 F0 귀환패가 몸 중심선 가까이에 있으나 장식처럼 노출하지 않음.
- V1–V3 일부: R03 절검은 ‘전용 성검’처럼 허리에 영구고정하지 않고 사건에 따라 휴대·반환 관계가 보인다.
- 기록용 짧은 연필·접힌 현장지도는 기능 소품.

### Default Gesture
- 방에 들어오면 사람보다 **출구·창·표식·바닥선**을 먼저 본다.
- 판단 직전 엄지로 장비띠의 빈 고리를 한 번 만지는 습관. 후반에는 귀환패가 사라져도 같은 동작이 남는다.

### Movement Read
- 검객처럼 과장된 준비자세보다 **짧은 이동 → 멈춤 → 확인 → 개입**.
- 싸움에서도 큰 회전보다 벽·문·사람 사이 좁은 경로를 쓴다.

### Damage / Wear
- 손상은 회차마다 사라지지 않는다. 외투 수선선, 장갑 교체, 귀환패 연결부 마모가 누적된다.
- V11 이후에는 신분표식이 줄어드는 것이 ‘더 멋진 장비 획득’보다 중요한 변화다.

### Variants
1. `F0 FIELD`: 가장 많은 등록표식과 귀환장비.
2. `ALTERED/WORN`: 여러 시대 수선재가 한 옷에 섞임.
3. `ADDRESS-LOSS`: 공식 표식이 하나씩 기능을 잃고 빈 고리·떼어낸 패치가 늘어남.
4. `FINAL-ECHO`: 공적 신분을 증명하는 장식이 거의 없고 기능적인 생활복만 남는 방향. C30과 동일인 확정은 금지.

### Thumbnail Test
검은 실루엣에서 **사선 외투 밑단 + 비대칭 어깨 + 몸 중심 가까운 작은 패/빈 고리** 3개가 보이면 통과.

### Merch Translation
대표 피규어는 ‘검 휘두르는 포즈’보다 **한 손에 접힌 지도, 다른 손이 빈 귀환패 고리 근처에 있는 이동 직전 자세**가 작품성을 더 잘 보존한다.

### Do-Not-Overlap
- 마르칸의 직사각 군복 실루엣
- 젊은 에이든의 열린 허리선·가벼운 장비
- C30의 익명 생활복

## C02 리아 세른 — PALIMPSEST ARCHIVIST / ICON

### Primary Silhouette
- 전투망토가 아니라 **서로 길이가 다른 겹소매 + 몸 옆으로 세로로 떨어지는 문서프레임/보관가방**.
- 상체 중심이 아니라 양손과 옆구리에 시선이 가는 실루엣.

### Face / Hair Read `[SOFT]`
- 머리카락은 문서 작업 중 방해되지 않도록 일부 고정하되, 완벽한 올림머리보다 반복해서 다시 묶은 흔적.
- 얼굴은 차가운 미인보다 **잠을 줄인 기록노동자의 집중감**이 먼저 보여야 한다.

### Material Grammar
`얇은 종이 / 반투명 염판 / 밀랍 / 가는 금속 프레임 / 반복 수선한 천`.

### Signature Props
- 출처표식 끈이 여러 겹 달린 문서갑.
- 서로 다른 시대 기록을 겹쳐 볼 때 쓰는 얇은 반투명 판.
- 개인 기억매체는 목걸이 장식처럼 상시 노출하지 않는다.

### Default Gesture
말하기 전 종이 모서리를 맞추거나, 상대가 말한 이름 옆에 **작은 출처점을 하나 더 찍는다**.

### Movement Read
달리기보다 장애물 사이에서 문서를 몸으로 보호하며 이동. 위험 순간에도 먼저 `무엇을 들고 있는가`가 보인다.

### Damage / Wear
잉크·밀랍·종이베임, 장갑 끝의 닳음. 후반으로 갈수록 가방은 무거워지기보다 **개인자료가 줄고 공공복제 표시가 늘어난다**.

### Variants
- `F0 PRIVATE ARCHIVE`: 개인 기억과 임무자료가 섞임.
- `PUBLIC EVIDENCE`: 사적 표식이 제거되고 검증 가능한 출처색인이 증가.
- `FINAL`: 에이든 관련 사적 기표가 물리적으로도 빈 자리처럼 남되, 기억이 기적복구되지 않는다.

### Thumbnail Test
`비대칭 겹소매 + 세로 문서갑 + 손끝의 얇은 판`.

### Merch Translation
아크릴/피규어는 종이폭풍보다 **겹친 투명판 사이에서 같은 문장이 다르게 보이는 구조**가 핵심.

### Do-Not-Overlap
하렌의 단단한 원본상자·봉인도구, 엘사의 생활형 문서끈과 구분.

## C03 아이리스 네르 — LOCAL ANCHOR / ICON

### Primary Silhouette
- **소매를 걷은 현장복 + 짧은 지역망토/어깨천 + 허리의 주민표식판과 배급끈**.
- 중앙 관료처럼 세로로 길지 않고, 옆으로 손이 뻗기 쉬운 안정된 삼각형.

### Face / Hair Read `[SOFT]`
- 바람·먼지에 노출되는 생활형 머리. 완벽한 장발 히로인 연출 금지.
- 표정은 강한 여전사보다 사람 수를 세고 이동경로를 보는 **현장책임자**의 긴장.

### Material Grammar
`바랜 지역천 / 목재표식 / 철제 실무고리 / 수선가죽 / 흙·재`.

### Signature Props
- 주민대피용 표식판 또는 작은 묶음표.
- 귀환표식 차단 작업 시 사용하는 절단·봉인 도구는 무기처럼 과장하지 않는다.

### Default Gesture
사람과 대화하면서도 **손으로 뒤쪽 사람의 이동을 유도**한다. 말과 동시에 공간을 정리하는 캐릭터.

### Movement Read
직선 돌파보다 사람 사이를 가르며 흐름을 만든다. 발이 멈춰도 손은 계속 일한다.

### Damage / Wear
무릎·소매·손바닥이 가장 먼저 닳는다. 중앙회의에 가도 새 예복으로 갈아입기보다 기존 옷 위에 최소한의 공식표식을 덧댄다.

### Variants
`WESTERN FIELD / COUNCIL OVERLAY / P1 REGIONAL AUDIT`.
최종형도 여전히 주민 현장으로 돌아갈 수 있는 옷이어야 한다.

### Thumbnail Test
`걷은 소매 + 짧은 어깨천 + 허리 주민표식 묶음`.

### Merch Translation
주민표식판을 들고 뒤를 돌아보며 사람들을 통과시키는 포즈.

### Do-Not-Overlap
리아의 기록가방, 유나의 추모물, 시아의 학교명부와 구분.

## C04 마르칸 베르 — F1 DEFENSE COMMANDER / SIGNATURE

### Primary Silhouette
- 넓은 장식갑옷보다 **곧은 직사각 군복 + 짧은 판금보강 + 목 아래 배급/구역 토큰줄**.
- 어깨선은 수평, 외투자락은 짧고 기능적.

### Face / Hair Read
짧게 정리된 머리와 실제 수면부족. 흉터를 과도하게 영웅화하지 않는다.

### Material Grammar
`군용직물 / 무광 금속 / 번호표 / 교체가능 판 / 배급끈`.

### Signature Prop
검보다 **구역배치판·접힌 방어지도·배급토큰**이 대표소품.

### Default Gesture
명령 전 지도에서 사람 숫자를 손가락으로 묶는다. 이름보다 구역을 먼저 보는 나쁜 습관이 시각적으로 드러난다.

### Movement
보폭이 일정하고 길을 비키게 만드는 군사적 리듬. 전투 때도 후퇴선 확인이 먼저.

### Damage / Wear
F1의 성과를 보여주는 잘 관리된 장비가 V12로 갈수록 시민대피 흔적으로 거칠어진다.

### Variant
`F1 ORDER / EVACUATION-WORN / LAST COMMAND`.
마지막은 더 화려한 지휘복이 아니라 계급표식 일부를 떼어낸 대피책임자 상태.

### Thumbnail
`직사각 군복 + 목 아래 토큰줄 + 평평한 방어지도`.

### Do-Not-Overlap
에이든의 비대칭, 브란의 요새장비와 구분.

## C05 오르바드 카르센 — FOUNDING COORDINATION DESIGNER / SIGNATURE

### Primary Silhouette
- 왕국의 현자 로브가 아니라 **서로 다른 문화의 작업복을 임시로 겹친 건국현장 조정자**.
- 한쪽에 도면통, 다른 쪽에 공사장 측정도구가 있어 수평이 맞지 않는다.

### Face / Hair Read
연령은 중년 이후. 왕관·수염으로 권위를 만드는 대신 **계속 현장을 보느라 고개가 약간 기울어진 자세**가 특징.

### Material Grammar
`거친 마포 / 카르둔 금속자 / 라하크 매듭 / 인간 행정판 / 에르나 기억표식`의 혼합.

### Signature Prop
완성된 청사진 한 장이 아니라 **여러 언어로 덧쓴 접이식 공정판**.

### Default Gesture
서로 다른 사람에게 같은 도면의 다른 면을 보여준다.

### Movement
직접 무거운 것을 들기보다 작업자 사이를 끊임없이 이동하며 충돌 지점을 찾는다.

### Damage / Wear
항상 손에 흙·분진·밀랍이 함께 묻어 있어 어느 한 기관 소속으로 보이지 않는다.

### Variant
`ERA O TEMPORARY COALITION / LATE FOUNDING STANDARDIZATION` 두 단계. 후자로 갈수록 통일 표식이 늘어나는 것이 그의 성공이자 위험.

### Thumbnail
`비대칭 도면통 + 다문화 작업표식 + 접이식 공정판`.

### Do-Not-Overlap
왕족·마법사 현자 실루엣 금지.

## C06 세렌 바일 — FIRST REFORMER / SIGNATURE

### Primary Silhouette
- 혁명가 망토보다 **감사관 실무복 + 잘린 군용검 R03 + 두꺼운 장부끈**.
- 허리의 절검은 칼날보다 `잘린 길이`가 먼저 읽혀야 한다.

### Face / Hair Read
정돈을 포기한 사람이 아니라 계속 이동하는 조사관. 눈빛 과장보다 입가의 피로.

### Material Grammar
`관청직물 / 낡은 가죽 / 철제 봉인도구 / 잉크 / 말라붙은 진흙`.

### Signature Prop
R03 절검과 감사를 위한 봉인끈. 절검은 영웅검이 아니라 문서·봉인을 끊는 작업도구처럼 보인다.

### Gesture
말할 때 상대보다 장부의 누락칸을 먼저 가리키는 버릇.

### Movement
앞서 나가지만 뒤의 대피속도를 놓치는 성격이 보이게 빠른 걸음.

### Final Image
E023 이후에는 시체 미학보다 **남겨진 절검·빈 자리·타인이 이어 쓰는 기록**이 대표 이미지가 된다.

### Thumbnail
`짧게 잘린 검 + 두꺼운 장부끈 + 감사관 실무복`.

### Do-Not-Overlap
성기사·반역귀족 비주얼 금지.

## C07 다렌 모트 — F1 COMRADE / SIGNATURE

### Primary Silhouette
- 군복은 마르칸보다 가볍고 **가족·생활물품이 군용장비 사이에 끼어 있는 실루엣**.
- 한쪽 가방에 민간용 수선끈이나 아이의 작은 표식이 달려 있다.

### Material Grammar
`F1 군용천 / 생활수선재 / 가족표식 / 재사용 플라스틱성 판재가 아닌 판타지식 압착섬유·금속`.

### Signature Prop
무기보다 가족을 증명하는 작은 생활표식. 이것이 F1을 되돌릴 수 없는 감정적 이유를 시각화한다.

### Gesture
에이든과 말할 때 습관적으로 옛 전우거리까지 다가오지만, 에이든은 그 기억이 없어 반 박자 어긋난다.

### Variant
`F1 COMRADE / CIVILIAN-PROTECTOR`.

### Thumbnail
`가벼운 군장 + 민간 수선끈 + 가족표식`.

### Do-Not-Overlap
마르칸의 완전한 제도 실루엣과 달리 생활 흔적이 중심.

## C08 젊은 에이든 로엔 — UNCLAIMED SELF / SIGNATURE

### Primary Silhouette
- C01과 얼굴 골격 일부는 닮아도 **허리선이 열려 있고 장비가 가볍다**.
- 사선 외투·귀환패·복합 수선 흔적이 없다.

### Face / Hair Read
C01보다 표정반응이 빠르고 시선을 오래 숨기지 않는다. 동일 헤어 복제 금지.

### Material Grammar
`Era N 생활천 / 지역가죽 / 구조도구 / 아직 표준화되지 않은 개인장비`.

### Signature Prop
전문 시간장비 대신 구조·구호에 쓸 수 있는 로프/표식도구.

### Gesture
현재 에이든이 출구를 볼 때 젊은 에이든은 먼저 사람 얼굴을 본다. 둘의 닮음보다 선택차이를 몸으로 보여준다.

### Variant
다른 미래의 에이든처럼 ‘강화형’으로 만들지 않는다. V11 이후 독립 공적 경로의 표식만 최소 추가.

### Thumbnail
`C01과 유사한 얼굴축 + 열린 허리선 + 구조로프/표식`.

### Do-Not-Overlap
C01의 귀환장비와 손상 누적을 절대 복제하지 않는다.

## C09 나하 아노르 — BLANK-ZONE RIGHTS FACE / SIGNATURE

### Primary Silhouette
- 기록마다 얼굴이 달라 보인다는 기믹을 괴물화하지 않고, **일관된 옷의 수선선·신발·손에 든 현재생활 표식**으로 인지시킨다.
- 머리·얼굴보다 `반복되는 현재 물건`이 아이콘.

### Material Grammar
`여러 출처의 천 조각 / 반복 덧댄 이름표 자리 / 나무·천 공동표식 / 생활용 금속`.

### Signature Prop
과거 신분증이 아니라 **현재 공동체가 갱신하는 증언표**.

### Gesture
누가 이름을 물으면 과거를 설명하기 전에 지금 어디서 먹고 자고 누구를 책임지는지 답하는 습관.

### Movement
경계선을 넘을 때 멈칫하는 게 아니라 주변 사람들의 확인을 기다리는 사회적 리듬.

### Variant
표식이 많아지는 것이 ‘정체성 복구’가 아니라 **현재 권리가 제도적으로 인정되는 과정**이어야 한다.

### Thumbnail
얼굴을 가려도 `같은 신발 형태 + 반복 수선선 + 현재 증언표`로 알아볼 수 있어야 한다.

### Do-Not-Overlap
후드·가면·안개로 정체불명을 표현하지 않는다.

## C10 메이라 솔 — RELIEF MEDIC / SIGNATURE

### Primary Silhouette
- 성직자 로브보다 **진료앞치마·접힌 소매·작은 약품/붕대 케이스가 층을 이루는 실무 의료복**.
- 성당 문양은 가슴 중앙이 아니라 도구와 기록표에 작게 반복.

### Face / Hair Read
긴 근무로 잔머리가 풀리고, 손을 씻기 위해 장신구가 거의 없다.

### Material Grammar
`세척 가능한 천 / 유리·도기 약용기 / 끓인 붕대 / 황동 잠금 / 종이 진료표`.

### Signature Prop
환자 분류표와 작은 손세척/소독도구. 마법지팡이 금지.

### Gesture
대화 중에도 손등이나 호흡을 관찰한다. 상대를 만지기 전 허락을 구하는 작은 멈춤.

### Movement
급하지만 환자 사이에서는 동선이 정교하다. 전투적 민첩성과 다른 ‘진료실 속도’.

### Variant
`CATHEDRAL RELIEF / REGIONAL MEDICAL NETWORK`. 후반에는 종교표식이 줄기보다 지역별 도구가 섞여 네트워크화가 보인다.

### Thumbnail
`겹 진료앞치마 + 작은 약품케이스 + 환자분류표`.

### Do-Not-Overlap
치유사 드레스·빛나는 지팡이·백색 성녀 클리셰 금지.
