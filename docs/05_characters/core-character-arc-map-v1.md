# Core Character Arc Map v1

Status: REVIEW  
Owner: Character & Relationship

## 에이든 — Field Traveler / callsign candidate

- Start Belief: 출발한 F0가 진짜이며 충분한 정보가 있으면 피해 없는 정답을 찾을 수 있다.
- GA1: 잘못된 명령을 수행하고 자기 선택이 미래를 망쳤음을 인정.
- GA2: F1 시민도 복원 대상이 아니라 현재의 사람임을 배움.
- GA3: 후대 비극을 알면서도 Era O 생존을 위해 장치 건설을 허용.
- GA4: 미래 선택권을 독점한 적과 자신이 닮았음을 직면; 젊은 자신에게 독립 선택 제공.
- GA5: 원래 미래가 아닌 존재권과 이의제기 절차를 지키며 자기 역사 주소를 희생.
- Final: 영웅으로 기록되지 않지만 독점권을 끝낸 살아 있는/남겨진 증인 후보.

## Ria — Palimpsest Archivist

- Start Belief: 충분히 정확히 기록하면 지워진 사람을 되살릴 수 있다.
- Conflict: 에이든에게 주소를 거부하고 기록의 윤리를 지킴.
- Midpoint: F0 기억이 자신에게도 서로 다르게 변한다는 사실 확인.
- Loss: V12–V14에 개인 기억을 공공 증거로 변환하며 관계의 세부를 잃음.
- Final: 기록은 부활이 아니라 현재의 권리 주장과 이의제기를 위한 것이라고 받아들임.

## Iris — Era N Local Anchor

- Start Belief: 미래 명분은 현재인을 도구화하므로 눈앞의 사람만 지키면 된다.
- Development: 자신의 선택도 후대 외부국·난민·무명종에 비용을 넘길 수 있음을 배움.
- Autonomy: 주민 희생 임무에는 귀환표식을 끊을 권리를 실제 행사.
- Final: 지역 거부권과 공동 감사제도의 설계자 후보. 에이든과의 관계는 로맨스 여부와 무관하게 동등한 정치·윤리 축.

## F1 Commander

- Belief: 현재 존재하는 F1 시민의 수가 지워진 F0 기억보다 우선한다.
- Benefit: F0보다 많은 생존자와 강한 재난 대응체계를 실제로 만듦.
- Harm: 지방·가문·기억을 선별적으로 제외.
- Arc: 적대자→상황별 동맹→F1 시민 대피를 위해 V12에서 영구 사망.
- Prohibition: 다른 시간대 버전으로 감정적 대체 금지.

## Era O Architect `[working: Balthazar]`

- Belief: 당대의 대량사망을 막는 기술은 후대 악용 위험보다 우선한다.
- Arc: 중앙 효율을 주장하다 에이든의 증거로 감사조항을 수용하지만 장치 건설은 포기하지 않음.
- Final Legacy: 영웅/악당이 아니라 필요한 체제를 만들고 불완전한 출구를 남긴 책임자.

## F1 Friend Slot

- F0에서는 적 또는 낯선 사람이었으나 F1에서는 에이든의 오랜 친구로 존재.
- 사도·종말교 추종자가 아니다.
- F1 가족과 시민을 지키기 위해 F0 복원에 반대.
- 관계의 비극은 배신이 아니라 서로 다른 실제 사람을 지키는 충돌.

## Younger Aiden

- 현재 에이든의 복제품이나 리셋 상태가 아니다.
- 미래 자신에게 인생을 강요받지 않을 독립 권리가 있다.
- V11에서 다른 길을 선택하며 현재 에이든의 역사 부채를 증가시킨다.
