## C11 테온 리브 — CALCULATION / ERROR RANGE

- **Silhouette:** 좁은 어깨, 짧은 상의, 양쪽 허리에 서로 크기가 다른 측정판과 필기판. 손이 늘 몸 앞에 있어 ‘계산하는 사람’이 실루엣에 남는다.
- **Face/Hair:** 기존 짧은 짙은 갈색 머리 유지. 왼손 둘째 손가락 계산화상은 얼굴보다 강한 인지점.
- **Material:** 잉크, 얇은 황동자, 관측유리, 닳은 소매.
- **Signature Prop:** 숫자가 빽빽한 완성표보다 **오차범위가 비워진 투명 계산판**.
- **Gesture:** 손가락으로 수치를 짚다가 모르는 값에서 멈추는 습관.
- **Movement:** 현장에서는 발보다 눈이 먼저 따라가고 보폭이 불규칙하다.
- **Variant:** `TOWER-CLEAN → FIELD-INKED → PUBLIC-AUDIT`, 후반일수록 깨끗한 표보다 수정흔적이 증가.
- **Thumbnail:** 잉크소매 + 화상 손가락 + 투명 오차판.
- **Merch:** 투명 아크릴판에 오차 범위를 겹쳐 인쇄하면 캐릭터성이 살아난다.
- **No-Overlap:** 리아의 출처기록과 달리 ‘숫자/오차’가 중심.

## C12 엘사 네르 — DISTRIBUTED RECORD

- **Silhouette:** 햇볕에 탄 현장기록관. 소매가 짧고 팔목의 문서끈이 반복 원형을 만든다.
- **Face/Hair:** 오래된 화상흉터와 야외생활 흔적. 귀족형 기록관 금지.
- **Material:** 거친 종이, 문서끈, 나무보관함, 불에 그을린 천.
- **Signature Prop:** 하나의 귀한 원본책보다 **서로 다른 주민이 보관하는 작은 기록묶음**.
- **Gesture:** 이름을 들으면 즉시 반복 확인하고 끈의 위치를 바꾼다.
- **Variant:** `LOCAL-ARCHIVIST → SEARCH/PURGE-WORN → SHARED-CUSTODY`.
- **Thumbnail:** 팔목 문서끈 + 화상흉터 + 작은 분산기록 묶음.
- **No-Overlap:** 하렌의 무거운 원본상자와 반대. ‘분산’이 핵심.

## C13 도르칸 카르바 — WORKSHOP OWNERSHIP

- **Silhouette:** 두꺼운 작업앞치마보다 **비대칭 도구걸이 + 호흡보호층 + 넓은 손**이 먼저 읽힌다. 체형을 ‘작은 대장장이’로 고정하지 않는다.
- **Face/Hair:** 기존 돌가루 밴 회색 수염, 오른 어깨 공방문신 유지.
- **Material:** 가죽 손잡이, 검은 철, 광분진 천, 오래 교체한 버클.
- **Signature Prop:** 귀한 무기보다 자신이 아끼는 오래된 가죽도구.
- **Gesture:** 물건을 받으면 무게보다 접합부부터 본다.
- **Variant:** `WORKSHOP-OWNER → FOUNDING-COBUILDER → DISMANTLER`.
- **Thumbnail:** 공방문신 + 가죽도구 + 비대칭 도구걸이.
- **No-Overlap:** 오르바드는 조정도면, 도르칸은 물질·접합.

## C14 사하드 렌 — ROUTE / NON-OWNERSHIP

- **Silhouette:** 기존 바랜 청색 천, 발목 경로매듭, 손등 길표식 유지. 몸에서 가장 선명한 선이 위가 아니라 **발목과 손등**에 있다.
- **Material:** 바람먹은 천, 뼈가 아닌 식물섬유 매듭, 가죽 물주머니.
- **Signature Prop:** 지도 대신 경로매듭. 신수 장식품을 전리품처럼 달지 않는다.
- **Gesture:** 방향을 손가락으로 가리키기보다 바람을 확인한 뒤 걸음 방향을 틀어 보여준다.
- **Variant:** 매듭색이 아니라 **매듭 수와 끊어진 구간**으로 길의 상실을 표현.
- **Thumbnail:** 발목매듭 + 층겹옷 + 빈 등(무기·깃발 없음).
- **No-Overlap:** 유목민 클리셰 깃털·동물머리 장식 금지.

## C15 베사르 움 — DEATH WITHOUT RESURRECTION

- **Silhouette:** 기존 검은 장례천과 작은 빈 보석틀, 손가락 판결끈을 유지. 머리보다 **손과 목의 빈 공간**이 인지점.
- **Material:** 빛을 먹는 천, 무광 금속, 불완전 결정, 얇은 판결끈.
- **Signature Prop:** 비어 있는 보석틀. 완성된 보석이 아니라 ‘비어 있음’이 아이콘.
- **Gesture:** 판결 전 손가락 끈 하나를 풀고 다시 묶는다.
- **Variant:** `FUNERAL-JUDGE → WAR-WITNESS → P1-LIMITED-EVIDENCE`.
- **Thumbnail:** 빈 목걸이틀 + 서로 다른 손가락끈 + 무광 장례천.
- **No-Overlap:** 사신·언데드·해골장식 금지.

## C16 마리엔 레바 — CONTRACT / EXTERNAL WITNESS

- **Silhouette:** 소금에 바랜 짧은 코트 + 몸 옆의 방수 가죽문서함 + 왼귀 항해거리 고리.
- **Material:** 소금먹은 가죽, 방수천, 얇은 동판, 밀랍봉인.
- **Signature Prop:** 젖어도 읽히는 외부계약 띠.
- **Gesture:** 악수 전 상대 손이 아니라 계약 당사자 표식을 본다.
- **Movement:** 배 위 균형감 때문에 육지에서도 발을 넓게 두는 습관.
- **Variant:** `COASTAL-NOTARY → BLOCKADE-ERA → INTERNATIONAL-AUDIT`.
- **Thumbnail:** 방수문서함 + 귀고리 + 소금바랜 코트.
- **No-Overlap:** 에스라의 항구 매듭·함대 대표성보다 ‘문서/공증’이 중심.

## C17 유나 벨 — MEMORY OF FAMILY

- **Silhouette:** 평범한 교사·민간인 체형을 유지하되 **옷 안쪽에만 꿰맨 사진조각 때문에 바깥에서 완전히 읽히지 않는 비대칭**.
- **Face/Hair:** 오래 말하면 갈라지는 목소리와 함께 목 주변 긴장이 인지점. 화려한 혁명가 외형 금지.
- **Material:** 일상직물, 종이사진, 보호천, 낡은 교사용 가방.
- **Signature Prop:** 펼쳐 전시하는 가족사진이 아니라 천 안쪽에 숨긴 조각.
- **Gesture:** 추상적 숫자가 나오면 손가락으로 사람 이름을 하나씩 센다.
- **Variant:** `MOURNER → PUBLIC-RESTORATION-FACE → MEMORIAL-SEPARATION`.
- **Thumbnail:** 평범한 민간복 + 안쪽 사진천이 살짝 보이는 가슴선 + 교사가방.
- **No-Overlap:** 광신 지도자 깃발·붉은 망토 금지.

## C18 카시안 로드 — TIME INDUSTRY / USEFUL DANGER

- **Silhouette:** 기존 현장용 방진코트를 회의실에서도 입는 방향 유지. **기능별 계약인장이 코트 한쪽에 세로로 정렬**되어 기업/기술성을 보여준다.
- **Material:** 방진천, 표준 인장금속, 내열유리, 교체형 문서슬롯.
- **Signature Prop:** 성과그래프가 아니라 서로 다른 색의 기능계약 인장 묶음.
- **Gesture:** 위험을 말할 때도 인장 하나를 빼서 ‘범위’를 한정한다.
- **Variant:** `F3 SUCCESS → EXPOSED-COMMON-NETWORK → LICENSE-LOST`.
- **Thumbnail:** 방진코트 + 세로 인장열 + 피로한 눈.
- **No-Overlap:** 미래 CEO 정장·고급 장식 금지.

## C19 에스라 마레사 — SEA DAMAGE / EXTERNAL PRESSURE

- **Silhouette:** 허리의 여러 항구매듭과 젖은 신발이 하체에 무게를 준다. 상체는 협상복, 하체는 실제 항해자.
- **Material:** 염분천, 밧줄, 방수도기, 녹청금속.
- **Signature Prop:** 항구매듭 허리띠. 매듭마다 도시·피해·약속이 달라 장식이 아니라 기록.
- **Gesture:** 협상 중 탁자보다 바닥에 펼친 항로를 발끝으로 짚는다.
- **Variant:** `DIPLOMAT → BLOCKADE → LIMITED-AUDIT`.
- **Thumbnail:** 매듭허리띠 + 젖은 신발 + 파도문신.
- **No-Overlap:** 마리엔의 공증문서함과 구분.

## C20 오렐 바스 — PROCEDURAL STABILITY

- **Silhouette:** 수선한 오래된 행정복, 좁은 어깨, 손에 항상 봉인서류. 화려한 관료망토 대신 **반복 수선된 같은 옷**이 신뢰/정체성을 만든다.
- **Material:** 붉은 밀랍, 오래된 양모, 얇은 황동펜, 문서판.
- **Signature Prop:** 손톱의 붉은 봉인왁스와 임기표식.
- **Gesture:** 갈등이 커질수록 옷깃을 고치지 않고 존칭과 서명칸을 더 정확히 맞춘다.
- **Variant:** `ROYAL-CLERK → TRANSITION-ADMIN → TERM-LIMITED-P1`.
- **Thumbnail:** 수선행정복 + 붉은 왁스 손 + 얇은 문서판.
- **No-Overlap:** 왕족 C21의 상징성, 리아/하렌의 기록전문성과 구분.
