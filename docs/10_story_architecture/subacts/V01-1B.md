## 이 구간이 끝날 때 바뀌는 것

| 층위 | 변화 |
|---|---|
| 인물 | 에이든: 도착 성공 → 신분 없이 관측당하는 체류 → **조건부 신분과 짧아진 시한**. 아이리스: 독자 추적자 → **조건부 협력자이자 귀환표식 차단권자** |
| 기록 | 임시 노역표 → 기사단 치료보조자 명부 등재 → 임시 통행권. 도시 안에서 그의 위치가 기록되기 시작 |
| 손실 | 표적 접촉 가능 시간 **반나절 확정 감소**, 냉각으로 귀환용 마력 일부 소모, 미래 장비 은폐 등급 하락, 본부 제거 시한 단축 |
| 제도 | 협력이 신뢰가 아니라 **상호 거부권**으로 성립 — 살아 있는 현지 앵커가 귀환표식을 거부하면 자동 강제귀환이 불가능하다 |
| 다음 원인 | E013에서 아이리스의 신원 보증으로 지방 기록소에 접근해 표적 혐의 검증을 시작한다 |

**1B에서 발생하지 않는 것**: 표적 접촉·제거 · 마나열병 정답 · 회색 종 원리 해명 · 별도 수레 목적지 확인 · 아이리스가 에이든의 정체를 간파 · 영구사망
