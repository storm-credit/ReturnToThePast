**시대**: F3. 원본: [ga04-episode-registry-e226-e300.md](../detail/ga04-episode-registry-e226-e300.md) Volume 10 머리 — `Era: O / N / F3` · `Primary Locations: 공개 시간항·외교항·농업개입지·왕실 쿠데타선`. 네 곳 중 **10A에 배정된 것은 공개 시간항 하나**이고 나머지는 10B·10D다. F3 정의는 [future-state-checkpoints-v1.md](../../01_timeline/future-state-checkpoints-v1.md): `더 풍요롭고 장치가 공개된 시간산업사회, 다국가 개입경쟁` / 위험 = `시간개입 군사·경제 무기화`.

**시간항의 운영 주체**: [institution-org-procedure-bible-v1.md](../../08_institutions/institution-org-procedure-bible-v1.md) §12.2 — `crosswalk V10 10A의 F3 공개 시간항이 이들(연대개입산업연합)이 운영하는 시설이다`. **국가 기관이 아니라 민간 사업자 연합의 시설이다.**

E226–E231 실제 동선 (원본: [v10-scene-ready-design-v1.md](../detail/v10-scene-ready-design-v1.md) 10A 카드)

공개 시간항 출입국·보험·고용·군사 창구 → 영웅 환영식장(거부) → 임무 원문·승인흐름 열람 자리 → 임무분류·인과지도 작업대 → 농업개입 성과 확인지 → 전염병·해상구조 성과 확인지 → **시간산업 연합 청문장** → 정부 압력 자리 → 여러 기관 운영교리 대조 자리 → 분류결과 공개 자리

⚠ **공개 시간항의 공간 구조가 정본에 없다.** crosswalk는 `F3 공개 시간항` 한 칸이고, 설계 카드는 `출입국·보험·고용·군사 창구`라는 기능 목록까지만 준다. 항의 규모·층 구성·시민 동선·도시명·소속 국가명을 정한 문서가 없다 `[설계 미정]`.

⚠ **E228의 농업·전염병·해상구조 성과 확인지가 어느 시대·어느 장소인지 미정.** crosswalk의 `동부 농업개입지`는 **10B** 주무대이고, [location-world-crosswalk-v1.md](../location-world-crosswalk-v1.md) 권역 색인은 `동부 곡창 — V10: 유익한 개입`만 적는다. E228이 현지로 이동하는지 시간항에서 자료로 확인하는지 정본에 없다 `[설계 미정]`.

⚠ **E229 청문장·E230 정부 압력 자리의 기관 소재지 미정.** 산업연합 청문과 `정부`는 서로 다른 주체인데(§활성 기관 참조) 두 자리가 같은 곳인지 정본에 없다 `[설계 미정]`.

⚠ **일자·계절·에이든의 주관적 누적일 미정.** F3의 연·월·일을 10A에 배정한 문서가 없다 `[설계 미정]`.

**이동 규칙**: E227 카드의 `Logistics` = **모든 임무를 직접 방문할 수 없는 시간·좌표 제한**. 10A는 열두 임무 현장을 순회하는 구간이 **아니다** — 그것이 E227의 우선순위 결정 근거다.
