## 금지

원본: 각 CP **§9 Anti-Repeat** 와 **§5 Character State** 의 금지 항목, **§6 Final hook** 의 금지 항목
(1A 표본이 인용한 `CP §11 Prohibitions`는 E001 CP의 절 번호다. E013–E018 CP는 절 구성이 달라 §11이 State Mutation Plan이다.)

구조 반복 금지

- 두 문서를 나란히 놓고 날짜를 대조하는 이미지 (E003·E013·E014 계열) 를 E015·E017·E018에서 재사용
- E015의 잠입 구조를 E016에서 재연 / E017의 단일 공간 대화를 E018에서 재연
- E001의 삭제된 글자 훅, E002의 기관 순회, E005의 `출발 인장에 다른 이름이 비친다`, E009의 진품 인장 두 장, E016의 세력 교차를 다른 회차로 이식
- 전투 승리나 회색 종 재타종으로 회차를 닫기

판정 반복 금지

- 세렌 무죄 확정 (전 회차). 영구사망은 E023–E025 소관 — [permanent-loss-lock-v1.md](../../12_losses/permanent-loss-lock-v1.md) L001
- `사실 개혁가는 완전히 결백했다` / `모든 왕실 문서가 위조였다` 단순 반전 — 동의 없는 기억채취는 실재한다
- 본부·왕실을 평면 악역화, 지방연맹을 순수 민중 편으로 미화
- 지방 문서가 왕실 문서를 이긴다는 성급한 역전 (E013), 해석이 뒤집힌 뒤 반대편으로 과잉 이동 (E015)

인물 처리 금지

- 아이리스: 에이든의 조수화·정보 제공기·양심 역할, 감동 후 전면 협력, 로맨스·삼각관계 신호, 위기의 에이든 구출
- 세렌: 모든 진실을 아는 예언자, 즉석 무죄 선언, 무죄 변론 구조의 훅, 시간여행 원리 강의
- 기록관: 만능 기록관, 압박 한 번에 자료 전부 제공, 비밀 원본을 몰래 꺼내 주기
- 에이든: 연설로 국면 전환, 갑작스러운 임무 포기, 본부 전체를 적으로 규정, 영웅적 자기희생 연출
- 환자를 이름 없는 숫자로만 제시

선취 금지

- E019의 서부 봉쇄 해제 정보 (CP E017 §6·§9)
- M05 `빈 세금장부 = 비용/희생 배분표` 해석 — 첫 단은 E036
- M10 출발 인장 원리 설명 — 첫 단은 E045
- 개인 흑막 암시 (M12) · 새 시간법칙 추가

| M03 | 리아는 왜 F0를 기억하는가 | 본편 언급 금지. E016 보조 POV의 봉인 행동으로만 존재 |

**공정성 규칙**

- 독자가 알아도 되는 것: 왕실·지방 문서가 같은 마을을 다르게 기록한다 / 보고서가 사건보다 먼저 작성됐다 / 명단은 삭제예정지 주민 목록이다 / 세렌의 불법행위 세 항목은 실재한다 / 세렌이 미래 물건을 알아볼 지식을 이미 갖고 있다
- 아직 알면 안 되는 것: 무엇이 마을을 지우는가 · 날짜층을 위조한 주체 · 세렌이 지방 소거를 늦췄다는 전체 기능 (E072) · 삭제된 증언자와 E014 서명자의 정체 · 19만 생존모델의 최종 오류구조 · 세렌의 생체인장과 서부 봉쇄의 관계 (E019 소관)
- 즉, 독자는 **행위는 유죄인데 결과의 인과가 서지 않는다**는 구조를 조립할 수 있어야 하지만, 위조 주체와 세렌의 실제 기능은 추론으로 확정할 수 없다
