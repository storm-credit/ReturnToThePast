## 갱신 조건

위 원본 중 하나라도 바뀌면 STALE이다. 원본을 먼저 고치고 여기를 맞춘다.

**이 문서가 SKELETON인 이유** — 아래 다섯 가지가 상위 정본에 채워지면 FULL로 승격한다.

1. **11D의 시대·연월일·에이든 주관적 누적일과 회차별 동선** — 고정석의 위치·개수, `마을주소 삭제`의 물리적 절차 포함 (「무대」)
2. **경쟁 미래·강제모집팀의 기관 규정** — 기관 설정집 §12에 F1–F2와 F3만 있고 11D의 적대 세력이 속한 미래가 없다. `F3 모집체계`·`주민 증언망`·`세 시대 증언보증`도 항목이 없다 (「활성 기관」)
3. **세력 → 정본 인물 배정** — 납치팀·투항요원·F0 출신처럼 보이는 요원·주민 대표에 얼굴이 없다. C02·C03의 실제 등장 여부, 가족의 11D 배정 (「등장 인물」)
4. **11D 중심 물건의 자산 등재** — 고정석·주소망·귀환석·출발인장·임시 존재증명서에 R 번호가 없다 (「활성 아이템」)
5. **`법적 출생·귀환권 붕괴`의 손실 ID 신설** — 이 구간 최대의 대가가 손실 대장에 독립 항목으로 없다 (「이 구간이 끝날 때 바뀌는 것」)
