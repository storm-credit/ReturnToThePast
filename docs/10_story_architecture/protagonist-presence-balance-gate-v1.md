## 5. Classification Rule

### A — AIDEN-CENTERED
3개 기준 중 2개 이상:
1. 국소 비가역 선택의 주체가 에이든.
2. 핵심 감정·관계·권리 비용이 에이든에게 귀속.
3. 에이든 직접행동이 없으면 Resolution 또는 Next Cause가 성립하지 않음.

### B — ENSEMBLE-CENTERED / AIDEN PRESENT
- 에이든은 등장.
- 다른 named face / community / institution이 먼저 움직임.
- 그들의 선택이 물리·법·자원·동맹 상태를 변경.
- 에이든은 기정사실을 협상·수습·거부·책임짐.

### C — AIDEN ABSENT
- 에이든은 물리적으로 등장하지 않음.
- 독립행동이 실제 상태를 변경.
- 단순 설명/보고용 side story가 아님.
- 1–3화 안에 주 플롯에 재합류하거나 결말 handoff 근거가 있음.
