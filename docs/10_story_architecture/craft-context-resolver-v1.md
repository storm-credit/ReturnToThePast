# Craft Context Resolver v1

Status: **ACTIVE PRODUCTION ROUTER — CRAFT BINDING LAYER**
Date: 2026-08-21
Scope: E001–E375
Authority: routing only. 새 문체를 창작하지 않는다. 이미 승인된 prose rule과 작가 선호를 **회차 신호에 결정적으로 연결**할 뿐이다.
Non-Scope: 사건·설정·인물·결말 생성, 새 문체 규칙 신설, 원고 작성

## 0. 왜 필요한가

`.agent/context-packs/deep/` 의 60개 Deep Master 전체에서 craft·prose·storycraft·문체·장면밀도 문서를 가리키는 소스 포인터는 **0건**이다. 22-field 계약 16번이 `scene density / craft route / anti-repeat`를 요구하지만, **어떤 문서의 어느 규칙을 가져올지 지정하는 곳이 없었다.**

`storycraft 문서를 참조` 수준으로는 문장이 나오지 않는다. 이 문서는 회차 신호 → 구체적 작법 규칙의 **결정적 경로**를 만든다.

## 1. 입력 신호 4개

회차 하나에서 아래 4개만 읽으면 Craft Route가 확정된다. 모두 `minimum-context-resolver-v1.md` §3.1 ALWAYS 번들 안에 있다.

| 신호 | 출처 | 형태 |
|---|---|---|
| **S1 밀도** | `scene-density-map-v1.md` 해당 행 | Q(2) / S(3) / E(4) / X(5~6) + 배정 사유 문장 |
| **S2 기능** | D6 Registry 해당 행 | Subact Beat · Goal · Choice & State Change · Hook |

## 2. 진단 — S2 → 중심 문제

D6 행의 `Subact Beat` + `Goal` 문구에서 아래 표로 중심 문제 **1개**를 뽑는다. `storycraft-orchestrator/SKILL.md` §1의 14개 범주를 그대로 쓴다.

| D6 문구에 나타나는 것 | 진단 범주 |
|---|---|
| 검문·잠입·보급·부상·탈출·시한 | 생존 압박 |
| 대조·검증·장부·기록 불일치·수사 | 조사·추리 |
| 도착오차·귀환창·좌표·시간선 변화 | 시간선 이상 |
| 승인·정족수·청문·법·시민권·소유권 판정 | 정치·법·행정 |
| 요구·거부권·양보·조건 교환 | 협상·거부권 |
| 포위·공성·추격·방어·개입 | 전투·추격·공성 |

**동점이면 `Subact Beat`가 이긴다.** `대항 세력` 비트는 대립자의 실제 성과를 중심에 놓는다는 뜻이고, `국소 해결` 비트는 비용 확정이 중심이라는 뜻이다.

독자 효과 1개도 §1의 12개 중에서 함께 고른다. 진단 범주와 **같은 이름을 고르지 않는다** — 효과는 독자가 무엇을 느끼는지이지 장면이 무엇을 하는지가 아니다.

## 3. Craft Route 조립

```text
CRAFT ROUTE =
  [기본층]  항상 적용
+ [밀도층]  S1이 결정
+ [POV층]   S3이 결정
+ [중심작법] §2 진단 → storycraft §8 조합표
+ [보조작법] 최대 2개
+ [장면유형 표본] prose-style-references §4
+ [Anti-Repeat] S4 GA 조항 + 앞 3화 대조
```

중심 작법 1개, 보조 최대 2개. **같은 조합 3화 연속 금지** (storycraft §공통규칙).

## 5. 밀도층 — S1이 결정

| S1 | 장면 수 | 장면 시작법 | 장면 종료법 | 이 유형의 실패 모드 |
|---|---:|---|---|---|
| **Q** | 2 | 목표를 이미 가진 채 공간 안으로 들어간다. 이동·설명 장면을 앞에 붙이지 않는다 | 한 대화 안에서 가치가 뒤집힌 지점에서 끊는다 | 두 장면을 세 장면 분량의 설명으로 늘리는 것 |
| **S** | 3 | 진입·목표 설정 → 충돌·오판 → 선택·상태변화 | 세 번째 장면의 상태변화가 훅을 낳는다 | 세 비트를 세 번의 회의로 처리 |
| **E** | 4 | S와 같되 **네 번째는 에필로그가 아니다** | 네 번째는 **비용** 또는 **반대편의 능동행동** | 네 번째를 여운·요약으로 소모 |
| **X** | 5~6 | 각 장면 첫 문단에 시간·장소·목표를 명시 | 각 장면이 **다른 권한·지역·인물의 원인**을 움직인 뒤 종료 | 빠르기만 한 몽타주 |

출처: `scene-density-and-pacing-overlay-v1` §2·§6, `scene-density-map-v1`.

**밀도지도의 배정 사유 문장이 장면 분할의 1차 근거다.** 예: E260 사유 = `모집팀 모델에 움브라·미등록난민·외국인·현지 거부권을 추가하면서 여러 지역과 세력의 셈이 동시에 바뀌고 출발인장 법칙까지 드러나는 교차 회차` → 장면 경계는 **추가되는 권리 주체 단위**로 자른다.

공통 장면 규칙 (overlay §6):
- 장소가 바뀌면 이동시간·비용·신분·보급 중 하나를 반영한다
- **회의 뒤에 또 회의를 붙이지 않는다** — 현장 검증 · 생활 후과 · 대립자 행동 중 하나
- 전투 뒤 최소 한 번은 부상·장례·배급·법적 책임을 추적한다
- 설명이 긴 회차는 감정·행동과 같은 공간에서 처리하고 **별도 강의장면을 만들지 않는다**

## 8. 장면 유형 → 문체 표본

`prose-style-references-v1` §4를 회차의 **각 장면마다** 지정한다. 회차 전체에 하나만 붙이지 않는다.

| 장면 유형 | 1순위 | 2순위 |
|---|---|---|
| 기관 회의·청문·승인 | 김훈 남한산성 | 르카레 |
| 이동·황무지·생존·탐험 | 매카시 로드 | 정유정 28 |
| 기록·소거·상실 | 오가와 요코 | 김초엽 |
| 대면·심문 (Q형) | 이시구로 | 김언수 |
| 단역·군중 화법 분화 | 이영도 | 김언수 |
| 절차·행정 처리 | 배명훈 | 김훈 |
| 회차 훅·연재 리듬 | 싱숑 | 비가 |

**규칙** (§1·§6): 번역서에서 문장 표면을 배우지 않는다 = 번역체 재생산. 문장 직접 차용은 A15 유사성 감사 대상. 배우는 것은 **기법 하나씩**이지 목소리 전체가 아니다. 내부 표본(E023 수술본 · 작가 수정 E001 · E015 물지게꾼)이 답을 주는 자리에서는 외부를 보지 않는다.

## 11. Anti-Repeat — 3층 검사

원고 시작 전 세 층을 모두 통과한다.

**층 1 — GA 조항** (`grand-acts-v1`)

| GA | Anti-Repeat |
|---|---|
| I | 첫 귀환 반전은 E025에 사용. 이후 모든 권 결말을 귀환 반전으로 끝내지 않는다 |
| II | 암살 대신 **법·도시·귀환 인프라·내전** 중심 |
| III | 탐사·건설·협상·재난 대응 중심. **보스 제거 구조 금지** |
| IV | 전투보다 **동시 임무 조율·자기 인과·권한 해체** 중심 |
| V | 최종 승리는 적 처치·유물 완성보다 **헌법·동의·희생의 실행** |

**층 2 — 병렬성 강도** (POV governance §6): GA I 낮음→중간 / GA II 중간→높음 / GA III 높음 / GA IV 최고 / GA V 높음→분산.
같은 진단·같은 밀도·같은 훅이어도 **누가 에이든 없이 무엇을 실행하는가**가 GA마다 달라야 한다.

**층 3 — 직전 3화 대조**: 앞 3화의 `진단 / 밀도 / 훅 유형 / 중심작법 / 장면 시작 방식`을 표로 적고 **하나 이상 다르게** 만든다. 같은 조합 3화 연속은 금지다.

## 12. Craft Manifest — 출력 형식

`storycraft-orchestrator` §9 필드를 그대로 쓰되, 각 값 옆에 **§ 출처**를 적는다.

```text
EPISODE / GA / VOLUME / SUBACT
S1 밀도 + 배정 사유
S2 진단 범주 + 독자 효과
S3 POV 유형 + 정보상한 (인물 Hub §4 인용)
S4 GA Anti-Repeat 조항
PRIMARY CRAFT / SECONDARY CRAFT ≤2   (§7 조합표 근거)
장면별 문체 표본                      (§8 매핑)
장면 시작법 / 종료법                  (§5 밀도표)
활성 화법 소스                        (§6 표)
HOOK 유형 H#                          (§10)
FALSE INTERPRETATION / 이 회차에서 말하지 않는 것  (Hub 공정성 규칙)
ANTI-REPEAT 3층 대조표                (§11)
WHY THIS COMBINATION
```

**이 필드가 없으면 원고를 시작하지 않는다** (storycraft §9).
**작법 이름만 적고 원고에서 구현하지 않는 행위는 금지다** (storycraft 공통규칙).

## 13. 적용 예 — E137

| 신호 | 값 | 출처 |
|---|---|---|
| S1 | **Q · 2장면 (고정)** — `장부 암호층의 건국 좌표 해독과 공개정족수 설계를 같은 자리에서 처리하는 집중형` | 밀도지도 E137 |
| S2 | Beat `6B · 국소 해결` / Goal `수도 생존과 지방 소거의 실제 수치를 확인` / Choice `공개 정족수와 대피 계획을 먼저 만든다` / Hook `장부에 건국 시대 원본 좌표가 숨겨져 있다` | ga02 registry E137 |
| S3 | **에이든 단독** — E132–E137에 보조 POV 배정 없음 | V06-6B Hub POV 배치 |
| S4 | GA II Anti-Repeat = `암살 대신 법·도시·귀환 인프라·내전 중심` | grand-acts GA II |

조립 결과:

- 진단 = **정치·법·행정** (`공개 정족수`·`대피 계획`) / 독자 효과 = **도덕적 곤란**
- 중심 = 이해관계 협상 / 보조 = 권한 절차 + 공정 단서
- 밀도 Q → 2장면. 이동·설명 장면을 앞에 붙이지 않고 **장부실 안에서 시작**. 종료는 정족수 설계가 뒤집히는 지점
- 문체 표본 = 장면1 절차·행정(배명훈/김훈) · 장면2 기관 회의·청문(김훈/르카레)
- 훅 = **H2 정보 역전**
- 정보상한 = M17 추론 가능 시점 **E344** → **6B에서 인장의 정체를 확정하지 않는다** / M12 추론 가능 시점 **E298** → 흑막 지목 금지 (V06-6B Hub 공정성 규칙)
- Anti-Repeat = GA II 조항상 이 회차의 해결은 제거가 아니라 **절차 설계**여야 한다
