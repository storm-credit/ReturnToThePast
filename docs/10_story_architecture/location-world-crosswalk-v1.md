# 375화 장소·세계관 교차표 v1

Status: D8 ENCYCLOPEDIA REVIEW  
Canon: 권별 기능·이동 인과 HARD LOCK / 세부 장소명 SOFT LOCK  
Purpose: 세계관 문서가 설정 설명으로 고립되지 않고 E001–E375 장면에 실제 사용되도록 연결

## 적용 규칙

- 한 Subact는 주무대 1–3곳과 이동비용을 가진다.
- 같은 장소가 재등장할 때 시간선·계층·정치·물리상태 중 최소 하나가 변해야 한다.
- 새 장소는 정보기능, 선택비용, 관계변화 중 하나 이상을 수행해야 한다.
- 권역 간 이동은 아틀라스 기준일을 따른다. 시간도약 직후 현지 이동을 생략하지 않는다.

## 이동·장면 감사

각 상세카드 작성 시 확인:
1. 이전 장면에서 현재 장소까지 실제 경로와 시간이 있는가?
2. 이동 중 검문·숙박·식량·부상·언어 문제가 반영되는가?
3. 시간도약이 공간이동과 동일하게 처리되지 않았는가?
4. 장소가 시대와 시간선에 따라 실제로 달라졌는가?
5. 지역 주민이 주인공을 기다리는 배경이 아니라 자기 일정을 갖는가?
