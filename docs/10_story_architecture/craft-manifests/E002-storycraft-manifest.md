# E002 Storycraft Manifest — 여섯 개의 승인

Status: D10 READY  
Owner: A20 Storycraft Director / A12 Architecture / A14 Reader Experience

## 1. Episode Function

- Volume Function: 시간여행이 능력이 아니라 분산된 책임·안전·비용 체계임을 보여 준다.
- Subact Function: 출발을 막는 첫 장벽을 구체적인 승인·검사·시간손실로 만든다.
- Local Question: 더 정확한 검증을 기다리는 선택은 신중함인가, 현재 사람을 죽이는 지연인가?
- Local Answer: 에이든은 즉시 출발을 거부하고 검증을 기다리지만, 그 선택의 실제 비용을 떠안는다.
- Next Cause: 짧아진 귀환석 수명 때문에 E003부터 공식증거와 생존수치의 설득력이 커진다.

## 2. Selected Craft Techniques

### Primary — 제한자원 선택

동시에 모두 지킬 수 없는 자원을 명확히 한다.

- 현재 구조 가능 인원
- 기록 검증 시간
- 현지 체류창
- 귀환석 수명
- 목표 범위

에이든의 선택은 ‘용기 대 비겁’이 아니라 무엇을 먼저 소모할지의 판단이다.

### Secondary A — 절차적 긴장

절차는 설명 목록이 아니라 서로 다른 실패를 막는 연속 행동으로 구현한다.

- 왕좌: 법적 책임 부재를 막음
- 성당: 몸·달력·계절 불일치를 막음
- 탑: 좌표오차를 막음
- 기록소: 잘못된 역사주소를 막음
- 귀환원: 돌아올 몸·물건·창을 등록
- 현장요원: 실제 행동과 위험을 동의

하나가 느리다는 이유로 무능한 기관으로 만들지 않는다.

### Secondary B — 시도–실패–학습

1. 에이든은 승인 절차를 빠르게 통과하려 한다.
2. 승인순서를 바꾸면 좌표오차가 커진다는 사실을 확인한다.
3. 귀환석 상태가 나빠 목표축소를 권고받는다.
4. 기록검증을 기다리는 편을 선택하고, ‘정답을 더 알면 피해가 줄어든다’는 믿음이 실제 시간비용을 만든다는 것을 배운다.

### Secondary C — 물건을 통한 미스터리 전진

귀환석 내부의 다른 시대 흙은 설명대사가 아니라 검사 과정의 물질 단서다.

- 현재 기능: 균열·오염·오차를 보여 줌
- 미스터리 기능: 이 장치나 좌표가 이전에 다른 시대와 접촉했을 가능성
- 제한: 출처·연대·주체는 확정하지 않음

## 3. Scene Architecture

### Scene 1 — 승인 회랑

- Entry Value: 서명만 모으면 출발 가능
- Opposition: 승인마다 서로 다른 실패조건과 선행순서가 있음
- Turn: 에이든이 기관 명칭 대신 실제 책임과 실패를 질문
- Exit Value: 출발은 명령이 아니라 상호의존 절차

### Scene 2 — 귀환석 검사대

- Entry Value: 귀환은 제한적이나 보장된다고 믿음
- Opposition: 균열이 깊고 목표 범위가 넓을수록 체류·귀환 가능성이 감소
- Choice Pressure: 임무 목표축소 또는 출발지연
- Exit Value: 돌아올 수 있다는 전제가 흔들림

### Scene 3 — 대기실·검증 창구

- Entry Value: 빨리 출발하면 현재 사람을 살릴 수 있음
- Opposition: 잘못된 주소로 출발하면 임무 전체가 재앙을 만들 수 있음
- Choice: 기록검증 서명을 기다림
- Cost: 방벽 숫자 감소와 체류창 축소
- Hook: 귀환석 내부에서 출발지와 다른 시대의 흙 발견

## 4. Emotional / Character Arc

- 표면 감정: 조급함 → 짜증 → 불안 → 억제된 결심
- 내적 충돌: 현장요원의 즉시행동 습관과 ‘정확한 정보가 정답을 만든다’는 믿음의 충돌
- 행동 표현: 서명을 재촉하기보다 담당자에게 실패조건을 반복 확인
- 관계 변화: 리아는 에이든의 판단을 대신하지 않고 기록검증 책임만 맡음

## 5. Information Design

독자에게 보여 줄 것:

- 분산 승인 기능
- 승인 순서가 좌표오차에 영향
- 귀환석 균열과 짧은 창
- 목표축소가 생존확률을 높인다는 권고
- 다른 시대 흙

숨길 것:

- 흙의 정확한 시대·장소
- 이전 개입자의 정체
- F0 자체가 이미 수정된 시간선이라는 최종 의미
- 기관 중 누가 향후 기록을 이용하는지

## 6. Reader Reward

- 시간여행 규칙의 구체적 제약
- 제도가 실제로 막는 실패의 종류
- 에이든이 즉시 명령을 따르지 않는 능동 선택
- 장기 미스터리의 물질 단서

## 7. Hook Design

- H1: 귀환석 물리위험
- H2: 출발지와 다른 시대의 흙

E003에서는 또 다른 장치 이상이 아니라, 공식 증거와 생존증가 수치가 에이든을 설득하는 방향으로 전환한다.

## 8. Anti-Repeat / Deliberate Non-Use

사용하지 않음:

- 새 재난현장 콜드오픈
- 리아가 몰래 모든 승인을 해결
- 담당자 중 한 명의 노골적 방해·배신
- 설명을 위한 여섯 개 독립 회의
- 귀환석 즉시 수리
- 다른 시대 흙의 즉각 정답화
- 보조 POV
