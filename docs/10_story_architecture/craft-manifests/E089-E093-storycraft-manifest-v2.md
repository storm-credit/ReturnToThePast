# Storycraft Manifest — E089–E093 v2

Status: AUTHOR REVIEW SUPPORT  
Scope: V4 Arc 08 / E089–E093

## 1. Arc Function

이 5화의 기능은 `복원이 곧 구원`이라는 직관과 `삭제가 곧 안전`이라는 반대 직관을 동시에 무너뜨리고, V4의 핵심 선택인 **불완전한 증언구역**을 실제 피해·권리·군사비용 속에서 성립시키는 것이다.

독자가 받아야 할 순서는 다음과 같다.

1. E088에서 가족관계 치환이 사람의 인식으로 번짐.
2. E089에서 주소가 약한 사람이 먼저 사라져 문제를 추상논쟁에서 생존문제로 바꿈.
3. E090에서 옛 시장의 회복이 눈앞의 기적으로 보이지만 현재 인격을 덮는 비용을 확인.
4. E091에서 군부의 재삭제안이 악의가 아니라 실제 국경 위험에서 나온 합리적 해법임을 확인.
5. E092에서 3개 선택지의 피해를 공개 비교한 뒤 불완전 공존을 선택.
6. E093에서 권리를 분리해 법적 구조를 만들고, 그 선택의 군사비용이 즉시 E094 침공으로 돌아옴.

## 2. Episode Craft

### E089 — 먼저 사라지는 움브라
- Density: Q / 2 scenes.
- Core emotion: 존재가 흐려지는 공포를 소음보다 조용한 불일치로 보여준다.
- Scene A: E088의 아이·어머니 사건 직후, 주소 기반이 약한 주민의 이름·얼굴·신체 인식이 먼저 흐려짐. 에이든 자신의 얼굴도 일부 주민에게 인식되지 않음.
- Scene B: 나하 아노르와 백지사슴 계약. 신수는 판결하지 않고 현재 관계 연속성의 보조증거만 제공. 마지막에 복원파 대표의 가족도 위험명단에 들어감.
- Hook: `복원을 원하는 쪽도 복원으로 가족을 잃을 수 있다.`

### E090 — 구원처럼 돌아온 시장
- Density: S / 3 scenes.
- Core emotion: 그리움이 눈앞에 돌아왔을 때 거부하기 어려운 유혹.
- Scene A: 옛 시장의 냄새·소리·약품·음식·돌길이 실체화되어 생존자에게 실제 구원처럼 보임.
- Scene B: 현재 명부·생활흔적 대조. 돌아온 상점과 인격이 현재 사람을 덮어쓰기 시작함.
- Scene C: 복원파 대표가 가족 소거 위험을 인정하면서도 공동체 회복을 포기하지 못함. 군부는 도시 재삭제안을 제출.
- Hook: `살리기 위해 다시 지우자.`

### E091 — 군부의 합리적인 삭제안
- Density: E / 4 scenes.
- Core emotion: 윤리적으로 싫은 선택이 실제 생존계산에서는 가장 효율적으로 보이는 압박.
- Scene A: 군부 방어지도와 방어회랑 수치.
- Scene B: 재삭제 시뮬레이션과 현재 주민 생존효과. 에이든은 실제 효용을 인정.
- Scene C: 주민 소거 권한을 군부에 주지 않기로 결정, 대체안을 요구.
- Scene D: 외부 함대가 약해진 회랑을 탐지하고 조약 위반 책임을 요구하며 접근.
- Hook: 내부 선택이 국제 문제로 확대.

### E092 — 원본 대신 증언구역
- Density: E / 4 scenes.
- Core emotion: 모두를 완벽히 구하지 못한다는 사실을 공개한 뒤에도 선택해야 하는 압박.
- Scene A: 완전복원 / 재삭제 / 불완전 공존의 피해표 공개.
- Scene B: 현재 주민·옛 후손·백지권·군부 등 영향당사자의 권리 범위를 분리하고 의사 확인.
- Scene C: 불완전 공존 선택. 감사인장·현재명부·옛 주소를 결합해 일부만 남김.
- Scene D: 과거 도시 전체가 돌아오지 않는 것을 확정하고 방어회랑이 완전히 소등되는 비용 제시.
- Hook: `도시는 살았지만 왕국의 벽 하나가 죽었다.`

### E093 — 지배권 없는 도시
- Density: S / 3 scenes.
- Core emotion: 승리가 아니라 권리의 경계를 문서로 고정하는 피곤하고 불완전한 성취.
- Scene A: 현재 거주권·옛 문화권·공동 보상권 판정.
- Scene B: 옛 귀족 세금권·재판권·강제이주권 복구 금지. 증언도시 법적 구조 확정.
- Scene C: 주민·옛 후손이 실제로 달라진 일상을 확인하는 순간 외부 침공 경보 발생.
- Hook: E094 첫 문장으로 바로 이어질 수 있는 `북서 국경 고정석 경보`.

## 3. Prose Controls

- 에이든은 판결을 독점하는 영웅이 아니라 **피해를 비교하고 결정권을 영향당사자에게 돌리는 실무자**로 쓴다.
- 설명문보다 물건·명부·도로·온도·냄새·사람의 반응으로 시간선 침식을 보여준다.
- 같은 논지를 대사와 서술로 반복하지 않는다.
- 철학 문장을 연속 배치하지 않는다. 제도 논리는 반드시 구체적 사람·물건·거리·시간 비용에 붙인다.
- `진짜/가짜`, `옳은 역사/잘못된 역사`를 단정형으로 쓰지 않는다.
- 복원파·군부·현재 주민·옛 후손 모두 자기 입장에서 실제 손실을 가진다.
- 장면 이동 때 위치·시간·행동 주체를 명확히 한다.

## 4. Continuity Locks

- E088 마지막: 아이가 실제 어머니의 냄새는 알아보지만 얼굴은 낯설게 인식.
- E089 시작은 이 현상의 확대여야 한다.
- E092에서 완전복원 포기와 증언구역 선택은 비가역.
- E093 끝에는 방어회랑 단절·침공 신호가 있어야 한다.
- E094 재작성본의 `증언도시의 첫 경보은 성벽이 아니라 북서쪽 국경 고정석에서 먼저 뜬다`는 진입과 모순 없어야 한다.
