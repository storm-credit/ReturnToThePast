# Storycraft Manifest — E038–E043

Status: DRAFT SUPPORT MANIFEST

## Spine
이번 서브액트의 반전은 `동료라서 살린다`가 아니다. 행동의 사실과 행동의 동기를 분리해 암살이라는 해결책 자체가 원인을 겨누는지 검증하는 것이다.

- E038 아는 얼굴 ≠ 자동 무죄.
- E039 기록관의 거부권 ≠ 배신.
- E040 왕실 접촉 사실 ≠ 배신 동기 확정.
- E041 피해예측이 진짜 ≠ 암살 효과 확정.
- E042 구조가 도덕적으로 좋아 보여도 귀환용량은 실제로 부족.
- E043 더 많은 거부권과 서명 = 더 느리고 실패경로가 많은 대신 독점 감소.

## Density

## Voice
에이든은 `기억 속 동료`를 이름 대신 역할로만 처리하지 않되, 정본 이름 미확정이므로 새 고유명을 만들지 않는다. 리아는 주소 검증 권한을 실제로 행사한다. 마르칸은 피해표의 실제 효용을 지킨다. 아이리스는 현지 권리 조건을 원격으로 강제한다.

## Prohibitions
- 두 번째 표적 이름 임의 생성 금지.
- 왕실 접촉기록을 전부 위조로 만들기 금지.
- 마르칸 피해예측을 선전으로 무효화 금지.
- 아벨을 증거물이라서 우선구조 금지.
- 리아의 주소 거부를 에이든이 우회·무효화 금지.
- 감시요원을 즉시 악역/흑막으로 지정 금지.
