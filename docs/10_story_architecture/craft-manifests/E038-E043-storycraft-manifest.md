# Storycraft Manifest — E038–E043

Status: AUTHOR REVIEW — AUTOMATED VALIDATION PASS

## Craft Spine
이번 서브액트의 반전은 `동료라서 살린다`가 아니다. 행동의 사실과 행동의 동기를 분리하고, 제거라는 해결책 자체가 실제 원인을 겨누는지 검증한다.

- E038: 아는 얼굴 ≠ 자동 무죄. 원자료와 후대 분석을 분리한다.
- E039: 기록관의 거부권 ≠ 편들기. 재검토해도 주소 판정이 성립하지 않으면 서명하지 않는다.
- E040: 왕실 접촉 사실 ≠ 배신 동기 확정. 같은 접촉 뒤 상반된 결과가 함께 생긴다.
- E041: 지연 피해가 진짜 ≠ 제거 효과 확정. 피해모형의 범위와 한계를 함께 기록한다.
- E042: 구조가 더 나아 보여도 무비용 선택이 아니다. 귀환용량 때문에 무엇을 포기할지 실제로 고른다.
- E043: 더 많은 거부권과 서명은 느리고 실패경로를 늘리지만 한 사람의 독점을 줄인다.

## Voice / Agency Locks
### 에이든 로엔
- 기억 속 친분을 무죄 근거로 쓰지 않는다.
- 숫자나 반대자료를 불편하다는 이유로 무효화하지 않는다.
- 행동 / 동기 / 결과를 분리한다.
- 구조안을 택해도 그 선택이 만드는 지연·용량·포기 비용을 지우지 않는다.

### 리아 세른
- 역사주소 검증은 실제 독립권한이다.
- 에이든 친분, 마르칸의 지연 피해, 본부 재검토 요구와 별개로 기준을 유지한다.
- 주소를 거부할 때는 최소 이동시간·식별강도·행정주소 생성계보 등 재현 가능한 근거를 남긴다.

### 마르칸 베르
- 실제 피해와 운영비용을 제시한다.
- 피해표를 협박용 허위자료로 만들지 않는다.
- 제거안의 효용과 한계도 같은 표에서 숨기지 않는다.

### 아이리스 네르
- 현지 대피 판단권을 실제 조건으로 행사한다.
- 환자와 주민이 본부의 기록·귀환 목적에 종속되지 않도록 조건을 건다.

## Anti-Repeat / Anti-Padding
- E038~E043에서 매 화 `기록이 틀렸다`로 끝내지 않는다. 계보, 주소, 피해모형, 용량, 승인구조라는 서로 다른 검증축을 사용한다.
- 새 조직·새 반전·날씨·감상으로 분량을 채우지 않는다.
- E038 보강은 원자료 독립성·위협평가 시한의 의미 확인.
- E039 보강은 주소 1계열씩 제외한 재검토와 주소 생성계보 확인.
- E040 보강은 왕실 접촉 뒤 운반자 탈출/환자 급습의 동시 시간축과 지휘계보 분리.
- E041 보강은 피해모형 민감도·범위 한계와 변경안의 실제 실패지점 명시.
- E042 보강은 동일 안전여유의 귀환 조합 비교와 현지 의료판정 전 인원 미확정.
- E043은 재승인 절차와 감시요원 권한한계를 실제 행동으로 완결.

## Prohibitions / Information Ceiling
- 두 번째 표적 이름 임의 생성 금지.
- 왕실 접촉기록을 전부 위조로 만들기 금지.
- 왕실 접촉을 곧바로 배신 동기로 확정 금지.
- 마르칸 피해예측을 선전으로 무효화 금지.
- 아벨 네르를 증거물이라서 개인 우선구조 대상으로 지정 금지.
- 리아의 주소 거부를 에이든이 우회·무효화 금지.
- 아이리스의 현지 대피권을 형식적 동의로 축소 금지.
- 감시요원을 즉시 악역·흑막·과거 운반자 동일인으로 확정 금지.
