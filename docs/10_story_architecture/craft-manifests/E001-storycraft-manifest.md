# E001 Storycraft Manifest — 마지막 도시의 다른 날짜

Status: D10 RETRO-AUDITED / READY  
Owner: A20 Storycraft Director / A12 Architecture / A14 Reader Experience

## 1. Episode Function

- Series Promise: 시간여행보다 먼저 ‘역사를 누가 운영하고 누가 비용을 지는가’를 체감시킨다.
- Volume Function: F0의 붕괴와 첫 임무의 필요성을 제시한다.
- Subact Function: 에이든을 구조 현장요원에서 시간 파견 후보로 이동시킨다.
- Local Question: 사람을 살릴 시간이 줄어드는 동안 불완전한 기록을 얼마나 검증해야 하는가?
- Local Answer: 브리핑 수령과 책임은 받아들이되 임무 동의와 정답 확정은 보류한다.
- Next Cause: 여섯 기관 승인과 귀환석 검사로 압박이 구체화된다.

## 2. Selected Craft Techniques

### Primary — 목표·방해·선택·비용

- 목표: 제칠 방벽 구조 또는 더 큰 생존해법 확보
- 방해: 구조승인 거부, 전체 생존계산, 기록접근 제한
- 선택: 브리핑을 수령하고 원자료 접근을 요구
- 비용: 구조 가능 인원 감소, 리아의 비인가 흔적

이 구조는 영웅이 명령을 받는 수동 도입을 막고, 첫 화부터 책임을 선택하게 한다.

### Secondary A — 정보 간극과 공정 단서

독자가 아는 것:

- 같은 사건에 세 날짜가 있다.
- 증언자 두 줄이 존재하지 않는다.
- 세렌의 범죄 일부가 소거를 늦췄다.

독자가 아직 알 수 없는 것:

- 누가 왜 기록을 바꿨는가
- 세렌의 실제 역할
- 첫 임무가 미래에 미칠 결과

정답을 감추되 추론할 자료는 제공한다.

### Secondary B — 관료제 공포의 물질화

제도는 설명되지 않고 다음 물질적 결과로 보인다.

- 승인 지연 동안 감소하는 구조인원
- 등록띠가 빛나지 않아 회색 천막으로 밀리는 환자
- 열람자·감사자·당사자 자격이 있어야 열리는 문
- 책임서명이 있어야 다음 문이 열리는 구조

관료제는 악역 장식이 아니라 생존·책임·배제의 실제 장치다.

### Secondary C — 약속·진행·회수의 미니 구조

- 약속: 첫 경보는 울리지 않고 종만 떤다.
- 진행: 기록과 날짜가 서로 어긋난다.
- 회수: 마지막에는 실제 경보가 울리고 삭제 실패 흔적이 드러난다.
- 재맥락화: 종과 경보는 단순 재난표시가 아니라 기록·주소 이상과 연결될 수 있다.

## 3. Scene Architecture

### Scene 1 — 관측실

- Value Start: 구조 가능한 재난
- Pressure: 주소·표식 자체가 사라짐
- Choice: 수동진입을 요구하지만 관측병 가족의 비용을 보고 멈춤
- Value End: 현장 해결이 제도·생활망 문제로 확대

### Scene 2 — 제삼 보고실

- Value Start: 구조대 출동 여부의 갈등
- Pressure: 구조가 다른 병원·계절·배급 사망을 늘림
- Choice: 과거 파견 해법의 정보를 요구
- Value End: 현재 구조와 과거 개입이 경쟁하는 선택으로 변화

### Scene 3 — 제이 브리핑실

- Value Start: 세렌이 공식 재앙 창시자
- Pressure: 날짜·증언자·효과가 충돌
- Choice: 브리핑 수령만 인정
- Value End: 공식 정답이 합리적 의심으로 바뀜

### Scene 4 — 기록 접근실

- Value Start: 원자료를 보면 판단 가능할 것이라는 기대
- Pressure: 접근권 순환논리와 비인가 열람 위험
- Choice: 제한선 가까이에서 잔문을 확인
- Value End: 삭제가 완전하지 않았다는 물질 단서 확보

## 4. Emotional Architecture

- 표면 감정: 긴급함 → 억눌린 분노 → 불신 → 집중
- 핵심 감정: 자기 구조대원을 포기하고 더 큰 숫자를 선택해야 할지 모르는 죄책감
- 표현법: 감정명 직접 반복 대신 굳은 손가락, 숫자 암기, 질문 방식으로 표현
- 관계 변화: 에이든과 리아가 서로를 신뢰해서가 아니라 서로 다른 검증기능이 필요해 동행

## 5. Worldbuilding Delivery

사용된 방식:

- 기능 실패: 방벽·고정망·병원·등록
- 직업행동: 관측병·구조요원·기록관·승인관
- 선택비용: 구조연료·격리구역·병원전력
- 공간동선: 관측실→복도→보고실→브리핑실→기록실

금지된 방식:

- 세계관 용어사전식 나열
- 시간여행 원리 전체 강의
- 제도 이름만 많은 회의
- 종교·마법의 장식적 언급

## 6. Hook Design

- Primary Hook: H2 정보 역전
- Secondary Hook: H4 제도 변화
- Open Questions:
  - 세 날짜 중 무엇이 잘못됐는가?
  - 빈 증언자는 누구인가?
  - `세`는 세렌인가 다른 이름인가?
  - 구조대는 살아 있는가?
  - 여섯 기관은 어떤 비용을 요구할 것인가?

E002는 같은 정보반전 훅을 반복하지 않고, 승인·귀환석의 물리적 한계로 진행한다.

## 7. Techniques Deliberately Not Used

- 악역 POV
- 미래결과 선공개
- 플래시백으로 과거관계 설명
- 예언·선택받은 자 암시
- 전투 승리로 첫 화 보상
- 세렌의 무죄 또는 유죄 확정
- 리아와의 로맨스 선행강조

## 8. Anti-Repeat Signature

E001 고유 조합:

`재난 현장 + 생존계산 + 기록 미스터리 + 접근권 공포`

다음 세 화에서 이 네 요소를 동일 순서로 반복하지 않는다.

- E002: 승인기관과 귀환석 검사
- E003: 공식 증거의 설득력과 삭제된 증언자
- E004: 현지 인적 앵커 없는 고위험 출발조건
