# Storycraft Manifest — E044–E050

Status: DRAFT SUPPORT MANIFEST

## Spine
V2 마지막 구간은 `암살에 실패해서 구조한다`가 아니라 **구조를 선택하기 위해 공식 성공을 버리는 과정**이다.

- E044 시간 오차는 정보가 아니라 장기 후폭풍을 직접 보게 만드는 비용.
- E045 좋은 의도의 과거 행동도 현지에서 간첩사건·단속 강화로 재분류될 수 있음.
- E046 배신은 진짜지만 목적과 피해분배는 공식 기록보다 복잡.
- E047 지휘분산은 효율을 낮추지만 현지인·미래요원·감시자 중 누구도 전체를 독점하지 못하게 함.
- E048 에이든이 `실패`라는 제도적 값을 자기 이름으로 받음.
- E049 구조 성공과 법적 존재 인정은 별개.
- E050 다렌의 추적은 우정 배신이 아니라 현재 시민 보호.

## Prohibitions
- 감시요원을 단순 악역화 금지.

- 두 번째 표적의 왕실 거래를 선의로 세탁 금지.
- 다렌을 세뇌·광신 추적자로 쓰기 금지.
- F1 구조 대상의 법적 부재를 사망/환상으로 처리 금지.
- 지도에서 지워진 길의 원인을 V2에서 확정 금지.
