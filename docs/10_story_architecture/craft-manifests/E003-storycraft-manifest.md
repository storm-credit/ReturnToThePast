# E003 Storycraft Manifest — 창시자의 증거

Status: D10 READY  
Owner: A20 Storycraft Director / A11 Mystery / A12 Architecture / A14 Reader Experience

## 1. Episode Function

- Volume Function: 세렌 바일 제거가 단순한 세뇌·거짓명령이 아니라 실제 증거와 생존논리를 가진 선택임을 보여 준다.
- Subact Function: 에이든의 의심을 없애지 않으면서도 출발과 임무수행 쪽으로 무게를 이동시킨다.
- Local Question: 기록이 충돌하더라도 실제 압수품·피해·생존효과가 있다면 행동해야 하는가?
- Local Answer: 현재 증거는 임무를 중단시킬 만큼 무너지지 않았지만, 삭제 증언자의 시간모순은 현지검증 필요성을 남긴다.
- Next Cause: E004에서 추가검증 지연과 현재 사망자의 직접 교환관계가 에이든의 최종 출발서명을 압박한다.

## 2. Selected Craft Techniques

### Primary — 경쟁하는 증거사다리

서로 다른 증거가 같은 결론을 단순 반복하지 않게 한다.

1. 물질 증거: 압수 도구의 실제 사용흔적
2. 피해 증거: 의식·침입·폭로 전후의 사망·실종
3. 법적 증거: 당시 절차에 따라 발부된 왕실 명령
4. 모델 증거: 세렌 제거 시 19만 생존증가 예측
5. 시간 반증: 삭제 증언자의 사망일이 범행일보다 앞섬

첫 네 증거는 제거 임무를 강화하고, 마지막 증거는 공식 설명의 일부를 무너뜨린다.

### Secondary A — 합리적 오답 강화

초기 오답:

> 세렌이 재앙을 일으키고 증언자를 제거한 뒤 기록을 지웠다.

이 오답은 다음 이유로 합리적이다.

- 금지 도구가 실제로 사용됨
- 피해자가 실제로 존재함
- 세렌이 시설침입·자료은닉을 저지름
- 제거 시 생존률이 높아진다는 모델이 있음
- 증언자 행이 물리적으로 삭제됨

그러나 사망일 시간모순으로 ‘세렌이 증언자를 제거했다’는 부분만 흔들린다. 세렌 전체 무죄로 비약하지 않는다.

### Secondary B — 숫자와 구체 피해의 윤리 압박

19만이라는 숫자를 추상적인 선전문구로 제시하지 않는다.

- 병상
- 약품
- 방벽 유지일
- 배급 인분
- 격리구역

같은 구체 입력을 통해 계산이 실제 사람과 생활망을 반영함을 보여 준다.

동시에 누락된 사람·지역·미등록 비용이 있을 가능성은 남기되 E003에서 모델을 무효화하지 않는다.

### Secondary C — 증거 후 반응

각 증거 뒤에 에이든의 판단 기준이 조금씩 바뀐다.

- 압수품: 기록 전체가 거짓이라는 기대 약화
- 피해명부: 세렌의 방법이 무해하지 않았음
- 19만 모델: 행동하지 않는 책임이 커짐
- 사망일 모순: 현지검증을 버릴 수 없음

## 3. Scene Architecture

### Scene 1 — 증거실

- Entry Value: 공식 기록이 상충하므로 혐의도 약할 수 있음
- Opposition: 실제 사용흔적과 실제 피해
- Turn: 에이든이 도구의 사용법·현장흔적을 검증하고 조작품으로 치부할 수 없음을 확인
- Exit Value: 세렌이 위험한 불법행위를 했다는 사실 강화

### Scene 2 — 피해 계산실

- Entry Value: 범죄증거와 재앙원인은 다를 수 있음
- Opposition: 세렌 제거 시 19만 생존증가 모델과 현재 붕괴
- Turn: 계산 담당자가 모델의 한계도 말하지만 방향성은 유지
- Exit Value: 추가검증을 기다리는 선택의 도덕적 비용 확대

### Scene 3 — 폐기기록 보관대

- Entry Value: 삭제 증언자는 세렌의 은폐행위 증거처럼 보임
- Opposition: 절단 흔적은 오래됐고 사망일은 범행일보다 앞섬
- Choice: 에이든은 임무를 취소하지 않되 현지 추가검증을 유지
- Exit Value: 제거 임무의 필요성과 공식서사의 불완전성이 동시에 강화

## 4. Emotional Architecture

- 표면 감정: 경계 → 불쾌한 납득 → 압박 → 불신의 재점화
- 핵심 감정: 세렌을 의심하는 것이 아니라, 죽일 충분한 이유가 생기는 것을 두려워함
- 표현 방식:
  - 피해자 이름을 끝까지 읽음
  - 계산 입력의 누락항목을 질문
  - 압수품을 직접 확인하되 파괴하지 않음
  - 사망일 모순 앞에서 안도하지 않음

세렌의 무죄 가능성을 발견해 기뻐하는 장면으로 만들지 않는다.

## 5. Dialogue Functions

### 에이든

- “이 물건이 무엇인가”보다 “누가 언제 사용했고 무엇이 바뀌었는가”를 질문
- 큰 숫자보다 입력과 제외대상을 확인
- 최종 판단은 짧게 유지

### 리아

- 증거를 부정하지 않음
- 사실 / 해석 / 검증불가를 구분
- 에이든의 결정을 대신하지 않음

### 분석 담당

- 19만을 선전 구호처럼 외치지 않음
- 계산이 살린 실제 사람과 놓친 사람을 모두 앎
- 모델의 불확실성을 말해도 제거 효과의 방향성을 철회하지 않음

## 6. Information Design

독자가 알게 되는 것:

- 세렌 관련 압수품과 피해는 완전한 날조가 아님
- 세렌은 위험하고 불법적인 방법을 사용함
- 제거 임무에는 실제 생존논리가 있음
- 삭제 증언자 사망일이 범행일보다 앞섬

독자가 아직 모르는 것:

- 세렌의 행위가 지방 소거를 늦춘 전체 구조
- 피해 중 어느 부분이 장치·왕실·세렌 각각의 책임인지
- 19만 모델의 누락비용 전체
- 증언자를 삭제한 주체

## 7. Reader Reward

- 표적이 단순 누명 피해자가 아니라는 복합성
- 제거 임무가 왜 합리적으로 선택될 수 있는지 이해
- 공식 증거를 무너뜨리지 않고 그 해석에 금을 내는 시간 단서
- E004의 ‘검증을 더 기다릴 것인가’ 선택을 더 어렵게 만드는 준비

## 8. Hook

Primary: H2 정보 역전

> 삭제된 증언자의 사망일이 세렌의 범행일보다 앞선다.

Hook meaning:

- 세렌이 범행 뒤 증언자를 죽였다는 공식 인과는 성립하지 않을 수 있음
- 증언자 기록 자체가 다른 사건·시간층에서 옮겨졌을 가능성

Hook prohibition:

- 사망일 한 줄로 세렌 무죄 확정
- 리아가 조작 주체를 알아차림
- 시간여행 법칙을 새로 추가해 설명

## 9. Anti-Repeat

- 승인문양·서명·카운트다운을 중심 이미지로 반복하지 않음
- 귀환석 토양을 다시 열어보지 않음
- E001처럼 삭제된 글자 하나가 나타나는 훅 금지
- 세 개 증거가 모두 회의 대사로 설명되는 구성 금지
- 모든 피해자가 이름 없는 숫자로만 등장하는 방식 금지
- ‘사실 모든 증거가 가짜였다’ 반전 금지
