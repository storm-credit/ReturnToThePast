# Storycraft Manifest — E032–E037

Status: DRAFT SUPPORT MANIFEST  
Scope: V2 / Subact 2B

## Craft Spine
- E032 물질은 남지만 의미는 자동으로 따라오지 않는다.
- E033 합법적 우회는 증거를 지키지만 감사흔적을 남긴다.
- E034 증거를 읽는 행위 자체가 증거를 닳게 한다.
- E035 편리한 기억일수록 증거로 쓰지 않는다.
- E036 권한 분할은 느리고 불편하지만 독점을 막는다.
- E037 분산보관은 본부뿐 아니라 에이든도 통제권을 잃게 한다.

## Density
E032 S / E033 E / E034 S / E035 Q / E036 S / E037 S.

## POV
에이든 근접 3인칭 고정. 감사 중 리아가 다른 방에서 겪는 일은 결과·진술로만 전달한다.

## Anti-Repeat
- 매 회차마다 `현재 DB에 없다` 하나로 결론내리지 않는다.
- 자료가 발견될 때마다 비밀 원본 전문을 바로 열지 않는다.
- 감사관을 숨은 조력자나 흑막으로 전환하지 않는다.
- 귀환패를 편리한 F0 복구키로 만들지 않는다.
- 증거 분산을 해킹·절도보다 법적 소유/보관권 분할로 처리한다.

## Reader Payoff
절검 제작소 → 자기 보고서 작성자 → 삭제도시 → 감사관 꿈 → 부담장부 → 분산보관이 하나의 조사사슬로 이어지고, 끝에서 다시 `사람을 제거하라`는 임무가 와 1권과 반대 선택을 준비한다.
