## 1. Episode Function

- Volume Function: 첫 시간개입의 결과를 벌이 아니라 보상의 형태로 제시하고, 그 보상 안에서 상실을 발견하게 한다.
- Subact Function: 1D의 후폭풍. 표적 제거와 귀환이라는 Subact 목표가 달성된 뒤, 그 달성이 무엇을 지웠는지 확정한다 (`subact-causal-matrix-v1.md` 1D).
- Local Question: 더 많은 사람이 살아 있는 세계에서, 사라진 사람들의 부재를 무슨 근거로 주장할 수 있는가?
- Local Answer: 근거가 없다. 그가 가진 것은 등록되지 않은 기억과 반쯤 잘린 명부뿐이며, 이 세계의 사람들은 실재한다.
- Next Cause: E026에서 그는 공적 기록을 직접 읽게 되고, 자기 공적 안에서 처음 보는 학살을 발견한다.

## 2. Selected Craft Techniques

### Primary — 보상으로 도착하는 상실

상실을 폐허·시체·경보로 제시하지 않는다. 정확히 반대로 배치한다.

1. 도착 — 절차가 매끄럽다. 아무도 그를 의심하지 않는다
2. 확인 — 없는 것은 시체가 아니라 등록이다
3. 환대 — 그의 살인이 국가적 구원으로 교육돼 있다
4. 우정 — 처음 보는 사람이 그의 가장 오랜 친구다
5. 접수 — 그가 가져온 증거는 이 체계의 분류표 안으로 들어간다
6. 외부 — 그가 없는 방에서, 어긋남이 하나도 없다는 사실이 확인된다

각 단계는 이전 단계보다 더 좋은 소식이고 더 나쁜 소식이다.

### Secondary A — 부재의 행정적 증명

죽음과 미등록을 구분한다. 이것이 이 작품의 손실 문법이다 (`permanent-loss-lock-v1.md` LR, `canon-constitution-v1.md` IMMUTABLE 5).

- 전몰기록을 뒤지는 행동은 애도의 준비다
- 그러나 전몰기록에도 없다
- 사망 기록이 없는 이유는 등록된 적이 없기 때문이다
- 애도할 대상이 서류상 존재하지 않으면 애도 자체가 절차적으로 불가능해진다

이 장면에서 에이든은 울지 않는다. 그는 검색 조건을 바꾼다.

### Secondary B — 호의의 무게

다렌 모트는 에이든을 시험하지 않는다. 그는 그냥 반갑다.

- 안부 대신 오늘의 생활 숫자를 먼저 댄다 — 아이 나이, 배급표 장수, 다음 근무 시각
- 옛일은 한 문장으로 끊고 곧바로 현재 약속으로 갈아탄다
- 가족사진은 증거로 내미는 것이 아니라 그냥 지갑에서 나온다

이 다정함이 회차에서 가장 무거운 압력이다. 그를 부정하지 않고는 F0를 주장할 수 없다 (`voice-relationship-state-bible-v1.md` §2-A C07, §3).

### Secondary C — 외부 시점 종결

권말을 주인공의 독백으로 닫지 않는다. 마지막 장면은 그가 없는 방에서 리아 세른의 시점으로 진행된다.

- 기능: 첫 귀환 뒤 F1 변화의 외부 후과를 독립적으로 증명
- 상한: 리아도 F0 전체를 모른다. 원인·주체를 판정하지 않는다
- 리아는 ‘기억한다’와 ‘증명할 수 있다’를 분리해 기록한다
- 전환은 1회. 시간·장소·인물 표식을 분명히 한다 (`secondary-pov` §2 P2)

## 3. Scene Architecture

X형 6장면. 설계 원본(`v01-scene-ready-design-v1.md` E025)의 3비트를 여섯 장면으로 펼쳤다 `[DEC-021]`. 앞 다섯 장면은 에이든, 마지막 한 장면은 리아다.

### Scene 1 — F1 귀환실 (에이든)

- Entry Value: 돌아왔으니 보고하면 된다
- Opposition: 절차·계급·문장이 다르고 그를 맞는 인물이 다르다
- Turn: F0 동료의 이름을 호명했는데 아무도 그 이름을 모른다
- Exit Value: 세계가 아니라 자기 기억이 틀렸을 가능성부터 계산하는 상태

### Scene 2 — 근무·전몰 명부 단말 (에이든)

- Entry Value: 명부를 보면 오해가 풀린다
- Opposition: 전몰기록에도 이름이 없다
- Turn: 사망을 찾다가 부재를 찾는다. 미등록은 검색으로 반박되지 않는다
- Exit Value: L002 관계 소실 확정. 애도 대상이 서류상 존재하지 않는다

### Scene 3 — 영접·공식 서사 (에이든)

- Entry Value: 사정을 설명하면 된다
- Opposition: 그들은 그를 이미 안다. 그의 살인은 국가적 구원으로 교육돼 있다
- Turn: 서사가 그가 한 일보다 크고, 그가 하지 않은 뒷일까지 붙어 있다
- Exit Value: 정정하려면 죽인 사람의 이름을 다시 꺼내야 한다는 것을 안다

### Scene 4 — 거주구 통로 (에이든)

- Entry Value: 아는 얼굴이 하나도 없다
- Opposition: 다렌 모트가 평생의 전우처럼 다가온다
- Turn: 가족사진이 이 현재의 실재를 증명한다
- Exit Value / Hook: 잃은 것을 주장하려면 이 사람의 현재를 부정해야 하는 구조가 성립

### Scene 5 — 반입품 접수·격리 보관실 (에이든)

- Entry Value: 가져온 물건이 그의 판단을 증명한다
- Opposition: F1 절차가 절검과 소거명부를 다른 분류로 접수하고, 그가 대는 F0 기관명 일부는 존재하지 않는다
- Turn: 그는 반입품을 지키려고 영웅 신분을 처음 사용한다
- Exit Value: 영웅 대우를 거부하지 않기로 한다. 그것이 남은 유일한 접근권이다

### Scene 6 — 기록관 대조실 (리아 세른 · 보조 POV)

- Entry Value: 귀환 등록 대조는 통상 업무다
- Opposition: F0 쪽 항목이 오류로 뜨지 않고 조용히 정합처리돼 있다
- Turn: 리아는 상태만 기록하고 원인·주체를 판정하지 않는다
- Exit Value / Final Image: 회색 종이 없는 본부에서 격리 보관실의 귀환석만 혼자 운다. 그는 그 이유를 모른다

## 4. Emotional Architecture

- 표면 감정: 안도 → 혼란 → 정중한 사양 → 압도 → 계산 → (리아) 직업적 침착
- 핵심 감정: 슬픔이 아니라 **자격 상실**. 그는 자기가 잃은 것을 애도할 법적·기록적 자격이 없다
- 표현 방식:
  - 이름을 부른 뒤 상대의 반응을 두 번 확인한다
  - 명부 검색 조건을 바꾸는 손동작이 감정을 대신한다
  - 환대에 짧게 답하고 화제를 절차로 되돌린다
  - 다렌 앞에서만 문장이 길어졌다가 곧 끊긴다
  - 리아 장면에서는 감정어를 쓰지 않고 확실성 등급만 적는다

에이든이 F1을 가짜라고 부르는 순간을 만들지 않는다. 그 판단은 V4–V6에서야 정리된다 (`voice-relationship-state-bible-v1.md` §4).

## 5. Dialogue Functions

### 에이든

- 이름을 묻는 대신 소속과 절차를 묻는다
- 자기 기억을 주장하지 않고 확인 요청 형태로 말한다
- 환대에 대한 답은 짧게 유지한다
- 금지: 폭로 선언, 시간선 변경의 원리 설명, ‘너희는 진짜가 아니다’

### 다렌 모트

- 오늘의 생활 숫자로 인사한다
- 과거형 문장은 한 번에 끊고 현재 약속으로 갈아탄다
- 기관명은 처음부터 축약형으로 부르고 풀어 설명하지 않는다
- 금지: 원망조 회상, 교단 구호, 유언조, 가족을 협상 카드로 사용

### 리아 세른

- 확정·미확정·검증불가를 구분해 적는다
- ‘기억한다’와 ‘증명할 수 있다’를 같은 문장에 넣지 않는다
- 금지: 예언자 말투, 정답 선취, 독자에게만 진실을 알려주는 내면 서술

### F1 영접 기능선

- 호의가 진심이고 절차가 합리적이다
- 새 핵심 인물을 즉석 확정하지 않는다
- 금지: 감시자 암시로 장면을 채우기

## 6. Information Design

독자가 알게 되는 것:

- 시간선이 실제로 바뀌었고 F1이 현재 현실이다
- F0 동료들은 죽은 것이 아니라 기록상 존재한 적이 없다
- 공식 서사가 에이든의 실제 행위보다 크다
- 이 미래에는 회색 종이 없다
- 리아 역시 어긋남을 관측하지만 원인을 모른다

독자가 아직 모르는 것:

- 세렌의 행위가 지방 소거를 늦추고 있었다는 전체 기능
- 기록을 뒤집은 주체와 이유
- 삭제된 증언자의 정체
- 19만 모델의 최종 오류구조
- F0와 F1의 차이를 만든 인과 전체
- 리아의 기억 보존 원리와 범위
- 재앙 발생일 변화(E029), 공적 속 학살의 구체 목록(E026), 다렌의 F0 소속(E030)

## 7. Reader Reward

- 첫 권의 약속이었던 ‘성공한 임무의 대가’를 설명이 아니라 명부·호칭·가족사진으로 체감
- 상실이 빈자리가 아니라 채워진 자리로 나타나는 역전
- 시간여행물의 관습적 귀환 반전을 감정 폭발 없이 행정적으로 처리하는 절제
- 주인공이 보지 못하는 장면으로 권을 닫아 다음 권의 관측자를 세우는 구조

## 8. Hook

Primary: H2 정보 역전 / Secondary: H4 제도변화

> 낯선 친구가 그를 평생의 전우라 부른다.

Final Image:

> 회색 종이 없는 미래 본부에서 에이든의 귀환석만 혼자 운다.

Hook meaning:

- 잃은 것을 알아보려면 새로 생긴 것을 부정해야 한다
- 종이 없는 곳에서 우는 귀환석은, 이 미래가 감지되지 않는 불일치를 안고 있다는 첫 물질 신호다

Hook prohibition:

- 다렌을 수상한 인물·감시자로 연출
- 에이든이 그를 F0의 적으로 지목
- 가족을 감정 인질로 사용
- 귀환석 울림을 대사로 해설하거나 새 시간법칙으로 설명
- E001의 ‘사라진 글자가 되살아남’ 형태로 되돌아가기
- 권말 요약 독백·연대기 나열

## 9. Anti-Repeat

- E001의 삭제 글자 훅 반복 금지. 여기서는 흔적 없이 정합된 상태가 공포의 형태다
- E002의 여섯 기관 순회·귀환석 검사 반복 금지. 기관 접촉은 반입품 접수 한 번뿐이다
- E003의 두 문서 대조 구성 금지. 리아 장면은 ‘어긋남이 없다’를 확인하는 역방향으로만 쓴다
- E024의 목록 작성·등록 선택 반복 금지. 여기서 반입품은 선택이 아니라 분류 통보다
- E023의 도시 전체 타종 반복 금지. 종이 없는 곳에서 귀환석 하나가 우는 축소·역전으로 쓴다
- 낯선 미래를 폐허·디스토피아 몽타주로 소개하지 않는다
- 다렌을 세뇌된 친구·광신자로 연출하지 않는다
- 즉시 폭로·항의·탈주 전개 금지 — E026–E031 담당
- 기억상실·꿈·환각·정신오염 처리 금지 — 정신오염 검사는 E031 훅
- 리아와 에이든의 기억 대조 장면 금지 — E028
- 보조 POV를 사망예고·정답 설명으로 사용 금지
- ‘모든 것이 가짜였다’ 반전 금지

## 10. Payoff Links

- 미등록된 F0 동료 → `LOCK` L002, V2 전체의 신분·증언 문제
- 공식 영웅 서사 → E026 공적 속 학살, E031 기록소 접근권 획득
- 다렌 모트 → `LOCK` L002-a, E030 문장 확인, V3 공개 대립, V6 민간망 동맹
- 절검·소거명부의 F1 접수 → V2 물증 교차검사, V3 유족 반환 요구
- 회색 종의 부재와 귀환석의 울림 → M16 사다리 E058·E092, M04 귀환패 오해
- 리아의 미판정 기록 → E028 P1 회차의 출발점, M03 사다리
- ‘원래 세계’라는 감각 → M14 E027 이후의 F0 비원본성
