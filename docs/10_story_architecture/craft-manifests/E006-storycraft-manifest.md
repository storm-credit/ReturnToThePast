# E006 Storycraft Manifest — 빗나간 도착

Status: D10 READY  
Owner: A20 Storycraft Director / A11 Mystery / A12 Architecture / A14 Reader Experience

## 1. Episode Function

- Volume Function: 시간도약을 능력의 개방이 아니라 앞선 다섯 화에서 지불한 값의 청구서로 제시한다.
- Subact Function: 1A를 닫는다. 출발표에 서명한 사람이 실제로 출발하고, 서명 당시 수용한 위험 목록이 항목 그대로 실현된다.
- Local Question: 최소 정족수로 출발한다는 것은 실제로 무엇을 감수하는 일인가?
- Local Answer: 도약은 성공하고 나머지는 전부 어긋난다. 좌표·장비·신분이 동시에 무너지지만 그중 어느 것도 사고가 아니다.
- Next Cause: E007에서 신분 없는 외지인의 취약성과 회색 종·귀환석 공명이 현지 추적을 부른다.

## 2. Selected Craft Techniques

### Primary — 절차의 순차 붕괴

E002에서 하나씩 통과한 여섯 항목이 E006에서 하나씩 되돌아온다.

| 승인 항목 | E006에서 되돌아오는 형태 |
|---|---|
| 법적 승인 | 긴급 최소정족수 — 책임은 있으나 여유가 없음 |
| 동기화 | 몸이 지불하는 통과 비용 |
| 좌표 | 오차 확대와 18km 이탈 |
| 역사주소 | 도약은 되지만 정확한 도착은 보장하지 않음 |
| 귀환·등록 | 잠긴 장비와 등록 밖 물품 |
| 현장요원 동의 | 신분문서 불일치를 혼자 감당 |

여섯 개의 부분 보증이 하나의 안전을 만들지 못한다는 것이 이 회차의 구조적 논지다.

### Secondary A — 등록되는 것과 등록되지 않는 것

이 화의 소지품 검사는 장비 나열이 아니라 **가능한 행동의 목록 작성**이다.

- 등록된 것: 귀환 가능, 사용 가능
- 등록되지 않은 것: 두고 가거나, 반입해도 잠기거나, 귀환할 수 없음
- 신고하지 않은 것: 리아의 경고 한 장

에이든이 무엇을 두고 가는지가 곧 그가 현지에서 무엇을 못 하는지다.

### Secondary B — 몸으로 지불하는 통과

설계 지시는 감각 묘사가 아니라 기능적 서술이다.

- 좌표 붕괴는 시야 묘사가 아니라 계기와 판정으로
- 몸의 부담은 형용사가 아니라 이후 행동 제약으로
- 끊긴 통신은 극적 침묵이 아니라 정보 손실 항목으로

### Secondary C — 소리로 넘기는 훅

앞선 다섯 화의 훅은 전부 문서·좌표·기록 위에서 일어났다. E006의 훅만 물리적 소리다.

- 종은 멀리 있고 접촉하지 않는다
- 반응하는 것은 에이든이 아니라 그의 귀환석이다
- 원리·정체·목격자를 이 화에서 확정하지 않는다

## 3. Scene Architecture

밀도표 확정값은 **X · 5~6장면**이며 고정이다. 본 매니페스트는 **6장면**으로 설계한다. 설계문서의 세 비트는 기능 비트이며 장면 수가 아니다 `[DEC-021]`.

### Scene 1 — 동기화실

- Entry Value: 정족수가 성립했으니 출발은 관리된 절차다
- Opposition: 각 담당이 자기 항목만 보증하고 서로의 오차는 책임지지 않음
- Turn: 에이든이 오차 합산을 묻지만 합산 책임자가 없음을 확인
- Exit Value: 승인의 합이 안전의 합이 아님

### Scene 2 — 출발대 등록구역

- Entry Value: 필요한 것을 챙기면 버틸 수 있다
- Opposition: 등록 규칙이 소지품을 세 부류로 가름
- Choice: 등록되지 않은 개인 물품을 두고 가고, 장갑 안쪽 경고는 신고하지 않음
- Exit Value: 소지품 목록이 현지 행동 가능 범위로 확정

### Scene 3 — 통과 개시

- Entry Value: 통과는 짧고 몸은 견딘다
- Opposition: 좌표 붕괴와 동기화 비용
- Turn: 리아의 마지막 전달이 중간에 끊김
- Exit Value: 출발 시점에 알던 정보가 마지막까지 오지 못함

### Scene 4 — 오차 구간

- Entry Value: 목표 근처로 나오면 된다
- Opposition: 오차가 상한을 향해 벌어지고 장비 일부가 잠김
- Choice: 강제복귀 1회를 오착 수정에 쓰지 않기로 함
- Exit Value: 귀환 자산을 지키는 대신 착지 조건을 포기

### Scene 5 — 서부 격리촌 외곽 진흙 수로

- Entry Value: 도착하면 임무 시계가 시작된다
- Opposition: 예정 도시 내부가 아닌 18km 밖, 잠긴 장비, 현지 법과 맞지 않는 신분문서
- Exit Value: 문제가 승인에서 생존과 신분으로 바뀜

### Scene 6 — 수로 위 들판

- Entry Value: 남은 것은 이동과 시간 계산뿐이다
- Opposition: 멀리서 종이 울림
- Exit Value: 귀환석이 같은 박자로 진동. 이 세계가 그의 도착을 이미 감지하고 있을 가능성

## 4. Emotional Architecture

- 표면 감정: 절차적 집중 → 통과의 부담 → 판정의 냉정함 → 착지 후의 정지 → 경계
- 핵심 감정: 두려움이 아니라 확인. 그는 놀라지 않는다. 자기가 서명한 항목이 그대로 나타나는 것을 본다
- 표현 방식:
  - 오차가 벌어질 때 감탄 대신 수치를 셈
  - 잠긴 장비를 확인하고 대체 수단을 먼저 계산
  - 신분문서를 버리지 않고 접어 넣음
  - 종소리에 몸이 아니라 귀환석을 먼저 봄

도약 자체를 경이·황홀로 처리하지 않는다. 이 세계에서 시간도약은 신비가 아니라 행정이다.

## 5. Dialogue Functions

### 에이든

- 각 담당에게 자기 항목의 실패조건만 짧게 확인
- 통과 중에는 말이 거의 없고 수치와 판정만 남음
- 착지 후 첫 말은 상황 요약이 아니라 시간 확인

### 리아

- 마지막 전달은 완결된 문장이 아니어야 한다. 끊긴 상태로 남는다
- 감정 표현 대신 정보 우선순위를 지킨다
- 배웅 장면을 이별 장면으로 만들지 않는다

### 여섯 담당

- 각자 자기 항목만 말하고 다음 사람에게 넘김
- 누구도 전체를 보증하지 않으며, 그 사실을 숨기지도 않음
- 배신·방해·경고 예언 금지

## 6. Information Design

독자가 알게 되는 것:

- 최소 정족수 출발이 실제로 무엇을 포기한 것인지
- 도약은 성공하지만 좌표·장비·신분이 동시에 어긋난다는 것
- 이 실패들이 E004의 선택에서 직접 나왔다는 것
- 회색 종과 귀환석이 같은 박자로 반응한다는 것

독자가 아직 모르는 것:

- 종이 무엇을 감지하는가 (추론 가능 시점 E092)
- 종의 반응을 누가 보고 있는가
- 세렌의 전체 기능, 조작 주체, 삭제된 증언자의 정체
- 19만 모델의 최종 오류
- 인장에 비친 다른 이름의 정체

## 7. Reader Reward

- 다섯 화 동안 쌓은 조건이 그대로 결과가 되는 인과의 정확성
- 시간여행을 처음 보여 주면서도 능력이 아니라 비용으로 보여 주는 전환
- Subact 1A의 닫힘과 1B의 문제 제시가 한 장면 안에서 교대되는 감각
- 장기 미스터리(M16)의 물리적 첫 접촉

## 8. Hook

Primary: H1 물리·좌표 위험 / Secondary: H2 정보 역전

> 멀리서 울린 회색 종이 에이든의 귀환석과 같은 박자로 진동한다.

Hook meaning:

- 미래의 장치와 과거의 물건이 같은 것에 반응한다
- 에이든의 도착은 아무도 모르는 사건이 아닐 수 있다

Hook prohibition:

- 종의 원리·기능 설명
- 종을 유물·열쇠·무기로 격상
- 아이리스를 이 화에서 등장시켜 즉시 회수
- 오착을 장치 고장이나 적의 방해로 설명 (overlay §8)

## 9. Anti-Repeat

- E001의 삭제된 글자, E005의 인장 이름과 다른 층의 훅을 쓴다 — 문서가 아니라 소리와 진동이다
- E002의 여섯 기관 순회 설명을 반복하지 않음. 담당자는 자기 항목만 확인하고 지나간다
- E002의 귀환석 검사대 장면을 재연하지 않음
- E003의 증거 대조, E004의 명단 낭독, E005의 목표 협상 구성을 반복하지 않음
- 도약 감각을 형용사로 나열하는 방식 금지
- 도착 직후 현지인·아이리스와 조우 금지 — E007–E008의 기능이다
- 강제복귀로 위기를 즉시 해소하는 전개 금지
- 마지막에 각오를 다지는 독백 금지
