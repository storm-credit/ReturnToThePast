# Storycraft Manifest — E089–E094

Status: DRAFT SUPPORT MANIFEST

## Spine
이 구간은 다수결로 과거 피해와 현재 생존을 한 번에 정리하지 않는다. 무엇을 돌려줄 수 있고 무엇을 돌려주면 현재 누가 사라지는지를 권리별로 나눈 뒤, 완전한 영토·지배권 복원을 비가역적으로 포기하고 증언도시라는 비영토 공동체를 만든다.

## Craft Rules
- 단일 주민투표를 만능 정당성으로 쓰지 않는다.
- 현재 존재 소거위험 당사자의 강한 거부권과 옛 도시 부분권리 보호 거부권을 서로 다른 대상으로 둔다.
- 부분권리 반환은 상징이 아니라 예산·조합·장례·계약·보상으로 실제 작동해야 한다.
- L004는 `도시 피해 부정`이 아니라 `현재 사람을 지우는 통째 복원 포기`다.
- 토지 보상은 현재 선의취득자에게 과거 시간손실을 전액 전가하지 않는다.
- 증언도시는 옛 시정부·영토국가·혈통정부가 아니다.

## Permanent Loss
옛 도시의 완전한 영토·지배권과 과거 공동생활의 연속성은 복구되지 않는다. 이후 에피소드에서 숨겨진 완전판·다른 시간도약으로 되돌리지 않는다.
