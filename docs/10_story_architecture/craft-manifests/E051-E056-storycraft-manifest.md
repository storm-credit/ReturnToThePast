# Storycraft Manifest — E051–E056

Status: DRAFT SUPPORT MANIFEST

## Spine
V3 초반은 `사라진 기록의 진짜 원본 발견`이 아니다. 서로 다른 존재가 서로 다른 방식으로 보존한 잔흔을 따라가며 중앙기록이 놓친 인과를 좁힌다.

## Density

## Anti-Repeat
- 지도에 없다는 이유만으로 마법적 삭제를 바로 확정하지 않는다.
- 민병을 무지한 폭도로 단순화하지 않는다.
- 아이 기억과 신수 기억을 인간 문서보다 상위 진실로 만들지 않는다.
- 미래 추적자와 즉시 화해하지 않는다.
- 장부 손실 뒤 비밀 완전판을 편리하게 발견하지 않는다. 축약판도 분산 판독과 누락을 가진다.
- 에르나 피부무늬를 장식·문자 하나로 단순화하지 않는다.

## Reader Ladder
지워진 길의 물질모순 → 지역 피해의 합리적 방어 → 아이 기억/절검 물질 겹침 → 미래 이름의 과거 존재 → 원본 손실과 축약 분산판 → 에르나 기록층으로 확장.
