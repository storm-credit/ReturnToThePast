# E101–E106 Storycraft Manifest — 사망자의 구조신호

Status: AUTHOR REVIEW SUPPORT  
Source: main V5 scene-ready design / GA02 registry / scene-density map

## Function

V5 첫 Subact는 `죽은 사람이 신호를 보냈다`는 괴담을 만드는 구간이 아니다. **누가 죽었다고 판정했고, 왜 문을 닫았으며, 그 문을 다시 여는 비용을 누가 지불하는가**를 구조 문제로 바꾸는 구간이다.

## Density

- E101 E · 4장면 — 신호 분석 / 사망기록 대조 / 현장 잔향 / 복수 코드 확장.
- E102 S · 3장면 — 요새 접근 / 소수대 편성 / 다른 연도의 감시실.
- E103 Q · 2장면 — 함정 판정과 장례잔영 검증의 집중 심문.
- E104 Q · 2장면 — 중앙 수호대 효용 논리와 공개 요구의 대면.
- E105 S · 3장면 — 선택표 / 귀환패 시험 / 주소고정 소모.
- E106 S · 3장면 — 얇은 연결 / 고립자 확인 / 장비한계.

## Craft rules

### 1. 사망과 사망처리 분리
- E101부터 `사망자`를 사실로 단정하지 않는다.
- 사망처리는 생존가능기간·귀환불가·정책 분류의 행정 판정일 수 있다.
- E103에서 직접 확인되는 것은 `귀환실까지 생존 도착 + 수용거부`이며 정확한 사망시점 전체가 아니다.

### 2. 중앙 정책의 합리성 유지
- R-17 계열 자동 거부정책은 실제 망 과부하를 막고 다른 의료·계절귀환 사용자를 보호한 기능이 있다.
- 동시에 현지 협력자·포로·미등록자를 후순위로 밀고 재구조가 충분히 이뤄지지 않는 피해가 있다.
- 악당 한 명을 찾는 구조로 만들지 않는다.

### 3. 등록되지 않은 존재
- 정규코드가 없다는 이유만으로 신호를 잡음으로 확정하지 않는다.
- 반대로 모든 잡음을 사람으로 확정하지 않는다.
- 코드 수와 생존자 수는 끝까지 분리한다.

### 4. F0 귀환패의 비용
- F0 복원 만능키가 아니다.
- 현재 존재하는 귀환망을 가리키는 기능을 우선 확인한다.
- 주소고정 선택으로 F0 잔류서명을 실제 영구비용으로 소모한다.
- 적 추적차단을 포기한 위험은 V5 후반까지 살아 있어야 한다.

### 5. 구조 전에 구조자도 검증
- E106에서 일반 장비가 시간풍화를 견디지 못함을 물질시험으로 보인다.
- 영웅적 돌입으로 해결하지 않는다.
- 경계갑의 권리문제가 구조를 지연시키는 것이 아니라, 장비를 쓸 권한 자체가 구조의 일부다.

## Character

### 에이든 로엔
- 먼저 기준과 실패조건을 묻는다.
- E103 이후에도 중앙을 적으로 확정하지 않는다.
- E105에서 F0 물질증거 일부를 스스로 소모하는 선택의 책임을 회피하지 않는다.
- 구조대상에 포로가 섞여 있어도 `구조 후 법적 처분`으로 분리한다.

### 아이리스 네르
- 현지 협력자·미등록자·포로까지 ‘현재 살아 있는 사람’의 관점에서 묻는다.
- 중앙 효용자료가 확인되면 그 사실을 인정하되 우선순위 구조를 계속 공격한다.
- 에이든의 도덕적 대변인이 아니라 독립 구조·현지권리 주체다.

### 중앙 수호대
- 정보 은폐와 망 보존 기능이 동시에 존재한다.
- 정책 담당자를 조롱·협박하는 악역 말투로 쓰지 않는다.
- `한 사람 때문에 전체를 잃을 수 없다`는 논리를 실제 데이터로 지지한다.

### 네바르 기록관 / 카르둔 안내자
- 새 핵심 이름 임의 확정 금지.
- 네바르 기록관은 사망·잔영 검증의 전문성만 담당.
- 카르둔 안내자는 시간왜곡·재료·경계갑 권리의 현지 전문성을 담당.

## Anti-repeat

- V1 세렌의 `유죄/원인 분리`를 그대로 반복하지 않는다. V5는 `정책 효용/버려진 사람`의 충돌이다.
- 문서가 틀렸다는 단일반전 금지. 중앙 사망기록은 절차적으로 일관되며 전제가 불완전하다.
- E102 시간겹침을 환각·꿈으로 처리하지 않는다.
- E103 수용거부를 개인 악의로 돌리지 않는다.
- E104에서 효용사례 확인 뒤 정책을 즉시 폐기하지 않는다.
- E105 F0 잔류서명 소실을 후회 독백으로 소비하지 않는다.
- E106에서 완전구조를 미리 실행하지 않는다.
