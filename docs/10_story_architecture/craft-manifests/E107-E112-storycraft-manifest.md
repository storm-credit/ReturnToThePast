# E107–E112 Storycraft Manifest — 이름을 먹는 갑옷

Status: AUTHOR REVIEW SUPPORT  
Source: main V5 scene-ready design / GA02 registry / scene-density map

## Function

이 Subact의 핵심은 `좋은 장비를 얻는다`가 아니다. 구조를 가능하게 하는 유산이 **과거의 강제징발·지워진 공동묘지·착용자의 공적이름 소모**를 품고 있어, 구조 자체가 또 다른 권리침해가 되지 않도록 사용권을 설계하는 과정이다.

## Density

- E107 S · 3장면 — 공방 확인 / 사용권 청구 / 기록부식 시연.
- E108 Q · 2장면 — 왕실 구매증 vs 카르둔 장례·문화권 / 권리분리 계약.
- E109 E · 4장면 — 반대파 / 강제징발 흔적 / 공동묘지 원재료 / 고립자 연루 훅.
- E110 E · 4장면 — 중앙군 회수명령 / 비살상 공동방어 / 조기 구조창 / 반겹침 비용.
- E111 S · 3장면 — 최종 계약 / 자발동의 / 착용과 이름소실.
- E112 X · 5~6장면 — 시간폭풍 진입 / 고립자 접촉 / 다중 시간층 / 책임대상 / 귀환거부 인장 확장.

## Craft rules

### 경계갑을 전리품으로 만들지 않는다
- 전투력 향상 장비가 아니다.
- 시간을 견디는 대가로 착용자의 공적 주소와 장비 자체가 닳는다.
- 왕실 구매의 정당성과 카르둔 장례권을 동시에 성립시킨다.

### 권리를 기능별로 분리한다
- 소유권이 곧 사용권·분해권·거부권이 아니다.
- 이번 구조는 사용권 계약으로만 해결하고 소유권 분쟁은 후속 심사로 남긴다.
- 반환·분해·재사용 거부조건을 실제 계약문으로 남긴다.

### 카르둔 반대를 이기심으로 쓰지 않는다
- 강제착용자 결정화 사망.
- 소거된 공동묘지 경계석이 핵심재.
- 과거 왕실의 정당한 보상 사례와 강제 사례가 모두 존재.
- 구조 찬성·반대가 공방 내부에서도 갈리게 한다.

### 중앙군도 단순 압수 악역이 아니다
- 구조창 종료와 실제 생존자 때문에 장비 확보를 서두른다.
- 사람을 죽이는 공격보다 출입권·인장·회수명령을 먼저 사용한다.
- 현장장교는 충돌 중 타격금지와 짧은 유예를 스스로 선택할 수 있다.

### 에이든의 비용은 실제 사회적 손실이어야 한다
- 경계갑 착용으로 공적문서에서 이름이 실제 소실된다.
- ‘마음속 기억이 남으니 괜찮다’로 처리하지 않는다.
- 후대 재증언은 새 기록이지 원래 기록의 복원이 아니다.

## Character

### 에이든 로엔
- 법적 소유만으로 강제징발하지 않는다.
- 구조창의 촉박함을 이유로 타인의 동의권을 삭제하지 않는다.
- 최종적으로 자기 공적주소 소모는 본인 동의로 감수한다.
- 구조대상 중 과거 가해 연루자가 있어도 구조와 책임판정을 분리한다.

### 아이리스 네르
- 장비보다 현재 사람과 실제 대피·의료를 우선한다.
- 카르둔 권리문제에서 무조건 공방 편이 아니라 장기 구조가능성을 본다.
- E111 이후 바깥에서 귀환문을 닫을 권한을 가진 독립 주체로 남는다.

### 카르둔 공동체
- 하나의 목소리가 아니다.
- 장인·유족·공동장례회가 서로 다른 권리와 판단을 가진다.
- 장비사용 동의가 왕실 충성이나 에이든 신뢰로 환원되지 않는다.

## Mystery ceiling

- 경계갑 안쪽의 다른 등록형식 `에이든 로엔`은 이름 동일만 확인.
- E112 미래 날짜 거부표식은 관측사실만 확인.
- 왜 갑옷이 공적주소를 연료로 쓰는지 최종 원리 확정 금지.
- 최종 귀환거부 체계의 책임자를 개인 하나로 확정 금지.

## Anti-repeat

- V4 유산 사용 논쟁을 반복하지 않는다. V4는 도시주소 vs 공격, V5는 장례문화권 vs 구조사용권이다.
- E108에서 법정 승패로 끝내지 않는다. 권리를 나눠서 일시 사용계약을 만든다.
- E109의 과거 피해가 현재 구조를 자동 금지하지 않는다.
- E110을 액션 전투로 키우지 않는다. 제도·인장·통로 차단이 핵심이다.
- E111의 이름소실을 감상적 기억상실로 만들지 않는다.
- E112에서 고립자 전원을 즉시 구출하지 않는다. 구조와 정책증거 확보가 다음 Subact로 이어져야 한다.
