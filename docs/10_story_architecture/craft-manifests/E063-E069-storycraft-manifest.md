# Storycraft Manifest — E063–E069

Status: DRAFT SUPPORT MANIFEST

## Spine
진실 공개 자체를 결말로 쓰지 않는다. 공개 방식이 현재 시민의 생존기능과 직접 충돌하고, 같은 사실이 복원파와 생존선별파 양쪽의 권한집중 명분으로 사용되는 과정을 보여 준다.

## Rules
- E063: 귀환 후 격리구역에서 시작한다. 기록망 운영자의 비밀 거래와 좌표 요구를 회차 훅으로 잠근다.
- E064: 배급·병원·귀환망의 실제 생존비용을 확인하고 단계공개안을 설계한다. 복원파 장부 탈취는 아직 발생시키지 않는다.
- E065: 마르칸의 실제 배급효용과 은폐 책임을 동시에 둔다. 빈 장부 사본 탈취는 이 회차에서 발생한다.
- E066: 복원파 선전의 사실 부분을 지우지 않는다. 원본·반대증언·불확실성·현재 피해를 함께 묶고 다렌의 차단 명령과 직접 접근으로 끝낸다.
- E067: 다렌은 에이든 편으로 전향하지 않는다. 가족 실명·사생활을 선전재료로 쓰지 않고, 차단을 `몇 분` 늦춘 뒤 임무를 계속한다.
- E068: 살인 오류·세렌의 불법행위·본부 효용과 은폐·복원 비용을 동시에 공개한다. 복원파와 생존선별파의 동시 봉기를 각각 능동행동으로 보여 준다.
- E069: 정치적 해결이나 공통자원 차단을 완료하지 않는다. 기록소·배급소·귀환실 포위, 민간망·환자구역 우선, 강제좌표 주입, 생활 고정망 에너지 유출, 환자 이름 변화까지 진행한다.

## Anti-Padding
- 새 조직·새 인물·새 흑막·임의의 정확한 피해수치로 분량을 채우지 않는다.
- 같은 자료 설명을 장면마다 반복하지 않는다.
- 각 장면은 공개권한·배급기능·시간장치·시민 존재권 중 최소 1개의 상태를 실제로 변화시킨다.
- E형 4번째 장면과 X형 각 장면은 독립된 기관 또는 반대편의 능동행동을 담당한다.
