# 보조 POV·주인공 부재 행동 배치표 v1

Status: D10 CANON-OPERATIONS OVERLAY  
Owner: A08 Character / A12 Architecture / A13 Continuity / A14 Reader Experience / A20 Storycraft  
Applies To: E001–E375  
Rule: 기존 사건·결말·정보공개 시점을 바꾸지 않고 시점 기능만 고정

## 1. 목적

기본 시점은 에이든 근접 3인칭이다. 그러나 세계와 인물이 에이든이 보는 순간에만 움직이면 다음 문제가 생긴다.

- 조연이 주인공의 도구로 보임
- F1·지역사회·기관의 실제 효용과 피해가 설명으로만 전달됨
- 동시다발 시간개입의 규모가 체감되지 않음
- 에이든의 오해를 독자가 공정하게 검토할 근거가 부족함

따라서 보조 POV는 주인공 비중을 분산하기 위한 장식이 아니라 **독립 인과 증명장치**로 사용한다.

## 2. 허용 유형

### P1 — 단일 보조 POV 회차
- 한 화 전체를 한 명의 보조 POV로 유지
- 에이든이 등장하지 않거나 후반에만 도착 가능
- 그 인물이 에이든 없이 선택하고 비용을 지불해야 함

### P2 — X형 다중 POV 회차
- 2–3개 POV를 명시적으로 분리
- 같은 사건의 동시 진행 또는 후과를 연결
- 전환마다 시간·장소·인물 표식을 분명히 함

### P3 — 제한 관찰자 삽입
- 800–1,500자 정도의 짧은 장면
- 생활 후과·전문 실무·피해 당사자의 독립 결정을 보여 줌
- 미스터리 정답·숨은 계획·에이든이 모를 최종진실을 공개하지 않음

## 3. 기본 제한

- P1 보조 POV 전체 회차는 시리즈의 약 8–12% 범위
- 한 권에 P1은 원칙적으로 2화, 최대 3화
- 연속 2화 이상 같은 보조 POV 금지
- 에이든이 없는 회차 뒤에는 1–3화 안에 결과가 주 플롯과 재합류
- 보조 POV 인물의 내면이 해당 인물 Bible·정보상한을 넘지 않음
- 악역 POV로 정답을 먼저 설명하지 않음
- 죽을 인물의 POV를 유언·사망예고 장치로만 사용하지 않음

## 7. 주인공 부재 행동 장부

보조 POV가 없는 동안에도 주요 인물은 다음 상태를 유지한다.

- 리아: 기록 검증·공개범위·봉인 여부를 독립 결정
- 아이리스: 주민 대피·지역 거부·생활망 우선순위를 독립 결정
- 마르칸: F1 배급·군사·시민대피를 실제 성과와 함께 운영
- 오르바드: Era O 당대 생존압박 아래 기술·감사 절충
- 젊은 에이든: 현재 에이든과 무관하게 가족·마을·직업을 선택
- C10–C29: 각 dossier의 `주인공 부재 중 행동`을 Episode CP에 반영

각 권 CP에는 최소 다섯 명의 `Offscreen Action → Consequence → Re-entry`를 기록한다.

## 8. Episode CP 필수 필드

보조 POV 사용 시 다음을 추가한다.

- POV 유형 P1/P2/P3
- 에이든 부재 이유
- 해당 POV만 보여 줄 수 있는 독립 선택
- 알고 있는 것 / 오해하는 것 / 알 수 없는 것
- 장면 시작·종료 가치변화
- 에이든 플롯과 재합류 회차
- 정답누설·사망예고·악역화 금지
- POV 종료 뒤 상태장부 변경

## 9. Red Team

- 주인공을 숨기기 위한 억지 cliffhanger인가?
- 보조 POV가 에이든보다 더 많은 정답을 편리하게 알고 있는가?
- 조연의 선택이 주인공에게 보고하기 위한 것뿐인가?
- 적대자 POV가 자기 계획을 독백으로 설명하는가?
- 같은 인물 POV가 동일 기능으로 반복되는가?
- 재합류 때 보조 POV에서 벌어진 일이 무효화되는가?
- 이름 없는 여행자의 정체를 과도하게 암시하는가?

하나라도 S1이면 해당 POV 배치를 수정한다.
