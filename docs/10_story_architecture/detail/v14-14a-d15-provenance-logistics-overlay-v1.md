## 3. No Same-Day Three-Archive Tour

E326's `same conditions` means **same audit protocol**, not same room.

Protocol:
1. each custodian freezes access state at an agreed timestamp/window;
2. original is sealed in place by local custodian + independent witness;
3. certified high-fidelity copy / permitted material sample / provenance ledger is created;
4. shared comparison workspace receives comparable evidence packages;
5. any destructive material test is performed only on approved sample or at the original custody site.

Therefore Aiden/Ria do not teleport or ride across three states in one scene.
