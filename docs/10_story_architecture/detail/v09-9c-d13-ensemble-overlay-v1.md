## 1. Core Conflict

9C는 `에이든 vs 왕족 악당`이 아니다.

동시에 존재하는 4개 계산:

- 레오르 세르바: 단독승인이 실제로 더 빠름.
- 오르바드 카르센: 중앙조정 기능이 오늘 겨울을 넘기는 데 필요.
- 협약/종족대표: 분산승인이 자기 공동체를 중앙비용에서 보호.
- 미래추격자: 누가 이기든 공개된 기술을 F3 확산에 이용.

## 3. E214 — 빠른 통합의 실제 이익

레오르는 혈통특권을 `신성한 권리`로만 주장하지 않는다.

보여줘야 할 실제 효과:
- 승인 대기시간 단축
- 피난수레 통과
- 공사자재 배정
- 계절 전환 전에 완공 가능성

이탈한 종족대표가 중앙편에 서는 이유도 자기 주민 생존이다.

Aiden은 이들을 배신자로 규정하지 않는다.
