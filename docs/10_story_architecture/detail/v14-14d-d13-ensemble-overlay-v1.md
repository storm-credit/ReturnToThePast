The engine has no ethics or self-will.

Structural danger:
- if priority fields change while the rest of the network remains connected, old technical routes can execute a new burden ordering without fresh consent from all parties.

This is not lawful 7-authority approval.
It is a dangerous legacy continuity behavior of a centralized system.
