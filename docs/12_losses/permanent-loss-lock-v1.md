# Permanent Loss Lock v1

Status: ACTIVE LEDGER  
Owner: Loss / Continuity  
Last Reviewed: 2026-08-07  
Canon Level: HARD LOCK

## Principles

1. 시간선 변경은 손실을 없애는 대신 다른 사람과 제도에 이전할 수 있다.
2. 다른 시간대의 동일인은 죽은 사람의 대체품이 아니다.
3. 기억이 남아도 관계·권리·공동 경험이 자동 복원되지 않는다.
4. 원래 미래 복원은 새 미래의 생존자를 소거할 수 있다.
5. 모든 대형 개입은 최소 하나의 영구 결과를 남긴다.

## Loss Categories

- Death
- Injury / Aging
- Relationship discontinuity
- Legal identity loss
- Erased birthplace or lineage
- Institution destruction
- Territory/history deletion
- Knowledge corruption
- Return-path loss
- Moral debt to erased futures

## Initial Locks

### L-001 — F0 동료 관계 소실
- Caused By: I-001
- State: LOCKED
- Meaning: F1에서 F0의 지휘관과 동료가 존재하지 않거나 에이든을 모름.
- Recovery Prohibition: 단순히 I-001 이전으로 돌아가 관계만 복구할 수 없음.
- Tradeoff: F0 복원은 F1의 새 생존자들을 소거할 가능성.

### L-002 — 제거된 개혁가의 죽음
- Caused By: I-001
- State: LOCKED
- Meaning: 다른 시대 버전이나 복제품은 원본을 되살리지 못함.
- Plot Use: 에이든의 첫 명령 불복종 동기와 본부 불신의 근거.
