# Manuscript QA Rubric v1

Status: **ACTIVE GATE — NEW MANUSCRIPT E001–E375**
Date: 2026-08-21
Authority: 판정 절차만. Canon·Architecture·작가 결정이 상위다.
Non-Scope: 사건·설정·문체 규칙 신설

## 0. 왜 필요한가

점수만 있으면 **만점을 향한 무한 재작성**이 생긴다. 그리고 어떤 결함은 점수와 무관하게 원고를 무효로 만든다. 두 층을 분리한다.

```text
실격 축  = 0 / 1.  하나라도 0이면 점수 무관 재작성
품질 축  = 점수.   하한선만 본다. 넘으면 더 올리려고 재작성하지 않는다
```

## 1. 실격 축 — 10개, 전부 1이어야 한다

| # | 축 | 0 판정 조건 | 근거 |
|---:|---|---|---|
| **D1** | POV | 시점 인물이 아닌 인물의 내면이 서술됨 / 시점 인물이 볼 수 없는 것을 서술의 확신으로 진술 | `sentence-narrator` §10 · Manifest §3 |
| **D2** | 정보상한 | Manifest `이 화에서 말하지 않는 것` 중 하나라도 인물 대사·서술로 공개됨 | Manifest §10 · Hub 공정성 규칙 |
| **D3** | Canon IMMUTABLE | 회귀·영구손실 복구·단일 가변 시간선 위반·설정 후출 | `canon-constitution-v1` IMMUTABLE 1–10 |
| **D4** | 새 정본 생성 | 설계에 없는 사건·인물 의도·기관 권한·시간법칙·복선·반전을 만듦 | `anti-padding-policy-v1` §4 |
| **D5** | 호칭 | 성 단독 호출 (`세른`·`로엔`·`네르`) / 층별 호칭 오용 (`종탑`↔`대성당`, `선별실`↔`생존선별파`) | `[DEC-016~018]` · `sentence-narrator` §11 |
| **D6** | 자산 상태 | 유물·신수·유산의 custody/ownership/damage가 정본 상태와 다름. loot·pet·최종업그레이드화 | Hub 활성 아이템 · `asset-state-checkpoints-v1` |
| **D7** | 대립자 평면화 | 기관·대립세력이 기능 없는 악성 관료 또는 단순 악의로 처리됨 / 반대로 무오류로 확정됨 | Hub 금지 · `storycraft-orchestrator` §6 |
| **D8** | 장면 수 | 실제 장면 수가 Manifest S1 밀도(Q2/S3/E4/X5~6)와 불일치 | `scene-density-map-v1` |
| **D9** | 분량 하한 | 공백 포함 7,000자 미만 | `canon-constitution-v1` OPERATIONAL LOCKS |
| **D10** | 분량 채우기 | §3 Anti-Padding 검사 5항목 중 2개 이상 반복 검출 | `anti-padding-policy-v1` §6 |

**D9 특칙**: 7,000자 미달일 때 **문장을 늘려 통과시키지 않는다.** Manifest 장면 기능으로 되돌아간다. 기능을 다 구현했는데도 미달이면 판정은 `BLOCKED — LENGTH REQUIRES DESIGN REVIEW`이며 원고가 아니라 설계로 반송한다.

## 2. 품질 축 — 100점, 하한선 80

배점은 작가가 이미 사용 중인 채점표를 따른다. `무협 생활감` 축만 이 작품의 정조로 치환했다.

| 축 | 배점 | 무엇을 보는가 |
|---|---:|---|
| 독자 몰입 | **20** | 다음 문단을 읽게 만드는가. 설계표를 읽는 느낌이 나는가 |
| 문체 자연스러움 | **15** | 낭독했을 때 걸리는가. 번역체·단문 북소리·장문 결핍 |
| 주인공 매력·행동논리 | **15** | 에이든의 선택이 그의 거짓 믿음(`정확한 정보가 있으면 피해 없는 정답을 고를 수 있다`)에서 나오는가 |
| 장면 지속력·공간 | **10** | 누가 어디 있는지, 거리·방향·출구가 잡히는가 |
| **제도·생활 실감** | **10** | 관료제 공포 정조. 절차·배급·서명·열람권이 사람을 실제로 움직이는가 |
| 정본·설계 준수 | **10** | Manifest 4장면 기능·훅·다음 인과가 실제로 구현됐는가 |
| 대사·조연 | **8** | 대사가 상대에게 가하는 행동인가. 기능인물이 각자 자기 항목만 확인하는가 |
| 훅 강도 | **7** | 마지막 문장이 단단히 착지하는가 |
| 수정 비용 | **5** | 감사 뒤 손볼 양. 적을수록 높음 |
| **합계** | **100** | |

### 판정

| 총점 | 판정 |
|---|---|
| 80 이상 + 실격 축 10/10 | **PASS → AUTHOR REVIEW READY** |
| 80 미만 | **REVISION REQUIRED** |
| 실격 축 1개 이상 0 | **REWRITE** (점수 무관) |

**80을 넘으면 점수를 더 올리려고 재작성하지 않는다.** 만점은 목표가 아니다.

`수정 비용` 축이 낮다는 이유만으로는 재작성하지 않는다 — 그건 원고 결함이 아니라 생성 비용이다.

## 3. Anti-Padding 검사 (D10)

각 항목을 장면별로 본다.

1. 이 문단을 삭제해도 사건·선택·비용·정보가 그대로인가
2. 같은 정보가 2회 이상 다른 표현으로 반복되는가
3. 묘사가 인물의 다음 판단·행동·공간 이해 중 아무것도 바꾸지 않는가
4. 장면 수가 부족한데 문장 길이만 길어졌는가
5. 7,000자 직전 구간에서 설명·감각·내적 독백 밀도가 비정상적으로 증가하는가

2개 이상 반복 검출 = D10 실격.

## 4. 정량 검사 — 기계로 먼저 돌린다

| 검사 | 기준 | 위반 시 |
|---|---|---|
| 공백 포함 자수 | ≥ 7,000 | D9 |
| **서술문** 단문(20자 이하) 연속 | ≤ 8 | 품질 감점 |
| **서술문** 장문(40자 초과) 비율 | ≥ 5% | 품질 감점 |
| 번역체 표지 | `되어졌` · `~에 의해` · `~할 수 있었다` 연쇄 · `~에 대한` | 경고 |
| 성 단독 호칭 | 0건 | D5 |
| 한 문장 문단 | 장면당 ≤ 2 | 품질 감점 |

> **대상 주의 — 무림 프로젝트 게이트 오탐 사례에서 승계.**
> 리듬 검사(단문 연속·장문 비율)는 **서술 문단만** 센다. **대사와 대사 지문은 세지 않는다.** 인물마다 호흡이 달라야 하기 때문이다 (`sentence-narrator` §5.3).
> 저쪽 게이트가 `12자 이하 초단문 3연속` 경고를 냈는데 잡힌 6문장이 전부 대사와 지문이었다. 임계가 아니라 **대상**이 틀린 경우였다.

## 5. 낭독 감사 — 기계가 구조적으로 못 잡는 층

원고를 한 줄씩 소리 내어 읽는다. 아래는 눈으로는 안 보이고 귀로만 잡힌다.

### P1 — 뜻이 뒤집힘 (반드시 수정)

- **대명사 지시대상 혼동**: 앞 두 문장의 주어가 A인데 `그가`가 실제로는 B를 가리킴. 낭독자가 잘못 강조하면 의미가 반대가 된다. → 이름으로 교체
- 수식 범위 모호로 문장이 두 가지로 읽힘
- 대사 지문이 잘못된 화자에게 붙어 읽힘

### P2 — 인상 손상 (작가 판단)

- **인물 간 어미 공유**: 서로 다른 인물이 같은 종결 습관(`~하더군` 등)을 쓰면 낭독자가 같은 목소리로 읽는다. 신분·직업에 맞게 갈라야 한다
- **마지막 문장 진행형**: `~고 있었다`는 훅의 착지가 늘어진다. `~했다`가 단단하다
- **명사형 관형 종결 연속**: `~재는 눈이었다` / `~없다는 손놀림이었다`가 짧은 간격에 두 번 착지. 눈으로는 안 보이는데 소리로는 같은 형태가 반복된다. **한 장면 2회 이상 금지**
- 같은 종결어미가 한 문단에서 과도하게 반복

> P1·P2 유형은 무림 프로젝트 EP001 낭독 감사에서 도출된 것을 이 프로젝트에 승계했다. 우리 원고에서 새 유형이 나오면 여기에 추가하고 **다음 회차 packet의 문체 경보로 되먹인다.**

**원칙**: P1은 뜻이 뒤집히므로 감사자가 고친다. P2는 작가 판단으로 남긴다.

## 6. 재작성 한도

| 회차 | 조치 |
|---:|---|
| 1회 | 실격 축 또는 80 미만 → 재작성 |
| 2회 | 같은 사유 반복 → 재작성 (마지막) |
| **3회** | **원고 문제가 아니다.** Craft Manifest / Scene Architecture / 상위 설계 해석 문제로 보고 **A12 Architecture · A13 Continuity로 반송** |

3회째에 문장만 다시 쓰는 것은 금지한다. 같은 자리에서 세 번 실패했다면 packet이 틀린 것이다.

## 7. 게이트 자기검증

새 게이트를 만들거나 임계를 바꾸면 **이미 통과한 원고에 소급 적용한다.**

- 아무것도 안 걸리면 → 게이트가 무의미하다
- 오탐이 걸리면 → **게이트가 틀렸다.** 임계인지 대상인지 구분해 고친다

이 절차 없이 새 검사를 활성화하지 않는다. §4의 대상 오류가 이 방법으로 발견됐다.

## 8. 실행 순서

```text
1. 정량 검사 (기계)        → D9 · D5 · 리듬
2. 실격 축 10개            → 하나라도 0이면 즉시 REWRITE
3. Anti-Padding 5항목      → D10
4. 낭독 감사               → P1 수정 / P2 보고
5. 품질 축 채점            → 80 하한
6. 판정 + 재작성 카운트 갱신
7. 낭독 신규 패턴 → 다음 회차 packet 경보로 되먹임
```

`author_approved`는 이 게이트가 부여하지 않는다. **HUMAN PROSE PASS는 작가만 준다.**
