# 1. Core 10 — 각 대상 공통

각 항목 `PASS / REVISE / FAIL`.

1. 이름을 가려도 식별 가능한가?
2. 다른 유명 판타지 IP의 대상이 바로 연상되지 않는가?
3. D16 Primary Silhouette가 실제 이미지에서 작동하는가?
4. 재질이 직업/역사/생태와 연결되는가?
5. 장식이 기능 없이 추가되지 않았는가?
6. 정본에 없는 설정/능력/소유권을 암시하지 않는가?
7. 64px thumbnail에서 읽히는가?
8. grayscale에서도 구분되는가?
9. 소장하고 싶은 시각적 Hook이 1개 이상 있는가?
10. 그 Hook이 작품의 반-가챠/반-독점 철학을 해치지 않는가?

5종 × 10 = **50/50 PASS**가 Pilot Core Gate.

# 9. Verdict Rules

- `PASS`: 구조·정본·충돌 모두 통과
- `REVISE`: 핵심 방향은 맞으나 1–2축 수정 필요
- `FAIL`: generic/clone/canon mutation/reference leak

FAIL이면 프롬프트에 장식을 더 넣지 않는다. 원인을 `shape / body / function / material / composition` 중에서 찾아 수정한다.
