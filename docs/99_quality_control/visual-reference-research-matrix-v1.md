# 0. Reference Policy

이 문서는 특정 작품의 캐릭터·배경·복식·무기 디자인을 복제하기 위한 문서가 아니다.

참조 가능한 것은 **설계 방법**뿐이다.

1. 얼굴과 체형을 어떻게 구별하는가
2. 실루엣만으로 역할을 어떻게 읽히게 하는가
3. 직업·지역·계층·문화가 복식에 어떻게 남는가
4. 같은 세력 안에서 공통문법과 개인차를 어떻게 동시에 유지하는가
5. 소품과 장비에 사용흔적·소유권·역사가 어떻게 시각화되는가
6. 생물과 환경을 어떻게 하나의 생태계처럼 연결하는가
7. 한 장소를 한 컷으로 기억하게 하는 랜드마크는 어떻게 만드는가
8. 캐릭터의 상태변화를 색 바꾸기가 아니라 물질·마모·권한의 변화로 어떻게 표현하는가
9. 대규모 앙상블에서 캐릭터를 어떻게 빠르게 식별시키는가
10. 팬이 최애·소장품을 고르게 하되 서사보다 상품성이 앞서지 않게 하는가

## 절대 금지

- 유명 캐릭터의 얼굴형·헤어·의상패턴·무기형태 1:1 복제
- 특정 작품의 화풍 자체를 재현
- 유명 배우 얼굴을 베이스 모델로 고정
- `A 캐릭터 + B 캐릭터 섞어줘` 방식의 합성 프롬프트
- 모든 남성을 좁은 턱의 미남형 또는 사각턱 전사형으로 수렴
- 모든 여성을 작은 코·큰 눈·V턱·긴 머리로 수렴
- 색상만 바꿔 인물·세력·시대를 구별
- 신수의 포켓몬화·펫화
- 유산을 공격력 등급표로 시각화

# 1. Primary Reference Library

## REF-A — 《던전밥 / Delicious in Dungeon》 + Ryoko Kui `Daydream Hour`

### 조사 근거
Yen Press는 `Daydream Hour`를 본편 제작 과정에서 나온 수백 페이지의 스케치·컬러 일러스트 모음으로 소개하고, `Adventurer's Bible`은 인물의 연령·체격 등 세부 캐릭터 정보를 별도 세계가이드로 정리한다.

### 참조할 설계 원리
- 같은 작가의 선 안에서도 얼굴·키·체격·연령이 분명히 다름
- 복장을 제거해도 체형과 얼굴비례로 인물을 구분 가능
- 직업과 생활습관이 몸의 형태·장비 배치에 반영
- 비주얼을 ‘모두 미형’으로 맞추지 않음

### 프로젝트 적용
- C01–C30 `Face DNA / Body DNA / Gesture DNA` 의무화
- 헤어·색상을 제거한 흑백 얼굴 테스트 실시
- 중년·노년·환자·노동자·관료·군인의 생활흔적을 얼굴과 손에 반영

### 가져오지 않을 것
- 원작 캐릭터 얼굴·종족 외형·복식
- 코믹 비율이나 작화체

## REF-B — 《Arcane》 / Fortiche

### 조사 근거
Netflix Tudum의 제작진 인터뷰에서 시즌 2 디자인 하나가 최대 20회 이상 반복 수정될 수 있고, Piltover와 Zaun은 도시별 디자인 언어를 분리한 뒤 시즌 진행에 따라 더 세분화했다고 설명한다. 캐릭터·공간·마법에도 동일한 shape language를 연결한다.

### 참조할 설계 원리
- 얼굴의 비대칭·흉터·코·턱·눈두덩·나이 차이를 적극 사용
- 캐릭터마다 걷기·서기·손동작이 다름
- 캐릭터와 출신도시가 재질·패턴에서 연결됨
- 변형형이 기존 인물의 흔적을 유지하면서도 상태변화를 보여줌
- 한 디자인을 여러 iteration으로 검증

### 프로젝트 적용
- 모든 핵심인물 `Imperfection Signature` 최소 1개
- 캐릭터별 `Default Pose / Stress Pose` 분리
- 지역 재질이 해당 지역 인물의 옷·소품에도 들어가야 함
- 첫 이미지 생성 후 그대로 확정 금지. 최소 4안 비교 후 채택

### 가져오지 않을 것
- Arcane 회화적 2D/3D 스타일
- 특정 챔피언 헤어·문신·색상·무기
- Piltover/Zaun 색상 대응표

## REF-C — 《마녀의 모자 아틀리에 / Witch Hat Atelier》

### 조사 근거
Kodansha는 Kamome Shirahama의 제작 과정·라이브 드로잉·영감 공개를 지속적으로 다루며, 작품 자체는 마법과 도구를 의복·문양·공예의 언어와 강하게 연결하는 대표 사례다.

### 참조할 설계 원리
- 로브 하나로 마법사를 정의하지 않고 재단선·도구·착용방식으로 직업을 구분
- 마법기술과 시각문양이 같은 원리에서 파생
- ‘입고 싶은 복식’과 ‘작동하는 복식’을 함께 만족

### 프로젝트 적용
- 마법사/기록관/관료 모두 후드·로브 클리셰 금지
- 기관마다 장식문양보다 실제 사용도구에서 문법을 도출
- 리아·하렌·테온의 직업차를 소매·가방·판·상자 사용법으로 구분

### 가져오지 않을 것
- 모자·망토·마법진의 구체적 디자인
- Shirahama의 선화·페이지 레이아웃 화풍

## REF-D — 《Andor》

### 조사 근거
StarWars.com의 Michael Wilkinson 인터뷰는 Ferrix 주민들을 단순히 같은 옷의 색만 바꾸지 않고, `무슨 일을 하는가 / 옷을 어디서 얻는가 / 무엇을 중요하게 여기는가`로 각 인물을 설계했다고 설명한다. 시즌 2에서는 동일 Imperial/ISB 체계 안에서도 직급·직무별 개인차를 유지하고, Yavin의 여러 출신 반군이 시간이 지나며 점차 공통복식으로 수렴하는 과정까지 시각화했다.

### 참조할 설계 원리
- 옷은 멋보다 생활·직업·계급·정치상태를 말해야 함
- 같은 조직 내부에서도 개인이 사라지면 안 됨
- 사회 전체를 학교아이·노동자·관료·상류층까지 확장해 문화가 보이게 함
- 캐릭터의 정치적 변화가 복식의 단순화·통합·이탈로 나타남

### 프로젝트 적용
- F01–F14는 공통문법을 갖되 NPC까지 동일 유니폼 복제 금지
- 지역은 영웅만 디자인하지 않고 노동자·아이·행정원·상인 생활복도 같은 재질문법을 공유
- C20·C21·C24 등 제도권 인물은 ‘같은 관료/군인 얼굴’로 만들지 않음

### 가져오지 않을 것
- Star Wars 실루엣·제국군복·색배열
- 특정 행성의 복식을 특정 칼레온 지역에 직접 대응

## REF-E — 《Black Panther》 / Ruth E. Carter

### 조사 근거
Marvel 및 Academy 자료에서 Ruth Carter는 여러 실제 문화 요소를 하나의 일관된 Wakandan 언어로 통합하되, 각 부족의 색·재료·장식 규칙을 구분하고, 의상과 production design이 함께 작동하도록 설계했다고 설명한다. Dora Milaje 장비는 전투에 실제로 필요한 보호·무기 구조와 전통의 의미를 동시에 갖게 했다.

### 참조할 설계 원리
- 한 문명 안에 여러 지역문화가 공존하면서도 전체적으로 같은 세계처럼 보이게 함
- 지역·세력별 재료와 구조를 분리
- 장식은 의미·상속·직업에서 나와야 함
- 의상과 건축을 따로 설계하지 않음

### 프로젝트 적용
- 8권역의 재질문법을 복식·유산·건축에 동시에 연결
- 세력색은 보조표식일 뿐, 형태·재료·사용법이 우선
- 장식품은 가문·노동·계약·장례 등 서사적 출처가 있어야 함

### 가져오지 않을 것
- 실제 아프리카 특정 문화의 문양을 맥락 없이 차용
- Wakanda 부족 색상·Dora Milaje 실루엣 복제

## REF-F — 《Dune》 영화 시리즈 / Jacqueline West

### 조사 근거
Motion Picture Association 인터뷰에서 Dune 의상은 환경에 실제로 버텨야 하는 기능성, Fremen 공동체의 생존문화, Bene Gesserit의 통제성, Harkonnen의 재질감처럼 서로 다른 사회적 기능을 실루엣과 소재로 구분한다. 촬영환경에 맞춘 실물 테스트도 반복했다.

### 참조할 설계 원리
- 환경압력이 복식을 결정
- 권력은 반드시 장식량과 비례하지 않음
- 재질만으로도 세력의 감정과 생활방식을 전달 가능
- 실제 움직임·기능 테스트가 중요

### 프로젝트 적용
- 서부·북부·남부·Era F 의복은 기후·노동·보급에서 도출
- 왕실 권력자를 무조건 화려한 왕관/망토로 표현하지 않음
- 경계갑·군복·작업복은 실제로 움직일 수 있는 구조로 설계

### 가져오지 않을 것
- Fremen/Atreides/Harkonnen 실루엣 직접 대응
- 검정·백색 같은 세력 팔레트 복제

## REF-G — 《ELDEN RING》 / FromSoftware

### 조사 근거
FromSoftware 제작자 인터뷰에서 아이콘·장비는 작은 화면에서도 인지되어야 하며, 사용으로 인한 마모와 ‘누가 만들었고 오래 사용했는가’라는 배경까지 디자인에서 느껴져야 한다고 설명한다. 배경 역시 concept art 분위기와 실제 플레이 목적을 함께 만족시켜야 한다.

### 참조할 설계 원리
- 작은 아이콘에서도 형태가 구분되어야 함
- 물건의 마모·손때·제작역사가 디자인에 남음
- 장비와 장소는 ‘과거에 누가 무엇을 했나’를 말해야 함
- 화려함보다 질감과 실재감

### 프로젝트 적용
- R01–R12는 실루엣 + 마모 + 소유권 흔적의 3중 식별
- Thumbnail 64px 수준에서도 R01/R03/R04/R10 등이 서로 구분되어야 함
- 유산의 Final 상태가 파괴/분해/용해여도 이전 형태의 흔적이 읽혀야 함

### 가져오지 않을 것
- Souls 갑옷·고딕장식·무기형태
- 폐허미학 자체를 칼레온 전역에 적용

## REF-H — 《Monster Hunter》

### 조사 근거
Capcom 개발 인터뷰는 몬스터를 단순 적이 아니라 환경 속 생태계 구성원으로 만들고, 생김새·행동·서식지·장비가 같은 생태적 컨셉에서 파생되어야 한다고 설명한다. Sunbreak의 Three Lords도 서구 괴물 모티프를 그대로 쓰지 않고 실제 살아 있는 생물처럼 보이도록 생태와 세계관 관계를 반복 검증했다.

### 참조할 설계 원리
- 생물의 외형은 행동·먹이·서식지에서 나와야 함
- 환경과 생물이 서로를 설명
- 장비는 생물의 소재·생태에서 일관되게 파생
- 대표 생물은 정지 실루엣뿐 아니라 움직임도 아이콘

### 프로젝트 적용
- B01–B05 `Rest Silhouette / Moving Silhouette / Trace Signature` 3종 의무
- 신수는 ‘멋진 동물’이 아니라 지역생태·이동·경보·조류·주소불일치 기능에서 외형 도출
- 신수 주변환경과 인간 계약도 함께 디자인

### 가져오지 않을 것
- 몬스터 사냥/소재파밍 구조
- 기존 MH 몬스터의 뿔·날개·비늘 조합

## REF-I — 《Tactics Ogre》 / Akihiko Yoshida 계열의 정치 앙상블

### 조사 근거
Square Enix는 공식 아트북에 인물·배경·타로·픽셀아트와 Akihiko Yoshida/Tsubasa Masao 인터뷰를 함께 수록하며, 대규모 정치 앙상블을 개별 캐릭터 아트와 집단문법으로 관리한다.

### 참조할 설계 원리

### 가져오지 않을 것

## REF-J — 《Fire Emblem》 시리즈

### 조사 근거
Nintendo 제작자 인터뷰는 수십 명 규모 캐릭터를 설계할 때 다양한 인물을 그려낼 수 있는 역량을 중요 조건으로 들고, 최신작에서는 캐릭터 움직임과 클로즈업 표정까지 개별적으로 설계했다고 설명한다.

### 참조할 설계 원리
- 대규모 캐스트에서 이름만 다른 인물 방지
- 얼굴·색·실루엣·움직임을 복합적으로 구분
- 한 캐릭터의 전투/일상 상태에도 동일 DNA 유지

### 프로젝트 적용
- 30명 모두 `Face DNA` 5축 이상 차등
- 캐릭터 Variant에서도 얼굴·몸짓 DNA 보존
- 얼굴과 머리만 잘라낸 portrait test + 검은 실루엣 test 둘 다 실시

- 백지권은 공포 풍경만 그리지 않고 식사·학교·수선 같은 생활 전경 포함

# 3. Face Diversity Hard Rules

## 3.1 Hair Is Not Identity

머리색·머리길이·장신구를 모두 제거한 얼굴 crop에서 C01–C30 주요 인물이 구분되어야 한다.

## 3.2 Face DNA Axes

각 인물은 아래 12축 중 최소 5축에서 인접 캐릭터와 다르게 설정한다.

1. 얼굴 전체 비율: 장방 / 중간 / 광폭 / 원형
2. 이마 높이·폭
3. 눈 크기 자체가 아니라 눈의 간격·깊이·기울기
4. 눈두덩·눈썹뼈
5. 코 길이·콧대·코끝·폭
6. 광대 위치
7. 턱 폭·턱끝 길이
8. 입 폭·입술 두께·기본 긴장
9. 귀 모양·노출
10. 나이선·피부질감
11. 흉터·화상·비대칭 등 imperfection
12. 기본 표정에서 힘이 들어가는 부위

## 3.3 Body DNA Axes

- 키만으로 구분 금지
- 어깨/골반 비율
- 몸 중심 높이
- 손 크기·손상
- 목/등 자세
- 보폭
- 노동/부상에서 나온 근육·굳은살
- 장비가 몸의 어느 축에 무게를 주는지

## 3.4 Gender Clone Ban

- 여성 캐릭터 1개의 얼굴 베이스에 눈·머리만 바꾸는 방식 금지
- 남성 캐릭터 1개의 얼굴 베이스에 수염·흉터만 바꾸는 방식 금지
- 여성도 넓은 턱·긴 코·깊은 눈·주름·강한 손 가능
- 남성도 좁은 어깨·둥근 얼굴·부드러운 턱·작은 체구 가능
- 아름다움/매력은 동일한 비율이 아니라 **인물의 자기 일치성**에서 나온다
