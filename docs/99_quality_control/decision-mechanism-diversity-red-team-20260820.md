`양측 모두 합리적 → 비용 공개 → 단일정답 거부 → 권리/권한 분리 → 절충`

## 3. High-Risk Cluster A — V4 / V13 / V14

공통점:
- 기록·권리·현재인·과거원본 충돌
- 공개청문/법정/기록검증이 주요 도구

차별점이 D6에 이미 존재한다.

### V4
- 핵심은 **사라진 도시와 현재 주민**.
- 물리 결과: 성벽 재출현, 방어회랑 단절, 외부 침공.
- 선택단위: 한 지역의 공존/소거.

### V13
- 핵심은 **주소가 없는 사람의 시민권 + 상속 + 식량**.
- 물리 결과: 방벽/재산/곡창, 유산 분해, 배급위기.
- 선택단위: 사람의 법적 존재와 복수 권리.

### V14
- 핵심은 **한 권의 진실을 만들지 않는 기록체제 + 중앙 점거**.
- 물리 결과: 원본 수송/봉인, 기억손실, 엔진 점거, 강제덮어쓰기.
- 선택단위: 사회가 상충진실을 저장·반박하는 방법.

Verdict: **structurally differentiated, prose execution risk remains.**

## 6. Hard Execution Guards

다음은 Story/Canon 변경이 아니라 CP/Craft/Prose QA 규칙이다.

1. **Abstract-only streak guard**  
   연속 2화가 회의/법정/문서판정만으로 끝나고 물리적 상태변화가 0이면 Red Team 재검토.

2. **Concrete consequence guard**  
   추상적 권리·승인·감사 결정은 같은 화 또는 다음 화의 기존 D6 물리/생활 결과를 반드시 보존.

3. **Split-authority distinction guard**  
   `권한을 나눈다`가 나올 때 V9 실험 / V12 제한정지 / V15 영구분리의 서로 다른 물리행동과 비용을 prose에서 명시적으로 체감시킨다.

4. **GA V three-episode materiality guard**  
   V13–V15의 임의 3화 창에서 최소 1화는 기존 D6의 음식·의료·공사·이동·전투·파손·대피·신체/주소 손실 중 하나가 장면 중심에 있어야 한다.

5. **Opponent protection-target guard**  
   대립자의 논리만 말하지 말고 이미 설계된 실제 보호대상/생활효용을 삭제하지 않는다.

6. **Ria-loss preparation guard**  
   기존 관계/기억 비트가 등장하는 회차에서 사적 의미를 제거해 단순 정보전달로 축소하지 않는다. 새 로맨스 사건 생성은 금지.
