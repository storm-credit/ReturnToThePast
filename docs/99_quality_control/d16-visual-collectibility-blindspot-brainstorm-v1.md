# 0. 핵심 판정

기존 D16은 `무엇을 다르게 만들 것인가`는 충분히 설계했다.
D16.2는 그 다음 질문을 다룬다.

> **실제 그림으로 옮겼을 때 AI/작화/상품화 관성 때문에 다시 똑같아질 지점은 어디인가?**

그리고 수집욕을 하나의 감정으로 취급하지 않는다.

- 최애 캐릭터를 고르는 욕구
- 특정 장비의 재질과 사용흔적을 좋아하는 욕구
- 같은 유산의 시대별 상태를 나란히 보고 싶은 욕구
- 신수의 행동·흔적을 관찰하고 싶은 욕구
- 특정 지역에 ‘살아 보고 싶다’는 장소애착
- 특정 세력의 문장·복식·도구를 좋아하는 욕구
- 상실된 최종상태까지 포함해 계보를 완성하고 싶은 욕구

이 감정들이 서로 다른 독자층을 잡아야 한다.

# 1. Blindspot Severity Scale

- **P0**: 기존 Canon/결말/인물 정체성을 깨뜨림. 즉시 중지.
- **P1**: 실제 제작물에서 다수 자산이 수렴해 D16 목적을 무너뜨림. 이미지 승인 금지.
- **P2**: 개별 자산 매력·인지성이 약화됨. Pilot 중 수정.
- **P3**: 선호·연출 차원의 개선 후보. SOFT.

현재 문서 설계 기준 Open P0 = 0, Open P1 = 0.
아래 Production Risk는 실제 이미지가 나오기 전까지 ‘검사해야 할 위험’으로 유지한다.

# 2. Character Blindspot Sweep

## B01 — AI 미형화 수렴

**공격**  
생성 모델은 성별·역할과 무관하게 대칭적인 얼굴, 매끈한 피부, 비슷한 눈 크기, 날렵한 턱, 높은 코로 수렴시키기 쉽다. D16의 직업·손·소품 차이가 있어도 얼굴만 떼면 같은 사람처럼 보일 수 있다.

**위험등급:** P1 Production Risk

**방어**
- Face DNA 8축 중 최소 4축 차이 규칙 유지.
- `잘생김/예쁨`을 Face DNA 필드로 사용하지 않는다.
- 동일 조명·무표정 Face Crop에서 먼저 비교한다.
- 미용적 비대칭이 아니라 **생활에서 생긴 좌우차**를 허용한다.
- 얼굴 승인 전 머리색·귀걸이·흉터·화장·장식 레이어를 숨긴다.

**Hard Fail**  
머리카락과 액세서리를 제거한 상태에서 3명 이상이 형제자매처럼 보이면 해당 묶음 재설계.

---

## B02 — 나이대 수렴

**공격**  
핵심 캐스트가 모두 20대 후반~30대 초반처럼 보이면 30명의 사회적 깊이가 사라진다.

**위험:** P1

**방어**
- 연령감은 주름 숫자가 아니라 피부질감, 눈꺼풀 무게, 볼륨 분포, 목·손, 자세 회복속도로 구분.
- 중년/노년을 ‘회색머리 버전의 젊은 얼굴’로 만들지 않는다.
- C05 오르바드, C13 도르칸 등 연령감이 역할과 연결된 인물은 실제 골격·조직량 차이를 요구.

**금지**
- 모든 여성은 젊게, 모든 남성 지도자는 중년으로 단순화.

---

## B03 — 체형·키 수렴

**공격**  
전원 장신·마른 전투체형이 되면 실루엣 Gate가 소품에 의존한다.

**위험:** P1

**방어**
- 키 숫자를 Canon으로 박지 않아도 `낮은/중간/높은 시선 높이`, `어깨폭`, `상하체 중심`, `보폭`, `무게 중심`을 분산.
- 직업이 체형을 100% 결정하지 않게 한다.
- 비전투직도 각각 다른 몸의 사용법을 가진다.

**검사**
30명 검은 전신 실루엣에서 소품 제거 후 80% 이상 구분 가능해야 함.

---

## B04 — 성별 시각코딩

**공격**  
여성은 긴 머리/잘록한 허리/작은 도구, 남성은 넓은 어깨/무기/중장비로 분리될 위험.

**위험:** P1

**방어**
- Primary Icon은 성별보다 직업·책임·생활흔적에서 나온다.
- 허리라인/가슴/노출도는 캐릭터 식별축에서 제외.
- 공구·행정판·식량주머니·문서·환자표식의 크기는 실제 기능에 따라 결정.

---

## B05 — 선악을 얼굴로 코딩

**공격**  
대립자는 날카롭고 어둡게, 협력자는 부드럽고 밝게 그리면 작품의 윤리구조가 평면화된다.

**위험:** P1

**방어**
- 레오르, 마르칸, 카시안, 유나 등 논쟁적 인물에게 ‘악역 얼굴’ 금지.
- 아이리스·리아 등 주역에게 자동적인 성스러운 조명 금지.
- 선악 대신 **책임 방식**이 자세·도구·공간점유에 드러나야 한다.

---

## B06 — 직업군 내부 수렴

### 기록군
C02 리아 / C12 엘사 / C22 하렌
- 리아 = 겹침/유동/출처점
- 엘사 = 생활분산/팔목끈/그을림
- 하렌 = 단단한 원본/정사각 상자/직선봉인

### 군사군
C04 마르칸 / C24 브란
- 마르칸 = 국가규모 구역배치/직사각 군정
- 브란 = 요새·마을·철회조건/쌍패

### 공방·정비군
C13 도르칸 / C25 케론
- 도르칸 = 소유·제작·접합
- 케론 = 수리시간·진동·가동

### 해안군
C16 마리엔 / C19 에스라 / C28 토마르
- 마리엔 = 계약/방수문서
- 에스라 = 항로/외교/매듭
- 토마르 = 하역/노동/화물패

**Hard Rule:** 같은 직업군에서는 Face DNA 최소 5/8, Body/Gesture 중 최소 2축 추가 차이.

---

## B07 — 시간요원계열 혼동

C01 에이든 / C08 젊은 에이든 / C29 렌 바르 / C30 이름 없는 여행자

**위험:** 최고 P1

- C01 = 돌아가려는 장비가 점차 사라지는 사람
- C08 = 아직 그 장비를 갖지 않은 가능성
- C29 = 돌아갈 수 있었으나 현지생활이 빈 장비자리를 채운 사람
- C30 = 과거를 증명하지 않고 현재 권리를 요구하는 일반 여행자

**Hard Rule**
- C01↔C08만 골격 유사 허용.
- C29는 직업유사성을 얼굴유사성으로 번역하지 않음.
- C30은 얼굴·상처·눈색·머리색으로 C01을 암시하지 않음.

---

## B08 — ‘대표소품 1개 = 사람 전체’ 문제

**공격**  
리아=문서판, 미라=곡물주머니처럼 한 소품만으로 캐릭터가 고정되면 게임 NPC 아이콘처럼 보인다.

**위험:** P2

**방어**
Primary Icon은 기억 진입점일 뿐, 반드시 다음 2개가 함께 있어야 한다.
1. Body/Gesture DNA
2. Wear/Material DNA

소품 없이도 캐릭터가 살아 있어야 한다.

---

## B09 — 모든 인물이 ‘한 가지 기믹’을 갖는 인공성

**공격**  
30명 전원이 너무 깔끔하게 ‘A는 매듭, B는 곡물, C는 상자’로 분류되면 카드게임 캐릭터처럼 느껴진다.

**위험:** P2

**방어**
- 대표 아이콘은 1개지만, 원고/이미지에서 매 장면 반복하지 않는다.
- 3번 연속 등장 중 같은 제스처를 3번 모두 쓰지 않는다.
- 직업 외의 평범한 생활상은 캐릭터 카드가 아니라 장면 맥락에서 드러낸다.

---

## B10 — 얼굴보다 머리색에 의존

**위험:** P1

**Hard Test**
- grayscale
- bald-cap conceptual test 또는 머리영역 마스킹
- 눈색 제거

이 상태에서 식별이 무너지면 얼굴 재설계.

# 3. Relic / Collection Blindspot Sweep

## B11 — 모든 유산이 휴대 가능한 ‘아이템’처럼 보임

**공격**  
R01–R12가 카드/검/장신구 크기로 몰리면 세계의 규모가 줄어든다.

**위험:** P1

**방어: Scale Spectrum**
- 손가락/손바닥 단위
- 몸에 착용
- 양손 휴대
- 다인 운반
- 설치물/공공설비

12개 전체가 최소 4개 Scale Band에 분산되어야 한다.
R07 건국 모루와 R12의 절차형 최종상태가 Scale 다양성의 앵커.

---

## B12 — Final State가 전부 ‘부서짐’으로 반복

**공격**  
D16은 상실형 완결을 강조하지만 R03 파괴, R06 분해, R10 용해가 반복되면 마지막 감정이 같은 패턴이 된다.

**위험:** P2

**4가지 Final Emotion**
A. **파괴** — 더 이상 쓸 수 없음
B. **반환** — 원권리자에게 돌아감
C. **분산** — 한 물건/권한에서 여러 사람·절차로 바뀜
D. **보존** — 사용은 끝났으나 증거로 남음

12개 유산의 Final은 이 4축에 분산시킨다. 기존 정본을 변경하지 않고 현재 최종상태를 이 감정축으로 분류한다.

---

## B13 — ‘갖고 싶은 순간’이 전투력으로 편향

**위험:** P1

**Desire Lanes**
- Craft Desire — 재질/제작기술
- Mystery Desire — 정체/기능을 알고 싶음
- Custody Desire — 누가 가질 권리가 있는지 궁금함
- Memory Desire — 과거 흔적을 보존하고 싶음
- Utility Desire — 실제 기능
- Loss Desire — 최종상태까지 계보를 완성하고 싶음

R01–R12는 최소 2개 Lane을 가져야 하고, Combat가 유일 Lane인 유산은 0개.

---

## B14 — Variant 과잉

**공격**  
O/U/C/F 4상태가 ‘4색 한정판’처럼 상품화되면 서사적 상태변화가 희석된다.

**위험:** P2

**방어**
- 실제 형태가 유의미하게 다른 경우만 별도 Variant.
- 소유권만 바뀌고 외형 변화가 없는 상태는 별도 상품형으로 만들 필요 없음.
- Variant 총량은 ‘상태 수’가 아니라 ‘독자가 한눈에 다른 역사로 읽는가’로 결정.

# 4. Sovereign Beast Blindspot Sweep

**공격**  
5종 모두 와이드샷에서 천천히 움직이는 거대 판타지 생물로 나오면 생태 차이가 사라진다.

**위험:** P1

**방어: Presence Type 분산**
- B01 길등짐승 = 경로/지면/집단 이동
- B02 종울음새 = 군집/소리/공기
- B03 유리등각수 = 바위/진동/정지와 미세 움직임
- B04 역조고래 = 거리/수면/계절적 부재
- B05 백지사슴 = 단독/관찰차/발자국

크기보다 **어떻게 존재를 알아차리는가**가 다르다.

## B16 — 귀여움/펫화 압력

**위험:** P1

- 새끼 버전이 인기여도 주인공이 안거나 데리고 다니는 구조 금지.
- 장비착용/안장/목줄/소환진으로 소유권을 시각화하지 않는다.

## B17 — 신수 디자인이 종족 문화보다 더 강하게 문화대표

**공격**  
라하크=신수 사람들처럼 보이면 인간·공동체 문화가 동물 아이콘에 흡수된다.

**위험:** P2

**방어**
신수 문양을 인간 복식에 과도하게 반복하지 않는다. 계약은 모방장식이 아니라 행동·금지선·공간사용으로 보인다.

# 5. Landmark / Faction Blindspot Sweep

**공격**  
작품 핵심 시각문장이 강해서 모든 지역에 겹문패·겹벽·겹문서만 넣을 위험.

**위험:** P1

**방어: Region Primary Verb**
- 아르켄 = **증축한다**
- 서부 = **수선한다**
- 셀카르 = **파고/접합한다**
- 라디아 = **흐르게/막는다**
- 조류도시 = **잠기고/드러난다**
- 백지권 = **다시 적는다**
- Era F = **재사용한다**
- P1 = **나눠 맡는다**

랜드마크는 명사가 아니라 동사로 구별한다.

## B19 — 세력이 로고·유니폼 군단처럼 보임

**위험:** P1

## B20 — 선악 팔레트

**위험:** P1

## B21 — 실제 문화·종교·정치 상징과 우연히 지나치게 닮음

- 현대 극단주의/혐오 상징과 오인 가능

충돌 시 SOFT 문양만 수정, 세력 기능은 유지.

# 9. Constrained Brainstorm — Art Direction 4안

아래는 **시안 방향**이지 Canon이 아니다. 특정 작품 화풍을 복제하지 않는다.

## A안 — Grounded Material Fantasy

**핵심:** 실제 천·가죽·금속·종이·돌의 질감과 노동 흔적을 강하게 보이는 준실사 판타지.

**장점**
- 유산의 provenance와 마모가 가장 잘 산다.
- 배경·기관의 생활기능 설득력이 높다.
- 중년/노년·체형 다양성에 유리.

**위험**
- 썸네일에서 캐릭터 차이가 약해질 수 있음.
- 판타지 수집욕이 지나치게 현실소품 쪽으로 기울 수 있음.

**적합:** R01–R12 / 셀카르 / 서부 / Era F.

---

## B안 — Graphic Shape Animation

**핵심:** 얼굴과 몸의 큰 형태, 음영 덩어리, 비대칭을 과감하게 분리하는 애니메이션형 시각언어.

**장점**
- 30명 얼굴·실루엣 차별화에 가장 유리.
- 64px 썸네일 인지성이 높다.
- 세력/랜드마크 shape language 구축에 강함.

**위험**
- 재질과 역사적 마모가 단순화될 수 있음.
- 과도한 stylization은 작품의 무게를 낮출 수 있음.

**적합:** Character lineup / Faction / 군중장면.

---

## C안 — Illustrated Chronicle / Painterly Fantasy

**핵심:** 기록화·삽화처럼 평면적 구성과 재질감을 살리는 회화형 판타지.

**장점**
- 작품의 ‘기록/겹침/역사’ 주제와 잘 맞음.
- 배경과 캐릭터를 한 장면에 묶기 좋음.
- 표지·권별 대표 일러스트에 강함.

**위험**
- 동일 얼굴 유지와 턴어라운드 제작은 상대적으로 불리.
- 액션/상품시트에 바로 쓰기 어렵다.

**적합:** 표지 / Grand Act key visual / 기록·장례·도시.

---

## D안 — Hybrid Graphic Realism **[추천 기본]**

**핵심:** 얼굴·실루엣은 B안처럼 과감하게 분리하고, 재질·손상·배경의 물성은 A안처럼 구체화. 최종 key art에서는 C안의 기록화 구성 일부를 사용.

**장점**
- 캐릭터 구별 + 유산 물성 + 배경 서사를 동시에 잡을 수 있다.
- 웹소설 표지, 캐릭터시트, 애니/게임 확장 모두 번역성이 높다.
- D16의 ‘형태 + 재질 + 서사 3중 서명’과 가장 직접적으로 맞는다.

**위험**
- 통제 없이 생성하면 스타일 혼합처럼 보일 수 있다.
- 명확한 제작순서와 동일한 비율기준이 필요.

**운영**
V0 Shape Study는 Graphic  
V1 Face는 Neutral  
V2 Integrated Concept부터 Material Detail  
Key Art에서만 Painterly Composition 추가.

**현재 추천:** D안. 단, Pilot 전 HARD LOCK 금지.
