## 4. Domain Readiness

### Time / System

- 주소 연결상실, 회색열, 분산 승인, 시간 파견의 필요가 기능으로 등장
- 새 시간법칙 후출 없음

### Geography / Logistics

- 관측실→복도→보고실→브리핑실→기록실 동선이 명확
- 구조대 출동의 연료·격리·병원전력 비용이 행동을 제한

### Institution / Law

- 여섯 기관은 명칭만 등장하지 않고 승인·열람·책임의 다른 기능을 가짐
- 관료제를 순수한 악이 아니라 생존과 배제의 양면으로 표현

### Character

- 에이든은 모든 문을 강제로 열거나 관측병을 희생시키지 않음
- 리아는 원자료 접근권이 없고 독립적으로 위험을 감수
- 방위총감은 실제 구조인원과 비용을 아는 합리적 대립자

### Religion / Culture / Item

- E001의 중심 기능이 아니므로 종교 의례·유산 도감의 과도한 선행투입 없음
- 솔라 종탑은 계절·병원 동기화라는 물질 기능으로 제한 사용

판정: 필요한 분야는 충분히 호출됐고, 비활성 분야를 억지로 설명하지 않았다.

## 5. Storycraft

선택된 조합:

1. 목표–방해–선택–비용
2. 정보 간극과 공정 단서
3. 관료제 공포의 물질화
4. 약속–진행–회수의 미니 구조

### 장면 가치변화

- 구조 가능한 재난 → 주소와 기록까지 무너지는 재난
- 현장구조 선택 → 다른 지역 생존과 경쟁하는 선택
- 공식 표적 → 합리적으로 의심되는 표적
- 원자료 접근 기대 → 삭제 실패 흔적만 얻은 위험한 접근

### 반복검사

- 전투승리·예언·악역독백·로맨스 훅을 사용하지 않음
- E002가 같은 붕괴 장면을 반복하지 않도록 인계됨

판정: PASS
