## 2. 에이전트 판정

### A00 Story Orchestrator

현재 문제는 단순 문체 교정이 아니다.

- 신규 명명 규칙 등록
- 기존 SOFT/AUTO LOCK 명칭의 재검토
- 기관·종교·시간·장비 Domain 동시 영향

따라서 `Naming Audit / Canon Change Preparation`으로 분류한다.

### A02 Canon Controller

현재 명명 패키지의 기관명은 정본 후보·자동 잠금 상태지만, 작가의 최신 명시 결정이 상위다. 이번 규칙 등록으로 기존 이름이 자동 변경되지는 않는다.

실제 개명에는 후보 승인, 영향표, 관련 Bible·설계·CP·원고·검증기 갱신이 필요하다.

### A05 Culture & Religion

종교명·교리명·성당명은 신화와 의례가 먼저 있어야 한다.

`아홉 상처`, `구흔교리`, `성력국`은 독자가 신화 구조를 알기 전에 이름부터 제시되면 의미를 해독해야 한다. 특히 숫자와 한자 축약을 동시에 사용하면 한국 웹소설 판타지의 자연스러운 명명보다 설정집 코드처럼 들린다.

### A06 Institution / Economy / Law

`연대출귀원`, `왕좌승인원`, `중앙관측탑연합`, `지역 연대감사소`는 기능을 한 이름에 과도하게 압축했다.

기관 설정 자체의 권한 분리는 유지할 가치가 있으나, 외부 명칭은 익숙한 조직어 1개로 단순화해야 한다.

### A07 Temporal Systems

이 작품은 단일 가변 시간선과 직접 시간여행을 사용한다.

`차원`은 한국 웹소설 독자에게 이세계·평행세계·공간 이동을 먼저 연상시킬 수 있으므로, 시간여행 전체의 기본 접두어로 자동 채택하면 설정을 오해시킬 위험이 있다.

`시간·과거·귀환·출발` 같은 일반어를 우선하고, `차원`은 실제 설정상 차원 개념이 확정된 대상에만 사용해야 한다.

### A10 Collection & Material Assets

장비는 이름보다 형태·재질·사용동작이 먼저다.

`지맥계`, `마도 조율판`, `전언패`, `기록패`, `생존 계수판` 같은 대체안은 현대 장비 기능을 유지한 채 판타지 접두어만 붙였으므로 채택 부적합이다.

### A15 Similarity Audit

- 라틴·그리스·북유럽 어감 자체는 사용할 수 있다.
- 실제 신화의 유명한 신·영웅·유물 이름을 직접 사용하지 않는다.
- `아카식 레코드`는 널리 알려진 오컬트 개념이므로, 단지 판타지 느낌을 내기 위한 기록기관 이름으로 사용하면 독창성과 기능 명확성이 모두 약해진다.
- 초월적 세계기록 체계가 정본에 실제로 필요할 때만 별도 유사성 감사를 거쳐야 한다.

### A19 Korean Prose Audit

현재 가장 큰 문제는 발음보다 **첫 청취 의미와 실제 대사 사용성**이다.

다음과 같은 이름은 입말에서 뜻이 곧바로 잡히지 않는다.

- 연대출귀원
- 성력국
- 구흔교리
- 잔문감사실
- 최후 연대국
- 지역 연대감사소

명칭을 설명하기 위한 별도 문장이 필요하다면 이름이 역할을 하지 못하고 있다.

### A16 Red Team

다음 위험을 확인했다.

1. 현대 행정·SF 구조를 유지한 채 이름만 판타지화
2. 추상 한자어 압축
3. `시공·연대·잔흔·각인·결계·마도` 접두어의 반복
4. 세계관 핵심 개념보다 명명 체계가 먼저 보임
5. 독자가 이야기가 아니라 용어를 해독하게 됨

판정: **S1 — 다음 화 명명 확장 전 해결 필요**

기존 사건과 시간 규칙은 유지할 수 있으므로 작품 전체 구조를 중단할 S0는 아니다. 그러나 현재 명명 체계를 그대로 확장하면 수정 범위가 기하급수적으로 커진다.

## 3. 외국어 어감 계열 판정

### 3.1 중앙 왕국

현재 중심 이름:

- 칼레온
- 아르켄
- 세르바
- 에이든
- 리아
- 세렌
- 카시안
- 마리엔

이 이름들은 엄밀한 실제 라틴어라기보다 **라틴·로망스·대륙 유럽풍을 섞어 한국어로 다듬은 판타지 이름군**에 가깝다.

판정:

- 중앙 왕국의 기본 어감으로 사용하기 적합
- 실제 라틴어 문법을 강제할 필요 없음
- 2~4음절, 모음이 분명하고 한국어로 읽기 쉬운 이름을 유지
- 기관명은 외국어 조어보다 `고유명 + 익숙한 한국어 조직명`을 우선

### 3.2 북부 지역

북유럽풍은 북부 산악·설원·전사 가문·룬 문화에 제한적으로 사용할 수 있다.

조건:

- 북부가 중앙과 구별되는 언어·문화 역사를 가져야 함
- 개인명과 지명에만 먼저 적용
- 오딘·토르·로키·발할라 등 직접 차용 금지
- 북부 인물 모두를 거친 자음과 동일 어미로 만들지 않음

판정: **부분 사용 가능**

### 3.3 고대 종교·유적

그리스·그리스로마풍은 고대 신전·별·예언·의술·비극 신화의 어감에 제한적으로 사용할 수 있다.

조건:

- 현재 왕실·마탑·북부 문화와 분리된 고대 문화층이어야 함
- 유명 신과 유물의 이름 직접 차용 금지
- 교리 이름보다 의례와 신화가 원고에 먼저 등장해야 함

판정: **보조 문화층으로만 사용 가능**

### 3.4 작품 전체 단일 계열

작품 전체를 라틴·그리스·북유럽 중 하나로 통일하는 것은 권장하지 않는다.

추천 구조:

- 중앙 왕국: 라틴·대륙 유럽풍을 느슨하게 참고
- 북부 변경: 제한된 북유럽풍
- 고대 종교·유적: 제한된 그리스풍
- 남부 해안·다종족: 각 문화 Bible에서 별도 음운 규칙

문화권 사이의 혼합은 정복·이주·교역·종교전파 같은 내부 역사로 설명한다.
