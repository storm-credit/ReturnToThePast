# Face & Silhouette Collision Gate v1

Status: **D16 PRE-PRODUCTION HARD GATE**  
Date: 2026-08-20  
Scope: C01–C30  
Purpose: 이미지 생성 모델이 여러 캐릭터를 같은 얼굴 베이스로 수렴시키는 문제를 구조적으로 차단한다.

> 아래 Face DNA는 **PRODUCTION SOFT DNA**다. 아직 작가 승인된 최종 얼굴 Canon이 아니다. 개별 축은 Visual Pilot에서 수정 가능하지만, 캐릭터 간 거리 규칙은 유지해야 한다.

---

# 1. 왜 별도 Gate가 필요한가

이미지 생성에서 흔한 실패:

- 남성 주연 여러 명이 같은 턱·코·눈을 공유하고 머리색만 다름
- 여성 캐릭터 여러 명이 같은 V턱·큰 눈·작은 코를 공유
- 중년 인물도 주름만 추가한 청년 얼굴
- 직업군이 같으면 얼굴과 체형까지 비슷해짐
- 같은 프롬프트 언어가 반복되면서 표정과 포즈가 수렴
- 캐릭터 A의 승인된 얼굴이 다음 캐릭터 생성의 숨은 베이스가 됨

이 프로젝트는 이를 **Face DNA / Body DNA / Gesture DNA / Silhouette DNA** 4층으로 분리한다.

---

# 2. Collision Distance Model

각 인물은 8축을 가진다.

1. Face Ratio
2. Brow Structure
3. Eye Set / Depth
4. Nose Structure
5. Jaw / Chin
6. Age / Skin Texture
7. Body Center / Posture
8. Imperfection / Asymmetry

두 캐릭터가 한 축에서 다르면 거리 +1.

## 통과 기준

- 일반 인물쌍: **8축 중 최소 4축 차이**
- 동일 기능 위험군: **최소 6축 차이 권장 / 5 미만 FAIL**
- C01 ↔ C08: 동일인 다른 시기이므로 예외. 얼굴골격 유사 허용. 대신 age/body/silhouette/gear에서 분리
- C01 ↔ C30: **최소 7축 차이**. C30 정체를 얼굴로 암시 금지

이번 production scaffold의 사전 조합 점검:

- 전체 비예외 인물쌍 최소거리: **6/8**
- 위험군 대부분: **7–8/8**
- C01↔C08: **3/8** — 의도된 동일인 유사성
- C01↔C29: **8/8**
- C01↔C30: **8/8**
- C08↔C30: **8/8**

즉 현재 scaffold 자체에는 얼굴 clone pair가 없다.

# 5. Image-Set Test Protocol

캐릭터 개별 이미지를 승인하기 전에 반드시 다음 contact sheet를 만든다.

## Sheet A — Face Crop 30
- 동일 조명
- 동일 초점거리 느낌
- 머리색을 모두 grayscale
- 장신구 제거
- 정면 30개 배열

PASS:
- 이름표를 가렸을 때 핵심 20명 이상을 얼굴만으로 재식별 가능
- 위험군을 두 번 이상 헷갈리면 재설계

## Sheet B — Black Silhouette 30
- 얼굴·색·재질 제거
- 전신 검정

PASS:
- C01/C04/C05/C13/C14/C15/C21/C24/C27/C28 등 핵심 실루엣 즉시 분리

# 6. Generation Isolation Rule

얼굴 수렴을 막기 위해 실제 생성 순서를 다음처럼 제한한다.

1. 한 캐릭터의 승인 이미지를 다음 캐릭터의 직접 레퍼런스로 사용하지 않는다.
2. 같은 성별/나이대 캐릭터를 연속 대량생성하지 않는다.
3. 각 캐릭터 프롬프트에 다른 캐릭터 이름을 `~처럼` 넣지 않는다.
4. 동일 seed/구도/렌즈를 전원에게 반복하지 않는다.
5. 첫 생성은 portrait보다 **silhouette/shape exploration** 우선.
6. 얼굴 확정은 실루엣 PASS 뒤 수행.
7. 최종 얼굴은 4안에서 선택하며, 선택 전 위험군 contact sheet와 비교.

권장 배치 예:
- C01 → C23 → C15 → C07 → C19 → C02 → C28 …

기능/성별/나이대가 연속되지 않게 교차한다.

# 7. Stop Conditions

다음 중 하나라도 발생하면 해당 캐릭터 생성 중지.

- 기존 승인 캐릭터와 얼굴 5축 이상 유사
- 머리색을 같게 하면 구분이 어려움
- 검은 실루엣에서 직업군 내 구분 실패
- 여성 캐릭터가 기존 여성 캐릭터 얼굴의 헤어 교체처럼 보임
- 남성 캐릭터가 기존 남성 캐릭터 얼굴의 수염/흉터 교체처럼 보임
