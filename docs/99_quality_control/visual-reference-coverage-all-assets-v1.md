## Relic State Production Rule

각 R은 `O / U / C / F` 4단계에서 단순 색상변경 금지.

- O Original: 제작문화·초기 기능
- U In Use: 손때·수리·사용자의 흔적
- C Contested: 소유권 분쟁·봉인·공동표식
- F Final: 반환·파괴·분해·용해·절차화

**12/12 모두 Final이 ‘강화형’일 필요가 없고, 오히려 이 작품에서는 상실형 Final이 핵심 수집가치다.**
