# Knowledge-Holder and Memory-Continuity Ledger v1

Status: ACTIVE LEDGER  
Owner: Mystery / Continuity / Character  
Last Reviewed: 2026-08-07  
Canon Level: CANON SCHEMA / DRAFT ENTRIES

## Knowledge Categories

- K0: 직접 목격
- K1: 출발 미래의 공식 기록
- K2: 팔림프세스트 잔흔
- K3: 적대 세력의 주장
- K4: 현지 시대의 공인 역사
- K5: 작가만 아는 정본 진실

어떤 인물도 K5 전체에 접근하지 않는다.

## Memory States

- STABLE: 시간선 변경 후에도 비교적 유지
- DECAYING: 세부가 점차 부식
- REWRITTEN: 새 역사만 기억
- CONTESTED: 둘 이상의 모순된 기억 보유
- EXTERNALIZED: 신체 밖 기록에 보존
- FALSE-STABLE: 확신하지만 조작된 기억

## Initial Holders

### KH-01 — 에이든 / 현장 요원
- Era: F 출신, N·O 파견
- Access: K0, 제한된 K1
- Memory State: DECAYING
- Knows: 출발 임무, 자신이 만난 현장 사실, 귀환 미래가 달라졌다는 체감
- Does Not Know: 본부 기록 조작의 주체, 장치 전체 구조, Era O의 진실
- Bias: 출발 미래를 ‘원래 세계’로 여기려는 경향
- Risk: 기억 부식 때문에 잘못된 확신을 가질 수 있음
- Authority: 현장 선택권만 보유

### KH-02 — `[ASSUMPTION]` 리아 / 팔림프세스트 기록관
- Era: F
- Access: K1, K2, 제한된 K0 증언
- Memory State: EXTERNALIZED + CONTESTED
- Knows: 여러 미래의 문서 파편, 삭제된 이름과 지도
- Does Not Know: 어느 기록이 최초인지
- Bias: 사라진 사람을 기록하면 존재를 구할 수 있다고 믿음
- Risk: 적이 심은 위조 잔흔을 진실로 보존할 수 있음
- Authority: 기록 열람·보존, 임무 진실 검증

### KH-03 — `[ASSUMPTION]` 아이리스 / Era N 현지 앵커
- Era: N
- Access: K0, K4
- Memory State: REWRITTEN
- Knows: 자기 시대의 실제 권력·지리·생활 비용
- Does Not Know: 미래의 세력 구도와 결과
- Bias: 미래 사람보다 현재 살아 있는 주민을 우선
- Risk: 에이든을 침략자나 왕실 첩자로 판단할 수 있음
- Authority: 현지 신분·은신·귀환 앵커 협조권

### KH-04 — F1 지휘관
- Era: F1
- Access: K1, 일부 K3
- Memory State: FALSE-STABLE
- Knows: F1의 공식 역사와 에이든의 영웅 기록
- Does Not Know: F0가 존재했다는 사실
- Bias: 시간 개입이 군사 효율을 증명했다고 믿음
- Risk: 합리적 성과를 근거로 선제 역사 제거를 확대
- Authority: 임무 승인과 자원 배분 일부

### KH-05 — Era O 설계자 집단
- Era: O
- Access: K0, 장치 원리의 일부 K5
- Memory State: STABLE within Era O
- Knows: 장치의 원래 목적과 분산 권한 이유
- Does Not Know: 수백 년 후 구체적 결과
- Bias: 당대 생존을 위해 미래의 비용을 정당화
- Risk: 후대가 악용할 구조를 의도적으로 남김
- Authority: 장치 구성요소 설계

## Mystery Safety Rules

- 한 인물의 설명으로 진실을 확정하지 않는다.
- 최소 두 종류 이상의 지식 범주가 일치해야 REVIEW 진실로 승격한다.
- 기억 보존은 도덕적 우월성이나 무오류를 뜻하지 않는다.
- 독자가 추론할 수 있도록 모순 기록의 원인과 접근권을 회차 카드에 표시한다.
