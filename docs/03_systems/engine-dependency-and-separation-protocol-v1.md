# 왕국 시간장치 의존성·기능분리 프로토콜 v1

Status: D9 CANON  
Owner: A06 Institution / A07 Temporal Systems / A13 Continuity  
Purpose: V12–V15 중앙정지와 생활망 이전의 기술·행정 인과 고정

## 1. 장치 구조

칼레온 장치는 하나의 엔진이 아니라 네 층의 상호의존망이다.

### Layer A — 생활안정층
- 계절·수문·농업 동기화
- 의료 인장·신분 대조
- 토지·도로·거리 안정
- 통신·장례·기본 기록

### Layer B — 주소·부담층
- 사람·지역·기관의 역사주소
- 안정비용 측정·배분
- 이의제기·피해기록
- 미등록·백지권 처리

### Layer C — 연대운영층
- 과거 출발 승인
- 시대·장소 좌표 계산
- 귀환점 검색
- 변경 전후 기록 비교

### Layer D — 강제개입층
- 국가가 원하는 역사 우선순위 입력
- 대규모 덮어쓰기
- 비밀 비용전가
- 군사·산업 개입 일정 자동화

결말은 A를 살리고 B를 개혁하며 C를 봉인하고 D를 폐쇄한다.

## 2. 핵심 의존성

| 기능 | 필수 입력 | 직접 의존 | 잘못 끊을 때 결과 |
|---|---|---|---|
| 계절 안정 | 성당력·천문·지역 수문 | A | 서리·홍수·파종 붕괴 |
| 의료 안정 | 몸·이름·생활장소 | A+B | 환자 오진·주소탈락 |
| 토지·거리 | 측량·고정석·지역기록 | A+B | 길·경계·소유권 흔들림 |
| 부담 배분 | 인구·세금·피해·거부 | B | 지방·무명종 자동 희생 |
| 시간 출발 | 승인·동기화·주소·좌표 | B+C | 오착·무허가 개입 |

## 3. 왜 단순 전원차단이 불가능한가

중앙은 수백 년 동안 생활안정층과 연대운영층의 인장·전력·기록주소를 공유하게 만들었다.

- 출발실 동기화가 성당 농업력과 같은 시계를 사용
- 귀환 고정력이 국경 거리안정과 같은 절점을 사용
- 역사주소 데이터가 출생·토지·의료 기록과 같은 대기록소에 있음
- 부담배분 계산이 세금·구휼·군수 장부와 결합

따라서 중앙 코어를 폭파하거나 모든 인장을 지우면 시간개입뿐 아니라 농업·병원·토지·국경도 무너진다.

## 4. 분리 순서

### S1 — 공개·동의·대피
- 현재 기능과 비용주체 공개
- 과거 잔류 요원의 마지막 자진귀환 창
- 병원·수문·고정석의 비상인력 배치
- 지역·종족·백지권의 거부권 확인

### S2 — 강제개입 우선순위 잠금
- D층의 새로운 목표 입력 차단
- 왕좌·성당·기록소 세 축의 비밀 변경을 공개감사로 전환
- 이미 진행 중인 덮어쓰기는 아직 멈추지 않음

### S3 — 출발부 폐쇄
- 신규 좌표 계산과 질량등록 중단
- 현지 잔류자는 현지법·정보제한·책임조건 선택
- C층 출발 기능과 A층 통신·천문을 분리

### S4 — 귀환부 종료
- 마지막 귀환창 종료
- 귀환표식과 국경 생활고정 표식을 분리
- 에이든 역사주소가 임시 다리 역할

### S5 — 지역 생활망 복제
- 성당력·수문·의료·토지 기능을 권역별 노드에 이전
- 건국 모루·경계갑·감사인장을 분해해 공공 부품으로 사용
- 지역마다 효율과 전환속도가 다름

### S6 — 부담·감사 분산
- 비용표 공개
- 상한·보상·항소·비참여권 도입
- 지역 내부의 소수종족 비용전가도 외부감사 대상

### S7 — 중앙 D층 영구폐쇄
- 강제 덮어쓰기 명령어·자동복원·비밀 희생경로 파괴
- C층은 재가동하려면 지역·종족·시민의 새로운 광범위 동의가 필요하도록 봉인
- A층 지역망은 불완전하게 계속 작동

## 5. 분리 중 실패 가능성

- S2 전에 출발부를 끄면 중앙이 기존 우선순위로 자동 덮어쓰기
- S3 전에 대피하지 않으면 과거 요원·병원·국경군이 고립
- S4에서 귀환표식과 고정석을 함께 끊으면 국경 거리붕괴
- S5가 늦으면 첫 수확과 의료망 붕괴
- S6 없이 분산하면 지역 권력자가 자기 소수집단에 비용 전가
- S7 없이 중앙을 남기면 위기 때 다시 비상독점

## 6. 유산 사용

- 건국 모루: 지역 노드 제작틀로 분해, 원형 제작능력 상실
- 경계갑: 이동식 고정재로 분해, 전투유산 기능 상실
- 감사인장: 단일 정지키가 아니라 지역 거부·감사 인장으로 분산
- F0 귀환패: 복원키가 아니며 마지막 귀환창 뒤 봉인
- 절검: 강제덮어쓰기 경로 지연에 사용 후 파괴

유산을 합쳐 궁극무기를 만들지 않는다.

## 7. P1 운영 상태

- 중앙은 기준·조정·분쟁중재를 담당하지만 단독 명령권 없음
- 지역망은 계절·의료·토지 안정 수준이 서로 다름
- 부유 지역의 기술·식량 지원 거부 문제 존재
- 마레사 자유해안동맹이 제한적 열람·피해청구·지원에 참여
- 백지권 일부는 어떤 망에도 연결되지 않아 영구손실로 남음
- 과거수정 대신 현재 재난대응을 선택하므로 더 많은 단기 사망 가능성 존재

## 9. 금지

- 엔진 중앙 코어 하나를 파괴해 모든 문제가 해결
- 에이든이 혼자 분리순서를 즉석에서 발명
- 분산망이 중앙보다 즉시 더 효율적·공정함
- 유산이 파괴되지 않고 전투력도 그대로 유지
- 백지권까지 완전히 복구
- 장치 재가동 버튼을 비밀리에 남겨 속편 편의로 사용
