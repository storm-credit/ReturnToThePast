# Departure Seal & F0 Return Plaque Distinction v1

Status: D14 TEMPORAL SYSTEMS CANON OVERLAY  
Owner: A07 Temporal Systems / A13 Continuity / A09 Collection  
Purpose: `출발 인장`과 R04 `F0 귀환패`의 역할·소유·소모·결말을 분리

## 1. 두 대상은 같은 물건이 아니다

### R04 F0 귀환패
휴대 가능한 물리 장비.

- F0 본부 발급
- 등록신분과 출발점 잔향 보조
- 귀환망 식별자 제공
- 현지 구조·귀환 안정에 제한 사용
- 발급기관 소멸 뒤 소유권 공백
- V5 기능 대부분 소모
- V14 F0 복원키가 아님을 공개
- V14–V15 봉인

### 출발 인장
여행자 개인에게 도약 때 형성되는 **비양도성 역사연속성 표식**.

- 육체·등록기록·동반등록물 일부에 같은 출발 식별을 남김
- 이동 중 여행자의 주관적 연속성 유지에 기여
- 시간선 변경 뒤 기억·법적신분·귀환자격이 즉시 전부 덮이지 않도록 지연
- 사용할수록/버틸수록 역사주소 부채 증가
- 독립 휴대 유산 아님

---

## 2. F0 출발 당시 관계

F0의 정식 파견에서:

1. 요원 등록
2. 출발 인장 생성/대조
3. 동반물 등록
4. R04 귀환패에 요원식별·귀환 보조정보 연결
5. 장치가 도약

순서로 작동한다.

R04는 출발 인장을 **담는 유일한 그릇**이 아니다.

여행자 몸·요원등록·동반 기록에도 출발 식별흔적이 분산된다.

따라서 R04가 파손돼도 출발 인장이 즉시 사라지지 않는다.

---

## 3. 왜 R-ID가 없는가

R01–R12는:
- 별도 소유권
- 보관·이전
- 공동사용
- 봉인/반환/파괴

을 추적해야 하는 물건·공공유산이다.

출발 인장은:
- 개인에게 종속
- 양도 불가
- 따로 보관 불가
- 다른 사람이 장착해 동일 권리 획득 불가

이므로 **Collection R-ID 대상이 아니다.**

장부에는 인물 상태/역사주소 부채로 추적한다.

---

## 4. 출발 인장이 하는 것

가능:
- 여행자가 `이전 미래가 달랐다`는 변화감지를 일정 기간 유지
- 장비·기록이 여행자를 이전 등록신분과 연결할 수 있게 도움
- P0–P2 변경 중 주관적 연속성 완충
- 귀환·신분 검증 시 하나의 근거

불가능:
- F0를 물리적으로 보존
- 모든 과거 기억 완벽 보존
- 법적신분 영구 유지
- 고정점 무시
- 주소부채 제거
- 죽음 복구

---

## 5. V5 R04 소모와 V11 출발 인장

V5에서 R04의 F0 잔류서명을 고립자 구조와 현재 주소 고정에 사용해 대부분 소모한다.

이후:
- R04 장비기능은 크게 약화.
- 하지만 에이든 몸/등록 흔적에 남은 출발 인장은 지속.

V11 E257–E260의 제한실험은 바로 이 개인 인장의 한계를 보여준다.

- 기록 한 줄 소실
- 장비가 서로 다른 이름으로 인식
- 관계 탈락
- 귀환자격 불안정

즉 R04가 남아 있어서 버티는 것이 아니라 **출발 인장도 이미 부식되고 있음**을 보여준다.

---

## 6. 장비마다 다른 이름을 읽는 이유

모든 장비가 동일 데이터 원본을 보지 않는다.

- R04/귀환계통: F0 등록잔향
- 경계갑: 현재 몸주소/공적 이름
- 귀환석: 현재 고정망과 귀환가능 주소
- 기록소: 현 시간선 공공 신분

시간선이 흔들리면 서로 다른 층이 다른 시점의 에이든을 가리킬 수 있다.

이것은 다중인격이나 평행세계 복제가 아니다.

하나의 사람을 여러 주소체계가 다르게 식별하는 현상이다.

---

## 7. V14 R04 봉인

E349에서 공개검증하는 대상은 R04 F0 귀환패.

결론:
- F0 자체를 되살리는 열쇠 아님.
- 현재 존재하는 귀환망과 연결하는 보조식별자였음.

따라서 공공 분산봉인 가능.

R04 봉인 뒤에도 에이든 개인의 출발 인장/역사주소는 남아 있을 수 있다.

---

## 8. V15 최종 비용

에이든이 마지막 다리로 쓰는 것은:

**R04 물건 자체가 아니라 자기 출발 인장 + 역사주소.**

그 비용으로:
- 공적 이름
- 법적 과거
- 귀환권
- 다수 사람의 관계기억

이 소실된다.

R04를 다시 꺼내 해결하는 우회는 금지.

---

## 9. 금지

- 출발 인장을 궁극 유물로 취급
- 다른 사람에게 이식해 기억면역 부여
- R04와 출발 인장을 문맥에 따라 같은 물건/다른 물건으로 임의 변경
- R04 봉인을 풀면 에이든 역사주소 복원
- 출발 인장 손상 = 즉시 신체사망
- 출발 인장 강화 = 시간 초능력 상승
