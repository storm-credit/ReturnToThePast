## Definition

시간여행은 영혼의 회귀나 기억 전송이 아니라, 왕국 문명장치가 사람의 육체·기억·소지품을 특정 역사적 주소로 옮기는 위험한 국가 운영 행위다.

## What Travels

- 여행자의 현재 육체
- 여행자의 주관적 기억
- 장치가 ‘동반 등록’한 소지품
- 출발 인장이 새겨진 제한된 기록

등록되지 않은 물건, 생물, 대규모 무기와 군대는 원칙적으로 이동할 수 없다.

## Five Distributed Keys

1. **왕좌 인장 — 승인권**  
   누가 시간 개입을 할 법적 권리가 있는지 정한다.

2. **성당력 — 동기화권**  
   연·월·일이 아니라 해당 시대의 성력·천문·의례 주기를 맞춘다.

3. **마탑 관측반 — 좌표권**  
   도착 장소와 오차 범위를 계산한다.

4. **왕실 연대기 — 주소권**  
   사람·사건·장소의 ‘진명’을 역사 속 주소로 지정한다.

5. **국경 고정석 — 귀환권**  
   여행자가 돌아올 미래와 육체를 붙잡는 앵커다.

현장 요원은 다섯 권한 중 어느 것도 단독으로 소유하지 않는다.

## Departure

- 최소 한 개의 역사적 증거와 한 명의 현지 연결점이 필요하다.
- 존재하지 않았거나 기록이 완전히 소거된 날짜로 갈 수 없다.
- 도착 시점은 ‘정확한 하루’보다 사건의 인과 범위로 지정된다.
- 좌표 오차는 거리, 시간, 신체 손상 중 하나 이상으로 발생한다.

## Arrival

- 여행자는 도착 직후 현지 역사에 자동으로 자연스러운 신분을 얻지 않는다.
- 신분·언어·통화·법적 권리는 별도 준비가 필요하다.
- 현지인은 독립된 목적을 가지며 미래를 위해 협조할 의무가 없다.
- 동일 인물의 더 어린 또는 더 늙은 버전과 공존할 수 있다.

## Return

- 출발 당시의 미래로 돌아간다는 보장은 없다.
- 귀환은 ‘현재 존재하는 미래의 고정석’으로 연결된다.
- 개입으로 고정석이나 운영기관이 사라지면 여행자는 다른 미래·다른 지역으로 귀환하거나 시대에 고립된다.
- 현지 앵커가 귀환을 거부하거나 파괴하면 강제 귀환은 불가능하다.

## Timeline Model

### Single Mutable Timeline
- 역사적 변경이 충분한 원인을 형성하면 개입 시점 이후가 덮어써진다.
- 덮어쓰기 전 시간선은 현실로 공존하지 않지만 ‘팔림프세스트 잔흔’으로 일부 기록·꿈·상처에 남는다.
- 잔흔은 정보 자원이며 동시에 정신오염·정치 선전의 도구가 될 수 있다.

### Correction Threshold
사소한 행동은 기존 인과에 흡수된다. 다음 중 하나가 바뀌면 미래 덮어쓰기가 발생한다.

- 왕위 계승
- 대규모 생존·사망
- 시간장치 운영권
- 핵심 치료·무기·교리의 배포
- 국경·수도·성당·마탑의 제도적 선택
- 기록의 진명과 공인 역사

## Fixed Points

고정점은 신이 정한 불변 운명이 아니라 **원인이 너무 많이 연결된 고관성 사건**이다.

- 표면적 인물·날짜·장소는 바꿀 수 있다.
- 상위 원인을 건드리지 않으면 동일 기능의 사건이 다른 형태로 재발한다.
- 고정점을 진짜로 바꾸려면 여러 시대와 기관의 원인을 동시에 수정해야 한다.
- ‘막을 수 없는 운명’이라는 설명만으로 실패를 강제하지 않는다.

## Memory Continuity

- 파견 중인 여행자는 출발 인장 덕분에 시간선 변경을 체감한다.
- 귀환 후 인장이 약해지면 이전 미래의 세부 기억이 부식된다.
- 기록관은 외부 기억 저장소로 보완하지만 그 기록도 완전하지 않다.
- 현지 앵커는 이전 미래를 기억하지 않지만 여행자의 행동과 남겨진 물건을 증거로 판단할 수 있다.
- 적대 세력도 별도의 기억 보존법을 가질 수 있다.

## Temporal Debt

시간여행의 비용은 ‘감정을 하나 잃는다’로 고정하지 않는다.

- 육체 노화와 감각 손상
- 역사적 신분 약화
- 출발 미래의 자원 소모
- 귀환 좌표 상실
- 다른 지역·계층의 권리 소거
- 이전 시간선 기억의 부식
- 시간장치 운영기관의 권력 강화
- 다른 가능성을 현실에서 폐기한 윤리적 책임

## Duplicate-Self Rule

- 서로 다른 주관적 나이의 동일인은 공존 가능하다.
- 접촉만으로 세계가 폭발하지 않는다.
- 두 사람이 서로의 핵심 선택을 직접 바꾸면 기억·육체·신분에 공명 손상이 생긴다.
- 자기 자신을 살해해도 자동으로 현재 여행자가 사라지지는 않지만 출생·승인·귀환 조건을 잃을 수 있다.

## Absolute Limits

- 무한 반복 불가
- 임의 날짜 선택 불가
- 대규모 군대 이동 불가
- 자동 귀환 불가
- 죽음 자동복구 불가
- 모든 변경을 완벽히 기억할 수 없음
- 한 번의 암살로 문명 규모의 고정점을 제거할 수 없음
