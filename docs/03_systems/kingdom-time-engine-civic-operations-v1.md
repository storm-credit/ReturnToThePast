## Seven Governable Authorities

아홉 원리 중 몸과 대가는 완전 위임할 수 없다. 제도는 몸을 기록할 수 있으나 당사자의 고통을 대신할 수 없고, 대가를 계산할 수 있으나 사라질 가능성의 윤리를 제거할 수 없다. 따라서 실제 운영권은 기존 다섯 열쇠에 시민 감사와 부담 배분을 더한 일곱 축으로 설계한다.

1. 승인
2. 동기화
3. 좌표
4. 역사 주소
5. 귀환
6. 부담 배분
7. 감사·이의제기

## Abuse Cases

- 부담 배분 권한을 숨기고 자연재해로 위장
- 감사 기록을 역사 주소에서 제거
- 의료 인장을 이용해 정치적 반대자를 환자로 분류
- 토지대장을 수정해 지역 자체를 약화
- 귀환 수용 거부로 실패 요원을 과거에 버림

## Reform Constraint

권한을 분산하면 공정성과 이의제기는 늘지만 긴급 대응은 느려진다. 결말은 장치 파괴만이 아니라 어떤 권한을 지역·종족·개인에게 돌리고 어떤 중앙 기능을 유지할지 결정해야 한다.

## Plot Uses

각 Grand Act는 최소 하나의 원리와 하나의 운영권을 중심 갈등으로 다룬다. 동일한 '부품 회수' 구조를 반복하지 않고 법·의례·전쟁·구조·협상·증언을 통해 권한을 바꾼다.
