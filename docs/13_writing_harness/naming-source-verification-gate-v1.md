# 명명 원문 검증 게이트 v1

Status: AUTHOR-DIRECTED PRODUCTION RULE — REVIEW REQUIRED  
Owner: A00 Story Orchestrator / A02 Canon Controller  
Applies To: 신규 명명, 기존 이름 평가, 개명 후보 제시, 원고 용어 교정

## 1. 목적

명칭을 자연스럽게 다듬는다는 이유로 장소의 구조, 기관의 권한, 종교의 기능, 장비의 작동 방식, 시간 규칙을 임의로 바꾸는 일을 금지한다.

명명 감사는 어감 평가보다 **설정 원문 확인이 먼저**다.

## 2. 필수 원문 확인 순서

이름을 평가하거나 후보를 제시하기 전에 다음 자료를 실제로 읽는다.

1. 작가의 최신 명시 결정
2. Canon Constitution / Amendment / Decision Log
3. 해당 명칭이 등록된 naming pack 또는 index
4. 대상의 기능과 구조를 설명하는 Domain Bible
5. 해당 장소·기관·장비가 쓰이는 Story Architecture / Crosswalk
6. 현재 원고와 Context Pack
7. Legacy 문서는 정본 자료가 부족할 때만 참고하며 정본으로 승격하지 않는다.

검색 결과의 파일명이나 짧은 문구만 보고 판단하지 않는다. 관련 문단을 열어 구조·기능·역사·사용 장면을 확인한다.

## 3. 후보명 제시 전 증거표

각 후보에는 다음 항목을 먼저 작성한다.

| 항목 | 확인 내용 |
|---|---|
| 현재 이름 | 정본·작업명·일상명 구분 |
| 대상 유형 | 사람 / 장소 / 조직 / 장비 / 현상 |
| 물리 구조 | 실제 형태와 수량 |
| 설정 기능 | 서사와 세계에서 수행하는 역할 |
| 역사적 의미 | 이름이 가리키는 사건·기억·문화 |
| 사용 장면 | 누가 어떤 상황에서 부르는가 |
| 잠금 수준 | HARD / SOFT / WORKING / 후보 |
| 확인한 원문 | 파일 경로와 관련 문단 |
| 변경 위험 | 구조·인과·문화·복선 손상 가능성 |

이 표를 채울 수 없으면 후보명을 제시하지 않고 `설정 확인 필요`로 중단한다.

## 4. 금지 규칙

다음을 금지한다.

- 설정집을 읽지 않은 상태에서 `실제로 2개라면`, `마법기관이라면`처럼 조건부 추측으로 개명안 제시
- 이름의 표면 뜻만 보고 물리 구조를 추정
- 고유명사를 단순화하면서 복선·역사·주민 인식을 삭제
- 어감 개선을 이유로 기관 권한·계급·종족·시간 모델 변경
- 한 문서의 명명표만 보고 Domain Bible과 Story Architecture를 생략
- 검색 결과가 없다는 이유로 설정이 없다고 단정

## 5. 장소명 추가 검사

장소명은 최소한 다음을 확인한다.

- 하나의 장소인가, 여러 장소의 연합인가
- 현재 물리 구조와 과거 구조가 같은가
- 지도상의 명칭과 주민의 호칭이 같은가
- 이름이 지형을 뜻하는가, 역사적 사건을 뜻하는가
- 시간선 변화로 서로 다른 기억이 겹친 장소인가
- 이름 변경이 장소의 미스터리나 복선을 노출하거나 삭제하는가

`쌍성`, `이중성`, `두겹성`, `반쪽성`처럼 수량이나 구조를 암시하는 말은 실제 구조와 설정 의미를 확인하지 않고 상호 치환하지 않는다.

## 6. 라베른 사례 정정

### 확인된 설정

- 작업명: `반쪽성`
- 명명 패키지의 정식명 후보: `두겹성 라베른`
- 물리 구조: 지도에는 **한 성**으로 기록됨
- 핵심 설정: 주민들이 같은 성을 **서로 다른 두 역사**로 기억함
- 서사 기능: 첫 개혁가의 실제 역할과 지역 대피를 드러내는 V1 핵심 장소

### 잘못된 판단

- `라베른 쌍성`: 성이 2개라는 물리 구조로 오해하게 하므로 부적합
- `라베른 성`: 일반명으로 단순화할 수는 있으나, 두 역사가 겹친다는 장소의 핵심 정체성을 삭제할 위험이 있어 근거 없이 채택 금지

### 현재 판정 — 해소됨 (DEC-015)

정식명은 **`두 역사의 라베른`**으로 확정됐다. 작가 승인 2026-08-08.

`두겹성`이 부적합했던 이유는 말맛이 아니라 **지시 대상 오류**다. 이 장소에서 겹치는 것은 성이 아니라 주민의 기억이므로, `겹`을 구조 수식어로 쓰면 성이 둘이라는 오독을 다시 만든다. `두 역사의`는 겹치는 대상을 역사로 명시해 이 문제를 제거하면서 `한 성에 두 역사가 겹친 장소`라는 기능을 보존한다.

작업명 `반쪽성`은 검색용 별칭으로 보존한다 (naming-pack §10).

이 절은 사례 기록으로 유지한다. 원문 확인 없이 제시됐던 `라베른 쌍성`과 자동 단순화 `라베른 성`은 철회 상태 그대로다.

## 7. 에이전트 책임

- A03: 지리·물리 구조와 지역 역사 확인
- A02: 잠금 수준과 변경 범위 확인
- A12/A13: 장소의 서사 기능과 연속성 확인
- A19: 한국어 입말과 낭독 자연스러움 검사
- A16: 설정을 읽지 않은 표면 개명과 의미 손실 공격
- A17: 확인한 원문과 실제 변경 파일 검증

## 8. 차단 기준

다음은 S1 차단이다.

- 원문 확인 없이 정본 이름의 폐기·교체를 권고함
- 물리 구조를 잘못 이해한 후보를 제시함
- 개명으로 장소의 복선·역사·기관 권한이 달라짐
- 후보의 출처와 변경 위험을 기록하지 않음

S1이 해소되기 전에는 개명 PR을 생성하거나 원고에 새 이름을 적용하지 않는다.
