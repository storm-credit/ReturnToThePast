# Anti-Padding Manuscript Policy v1

Status: CANON-OPERATIONS / HARD STOP
Applies To: E001–E375 manuscript drafting, revision, read-aloud audit, release gate

## 1. Core Rule

최소 분량은 장면을 충분히 구현했는지 확인하는 하한선이지, 문장을 늘리라는 지시가 아니다.

다음 방식으로 분량을 채우는 것을 금지한다.

- 이미 전달한 정보를 다른 표현으로 반복
- 감정이 드러난 뒤 감정을 다시 설명
- 공간·날씨·사물을 사건과 무관하게 길게 묘사
- 모든 동작에 촉감·소리·시선을 덧붙임
- 같은 판단을 독백·대사·서술로 반복
- 의미 없는 이동·준비·정리 동작 추가
- 장면 종료 뒤 주제문·격언·의미 해설 추가
- 장면 기능 없이 생활 디테일만 연속 삽입
- 짧게 끝날 사건을 문장 길이와 수식어만 늘려 확장

## 2. If a Draft Is Under Minimum Length

공백 포함 7,000자 미달이면 A18 Prose가 문장을 늘리지 않는다.

반드시 H5 Scene Architecture로 되돌아간다.

다음 순서로 점검한다.

1. 정본 설계에 있는 기능 비트 중 실제 장면으로 충분히 구현되지 않은 것이 있는가.
2. 인물의 목표·방해·선택·비용 중 원고에서 생략된 단계가 있는가.
3. 이동·부상·보급·법적 후과·기관 반응 등 이미 정본에 예정된 후과가 빠졌는가.
4. 증거 검증·대조·실패·반대 논리 등 사건 이해에 필요한 행동 장면이 빠졌는가.
5. Q/S/E/X 밀도에 필요한 실제 장면 수가 충족됐는가.

보강은 위 항목처럼 **사건을 움직이는 장면 기능**으로만 한다.

## 3. What May Be Added

새 사건·새 설정·새 인물 의도를 만들지 않는 범위에서, 이미 승인된 정본과 Episode CP가 요구하는 기능을 장면으로 구체화할 수 있다.

허용 예:

- 설계에 적힌 충돌을 실제 대면·행동으로 펼침
- 선택 전에 필요한 검증 절차를 실제 행동으로 보여 줌
- 선택의 즉시 비용과 후과를 현장에서 확인
- 반대 세력이 가진 합리적 이유를 실제 행동과 결과로 구현
- 이동·보급·치료·행정·법적 처리처럼 다음 장면에 영향을 주는 과정 구현
- 장면 안에서 위치·거리·행동 결과를 이해시키는 최소 묘사

## 4. What Must Not Be Invented

분량 확보를 이유로 다음을 추가하지 않는다.

- Story Architecture에 없는 새 사건
- 캐릭터의 새 비밀·트라우마·관계 변화
- 새 세계관 규칙·기관 권한·시간법칙
- 새 복선·맥거핀·반전
- 새 적대세력의 행동
- 결말이나 미스터리 공개시점 변경

이 중 하나가 필요해 보이면 A18이 쓰지 않고 A02/A12/A13으로 되돌려 설계 변경 승인을 받아야 한다.

## 5. Hard Stop

정본 기능을 충분히 구현했는데도 7,000자 미달이면 원고를 억지로 늘리지 않는다.

판정은 `BLOCKED — LENGTH REQUIRES DESIGN REVIEW`이다.

A18은 추가 집필을 중단하고 A12 Story Architecture, A13 Continuity, A16 Red Team에 이관한다.
작가 승인 또는 설계 보강 없이 분량만 늘려 PASS 처리할 수 없다.

## 6. Anti-Padding Audit

A19/Human Prose Audit은 각 화에서 다음을 별도로 확인한다.

- 이 문단을 삭제해도 사건·선택·비용·정보가 그대로인가.
- 같은 정보가 2회 이상 다른 표현으로 반복되는가.
- 묘사가 인물의 다음 판단·행동·공간 이해 중 아무것도 바꾸지 않는가.
- 장면 수가 부족한데 문장 길이만 길어진 것은 아닌가.
- 7,000자 직전 구간에서 설명·감각·내적 독백 밀도가 비정상적으로 증가하는가.

위 항목이 반복되면 `REVISION REQUIRED` 또는 `BLOCKED`이다.

## 7. Release Rule

분량 PASS는 다음을 모두 만족할 때만 인정한다.

- 공백 포함 최소 7,000자
- Q/S/E/X 실제 장면 밀도 충족
- 각 장면에 목표·방해·선택/변화·비용 또는 후과가 존재
- 최소 분량용 반복·장식 묘사 없음
- 새 Canon 사실 생성 없음

`7,000자 이상`만으로 원고 품질 PASS를 선언할 수 없다.
