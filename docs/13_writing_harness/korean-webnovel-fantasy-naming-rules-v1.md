# 한국 웹소설 판타지 명명 규칙 v1

Status: AUTHOR-DIRECTED PRODUCTION RULE — REVIEW REQUIRED  
Owner: A00 Story Orchestrator / A02 Canon Controller  
Scope: 인물·국가·도시·기관·종교·직업·장비·공간·현상·기술 용어의 생성·교체·검수  
Authority: 이 문서는 명명 절차와 문체 기준을 정한다. 기존 정본 명칭을 자동으로 폐기하거나 바꾸지 않는다.

## 1. 목표

이 작품의 이름과 용어는 **한국 웹소설 판타지 독자가 첫 등장과 첫 낭독만으로 대략적인 역할과 분위기를 이해할 수 있어야 한다.**

다음 상태를 피한다.

- 현대 행정기관을 억지 한자 조어로 바꾼 이름
- 모든 말에 `시공·연대·잔흔·각인·성력·마도·결계`를 붙인 이름
- 설정집 안에서는 설명되지만 원고에서 뜻을 해독해야 하는 이름
- 판타지처럼 보이기 위해 평범한 사물까지 고유명사화한 이름
- 라틴·그리스·북유럽·영어식 어감을 근거 없이 한 문화 안에 섞은 이름
- 유명 신화·게임·소설의 고유명사를 그대로 빌려 온 이름

## 2. 핵심 원칙

### 2.1 고유명사는 적게 사용한다

고유명사를 우선 부여할 대상:

- 국가와 수도
- 대도시·영지·산맥처럼 반복 등장하는 주요 지역
- 왕조·기사단·마탑·교단·길드처럼 독립 정체성이 있는 대형 조직
- 서사의 핵심이 되는 단 하나의 유물·장치·의식
- 실제 역사와 문화가 있는 종족·가문·신앙

고유명사를 만들지 않는 것이 기본인 대상:

- 일반 방·복도·회의실·지휘실
- 평범한 통신·관측·기록 도구
- 일회성 내부 부서
- 현장 상태와 장애 보고
- 독자가 기능만 알면 되는 표·명부·보고서

이름을 만들지 않고 행동과 물성으로 설명하는 편이 더 자연스러우면 설명을 택한다.

### 2.2 이름은 기능 설명을 대신하지 않는다

처음 등장한 이름은 문맥만으로 최소한 다음 중 하나를 알 수 있어야 한다.

- 사람인가, 장소인가, 조직인가, 물건인가
- 왕실·성당·마탑·군대·학교 중 어디에 속하는가
- 장면에서 무엇을 할 수 있는가

이름만 제시한 뒤 별도 설정 설명이 없으면 이해할 수 없는 경우, 이름을 단순화하거나 일반명으로 되돌린다.

### 2.3 한국어 입말과 낭독을 우선한다

다음 문장 안에서 자연스럽게 불릴 수 있어야 한다.

- `___에서 사람이 왔다.`
- `___의 승인이 필요하다.`
- `___ 소속이다.`
- `___로 가자.`
- `___가 무너졌다.`

입으로 말했을 때 끊기거나, 같은 음절이 반복되거나, 조사와 붙었을 때 뜻이 흐려지면 탈락시킨다.

### 2.4 익숙한 장르어를 억지로 대체하지 않는다

역할이 정확하다면 다음과 같은 한국 웹소설 판타지의 익숙한 일반어를 사용할 수 있다.

- 왕국, 제국, 공국, 왕도, 영지
- 왕실평의회, 기사단, 근위대, 사령부
- 마탑, 대성당, 수도원, 교단
- 길드, 상단, 기록원, 도서관, 서고
- 아카데미, 병동, 치료소, 구호소
- 지휘실, 회의실, 연구실, 기록실

단, 익숙하다는 이유만으로 기능이 다른 조직에 붙이지 않는다.

- `아카데미`: 귀족·기사·마법사 등 전문 인력을 체계적으로 교육하는 중심기관에만 사용
- `기사단`: 실제 기사 신분·서약·지휘체계가 있을 때만 사용
- `마탑`: 마법 연구·면허·교육·관측 등 마법사 조직일 때만 사용
- `차원`: 세계관이 실제로 차원 또는 평행공간을 다룰 때만 사용

이 작품의 기본 시간모델은 단일 가변 시간선이므로, `차원`을 `시간여행`의 멋있는 동의어로 자동 사용하지 않는다.

## 3. 금지에 가까운 조어 방식

다음 패턴은 원칙적으로 경보 처리한다.

### 3.1 기능어 3개 이상 압축

예:

- 연대 + 출발 + 귀환 + 원
- 지역 + 시공 + 감찰 + 원
- 생존 + 계수 + 판

여러 기능을 한 이름에 압축하지 않는다. 조직의 대표 기능 1개만 이름에 남기고 나머지는 설명과 조직도에서 처리한다.

### 3.2 분위기 접두어 자동 부착

`시공·연대·잔흔·각인·성력·마도·결계`는 실제 설정상 독립된 뜻이 있을 때만 쓴다.

단순히 판타지처럼 보이게 하려고 다음처럼 붙이지 않는다.

- 마도조율판
- 시공잔향
- 각인상실자
- 잔흔감찰실
- 결계핵

### 3.3 일반 사물의 과잉 고유명사화

도구 이름을 새로 만들기 전에 다음 순서로 검토한다.

1. 그냥 행동으로 묘사할 수 있는가
2. 기존 일반명으로 충분한가
3. 재질과 형태를 짧게 붙이면 되는가
4. 여러 화에서 핵심 자산으로 반복되는가

4번까지 충족하지 않으면 고유 장비명을 만들지 않는다.

### 3.4 뜻이 겹치는 추상명사 결합

다음처럼 서로 비슷한 추상어를 이어 붙이지 않는다.

- 역사주소층
- 존재각인표식
- 시공연대잔향

독자가 이해해야 할 실제 현상을 문장으로 설명한다.

## 4. 대상별 명명 규칙

### 4.1 국가와 수도

- 국가는 `고유명 + 왕국/제국/공국`처럼 단순하게 구성한다.
- 수도는 `왕도 + 도시명` 또는 도시명만 쓴다.
- 국가명과 수도명은 서로 다른 대상임을 원고에서 분명히 한다.

예시 구조:

- 국가: `칼레온 왕국`
- 수도: `아르켄`
- 서술형 호칭: `왕도 아르켄`

이 예시는 구조 설명이며, 별도 정본 변경 승인을 대신하지 않는다.

### 4.2 지역과 지형

- 독자가 지도 없이도 지형을 상상할 수 있는 일반명을 사용한다.
- `영역`은 마법적 경계나 법적 특수구역일 때만 쓴다.
- 일반 재난지역에는 `지대·구역·변경·평원·산맥·해안`을 우선한다.
- `쌍성`은 실제로 2개의 성이 한 체계를 이룰 때만 사용한다.

### 4.3 학교와 교육기관

- 일반 학교: 학교, 학당
- 종교 교육: 신학교, 수도원 학교
- 전문 엘리트 교육: 아카데미
- 마법 전문 교육: 마법 아카데미 또는 마탑 산하 교육부

`아카데미`는 장르적으로 자연스럽지만 모든 학교를 아카데미로 바꾸지 않는다.

### 4.4 왕실과 행정기관

- 왕조명이나 도시명을 앞에 붙이고, 뒤에는 익숙한 기능어 1개를 둔다.
- `평의회·사령부·기록원·재판소·기사단`처럼 역할이 분명한 말을 우선한다.
- `국·원·실`을 연속해서 늘어놓지 않는다.
- 내부 부서는 외부 독자가 자주 볼 필요가 없다면 일반명으로 둔다.

### 4.5 종교와 교리

- 종교명·교단명·대성당명·교리명을 한꺼번에 만들지 않는다.
- 먼저 신화, 숭배 대상, 성직체계, 의례가 실제 장면에 존재하는지 확인한다.
- 숫자를 붙인 교리는 숫자의 기원과 상징이 원고에서 반복적으로 드러날 때만 명명한다.
- `구흔교리`처럼 한자를 알아야 뜻이 보이는 축약명은 사용하지 않는다.
- 독자가 개념을 알기 전에는 `9개의 상처에 관한 교리`처럼 풀어 쓴다.

### 4.6 시간여행 관련 용어

- `시간여행·과거 파견·귀환·출발·도착`처럼 바로 이해되는 일반어를 우선한다.
- 시간여행자를 반드시 별도 종족명이나 직업명으로 만들 필요는 없다.
- 실제 조직과 계급이 확정되기 전에는 `파견자·요원·기사`를 임의로 격상하지 않는다.
- `시공·차원·연대` 중 하나를 작품 전체 공통 접두어로 자동 통일하지 않는다.
- 시간 현상은 이름보다 관찰 가능한 결과를 먼저 쓴다.

### 4.7 장비와 마법 도구

- 형태, 재질, 사용 동작이 장면에 보이게 한다.
- 현대 장비의 기능을 그대로 옮겨 놓고 이름만 판타지식으로 바꾸지 않는다.
- 하나의 물건이 화면·통신기·신분증·태블릿 역할을 모두 하지 않게 한다.
- 이름이 필요한 경우에도 2~4음절 또는 익숙한 일반명 조합을 우선한다.

### 4.8 현상과 피해자 집단

- 사람 집단을 현상명 하나로 낙인찍지 않는다.
- `주소상실자`, `무명자`, `각인상실자`처럼 설정을 알아야 이해되는 명칭은 자동 채택하지 않는다.
- 원고에서는 먼저 `기록에서 이름이 사라진 사람들`처럼 풀어 쓴다.
- 집단이 스스로 사용하는 이름, 행정기관의 분류명, 멸칭을 구분한다.

## 5. 라틴·그리스로마·북유럽식 명명 사용 규칙

외국어·신화 계열은 이름을 멋있게 만드는 장식이 아니라 **문화권별 음운과 역사적 인상을 일관되게 만드는 참고 틀**로만 사용한다.

### 5.1 공통 규칙

- 문화권 하나에 주된 어원 계열 하나를 정한다.
- 같은 지역에서 라틴식, 고대그리스식, 북유럽식, 현대영어식을 무작위로 섞지 않는다.
- 실제 신·영웅·유물의 유명한 이름을 그대로 사용하지 않는다.
- 어근을 참고하더라도 한국어로 읽기 쉬운 2~4음절 이름으로 다시 다듬는다.
- 실제 언어의 정확한 문법을 흉내 낸다고 주장하지 않는다.
- 참고 어원보다 작품 내부의 발음 일관성과 독자 기억성을 우선한다.

### 5.2 라틴 계열

어울리는 영역:

- 왕국·제국의 수도권
- 왕실, 법, 행정, 군단
- 기록원, 아카데미, 학술기관

장점:

- 제국적·법률적·고전적인 인상
- 한국어 판타지 인명과 도시명으로 다듬기 쉬움

주의:

- 실제 라틴어 단어를 길게 그대로 쓰지 않는다.
- 모든 기관을 `-움·-우스·-아`로 끝내지 않는다.
- 법률용어를 직역해 관료제 이름으로 만들지 않는다.

### 5.3 고대그리스·그리스로마 신화 계열

어울리는 영역:

- 신전, 예언, 별, 운명, 의술, 학문
- 오래된 유적과 신화 시대

장점:

- 신화적·비극적·천문학적 인상

주의:

- 제우스, 아테나, 아폴론, 크로노스, 타르타로스처럼 즉시 연상이 강한 이름은 그대로 사용하지 않는다.
- 유명 신화의 관계와 사건을 그대로 옮기지 않는다.
- `아카식 레코드`는 그리스로마가 아니라 근대 오컬트 계열의 널리 쓰인 개념이다. 실제로 세계 전체의 초월적 기록층이 정본에 존재할 때만 A15 유사성 감사를 거쳐 사용한다.

### 5.4 북유럽·북부유럽 계열

어울리는 영역:

- 북부 변경, 산악·설원 지역
- 전사 가문, 항해민, 룬 문화
- 거친 기후와 오래된 요새

장점:

- 짧고 단단한 인명, 변경·전사 문화와 잘 맞음

주의:

- 오딘, 토르, 로키, 발할라, 라그나로크를 그대로 쓰지 않는다.
- 북부 사람의 이름을 모두 거친 자음과 `-손`으로 통일하지 않는다.
- 북유럽풍 이름을 남부 성당·중앙 왕실·해안도시에 무작위로 섞지 않는다.

### 5.5 권장 적용 방식

각 문화권 Bible에 다음 표를 만든 뒤 이름을 생성한다.

| 항목 | 기록 내용 |
|---|---|
| 참고 어감 | 라틴 / 그리스 / 북유럽 / 독자 창작 |
| 허용 음절 | 자주 쓰는 초성·중성·받침 |
| 이름 길이 | 개인명·도시명·가문명별 범위 |
| 직함 방식 | 이름 앞/뒤, 세습/임명 여부 |
| 지명 접미 | 성·항·산·분지 등 |
| 금지 혼합 | 같은 문화에 섞지 않을 계열 |
| 대표 예시 | 정본으로 승인된 이름만 |

   - A10: 장비·유물·문서
4. **A15 Similarity Audit** — 실존 신화·언어·유명 작품과의 직접 연상 및 차용 위험 검사
5. **A19 Sentence Narration & Korean Prose Audit** — 한국어 입말, 첫 청취, 조사 결합, 호칭과 문장 속 사용 검사
6. **A16 Red Team** — AI 조어, 과잉 고유명사, 문화 혼합, 설정 강의 필요 여부 공격
7. **A17 GitHub State Verifier** — 변경 파일, 브랜치, PR, merge, main 반영 확인

A20 Storycraft Director는 이름이 장르 약속·정보 공개·반복 리듬에 영향을 줄 때만 보조로 참여한다. 명칭 자체를 A20이 단독 설계하지 않는다.

### 정본 개명 정족수

기존 정본 이름을 바꿀 때:

- A00 + A02 + 영향 Domain + A13 + A15 + A16
- 작가의 명시적 이름 승인
- 전체 참조 검색과 영향표
- Amendment 또는 Decision Log 필요 여부 판정
- 원고·Bible·Architecture·CP·검증기 일괄 갱신

## 7. 7단계 합격 검사

후보 이름마다 다음을 검사한다.

1. **첫 청취 검사**: 한 번 들으면 발음과 단어 경계를 알 수 있는가
2. **기능 추정 검사**: 설명 없이 사람·장소·조직·물건 중 무엇인지 짐작 가능한가
3. **대사 삽입 검사**: 실제 대사 3개에 넣었을 때 자연스러운가
4. **장르 검사**: 한국 웹소설 판타지의 문장 안에서 튀지 않는가
5. **과잉 조어 검사**: 일반어로 충분한데 새 말을 만들지 않았는가
6. **문화 일관성 검사**: 같은 문화권의 기존 이름과 음운·어원이 맞는가
7. **유사성 검사**: 유명 신화·게임·소설 고유명사를 직접 연상시키지 않는가

1개라도 중대한 실패가 있으면 정본 후보로 올리지 않는다.

## 8. 검수 출력 형식

기존 원고를 검수할 때는 수정이 필요한 항목만 다음 형식으로 제시한다.

`위치 / 기존 명칭 또는 문장 / 문제점 / 분류 / 교체 원칙 / 후보 최대 4개 / 정본 변경 필요 여부`

후보를 바로 확정하지 않는다. 작가가 승인한 이름만 정본 치환 대상으로 삼는다.

## 9. 현재 명칭에 대한 적용 제한

이 규칙을 등록하는 것만으로 현재 정본 명칭이 자동 변경되지는 않는다.

다음은 별도 전수감사 대상이다.

- 국가·수도·권역
- 왕실·성당·마탑·기록기관·귀환기관
- 시간여행자와 파견 조직
- 종교·교리·신화 용어
- 기록·주소·소거 관련 용어
- 원고의 현대식 장비·상황실 표현

전수감사 결과와 작가 승인 전에는 새로운 대체 이름을 원고에 임의 반영하지 않는다.
