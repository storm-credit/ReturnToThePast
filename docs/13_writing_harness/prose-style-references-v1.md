# 문체 참고 작가·작품 v1

Status: REVIEW — AUTHOR APPROVAL REQUIRED
Owner: A20 Storycraft Director
Applies To: E001–E375 원고 산문
Rule: **문장을 베끼지 않는다. 패턴을 배운다.** 직접 차용 의심 표현은 A15 유사성 감사를 통과해야 한다.

## 0. 왜 필요한가

현행 문체 규격은 **금지 목록**뿐이다 — 번역체 금지, 격언 금지, 톤태그 금지. 금지만 주면 에이전트는 금지를 피하는 방법 하나를 찾아 반복한다. 실제로 그렇게 됐다 (`-고,` 63%, 손 독식 18회차).

「이렇게 써라」의 표본이 필요하다. 이 문서는 그 표본의 **출처 목록**이다.

## 1. 대원칙 — 번역서는 문장 표본이 아니다

**번역서의 문체는 번역가의 한국어다.** 번역서에서 문장 표면(리듬·어미·조사 운용)을 배우면 그게 곧 번역체다 — 작가가 명시적으로 싫어하는 축.

| 배울 수 있는 것 | 어디서 |
|---|---|
| 문장 표면 — 리듬·어미·조사·호흡 | **한국어 원작에서만** |
| 정보 배분·시선 운용·장면 설계 | 번역서도 가능 |

## 2. 한국어 원작 — 문장 표면까지 배운다

| 작가 · 작품 | 배우는 것 | 경계할 것 |
|---|---|---|
| **김훈 《남한산성》《칼의 노래》** | **기관·명분·문서의 언어를 소설 문장으로.** 회의 장면이 문장만으로 긴장을 만든다. 사실 서술이 감정을 대신한다 — 우리 원칙과 동일 | 명사 종결·격언화 리듬. 우리 Hard Stop(격언 2개 초과 금지)과 충돌하는 버릇이므로 **무게만 가져오고 리듬은 가져오지 않는다** |
| **이영도 《눈물을 마시는 새》** | **인물·종족별 화법 분화의 표준.** 레콘·나가·도깨비가 어휘와 호흡부터 다르다 — 화법 규격 8종이 지향하는 상태. 한국 정통 판타지 문장의 기준선 | 만연체 구간. 사변이 길어지는 자리 |
| **정유정 《28》《7년의 밤》** | **몸으로 쓰는 문장.** 감각이 판단으로 이어지는 묘사, 재난 속 다인물 시점 — 신체 채널 배정 작업의 실제 표본 | 스릴러 가속 리듬은 우리 밀도 유형과 다름 |
| **배명훈 《타워》** | **관료제·절차를 지루하지 않게.** 행정 언어의 유머와 정확성. 문서가 사건을 만드는 구성 | 풍자 톤. 우리는 풍자가 아니라 체중 |
| **김언수 《설계자들》** | 한국어 하드보일드. 건조하지만 죽지 않는 문장, 단역의 생활 디테일 | 냉소 과잉 |
| **편혜영 《재와 빨강》** | 재난 이후의 일상을 관찰하는 냉담한 거리. 불안을 형용사 없이 만드는 법 | 인물 온도가 우리보다 낮음 |
| **김초엽 단편들** | 상실·기록의 정서를 담백하게. 설정을 강의하지 않고 감각으로 | — |
| **싱숑 《전지적 독자 시점》** | **375화급 장기 연재의 리듬 관리.** 회차 훅 배치, 짧은 문장을 강조에만 쓰는 절제 | 메타 장치·시스템 창은 우리 세계와 무관 |
| **비가 《화산귀환》** | 대사 중심 리듬, 생활감으로 독자를 붙잡는 법 — 우리에게 부족한 축 | 유머 비중. 톤 이식 금지 |

## 3. 번역서 — 정보 배분과 시선만 배운다

| 작가 · 작품 | 배우는 것 |
|---|---|
| **가즈오 이시구로 《남아 있는 나날》《나를 보내지 마》** | **말하지 않음으로 말하기.** 시점 인물이 못 보는 것·안 보려는 것으로 서사를 끄는 법 — 정보상한 운용의 교과서 |
| **존 르카레 《팅커 테일러 솔저 스파이》** | **기관 내부 대화의 긴장.** 회의·문서·심문에서 누가 무엇을 아는지의 배분. 우리 6기관 승인 장면의 원형 기술 |
| **오가와 요코 《은밀한 결정》** | **소거를 담담하게.** 사라짐을 비명 없이 쓰는 법 — 무명화·기록 소거 장면과 직결 |
| **코맥 매카시 《로드》** | 이동·생존 구간의 최소 문장. 대화가 짧아도 인물이 갈리는 법 — E006~E007형 회차 |
| **테드 창 단편들** | 개념을 감각으로 번역하는 정확성. 시간 규칙을 강의 없이 보여주는 법 |

## 4. 장면 유형 → 표본 매핑

집필·수술 에이전트에게 회차 유형별로 지정한다.

| 장면 유형 | 1순위 | 2순위 |
|---|---|---|
| 기관 회의·청문·승인 | 김훈 남한산성 | 르카레 |
| 이동·황무지·생존 | 매카시 로드 | 정유정 28 |
| 기록·소거·상실 | 오가와 요코 | 김초엽 |
| 대면·심문 (Q형) | 이시구로 | 김언수 |
| 단역·군중 화법 분화 | 이영도 | 김언수 |
| 절차·행정 처리 | 배명훈 | 김훈 |
| 회차 훅·연재 리듬 | 싱숑 | 비가 |

## 5. 내부 표본이 최우선이다

외부 작가보다 먼저 쓰는 표본은 **이 작품 안에 있다.**

- **E023 수술본** — 현행 문체 기준 (V1 정본)
- **E015 물지게꾼** — 단역 화법의 작동 표본
- **작가 직접 수정 E001** — 명료·설명 방향의 기준 (DEC-026)

외부 표본은 내부 표본이 답을 못 주는 자리에서만 참조한다.

## 6. 금지

- 문장·구절 직접 차용 (A15 유사성 감사 대상)
- 번역서에서 문장 표면 모방 (= 번역체 재생산)
- 특정 작가 문체의 전면 이식 — 배우는 것은 **기법 하나씩**이지 목소리 전체가 아니다
- 이 문서에만 있는 사실을 작품 설정으로 사용
