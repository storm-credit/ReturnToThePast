# 📅 제13권 사건 흐름표: 대균열
**"시간이 멈추기까지 5일"**

| 일정 | 화수 | 주요 사건 | 비고 |
| :--- | :--- | :--- | :--- |
| **D+0** | 제1화~제3화 | 인과율 균열 + 미뤄졌던 빚 낙하 + 시간 혼합 + 죽은 자 부활. | 종말 |
| **D+1** | 제4화~제5화 | 항체 광란 + 남은 빚 강제 회수 + 아이리스 방어전. | 카오스 |
| **D+1 (낮)** | 제6화~제7화 | 에이든 목표 재정립: 시간의 심장에서 빚의 귀착을 정해야 한다 + 진격 시작. | 진격 |
| **D+2** | 제8화~제9화 | 발타자르 유령 + 아레시온 부활. | 과거 귀환 |
| **D+3** | 제10화~제11화 | 황제 망령 + 1황자 부활. | 심판 |
| **D+3 (밤)** | 제12화~제13화 | **리아 기억 일부 회복** + 바르칸 동행. | 희망 |
| **D+4** | 제14화~제16화 | 심장 접근 + 항체 총공격 + 아이리스 길 열기. | 돌파 |
| **D+5** | 제17화~제18화 | 찰나 연속 사용(수명↓) + **시간 완전 정지.** | 정지 |
| **D+5 (정지)** | 제19화~제20화 | 에이든 홀로 심장 앞 + 심장에 손을 댐. | 도달 |
| **D+5 (정지)** | 제21화~제23화 | 선택 A/B 제시 + 리아의 눈 움직임. | 선택 |
| **D+5 (정지)** | 제24화~제25화 | "...에이든?" + 결단 보류. 13권 종료. | 종료 |

---
### ⏱️ 속도감 분석
- **총 소요 시간**: 약 **5일 + 시간 정지**.
- **특징**: 후반부는 시간이 멈춘 상태에서 진행. 우주적 스케일.
- **개연성**: 대균열은 인과율 자체의 붕괴. 물리적 시간 개념 무너짐.
