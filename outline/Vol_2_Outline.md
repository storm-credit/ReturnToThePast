# 📜 제2권 세부 개요: 인형사

> **범위**: 제1화 ~ 제25화 (완결)
> **핵심 목표**: 황제의 죽음(고정점) 시각 조작 → 3황자 추대
> **시간 사건**: 고정점 타격
> **대가**: 황제에게 받았던 유일한 칭찬의 기억 상실
> **권상 위치**: 전체 권수 설계표 아크 5 / 제2부 시작

---

## 📽️ 제2권 줄거리 요약 (시놉시스)
**"죽음을 막을 수 없다면, 죽는 시각을 바꿔라."**

학회 사건이 있은 뒤 스무 날 남짓.
회색 도시는 학회 잔당과 제국 경비의 뒤엉킨 숙청 아래 흔들리고, 리아는 여전히 기억을 되찾지 못한 채 펜리르와 검은 시장 의사의 보호 아래 숨어 있다.
에이든과 아이리스는 수도 외곽까지 함께 움직인 뒤, 궁 안과 궁 밖의 역할을 나눈다. 에이든은 황궁 안쪽 손잡이를, 아이리스는 바깥 하층 연락선을 맡는다.
에이든은 회색 도시를 지키려면 더 높은 손잡이를 먼저 틀어쥐어야 한다고 판단한다. 다음 단계는 황궁.
172번의 기억으로 그는 안다: 황제는 반드시 죽는다. 고정점이다.
에이든은 죽음을 막는 대신, **죽는 시각을 6시간 앞당겨** 정치적 이득으로 전환한다.
하급 시종으로 위장하여 황궁에 잠입한 에이든은 1황자와 2황자를 사전에 무력화하고,
가장 약하지만 조종 가능한 3황자를 옥좌에 앉힌다.
**대중은 에이든의 존재를 모른다.** 그는 끝까지 이름 없는 시종일 뿐이다.
대가로, 황제에게 받았던 유일한 칭찬의 기억이 사라진다.

---

## 🏗️ 제1막. 시종의 가면 (제1화 ~ 제7화)
*   **목표**: 황궁 잠입 및 내부 정세 파악.
*   **분위기**: 가면무도회, 화려함 속의 부패, 쥐가 궁전에 들어감.

| 화수 | 제목 (가제) | 핵심 사건 |
| :--- | :--- | :--- |
| **제1화** | 왕의 도시 | 리아를 펜리르와 검은 시장 의사 손에 남겨둔 뒤, 에이든과 아이리스가 함께 수도 외곽으로 이동. 에이든은 "회색 도시를 지키려면, 먼저 왕이 죽는 시각부터 쥐어야 한다"고 결심한다. |
| **제2화** | 이름 없는 시종 | 얼굴 없는 토마르가 넘긴 위조 신분과 류드의 루트를 이용해 하급 시종으로 황궁 잠입. 궁전 내부 구조와 경비 패턴 학습. |
| **제3화** | 세 마리의 독수리 | 1황자(무력파), 2황자(음모가), 3황자(유약). 172번의 기억으로 약점 분석. |
| **제4화** | 하수구의 왕, 궁전의 쥐 | 빈민가 조직과 황궁을 연결하는 정보 루트 개설. 아이리스는 수도 외곽 하층에 남아 회색 도시-수도 연락선과 리아 보호 자원을 묶고, 에이든은 궁 안쪽 손잡이만 맡는다. |
| **제5화** | 고정된 운명 | 에이든이 황제의 죽음을 막으려 시도. **실패.** "이건 바꿀 수 없는 것이다." |
| **제6화** | 시각의 가치 | 깨달음: 죽음은 못 막지만 **죽는 시각**을 바꾸면 후계 구도가 뒤집힌다. |
| **제7화** | 연금술사 | 황궁 외곽에서 **발타자르**와 조우. "네가 시간을 만지는 것... 알고 있다." |

## 🏗️ 제2막. 줄을 잡는 자 (제8화 ~ 제13화)
*   **목표**: 발타자르 관계 형성 + 3황자 포섭 + 경쟁자 제거.
*   **분위기**: 심리전, 체스 게임, 느와르적 음모.

| 화수 | 제목 (가제) | 핵심 사건 |
| :--- | :--- | :--- |
| **제8화** | 스승과 제자 | 발타자르가 에이든에게 **시간의 법칙** 강의. "감정의 대가는 반드시 돌아온다." |
| **제9화** | 1황자의 칼 | 1황자의 쿠데타 준비 정보를 172번째 기억으로 읽어냄. 사전 공작 개시. |
| **제10화** | 2황자의 독 | 2황자의 암살 음모를 역이용. 측근끼리 의심하도록 정보 조작. |
| **제11화** | 빈 왕좌의 그림자 | 3황자에게 접근 → **근위대에 발각 직전.** 시종 신분으로 간신히 위장. 유약하지만 유일하게 부패하지 않은 3황자와 비밀 면담. |
| **제12화** | 뒷골목의 장기판 | 에이든이 귀족 파벌에 거짓 정보 유포. 양쪽 자멸 유도. **시종은 보이지 않는다.** |
| **제13화** | 잔향의 속삭임 | 에이든의 두통 심화. '잔향'이 간헐적으로 들림. "네 빚이 늘고 있다." |

---

## 🏗️ 제3막. 왕의 죽음 (제14화 ~ 제19화)
*   **목표**: 황제 죽음 시각 조작 → 후계 공작 → 숙청.
*   **분위기**: 비극, 숙청, 어둠 속의 집행자.

| 화수 | 제목 (가제) | 핵심 사건 |
| :--- | :--- | :--- |
| **제14화** | D-Day | 황제의 죽음이 예정된 날. 에이든이 시각을 **6시간 앞당김.** |
| **제15화** | 피 묻은 옥좌 | 황제 사망. 에이든이 계획한 시각에, 계획한 증인들 앞에서. |
| **제16화** | 시종의 유언장 | 에이든이 사전에 끼워둔 유서. **3황자를 후계자로 지명.** |
| **제17화** | 1황자의 난 | 쿠데타 시도. 하지만 에이든이 이미 군부 핵심을 조용히 매수해둔 상태. |
| **제18화** | 어둠 속의 집행 | 1황자 파벌 숙청. 에이든은 어둠 속에서 움직임. **아무도 그를 못 봤다.** |
| **제19화** | 대가 지불 | **[대가 지불]** 황제를 이용한 대가: "잘했다"라는 칭찬의 기억이 사라진다. |

---

## 🏗️ 제4막. 보이지 않는 손 (제20화 ~ 제25화)
*   **목표**: 새 체제 안착 + 다음 위기 복선.
*   **분위기**: 공허, 성취 없는 승리, 여전히 뒷골목의 쥐.

| 화수 | 제목 (가제) | 핵심 사건 |
| :--- | :--- | :--- |
| **제20화** | 새 황제 | 3황자 즉위. 에이든은 그림자 속에 남음. "시종 하나가 사라져도 아무도 모른다." |
| **제21화** | 발타자르의 강의 | 고정점의 원리. "인과율은 큰 흐름을 지킨다. 네가 바꿀 수 있는 건 디테일뿐." |
| **제22화** | 역병의 냄새 | 수도 외곽에서 마나열병 확산. 빈민가 봉쇄와 회색 도시 검문이 시작되며, 에이든의 선택이 늦었다면 리아의 은신도 들켰을 상황이었음이 드러난다. |
| **제23화** | 학회의 움직임 | 황실 연금술 학회가 새 황제에게 접근. 불길한 의도. |
| **제24화** | 발타자르의 경고 | **"너무 많은 줄을 잡으면, 줄이 너를 잡는다."** 에이든은 묵묵히 듣기만 함. |
| **제25화** | 인형사 | 에이든은 뒷골목으로 돌아간다. 왕을 만들었지만, 여전히 쥐다. 2권 종료. |
