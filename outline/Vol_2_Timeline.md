# 📅 제2권 사건 흐름표: 인형사
**"시종이 왕을 만들기까지 50일"**

## 브리지 메모

- 제1권 종료 후 약 20일 동안 회색 도시 숙청과 검문이 이어진다.
- 리아는 펜리르의 안전가옥과 검은 시장 의사의 손 아래 숨겨지고, 아이리스는 하층 정보망을 묶는다.
- 에이든은 황제의 고정된 죽음 시각이 다가오기 전에 수도로 움직인다.

| 일정 | 화수 | 주요 사건 | 비고 |
| :--- | :--- | :--- | :--- |
| **D+0** | 제1화 | 제국 수도 도착. 리아를 회색 도시에 남겨둔 채 황궁 정찰 시작. | 브리지 완료 |
| **D+3** | 제2화 | 토마스의 위조 신분과 류드의 루트로 하급 시종 잠입. | 위장 |
| **D+7** | 제3화 | 세 황자 역학관계 분석 완료. | 정보 |
| **D+10** | 제4화 | 하수구↔황궁 비밀 루트 개설. 아이리스 외부 연결. | 기반 |
| **D+11** | 제5화 | 고정점(황제의 죽음) 확인. "이건 바꿀 수 없다." | 핵심 발견 |
| **D+12** | 제6화 | 깨달음: 죽는 시각 조작 전략 수립. | 전략 |
| **D+14** | 제7화 | **발타자르 첫 만남** + 시종 정보망 장악. | 조우 |
| **D+18** | 제8화 | 발타자르 스승-제자 관계 시작. | 세계관 |
| **D+22** | 제9화~제10화 | 1황자 쿠데타 정보 + 2황자 음모 역이용. | 공작 |
| **D+25** | 제11화~제12화 | 이간질 + 발타자르 강의. | 심리전 |
| **D+28** | 제13화 | 아이리스 외부 보고. 역병 복선. | 복선 |
| **D+35** ⭐ | 제14화~제15화 | **황제 당일.** 시각 6시간 앞당김. 황제 사망. | 고정점 |
| **D+36** | 제16화 | 유언장 공개. 3황자 후계자 지명. | 승계 |
| **D+37** | 제17화~제18화 | 1황자 쿠데타 진압 + 숙청. | 무력 |
| **D+38** | 제19화 | **대가 지불**: 칭찬의 기억 상실. | 대가 |
| **D+42** | 제20화~제21화 | 3황자 즉위 + 발타자르 강의. | 새 체제 |
| **D+45** | 제22화~제24화 | 학회 접근 + 역병 + 회색 도시 검문 강화 + 발타자르 경고. | 복선 |
| **D+50** | 제25화 | 에이든 뒷골목으로 복귀. 2권 종료. | 에필로그 |

### ⏱️ 속도감 분석
- **총 소요 시간**: 약 **50일**.
- **특징**: 제1권(2주)과 대비되는 느린 궁정 체스 게임.
- **개연성**: 172회차 기억으로 공작 기간 단축. 고정점 날짜까지 대기 필요.
