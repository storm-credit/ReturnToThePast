# 📜 제14권 세부 개요: 기억의 심연 (Abyss of Memory)

> **범위**: 제1화 ~ 제25화 (완결)
> **핵심 목표**: 최종 선택 (A: 영시가 된다 vs B: 인간으로 돌아간다)
> **타임 이벤트**: 세계의 근원적 분해 + 재탄생
> **등가교환의 종결**: B를 선택 — 172번 분의 기억/능력 전부 소멸, 감정 회복
> **Arc**: Roadmap Arc 14

---

## 📽️ 제14권 줄거리 요약 (시놉시스)
**"이제 좀 쉬고 싶다."**

시간의 심장을 쥔 에이든에게 두 가지 선택이 주어진다.
A: 영시(零時)가 되어 세계를 다시 구축한다. 영생. 0회차의 운명을 이어받는다.
B: 모든 기억과 능력을 잃고, 평범한 인간으로 다시 태어난다.
등가교환의 종결: B를 선택하면 172번 분의 고통, 사랑, 기억이 전부 대가로 사라진다.
**하지만 감정을 되찾는다.**
세계가 근원적 조각으로 분해되는 동안, 에이든은 자신의 모든 기억을 뒤돌아본다.
172번의 생애. 수천 번의 죽음. 한 번의 웃음.
**"이제 좀 쉬고 싶다."** 에이든은 B를 선택한다.

---

## 🏗️ 제1막. 선택의 방 (제1화 ~ 제7화)
*   **목표**: A와 B 선택의 의미 파악.
*   **분위기**: 고요, 존재론적 질문, 시간이 멈춘 공간.

| 화수 | 제목 (가제) | 핵심 사건 |
| :--- | :--- | :--- |
| **제1화** | 심장을 쥔 손 | 에이든이 시간의 심장을 쥐고 있다. 세계가 정지해있다. |
| **제2화** | 선택 A | A: 영시가 된다. 인과율의 새 직조자. 영생. 하지만 인간이 아니게 된다. |
| **제3화** | 선택 B | B: 평범한 인간으로 돌아간다. 모든 기억과 능력을 잃는다. 하지만 감정을 되찾는다. |
| **제4화** | 무게 | A를 선택하면 영시처럼 **영원히 혼자** 인과를 짜야 한다. B를 선택하면 **모든 것을 잃는다.** |
| **제5화** | 아이리스의 눈 | 정지된 세계에서 아이리스의 표정. 마지막으로 본 웃음. 지금은 기억도 못 한다. |
| **제6화** | 리아의 눈 | 리아. 172번 구하려 한 여자. 기억을 잃어도, 그 눈만은 똑같다. |
| **제7화** | 질문 | "나는 누구인가? 에이든인가, 영시인가, 아니면 그냥... 지친 사람인가?" |

---

## 🏗️ 제2막. 172번의 회고 (제8화 ~ 제13화)
*   **목표**: 에이든의 전 회귀 회고. 시리즈 전체의 감정적 총결산.
*   **분위기**: 회상, 비극, 온기, 인생의 총결산.

| 화수 | 제목 (가제) | 핵심 사건 |
| :--- | :--- | :--- |
| **제8화** | 1회차 | 아무것도 모르던 소년. 처음 리아를 만난 날. 비 오는 날. |
| **제9화** | 50회차 | 처음으로 누군가를 구했다. 그때의 기쁨. 지금은 기억만 남았다. |
| **제10화** | 100회차 | 감정이 반쯤 사라진 에이든. 리아에게 "미안해"라고 말한 마지막 회차. — **인과의 실 하나가 끊어진다. 세계 분해가 가속. 시간이 없다.** |
| **제11화** | 171회차 | 직전 회차. 거의 성공했다. 하지만 마지막에 무너졌다. |
| **제12화** | 172회차 | 이번 회차. 빈민가, 아이리스, 발타자르, 영시. 가장 멀리 왔다. |
| **제13화** | 빵집 | 무한 루프에서의 기억. 빵의 맛. 석양의 색. 고양이의 온기. 이미 잃어버린 것. |

---

## 🏗️ 제3막. 세계의 분해 (제14화 ~ 제19화)
*   **목표**: 세계가 근원적 조각으로 분해 + 선택의 순간.
*   **분위기**: 종말의 아름다움, 우주적 스케일, 최후의 결단.

| 화수 | 제목 (가제) | 핵심 사건 |
| :--- | :--- | :--- |
| **제14화** | 분해 | 시간의 심장이 반응. **세계가 근원적 조각으로 분해되기 시작.** |
| **제15화** | 조각들 | 세계의 조각: 하늘, 바다, 도시, 사람들 — 전부 빛의 입자로 분해. |
| **제16화** | 영시의 목소리 | 소멸한 영시의 마지막 메시지. "어떤 선택이든, 네 선택이야." |
| **제17화** | A의 유혹 | 에이든이 A를 떠올린다. 영생. 세계를 다시 짤 수 있다. 리아를 구할 수 있다. |
| **제18화** | B의 의미 | B를 선택하면 리아도, 아이리스도, 172번의 기억도 — 전부 사라진다. |
| **제19화** | 결심 | **"이제 좀 쉬고 싶다."** 에이든은 B를 선택한다. |

---

## 🏗️ 제4막. 등가교환의 종결 (제20화 ~ 제25화)
*   **목표**: B 선택의 실행 + 에이든의 소멸 + 15권 연결.
*   **분위기**: 평화, 이별, 끝의 시작.

| 화수 | 제목 (가제) | 핵심 사건 |
| :--- | :--- | :--- |
| **제20화** | 등가교환의 종결 | 172번 분의 기억이 빛으로 흩어진다. 고통의 기억부터 사라진다. |
| **제21화** | 사라지는 기억들 | 전투의 기억, 동료의 이름, 적의 얼굴 — 하나씩 사라진다. |
| **제22화** | 마지막 기억 | 마지막으로 남는 기억. **비 오는 날, 버스 정류장, 리아의 얼굴.** |
| **제23화** | 감정의 귀환 | 기억이 사라지는 대신 **감정이 돌아온다.** 슬프다. 처음으로 운다. |
| **제24화** | "비가 그치질 않네" | 모든 기억이 사라진다. 마지막 한 마디만 남는다. **"비가... 그치질 않네."** |
| **제25화** | 재탄생 | 세계가 재구성된다. 에이든은 빛 속으로 사라진다. 14권 종료. |
