# 📅 제6권 사건 흐름표: 배신자들
**"존재 소거까지 30일"**

## 브리지 메모

- 제6권의 시작은 종전 직후가 아니라, 야전막사와 회복막사가 겨우 굴러가기 시작한 시점이다.
- 아이리스는 이미 생존권에 들어왔지만, 붕대 교체와 열 관리가 계속 필요하다.
- 에이든의 고립은 전투 기록 유포만이 아니라, 전후 수습 과정에서 드러난 차가움이 며칠간 퍼지며 굳어진 결과다.

| 일정 | 화수 | 주요 사건 | 비고 |
| :--- | :--- | :--- | :--- |
| **D+0** | 제1화~제2화 | 전후 약 일주일. 에이든의 전투 기록 유포. 동료 불신. | 균열 시작 |
| **D+5** | 제3화~제4화 | 바르칸 질문 + 동료 반발 확산. | 고립 |
| **D+8** | 제5화~제6화 | 아이리스 질문 + 회복막사 붕대 교체 + 에이든 뒷골목에서 진통제. | 단절 |
| **D+10** | 제7화~제8화 | 금기 속삭임 + 감정 없는 결심. | 결단 |
| **D+12** | 제9화 | 발타자르 반대. "대가가 존재 자체야." | 경고 |
| **D+15** | 제10화~제12화 | 마지막 순찰: 회복막사/영안실/동료들 방문 + 리아 멀리서 관찰. | 이별 |
| **D+17** ⭐ | 제13화 | **금기 발동. 기억 소거.** | 핵심 사건 |
| **D+18** | 제14화~제15화 | 존재 소거 완료 + '변절자' 오명. | 소거 |
| **D+20** | 제16화~제18화 | 혼자의 전투. 유령의 전쟁. 기록 미남. | 고독 |
| **D+25** | 제19화~제21화 | 발타자르만 기억 + 적의 함정 + 그림자 사냥. | 추적 |
| **D+28** | 제22화~제24화 | 발타자르 제안(탑) + 잔향 포효 + 결의 + 탑 문턱 접근. | 전환 |
| **D+30** | 제25화 | 발타자르와 탑 문턱 통과. 외부 시간은 여기서 멎고, 첫 가짜 아침이 시작된다. 6권 종료. | 에필로그 |

---
### ⏱️ 속도감 분석
- **총 소요 시간**: 약 **30일**.
- **특징**: 전반부 느리게(고립 묘사), 제13화 이후 가속.
- **개연성**: 종전 후 회복과 소문 확산 기간을 거쳐 동료 불신 → 결심까지 약 2주, 행동까지 3일.
