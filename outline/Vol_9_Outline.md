# 📜 제9권 세부 개요: 귀환

> **범위**: 제1화 ~ 제25화 (완결)
> **핵심 목표**: 인과의 고삐 탈취 + 찰나(刹那) 획득 + 발타자르 추적
> **시간 사건**: 인과의 고삐 - 인과를 직접 쥐는 능력 일부 획득
> **대가의 한계**: 찰나를 쓸 때마다 새로운 기억이 희미해짐 (미래가 흐릿해진다)
> **권상 위치**: 전체 권수 설계표 아크 10 / 제3부 시작

---

## 📽️ 제9권 줄거리 요약 (시놉시스)
**"신분조차 없는 유령이, 적들을 학살한다."**

시간의 탑에 진입한 에이든은 탑의 첫 번째 시련에서 깨달음을 얻는다:
시간의 감옥에서 보낸 수천 번의 반복이 에이든에게 **인과율을 직접 읽는 능력**을 줬다.
**"찰나(刹那)"** — 눈 한 번 감았다 뜰 만큼의 시간을 붙드는 권능. 쓸 때마다 수명 1년이 줄어든다.
하지만 능력에는 대가가 있다: 찰나를 쓸수록 **앞으로 만들 새 기억이 희미해진다.**
과거만 선명하고, 미래가 흐릿해지는 남자.
에이든은 찰나를 무기로 폐허가 된 제국을 정리하고, 발타자르를 추적한다.

---

## 🏗️ 제1막. 탑의 첫 번째 시련 (제1화 ~ 제7화)
*   **목표**: 인과의 고삐 획득 + 찰나 첫 발동.
*   **분위기**: 깨달음, 힘의 각성, 대가의 그림자.

| 화수 | 제목 (가제) | 핵심 사건 |
| :--- | :--- | :--- |
| **제1화** | 탑의 문 | 시간의 탑 진입. 첫 번째 층. 인과율의 소용돌이. |
| **제2화** | 시련 | 탑이 에이든에게 묻는다: "네가 지불한 대가의 총량을 기억하는가?" |
| **제3화** | 빚의 장부 | 에이든이 172번 + 1847번의 반복 + 모든 대가를 직면. 빚의 규모. |
| **제4화** | 깨달음 | 수천 번의 반복이 에이든의 인식을 바꿨다. **인과율의 흐름이 보인다.** |
| **제5화** | 인과의 고삐 | 에이든이 인과율을 **직접 쥐는** 능력을 일부 획득. 시간의 실이 보인다. |
| **제6화** | 찰나 (刹那) | 시간 정지 권능 첫 발동. **눈 한 번 감았다 뜰 만큼의 정지에 수명 1년.** 에이든의 남은 수명이 깎인다. |
| **제7화** | 대가의 새 형태 | 찰나를 쓰자 **오늘 아침의 기억이 희미해졌다.** 미래가 흐릿해진다. |

---

## 🏗️ 제2막. 유령의 학살 (제8화 ~ 제13화)
*   **목표**: 폐허 제국 정리 + 적 세력 제거.
*   **분위기**: 유령, 학살, 처단, 느와르 극대화.

| 화수 | 제목 (가제) | 핵심 사건 |
| :--- | :--- | :--- |
| **제8화** | 돌아온 유령 | 탑에서 나온 에이든. 폐허의 수도. 이름도 신분도 없는 **유령.** |
| **제9화** | 학살의 밤 #1 | 에이든이 내전 군벌 거점 단독 습격. 찰나 사용. 기록 없는 전멸. |
| **제10화** | 학살의 밤 #2 | 두 번째 거점. 에이든은 말없이 일한다. 죽은 자의 이름도 모른다. |
| **제11화** | 소문 | 빈민가에 소문이 퍼진다: **"유령이 있다."** 이름 모를 유령이 악인을 처단한다. |
| **제12화** | 아이리스의 감시 | 아이리스가 '유령'의 정체를 파악하려 미행. 에이든을 목격하지만 **기억하지 못한다.** |
| **제13화** | 짧은 대화 | 에이든과 아이리스가 뒷골목에서 마주침. "당신, 혹시 예전에 만난 적 있어요?" "없어." |

---

## 🏗️ 제3막. 발타자르의 흔적 (제14화 ~ 제19화)
*   **목표**: 발타자르 추적 + 시간의 탑으로의 본격 여정 시작.
*   **분위기**: 추적, 의심, 점점 가까워지는 진실.

| 화수 | 제목 (가제) | 핵심 사건 |
| :--- | :--- | :--- |
| **제14화** | 흔적 | 발타자르가 남긴 연금술 흔적 추적. 탑의 **상층부**로 향하는 단서. |
| **제15화** | 발타자르의 기록 | 폐허에서 발타자르의 연구 노트 발견. 시간의 구조에 대한 방대한 이론. |
| **제16화** | "나는 안내자였을 뿐" | 연구 노트의 마지막 페이지: 의미를 알 수 없는 문장. |
| **제17화** | 후영의 인도 | 후영이 에이든을 탑으로 인도한다. **"올라와라. 끝내자."** |
| **제18화** | 탑의 두 번째 시련 | 탑의 중간 층에서 두 번째 시련. 에이든의 선택들이 심판받는다. |
| **제19화** | 통과 | 시련 통과. 대가: 찰나 한 번 사용. 수명이 또 줄어든다. |

---

## 🏗️ 제4막. 탑을 오르며 (제20화 ~ 제25화)
*   **목표**: 탑 상층부 접근 + 10권 연결.
*   **분위기**: 최종전 전야, 결의, 과거의 그림자.

| 화수 | 제목 (가제) | 핵심 사건 |
| :--- | :--- | :--- |
| **제20화** | 과거의 메아리 | 탑 안에서 이전 회차의 잔영들이 나타나기 시작. 1~10회차의 에이든들. |
| **제21화** | 실패의 벽 | "너도 결국 실패할 거야." 과거 자신들의 조롱. 에이든은 묵묵히 전진. |
| **제22화** | 아이리스의 결정 | 아이리스가 에이든을 따라 탑에 진입. "당신이 누군지 모르겠지만, 내 검법을 쓰는 사람은 한 명뿐이야. **내 몸이 당신을 기억해.**" |
| **제23화** | 동행 | 에이든과 아이리스. 기억 없는 동행. 말은 없지만 걸음은 같다. |
| **제24화** | 탑의 중심 | 탑의 구조가 보인다. 꼭대기에 **무언가**가 있다. 발타자르인가, 후영인가. |
| **제25화** | 꼭대기를 향해 | 에이든이 탑의 최상층으로 향한다. 9권 종료. |
