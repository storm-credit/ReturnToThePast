# 📅 제8권 사건 흐름표: 시간의 감옥
**"탈출 후 3년 뒤의 세계에서 40일"**

## 브리지 메모

- 3년 뒤의 수도는 같은 구역 이동도 며칠을 잡아먹을 수 있는 붕괴 도시다.
- 승강기, 검문, 붕괴 잔해, 약탈자 무리가 실제 이동 속도를 크게 낮춘다.
- 식량과 약품은 탐색 파트의 시간 소모를 만드는 핵심 압박이다.

| 일정 | 화수 | 주요 사건 | 비고 |
| :--- | :--- | :--- | :--- |
| **루프 1848** | 제1화~제4화 | 마지막 루프. 빵, 석양, 고양이. 탈출 술식 실행. | 루프 내 |
| **루프 1848 (끝)** | 제5화~제6화 | **대가 지불**: 평범한 행복 감정 상실 + 발타자르 환영. | 대가 |
| **D+0 (탈출)** | 제7화 | **루프 탈출.** 현실 = 3년 경과. | 탈출 |
| **D+1~3** | 제8화~제9화 | 폐허 수도. 3년 공백 정보 수집. 붕괴 구획 우회와 생존자 접선. | 상황 파악 |
| **D+3** | 제10화~제11화 | 아이리스 발견 + **"누구세요?"** | 재회 |
| **D+5** | 제12화~제13화 | 이중 고립 확인 + 발타자르 흔적 추적. | 추적 |
| **D+10** | 제14화~제15화 | 유령의 칼: 내전 세력 단독 제거. | 처단 |
| **D+15** | 제16화~제17화 | 발타자르→시간의 탑 추적 + 잔향 강화. | 추격 |
| **D+20** | 제18화~제19화 | 탑 입구 도착 + 결의. | 도달 |
| **D+25** | 제20화~제21화 | 아이리스 동행 합류 + 빈민가 생존자 결집 + 식량/약품 분배. | 동맹 |
| **D+30** | 제22화~제23화 | 최종 장비 + 아이리스 "왜 이렇게 익숙하죠?" + 폐허 통과 루트 정리. | 준비 |
| **D+35** | 제24화 | 제2부 종결. 돌아갈 곳 없음. | 전환 |
| **D+40** | 제25화 | 시간의 탑 진입. **제3부 시작.** 8권 종료. | 진입 |

---
### ⏱️ 속도감 분석
- **총 소요 시간**: 루프 내 5화 + 현실 **40일**.
- **특징**: 3년 시간 건너뛰기가 핵심 충격. 폐허 탐색 중심.
- **개연성**: 붕괴 도시 탐색, 생존자 접선, 식량/약품 마련이 실제 이동 시간을 잡아먹는다.
