# 📜 제4권 세부 개요: 균열의 전조

> **범위**: 제1화 ~ 제25화 (완결)
> **핵심 목표**: 이계 괴물 위협 대응 + 망한 시간선 무기 확보
> **시간 사건**: 인과의 집행자 소환 시작, 무너진 시간선 접속
> **대가**: 수명 3년 (금기 발동 비용)
> **권상 위치**: 전체 권수 설계표 아크 7a (제7권 전반부)

---

## 📽️ 제4권 줄거리 요약 (시놉시스)
**"하늘이 갈라졌다. 172번의 기억에도 이건 없었다."**

학회 숙청 후 평화는 오래가지 않는다. 하늘에 균열이 나타나고 이계 괴물이 쏟아진다.
에이든은 공포에 빠진다 — 172번 어떤 회차에서도 **이 사건은 일어난 적이 없다.**
발타자르가 설명한다: 에이든이 쌓은 **인과의 빚**이 세계를 약하게 만들어 이계의 문이 열린 것.
재래식 무기로는 이길 수 없는 적. 에이든은 금기에 손을 댄다 —
**이미 멸망한 미래의 시간선**에서 무기를 빌려오기로 결심한다.

---

## 🏗️ 제1막. 172번에도 없던 재앙 (제1화 ~ 제7화)
*   **목표**: 이계 침공 인지 + 에이든의 무력감.
*   **분위기**: 공포, 미지, 절망.

| 화수 | 제목 (가제) | 핵심 사건 |
| :--- | :--- | :--- |
| **제1화** | 갈라진 하늘 | 수도 상공에 거대한 균열. **이계 마수** 첫 출현. 시민 공포. |
| **제2화** | 피의 비 | 이계 괴물 외곽 마을 습격 — **인과율이 약한 지점(영맥 교차점)만 골라 공격.** 본능이 아닌 의도가 있다. 황실 기사단 전멸. 재래식 한계. |
| **제3화** | 기억에 없는 것 | **172번 어떤 회차에서도 이 침공은 없었다.** 에이든의 기억이 무력해지는 충격. |
| **제4화** | 인과의 빚 | 발타자르 설명: 에이든의 시간 조작이 쌓은 **인과율의 빚이 세계를 약하게 만들었다.** |
| **제5화** | 전쟁 회의 | 3황자가 에이든에게 비밀리에 대책 요청. 에이든은 여전히 그림자 참모. |
| **제6화** | 전선 | 에이든이 전선으로. 기사단이 박살나는 광경. "칼로 벨 수 있는 놈들이 아니다." |
| **제7화** | 금기의 문 | 발타자르의 제안: **"멸망한 미래에서 무기를 빌려올 수 있다."** |

---

## 🏗️ 제2막. 금기의 유혹 (제8화 ~ 제13화)
*   **목표**: 금기 결심 + 동맹 규합 + 시간선 접속 준비.
*   **분위기**: 갈등, 유혹, 위험한 도박.

| 화수 | 제목 (가제) | 핵심 사건 |
| :--- | :--- | :--- |
| **제8화** | 대가의 무게 | 발타자르: **"시간선을 열면 인과율의 항체가 몰려온다."** 에이든 주저. |
| **제9화** | 아이리스의 반발 | "너는 항상 혼자 결정한다." 에이든의 독단에 대한 아이리스의 분노. |
| **제10화** | 연합전선 | 에이든이 뒷골목에서 용기사단, 변경 영주, 용병단을 비밀리에 규합한다. 전령, 마차, 부상병 수송대까지 묶어야 전선이 움직인다는 사실이 드러난다. |
| **제11화** | 최전선 | 연합군 vs 이계 괴물 첫 전투. 참혹한 피해. 괴물이 **에이든 주변으로 집중 출현** — 인과의 빚이 큰 자를 감지한다. **칼로는 안 된다. 확정.** |
| **제12화** | 결심 | "빚이야 항상 지고 있었다. 하나 더 추가할 뿐." 에이든이 금기를 쓰기로 결정. |
| **제13화** | 제물 | 금기 발동 비용: 에이든의 **수명 3년.** 발타자르: "정말로 할 거냐?" |

---

## 🏗️ 제3막. 멸망한 미래 (제14화 ~ 제19화)
*   **목표**: 망한 시간선 접속 + 무기 '해방자' 확보.
*   **분위기**: 코스믹 호러, 폐허의 미학, 존재론적 공포.

| 화수 | 제목 (가제) | 핵심 사건 |
| :--- | :--- | :--- |
| **제14화** | 시간선의 문 | 발타자르의 술식으로 **멸망한 미래**에 에이든의 정신을 투영. |
| **제15화** | 폐허의 세계 | 모든 것이 파괴된 미래. 회색 하늘, 부서진 도시, 죽은 바다. |
| **제16화** | 잔해 속의 무기 | 미래의 연금술 병기 **'해방자(Liberator)'** 발견. |
| **제17화** | 미래의 유령들 | 멸망한 시간선의 잔류 의식이 경고: "돌아가지 마. 여기 있어." |
| **제18화** | 접속 해제 | 해방자를 현재로 가져오는 순간, **인과율이 폭발적으로 반응.** |
| **제19화** | 항체 출현 | **인과율의 항체(Antibodies)** 첫 대규모 출현. 에이든을 제거하려는 그림자 괴물들. |

---

## 🏗️ 제4막. 폭풍 전야 (제20화 ~ 제25화)
*   **목표**: 항체 격퇴 + 대결전 준비 + 5권 연결.
*   **분위기**: 결의, 전쟁 전야, 폭풍 전의 고요.

| 화수 | 제목 (가제) | 핵심 사건 |
| :--- | :--- | :--- |
| **제20화** | 항체와의 전투 | 항체 격퇴. 에이든 중상. 수명 3년이 빠져나감을 체감하고, 야전막사에서 하룻밤 내내 봉합과 열병을 견딘다. |
| **제21화** | 해방자 시험 | 확보한 무기 '해방자' 시험 발동. 이계 괴물에 유효함 확인. 하지만 재장전과 봉인 보정에 사람과 시간이 든다는 사실이 드러난다. |
| **제22화** | 연합군 재편 | 최종 결전 작전 수립. 에이든은 그림자에서 작전을 짜고, 바르칸이 표면 지휘. 후송로와 약품 배분까지 전쟁 계획에 포함된다. |
| **제23화** | 마지막 밤 | 전투 전야. 에이든이 혼자 뒷골목에 앉아 진통제를 마신다. |
| **제24화** | 발타자르의 선물 | 발타자르가 특수한 부적을 줌. "최악의 순간에 써라." 의미심장. |
| **제25화** | 전장으로 | 연합군 진격 개시. 탄약 마차와 부상병 수송차가 함께 움직이고, 하늘의 균열이 최대로 벌어진다. 4권 종료. |
