# 📜 제10권 세부 개요: 탑

> **범위**: 제1화 ~ 제25화 (완결)
> **핵심 목표**: 과거 회차의 자신들을 넘어 발타자르 도달 + 발타자르 처치
> **타임 이벤트**: 과거의 그림자들 — 1~171회차 에이든 출현
> **🎭 미끼 단서 회수**: 발타자르 유언 — "거울을 봐라"
> **권상 위치**: 전체 권수 설계표 11번 구간

---

## 📽️ 제10권 줄거리 요약 (시놉시스)
**"너도 결국 실패할 거야."**

시간의 탑 상층부. 이곳에서는 실패한 1~171회차의 에이든들이 적으로 나타난다.
과거의 자신들은 각자의 방식으로 실패했고, 각자의 후회를 품고 있다.
에이든은 자신의 나약했던 과거를 **직접 베어 넘기며** 전진한다.
꼭대기에서 발타자르를 마주치고, **에이든은 발타자르를 죽인다.**
하지만 발타자르의 유언이 모든 것을 뒤집는다:
**"나는... 안내자였을 뿐이다. 진짜 적은... 거울을 봐라."**

---

## 🏗️ 제1막. 그림자들의 층 (제1화 ~ 제7화)
*   **목표**: 과거 회차 에이든들 등장 + 첫 전투.
*   **분위기**: 거울, 자기혐오, 과거와의 대면.

| 화수 | 제목 (가제) | 핵심 사건 |
| :--- | :--- | :--- |
| **제1화** | 탑의 시련 | 탑 상층부 진입. 인과율의 구조가 결정처럼 보인다. |
| **제2화** | 1회차 | **1회차의 에이든.** 아무것도 모르고, 모든 것에 겁먹었던 소년. |
| **제3화** | 10회차 | 10회차의 에이든. 처음으로 리아를 구하려 한 자. 실패하고 울었던 자. |
| **제4화** | 50회차 | 50회차의 에이든. 냉혹해지기 시작한 자. "감정을 버려야 한다." |
| **제5화** | 100회차 | 100회차의 에이든. 이미 감정의 절반을 잃은. "넌 나보다 나을 거라 생각해?" |
| **제6화** | 실패의 합창 | 모든 과거 에이든들이 외친다: **"너도 결국 실패할 거야."** |
| **제7화** | 첫 번째 베기 | 에이든이 1회차의 자신을 벤다. "미안하다. 하지만 나는 멈출 수 없다." |

---

## 🏗️ 제2막. 과거를 넘어 (제8화 ~ 제13화)
*   **목표**: 과거 에이든들과의 전투 + 동료 환영.
*   **분위기**: 전투, 비극, 자기 극복.

| 화수 | 제목 (가제) | 핵심 사건 |
| :--- | :--- | :--- |
| **제8화** | 130회차 | 130회차의 에이든. 거의 성공했다가 마지막에 무너진 자. 가장 강한 적. |
| **제9화** | 171회차 | 직전 회차의 에이든. 가장 가까운 실패. "한 걸음만 더 갔으면 됐는데." |
| **제10화** | 아이리스의 환영 | 인과율이 만들어낸 **아이리스의 환영.** 에이든을 원망한다. "왜 나를 잊었어?" |
| **제11화** | 바르칸의 환영 | 바르칸의 환영. "넌 언제나 혼자 결정했어. 그게 네 실패의 원인이야." |
| **제12화** | 리아의 환영 | 리아의 환영. "나를 구하겠다면서, 왜 내 기억을 가져갔어?" |
| **제13화** | 돌파 | 에이든이 모든 환영을 넘긴다. **"미안하다. 하지만 멈추지 않겠다."** |

---

## 🏗️ 제3막. 발타자르 (제14화 ~ 제19화)
*   **목표**: 탑 꼭대기 + 발타자르와의 대면 + 처치.
*   **분위기**: 클라이맥스, 스승 살해, 충격의 유언.

| 화수 | 제목 (가제) | 핵심 사건 |
| :--- | :--- | :--- |
| **제14화** | 탑의 꼭대기 | 최상층 도달. 발타자르가 기다리고 있다. |
| **제15화** | 대면 | 발타자르: "드디어 올라왔구나." 에이든: "네가 모든 것의 배후다." |
| **제16화** | 스승과의 전투 | 에이든 vs 발타자르. 발타자르는 싸우지 않는다. 방어만 한다. |
| **제17화** | "왜 안 싸워?" | 발타자르가 웃는다. "내 역할은 여기까지니까." |
| **제18화** | 처형 | **에이든이 발타자르를 죽인다.** 스승의 피가 탑의 바닥에 흐른다. |
| **제19화** | 유언 | 발타자르의 마지막 말: **"나는... 안내자였을 뿐이다. 진짜 적은... 거울을 봐라."** |

---

## 🏗️ 제4막. 거울 (제20화 ~ 제25화)
*   **목표**: 유언의 의미 탐색 + 잔향의 정체 접근.
*   **분위기**: 충격, 의문, 전환점.

| 화수 | 제목 (가제) | 핵심 사건 |
| :--- | :--- | :--- |
| **제20화** | 발타자르 사후 | 발타자르를 죽였는데... **잔향이 사라지지 않는다.** |
| **제21화** | 거울 | "거울을 봐라." 에이든이 탑의 거울 앞에 선다. **자신의 얼굴이 미세하게 다르다.** |
| **제22화** | 의문 | 잔향의 정체는 발타자르가 아니다. 그럼 누구인가? 에이든이 흔들린다. |
| **제23화** | 아이리스의 도착 | 아이리스가 탑 꼭대기에 도달. "이 사람은... 누구였어요?" 발타자르의 시체 앞에서. |
| **제24화** | 탑의 비밀 | 탑이 반응한다. 발타자르의 죽음이 **열쇠**였다. 숨겨진 공간이 열린다. |
| **제25화** | 0회차 | 숨겨진 공간에 각인된 문장: **"0회차."** 10권 종료. |
