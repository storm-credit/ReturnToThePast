# 📜 제3권 세부 개요: 마녀 사냥 (Witch Hunt)

> **범위**: 제1화 ~ 제25화 (완결)
> **핵심 목표**: 이레이저 격퇴 + 학회를 시해범으로 몰아 숙청
> **타임 이벤트**: 나비효과 요격(Butterfly Effect), 시간 전쟁 개막
> **등가교환**: (이 권에서는 직접적 등가교환 없음 — 인과의 빚이 쌓이는 과정)
> **Arc**: Roadmap Arc 6

---

## 📽️ 제3권 줄거리 요약 (시놉시스)
**"적도 시간을 쓴다."**

3황자가 즉위한 직후, 학회가 반격한다.
과거로 **'이레이저(Eraser)'** — 시간 암살자를 보내 에이든을 제거하려 한다.
이레이저는 나비효과를 역으로 이용해 에이든의 동맹을 무너뜨리는 자.
에이든은 생애 처음으로 **같은 규칙의 적**과 두뇌전을 벌인다.
승리한 에이든은 학회를 '황제 시해범'으로 몰아 대숙청을 감행한다.
어둠 속에서 집행하는 건 여전히 에이든이다. 발타자르의 의미심장한 고백이 불안을 남긴다.

---

## 🏗️ 제1막. 시간 전쟁의 서막 (제1화 ~ 제7화)
*   **목표**: 이레이저 등장 및 나비효과 공격 인지.
*   **분위기**: 추적당하는 공포, 보이지 않는 적, 불안정.

| 화수 | 제목 (가제) | 핵심 사건 |
| :--- | :--- | :--- |
| **제1화** | 새벽의 칼 | 에이든 암살 미수. 미래 기술을 쓰는 정체불명의 적. 뒷골목에서 기습. |
| **제2화** | 이레이저 | 적의 정체 파악: 학회가 과거로 보낸 **시간 암살자 '이레이저'.** |
| **제3화** | 나비의 날갯짓 | 이레이저가 **과거의 작은 사건을 변경** → 에이든의 정보상 동맹 무너짐. |
| **제4화** | 무너지는 그물 | 에이든이 구축한 빈민가 조직망에 균열. 미래 지식의 한계를 체감. |
| **제5화** | 역나비효과 | 에이든이 나비효과를 **역으로 이용**하여 이레이저의 개입을 상쇄. |
| **제6화** | 시간의 지문 | 이레이저가 남긴 시간 왜곡 흔적을 발타자르와 분석. 시간 전쟁을 이해. |
| **제7화** | 규칙이 같은 적 | 이레이저도 에이든처럼 시간을 읽는다. **같은 규칙의 적과의 두뇌전 시작.** |

---

## 🏗️ 제2막. 그림자와 거울 (제8화 ~ 제13화)
*   **목표**: 이레이저와의 두뇌전 + 학회의 진실 폭로.
*   **분위기**: 심리 스릴러, 반전의 반전, 김을 넘기는 싸움.

| 화수 | 제목 (가제) | 핵심 사건 |
| :--- | :--- | :--- |
| **제8화** | 미끼 | 에이든이 거짓 정보를 흘려 이레이저를 함정으로 유인. |
| **제9화** | 반격 | 이레이저의 역-함정. 에이든이 간신히 탈출. **아이리스 부상.** |
| **제10화** | 두뇌전의 법칙 | 에이든과 이레이저의 차이: 에이든은 **기억**, 이레이저는 **계산**. |
| **제11화** | 역병의 진실 | 이레이저가 폭로: **창백한 의회가 마나열병을 의도적으로 유포.** |
| **제12화** | 발타자르의 해독 | 발타자르가 이레이저의 시간 이동 술식을 해독. **"내가 연구한 이론과 같은 구조야."** |
| **제13화** | 양동 작전 | 이레이저를 최종 함정에 빠뜨리기 위한 에이든의 이중 작전 수립. |

---

## 🏗️ 제3막. 마녀 사냥 (제14화 ~ 제19화)
*   **목표**: 학회 숙청 + 이레이저 최종전.
*   **분위기**: 재판극, 화형, 어둠 속의 집행자.

| 화수 | 제목 (가제) | 핵심 사건 |
| :--- | :--- | :--- |
| **제14화** | 시해범 | 에이든이 학회를 **'황제 시해범'**으로 몰기 위한 증거 수집 개시. |
| **제15화** | 증거의 조립 | 학회의 시간 실험 기록을 '시해 증거'로 변조. 에이든은 잠도 못 잔다. |
| **제16화** | 여론의 불씨 | 빈민가에 역병 피해 사실 유포. 학회에 대한 민심 이반. 뒷골목에서 퍼지는 소문. |
| **제17화** | 공개 재판 | 3황자의 칙령으로 학회 수장 공개 재판. 에이든은 방청석 구석에 앉아있다. |
| **제18화** | 화형 | 학회 지부 일제 소각. 에이든은 어둠 속에서 집행함. 연기 냄새만 맡는다. |
| **제19화** | 이레이저의 최후 | 도주하는 이레이저 추적. 최종 대결. 에이든의 172번 패턴으로 제압. |

---

## 🏗️ 제4막. 재 위의 승리 (제20화 ~ 제25화)
*   **목표**: 전후 처리 + 복선 + 잔향 강화.
*   **분위기**: 공허, 불안, 다음 폭풍의 전조.

| 화수 | 제목 (가제) | 핵심 사건 |
| :--- | :--- | :--- |
| **제20화** | 승리의 재 | 학회 숙청 완료. 에이든은 허무만 느낌. 아무도 그에게 감사하지 않는다. |
| **제21화** | 탈출한 쥐 | 학회 핵심 인물(창백한 의회 연결고리) 일부 도주. 불완전한 승리. |
| **제22화** | 발타자르의 고백 | **"이레이저의 술식과 내 이론은 같은 구조다."** 발타자르는 뭘 알고 있는가? |
| **제23화** | 잔향의 목소리 | '잔향'이 더 선명하게 들림. 에이든의 두통 심화. 인과의 빚이 쌓인다. |
| **제24화** | 리아의 편지 | 기억을 잃은 리아가 에이든에게 편지를 보냄. 에이든은 읽고... 아무것도 느끼지 못한다. |
| **제25화** | 하늘의 균열 | 수도 상공에 미세한 **균열**. 이계의 기운. 다음 재앙의 전조. 3권 종료. |
