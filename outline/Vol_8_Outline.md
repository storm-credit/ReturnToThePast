# 📜 제8권 세부 개요: 시간의 감옥

> **범위**: 제1화 ~ 제25화 (완결)
> **핵심 목표**: 무한 루프 탈출 + 평범한 행복 대가 지불 + 3년 후 세계
> **시간 사건**: 루프 탈출, 행복의 대가
> **대가**: "평범한 하루"의 행복 감정 상실
> **권상 위치**: 전체 권수 설계표 아크 9b (제9권 후반부)
> **🎭 미끼 단서 절정**: 발타자르의 환영 — "너를 여기 가둔 건... 나다."

---

## 📽️ 제8권 줄거리 요약 (시놉시스)
**"행복을 대가로 바치고, 3년 뒤의 폐허에 선다."**

에이든은 마침내 무한 루프에서 탈출한다. 대가로 **평범한 행복의 감정**을 잃는다.
빵의 맛을, 석양의 색을, 고양이의 온기를 — 다시는 느끼지 못한다.
탈출한 에이든이 마주한 것은 **3년이 흘러버린 세계.** 제국은 폐허가 되어있다.
무한 루프 안에서 발타자르의 환영이 말했다: **"너를 여기 가둔 건... 나다."**
발타자르에 대한 의심이 확신으로 변한다.
하지만 폐허의 수도는 지도 한 장으로 건널 수 있는 도시가 아니다.
무너진 구획, 끊어진 승강기, 약탈자 검문, 굶주린 생존자 무리가 길 하나를 며칠짜리 원정으로 바꿔 놓는다.

---

## 🏗️ 제1막. 마지막 반복 (제1화 ~ 제7화)
*   **목표**: 탈출 실행 + 대가 지불.
*   **분위기**: 결연, 이별, 가장 아름다운 것의 소멸.

| 화수 | 제목 (가제) | 핵심 사건 |
| :--- | :--- | :--- |
| **제1화** | 1848번째 아침 | 마지막 아침. 에이든이 모든 것을 기억하면서 하루를 시작한다. |
| **제2화** | 마지막 빵 | 빵집에서 마지막 빵을 산다. 맛을 음미한다. 기억에 새긴다. |
| **제3화** | 마지막 석양 | 마지막 석양을 본다. 색이 사라지기 전에, 눈에 담는다. |
| **제4화** | 탈출 술식 | 에이든이 1847번의 반복에서 알아낸 탈출 술식을 실행. |
| **제5화** | 행복의 대가 | **평범한 행복의 감정이 사라진다.** 빵은 맛이 없다. 석양은 회색이다. 고양이는 차갑다. |
| **제6화** | 발타자르의 환영 | 루프 붕괴 직전, 발타자르의 환영: **"너를 여기 가둔 건... 나다."** |
| **제7화** | 탈출 | 루프 붕괴. 에이든이 현실로 돌아온다. **3년이 흘러있다.** |

---

## 🏗️ 제2막. 3년 뒤의 세계 (제8화 ~ 제13화)
*   **목표**: 폐허가 된 제국 파악 + 상황 인식.
*   **분위기**: 포스트 아포칼립스, 낯선 세계, 유령의 귀환.

| 화수 | 제목 (가제) | 핵심 사건 |
| :--- | :--- | :--- |
| **제8화** | 폐허 | 수도가 반파. 이계 재침공 + 내전의 흔적. 에이든이 아는 세상이 아니다. |
| **제9화** | 3년의 공백 | 에이든의 부재 동안 일어난 사건들 정보 수집. 3황자는 폐위. 내전 중. 무너진 구획 때문에 소문 하나 모으는 데도 며칠이 든다. |
| **제10화** | 아이리스의 행방 | 아이리스가 혼자서 빈민가를 지키고 있었다. 한 팔로. |
| **제11화** | 재회 | 아이리스: "누구세요?" 에이든을 기억하지 못한다. (6권 기억 소거의 여파) |
| **제12화** | 유령 | 에이든은 아무도 기억하지 못하는 **유령.** 3년의 공백 + 존재 소거. 이중 고립. |
| **제13화** | 발타자르의 흔적 | 발타자르가 루프 이후 사라졌다는 정보. **"그놈이 모든 것의 배후다."** |

---

## 🏗️ 제3막. 폐허의 전쟁 (제14화 ~ 제19화)
*   **목표**: 에이든의 단독 정리 작전 + 발타자르 추적.
*   **분위기**: 고독한 처단, 느와르 극대화, 유령의 폭력.

| 화수 | 제목 (가제) | 핵심 사건 |
| :--- | :--- | :--- |
| **제14화** | 유령의 칼 | 에이든이 내전 세력 하나를 단독으로 제거. 기록에 남지 않는 전투. |
| **제15화** | 이름 없는 폭력 | 에이든이 빈민가를 위협하는 세력을 척결. 아이리스가 '유령'의 **검흔**을 발견 — 자신이 아는 검법의 변형이다. \"이 검법... 내가 가르친 건가?\" 기억은 없지만 **몸이 반응한다.** |
| **제16화** | 추적 | 발타자르의 흔적을 추격. 그가 향한 곳은 — **'시간의 탑.'** |
| **제17화** | 잔향의 강화 | 잔향이 더 선명하게 들린다. 이제 단어가 들린다. **"올라와라."** |
| **제18화** | 탑의 입구 | 에이든의 의식이 인과율의 구조 속으로 빨려 들어간다. 눈앞에 펼쳐지는 것은 건물이 아니라 **인과의 실(絲)들이 수직으로 뻗은 구조** — 이것이 '시간의 탑'. |
| **제19화** | 결의 | "발타자르를 죽인다. 잔향을 멈춘다. 루프를 끊는다." |

---

## 🏗️ 제4막. 탑을 향해 (제20화 ~ 제25화)
*   **목표**: 탑 진입 준비 + 9권 연결.
*   **분위기**: 최종전 직전의 결의, 제3부로의 전환.

| 화수 | 제목 (가제) | 핵심 사건 |
| :--- | :--- | :--- |
| **제20화** | 마지막 동맹 | 아이리스가 에이든을 기억하지 못하지만, **직감으로 동행을 결정.** 폐허 구획을 건널 식량과 약품을 나눠 메는 장면이 붙는다. |
| **제21화** | 뒷골목의 군대 | 빈민가 생존자들이 에이든을 따른다. 기억은 없지만, 그가 남긴 **흔적**은 남아있다. |
| **제22화** | 무장 | 해방자 + 172번의 경험 + 잃을 것 없는 남자. 에이든의 최종 장비. |
| **제23화** | 아이리스의 감 | 아이리스: "당신을 모르겠는데, 왜 이렇게 익숙하죠?" 에이든: "...그냥 그런 얼굴이야." |
| **제24화** | 제2부 종결 | 에이든이 뒤를 돌아본다. 빈민가, 폐허, 잿빛 하늘. 돌아갈 곳은 없다. |
| **제25화** | 탑으로 | 에이든이 시간의 탑에 진입한다. **제2부 종료. 제3부 시작.** 8권 종료. |
