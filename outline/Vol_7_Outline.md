# 📜 제7권 세부 개요: 끝없는 하루 (The Endless Day)

> **범위**: 제1화 ~ 제25화 (완결)
> **핵심 목표**: 무한 루프 진입 + 수천 번의 반복 + 평범한 행복 발견
> **타임 이벤트**: 무한 루프(Infinite Loop) — 영원히 반복되는 하루
> **등가교환**: (이 권에서는 축적 — 8권에서 지불)
> **Arc**: Roadmap Arc 9a (제9권 전반부)

---

## 📽️ 제7권 줄거리 요약 (시놉시스)
**"오늘이 끝나지 않는다."**

적의 함정에 빠진 에이든은 **동일한 하루가 영원히 반복되는 감옥**에 갇힌다.
이것은 172번의 회귀와다르다 — 하루가 끝나면 처음으로 돌아가고, 기억만 남는다.
에이든은 수백 번 탈출을 시도하고, 수백 번 자살한다.
하지만 하루는 끝나지 않는다.
그러다 에이든은 처음으로 **'평범한 하루의 행복'**을 발견한다.
반복 속에서 만난 빵집 주인, 석양, 고양이의 온기.
172번의 회귀에서 한 번도 느끼지 못한 **평범한 감정.**
탈출할 방법은 있다. 하지만 그 대가는 **이 행복 자체.**

---

## 🏗️ 제1막. 반복의 시작 (제1화 ~ 제7화)
*   **목표**: 무한 루프 진입 + 초기 반응.
*   **분위기**: 혼란, 데자뷔, 점점 커지는 공포.

| 화수 | 제목 (가제) | 핵심 사건 |
| :--- | :--- | :--- |
| **제1화** | 평범한 아침 | 에이든이 방에서 눈을 뜬다. **이상하게 평범한 하루.** |
| **제2화** | 데자뷔 | 같은 하루의 반복. 에이든이 미세한 이상을 감지. |
| **제3화** | 루프 | 세 번째 반복. **에이든이 무한 루프에 갇혔음을 확인.** |
| **제4화** | 탈출 시도 #1 | 도시를 벗어나려 함. 경계에서 **하루가 리셋.** |
| **제5화** | 탈출 시도 #14 | 여러 방법 시도. 전부 실패. 리셋. 리셋. 리셋. |
| **제6화** | 발타자르의 메시지 | 루프 안에서 발타자르의 환영이 남긴 단서. "규칙을 찾아라." |
| **제7화** | 규칙 | 루프의 규칙 일부 파악: 특정 시간에 특정 장소에서 특정 행동을 하면 변수가 생긴다. |

---

## 🏗️ 제2막. 수천 번의 죽음 (제8화 ~ 제13화)
*   **목표**: 반복의 지옥 + 정신 붕괴.
*   **분위기**: 절망, 광기, 정신적 피폐 극대화.

| 화수 | 제목 (가제) | 핵심 사건 |
| :--- | :--- | :--- |
| **제8화** | 89번째 아침 | 에이든이 반복 횟수를 세기 시작. 89번째 아침. |
| **제9화** | 자살 #1 | 탈출을 위해 자살. 하지만 **같은 아침에 눈을 뜬다.** |
| **제10화** | 324번째 아침 | 수백 번의 자살. 수백 번의 리셋. 에이든의 정신이 마모된다. |
| **제11화** | 광기의 문턱 | "나는 회귀자다. 반복은 익숙해야 한다. **하지만 이건 다르다.**" |
| **제12화** | 포기 | 에이든이 처음으로 **아무것도 하지 않기로 결정.** 그냥 하루를 보낸다. |
| **제13화** | 빵집 | 아무것도 하지 않은 날. 빵집에 들어가 빵을 사먹는다. **맛있다.** |

---

## 🏗️ 제3막. 평범한 하루 (제14화 ~ 제19화)
*   **목표**: 에이든이 평범한 행복을 발견.
*   **분위기**: 따스함, 소소한 기쁨, 처음으로 웃는 에이든.

| 화수 | 제목 (가제) | 핵심 사건 |
| :--- | :--- | :--- |
| **제14화** | 석양 | 처음으로 석양을 본다. 172번의 회귀에서 한 번도 올려다보지 않은 하늘. |
| **제15화** | 고양이 | 뒷골목의 고양이가 무릎에 올라온다. 에이든이 쓰다듬는다. 따뜻하다. |
| **제16화** | 빵집 주인 | 빵집 주인과 대화. 이름도, 과거도, 미래도 없는 대화. 편하다. |
| **제17화** | 웃음 | **에이든이 처음으로 웃는다.** 작고, 어색하고, 금방 사라지는 웃음. |
| **제18화** | 평범한 하루 | 아침에 일어나, 빵을 사먹고, 고양이를 쓰다듬고, 석양을 본다. **행복하다.** |
| **제19화** | 대가 | 탈출 방법을 찾았다. 하지만 대가는 **이 평범한 행복의 감정.** |

---

## 🏗️ 제4막. 감옥의 열쇠 (제20화 ~ 제25화)
*   **목표**: 탈출 결심 + 대가 지불 준비 + 8권 연결.
*   **분위기**: 결단의 고통, 가장 인간적이었던 순간의 포기.

| 화수 | 제목 (가제) | 핵심 사건 |
| :--- | :--- | :--- |
| **제20화** | 선택 | 탈출하면 행복을 잃는다. 남으면 영원히 행복하지만 세계는 무너진다. |
| **제21화** | 1847번째 아침 | 에이든이 마지막으로 평범한 하루를 보낸다. |
| **제22화** | 빵집에서의 이별 | 빵집 주인에게 인사. "맛있었습니다." 주인: "내일도 오세요." "...네." |
| **제23화** | 고양이에게 | 고양이를 마지막으로 안는다. 울지 못한다. |
| **제24화** | 결심 | "이 감정을 기억하겠다. 잃더라도." 에이든이 탈출을 결심. |
| **제25화** | 끝없는 하루의 끝 | **탈출 준비 완료.** 에이든은 문 앞에 선다. 7권 종료. |
