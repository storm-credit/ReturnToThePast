# 📅 제15권 사건 흐름표: 잿빛 비
**"평범한 10주"**

| 일정 | 화수 | 주요 사건 | 비고 |
| :--- | :--- | :--- | :--- |
| **1주차** | 제1화~제3화 | 대학생 에이든. 평범한 일상. 데자뷔. | 일상 |
| **2주차** | 제4화~제6화 | 빵집 눈물 + 석양 가슴 아픔 + 고양이. | 잔상 |
| **3주차** | 제7화 | 이상한 꿈. 회색 도시, 검, 피. | 꿈 |
| **1개월** | 제8화~제10화 | '아이리스' 이름 + 검도 + '발타자르'. | 잔상 심화 |
| **5주차** | 제11화~제12화 | 빈민가 골목 + 설명 못하는 흉터. | 미스터리 |
| **6주차** | 제13화 | 비. 이유 없는 슬픔. | 비 |
| **7주차** ⭐ | 제14화~제16화 | **비 오는 버스 정류장. 리아 등장.** 침묵. | 만남 |
| **7주차** | 제17화~제18화 | **"비가... 그치질 않네."** + 리아 뒤돌아봄. | ⭐⭐ 핵심 |
| **7주차** | 제19화~제20화 | "처음인데 왜 익숙하죠?" + 카페 대화. | 대화 |
| **8주차** | 제21화~제22화 | 커피 + 희미한 잔상 (회색 도시). | 여운 |
| **9주차** | 제23화 | 대가의 역설: 왜 이 한 마디만 남았는가? | 테마 |
| **10주차** | 제24화 | 비가 그친다. "또 만날 수 있을까요?" | 희망 |
| **10주차** | 제25화 | 에이든이 걸어간다. **입꼬리가 올라간다.** 끝. | 끝 |

---
### ⏱️ 속도감 분석
- **총 소요 시간**: 약 **10주 (2.5개월)**.
- **특징**: 시리즈에서 가장 느린 권. 일상의 속도. 여운과 잔상.
- **개연성**: 평범한 세계. 급할 이유가 없다. 시간이 자연스럽게 흐른다.
