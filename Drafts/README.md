# Drafts — LEGACY QUARANTINE

Status: LEGACY / REFERENCE ONLY / DEFAULT EXCLUDED  
Applies To: `Drafts/` 전체

## 목적

이 디렉터리는 현행 정본 체계 이전에 작성된 옛 원고를 보존하기 위한 격리 구역이다.

파일이 존재한다는 이유만으로 현재 작품의 사건·설정·인물관계·문체·회차 진행 상태를 증명하지 않는다.

## 기본 금지

다음 작업에서는 `Drafts/`를 기본 입력으로 사용하지 않는다.

- 새 원고 집필
- 기존 `manuscript/` 원고 교정·검수
- Context Pack 컴파일
- Canon / Continuity 판정
- 인물·기관·아이템·세계관 사실 검색
- 현재 집필 진도 계산
- 다음 화 결정
- 문체·낭독 기준 추출

자동 검색이나 저장소 전체 검색 결과에 `Drafts/`가 잡혀도 현재 원고의 근거로 채택하지 않는다.

## 예외

작가가 명시적으로 `옛 원고`, `레거시`, `Drafts`, `살베지`를 지정해 참고를 요청한 경우에만 읽을 수 있다.

그 경우에도 자동 승계하지 않는다. 채택하려는 이름·장소·관계·사건·장면은 반드시 `docs/00_project/legacy-salvage-ledger-v1.md` 절차를 거친다.

## 현재 원고 기준

현재 집필·검수 대상 원고는 `manuscript/`만 사용한다.

정확한 현재 회차와 다음 생산 단위는 다음 파일을 따른다.

- `docs/00_project/GATE_STATUS.md`
- `manuscript/PROGRESS.md`

## 삭제 금지

이 디렉터리의 파일은 `docs/00_project/legacy-migration-policy-v1.md`의 HARD LOCK에 따라 보존한다.

삭제 대신 **검색·집필·검수 경로에서 격리**한다.
